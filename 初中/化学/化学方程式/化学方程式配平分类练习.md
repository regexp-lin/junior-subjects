# 化学方程式配平分类练习

## 练习说明

共 25 题，每种方法 5 题。请在每种物质的化学式前填写适当的系数，使反应前后**每种元素的原子个数分别相等**。系数为 1 时可以省略，最终系数应为最简正整数比。

每组推荐的方法只是练习方向，同一道题也可能用其他方法配平。条件和必要的气体、沉淀符号已给出，不需要在空格里填写；注意不要改变化学式中的下标。

方法讲解可参阅同目录下的《初中化学方程式配平方法》。

## 一、观察法

先观察两边原子个数的差异，尝试调整系数；没有变化的原子团有时可以先作为整体考虑。

1. $\underline{\quad}\,Mg + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,MgO$

2. $\underline{\quad}\,Zn + \underline{\quad}\,HCl \rightarrow \underline{\quad}\,ZnCl_2 + \underline{\quad}\,H_2\uparrow$

3. $\underline{\quad}\,NaOH + \underline{\quad}\,H_2SO_4 \rightarrow \underline{\quad}\,Na_2SO_4 + \underline{\quad}\,H_2O$

4. $\underline{\quad}\,CuO + \underline{\quad}\,H_2 \xrightarrow{加热} \underline{\quad}\,Cu + \underline{\quad}\,H_2O$

5. $\underline{\quad}\,Ca(OH)_2 + \underline{\quad}\,HCl \rightarrow \underline{\quad}\,CaCl_2 + \underline{\quad}\,H_2O$

## 二、最小公倍数法

先选择一种在等号两边各只出现于一种物质中的元素，求两边原子个数的最小公倍数，再配平其他元素。

1. $\underline{\quad}\,Al + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,Al_2O_3$

2. $\underline{\quad}\,Fe + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,Fe_3O_4$

3. $\underline{\quad}\,Cu + \underline{\quad}\,O_2 \xrightarrow{加热} \underline{\quad}\,CuO$

4. $\underline{\quad}\,Na_3PO_4 + \underline{\quad}\,CaCl_2 \rightarrow \underline{\quad}\,Ca_3(PO_4)_2\downarrow + \underline{\quad}\,NaCl$

5. $\underline{\quad}\,Al + \underline{\quad}\,CuSO_4 \rightarrow \underline{\quad}\,Al_2(SO_4)_3 + \underline{\quad}\,Cu$

提示：第 4、5 题可以先把反应前后没有变化的原子团分别看作整体。

## 三、奇偶法

先找一种原子个数在两边呈现奇偶差异的元素，调整相关系数，再检查其他元素。

1. $\underline{\quad}\,KClO_3 \xrightarrow{MnO_2、加热} \underline{\quad}\,KCl + \underline{\quad}\,O_2\uparrow$

2. $\underline{\quad}\,H_2O_2 \xrightarrow{MnO_2} \underline{\quad}\,H_2O + \underline{\quad}\,O_2\uparrow$

3. $\underline{\quad}\,H_2O \xrightarrow{通电} \underline{\quad}\,H_2\uparrow + \underline{\quad}\,O_2\uparrow$

4. $\underline{\quad}\,P + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,P_2O_5$

5. $\underline{\quad}\,FeS_2 + \underline{\quad}\,O_2 \xrightarrow{高温} \underline{\quad}\,Fe_2O_3 + \underline{\quad}\,SO_2$（提高题）

提示：第 5 题先观察右边两种生成物中氧原子个数的奇偶性，再配铁和硫。

## 四、设 1 法

先把燃料的系数设为 1，依次配碳、氢、氧。若氧气系数出现分数，最后将所有系数同时乘以适当的整数。

以下均为燃料在氧气中**完全燃烧**。

1. $\underline{\quad}\,CH_4 + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,CO_2 + \underline{\quad}\,H_2O$

2. $\underline{\quad}\,C_3H_8 + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,CO_2 + \underline{\quad}\,H_2O$

3. $\underline{\quad}\,C_2H_2 + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,CO_2 + \underline{\quad}\,H_2O$

4. $\underline{\quad}\,C_2H_6 + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,CO_2 + \underline{\quad}\,H_2O$

5. $\underline{\quad}\,CH_3OH + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,CO_2 + \underline{\quad}\,H_2O$

提示：第 5 题的燃料甲醇本身含有氧，计算氧气系数时要计入。

## 五、待定系数法

为每种物质设一个字母系数，按元素分别列出原子守恒关系，再求出最简正整数比。

1. $\underline{\quad}\,Fe_2O_3 + \underline{\quad}\,CO \xrightarrow{高温} \underline{\quad}\,Fe + \underline{\quad}\,CO_2$

2. $\underline{\quad}\,KMnO_4 \xrightarrow{加热} \underline{\quad}\,K_2MnO_4 + \underline{\quad}\,MnO_2 + \underline{\quad}\,O_2\uparrow$

3. $\underline{\quad}\,FeCl_3 + \underline{\quad}\,Ca(OH)_2 \rightarrow \underline{\quad}\,Fe(OH)_3\downarrow + \underline{\quad}\,CaCl_2$

4. $\underline{\quad}\,C_2H_5OH + \underline{\quad}\,O_2 \xrightarrow{点燃} \underline{\quad}\,CO_2 + \underline{\quad}\,H_2O$（完全燃烧）

5. $\underline{\quad}\,Fe + \underline{\quad}\,H_2O \xrightarrow{高温} \underline{\quad}\,Fe_3O_4 + \underline{\quad}\,H_2$（水以水蒸气形式参与反应）

## 参考答案

先独立完成，再逐题核对。请同时检查系数是否已经化为最简整数比。

### 一、观察法

1. $2Mg + O_2 \xrightarrow{点燃} 2MgO$
2. $Zn + 2HCl \rightarrow ZnCl_2 + H_2\uparrow$
3. $2NaOH + H_2SO_4 \rightarrow Na_2SO_4 + 2H_2O$
4. $CuO + H_2 \xrightarrow{加热} Cu + H_2O$
5. $Ca(OH)_2 + 2HCl \rightarrow CaCl_2 + 2H_2O$

### 二、最小公倍数法

1. $4Al + 3O_2 \xrightarrow{点燃} 2Al_2O_3$
2. $3Fe + 2O_2 \xrightarrow{点燃} Fe_3O_4$
3. $2Cu + O_2 \xrightarrow{加热} 2CuO$
4. $2Na_3PO_4 + 3CaCl_2 \rightarrow Ca_3(PO_4)_2\downarrow + 6NaCl$
5. $2Al + 3CuSO_4 \rightarrow Al_2(SO_4)_3 + 3Cu$

### 三、奇偶法

1. $2KClO_3 \xrightarrow{MnO_2、加热} 2KCl + 3O_2\uparrow$
2. $2H_2O_2 \xrightarrow{MnO_2} 2H_2O + O_2\uparrow$
3. $2H_2O \xrightarrow{通电} 2H_2\uparrow + O_2\uparrow$
4. $4P + 5O_2 \xrightarrow{点燃} 2P_2O_5$
5. $4FeS_2 + 11O_2 \xrightarrow{高温} 2Fe_2O_3 + 8SO_2$

第 5 题的思路：左边氧原子总数是偶数，右边 $SO_2$ 中氧原子总数一定是偶数，因此 $Fe_2O_3$ 中的氧原子总数也应是偶数。可先将 $Fe_2O_3$ 的系数设为 2，再依次配铁、硫和氧。

### 四、设 1 法

1. $CH_4 + 2O_2 \xrightarrow{点燃} CO_2 + 2H_2O$
2. $C_3H_8 + 5O_2 \xrightarrow{点燃} 3CO_2 + 4H_2O$
3. $2C_2H_2 + 5O_2 \xrightarrow{点燃} 4CO_2 + 2H_2O$
4. $2C_2H_6 + 7O_2 \xrightarrow{点燃} 4CO_2 + 6H_2O$
5. $2CH_3OH + 3O_2 \xrightarrow{点燃} 2CO_2 + 4H_2O$

第 5 题的思路：先设 $CH_3OH$ 的系数为 1，配碳、氢后得到 $CH_3OH + O_2 \rightarrow CO_2 + 2H_2O$。右边共有 4 个氧原子，其中 1 个已由甲醇提供，因此氧气的系数暂时为 $\frac{3}{2}$；所有系数同乘 2 即得答案。

### 五、待定系数法

1. $Fe_2O_3 + 3CO \xrightarrow{高温} 2Fe + 3CO_2$
2. $2KMnO_4 \xrightarrow{加热} K_2MnO_4 + MnO_2 + O_2\uparrow$
3. $2FeCl_3 + 3Ca(OH)_2 \rightarrow 2Fe(OH)_3\downarrow + 3CaCl_2$
4. $C_2H_5OH + 3O_2 \xrightarrow{点燃} 2CO_2 + 3H_2O$
5. $3Fe + 4H_2O \xrightarrow{高温} Fe_3O_4 + 4H_2$

第 2 题的思路：设 $aKMnO_4 \rightarrow bK_2MnO_4 + cMnO_2 + dO_2$。根据钾、锰、氧原子守恒，分别有 $a=2b$、$a=b+c$、$4a=4b+2c+2d$；取 $b=1$，得到 $a=2$、$c=1$、$d=1$。
