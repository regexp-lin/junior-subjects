# 初中化学方程式配平方法

## 一、为什么要配平？

化学反应前后，**每一种元素的原子种类和原子总数都不变**。因此，化学方程式等号两边每种元素的原子个数必须相等，这就是配平的依据。

例如，氢气燃烧可以写成：

$$2H_2 + O_2 \xrightarrow{点燃} 2H_2O$$

左边氢原子有 $2\times2=4$ 个、氧原子有 2 个；右边氢原子有 $2\times2=4$ 个、氧原子有 $2\times1=2$ 个。每种原子都守恒。

**配平只能改变化学式前面的系数，不能改变化学式中元素符号右下角的数字。**例如，$2H_2O$ 表示 2 个水分子；把 $H_2O$ 改成 $H_2O_2$ 则变成了另一种物质，不能用于配平水。

## 二、五种常用方法

### 1. 观察法

**适用：**方程式比较简单，系数容易直接看出来。

**思路：**先找两边原子个数不相等的元素，尝试在化学式前填系数，再逐一调整其他元素。

**例：氢气和氧气反应生成水。**

1. 先写出正确的反应物和生成物：$H_2 + O_2 \rightarrow H_2O$。
2. 左边氧原子有 2 个，右边只有 1 个，先在水前面写 2：$H_2 + O_2 \rightarrow 2H_2O$。
3. 右边现在有 4 个氢原子，在氢气前面写 2。
4. 检查后写上反应条件：

$$2H_2 + O_2 \xrightarrow{点燃} 2H_2O$$

**小技巧：**如果某个原子团反应前后没有改变，可以先把它看成一个整体。例如：

$$2NaOH + H_2SO_4 \rightarrow Na_2SO_4 + 2H_2O$$

左右两边各有一个 $SO_4$，再根据右边的 2 个钠原子，确定 $NaOH$ 前的系数为 2，最后配平水。配完后仍要逐种元素检查。

### 2. 最小公倍数法

**适用：**某种元素在等号两边各出现在一种物质中，而且原子个数不同。

**思路：**先求这种元素在两边原子个数的最小公倍数，再确定对应物质的系数。

**例：磷在氧气中燃烧。**

1. 写出未配平的式子：$P + O_2 \rightarrow P_2O_5$。
2. 氧在左边每个 $O_2$ 中有 2 个，在右边每个 $P_2O_5$ 中有 5 个；2 和 5 的最小公倍数是 10。
3. 要使两边各有 10 个氧原子，在 $O_2$ 前写 5，在 $P_2O_5$ 前写 2。
4. 右边有 $2\times2=4$ 个磷原子，在 $P$ 前写 4：

$$4P + 5O_2 \xrightarrow{点燃} 2P_2O_5$$

**注意：**选中的元素最好在左右两边都只出现于一种物质中；如果一侧有多种物质都含有该元素，就不能直接只对其中一项套用。

### 3. 奇偶法

**适用：**某元素在一边以偶数个原子出现，在另一边以奇数个原子出现，且容易通过调整系数使个数一致。

**思路：**先处理奇偶不一致的元素，再调整其他元素。它常与最小公倍数法、观察法结合使用。

**例：加热氯酸钾制氧气。**

1. 写出未配平的式子：$KClO_3 \rightarrow KCl + O_2$。
2. 左边每个 $KClO_3$ 有 3 个氧原子，右边每个 $O_2$ 有 2 个氧原子。为使左边氧原子数变为偶数，在 $KClO_3$ 前写 2。
3. 左边现在有 6 个氧原子，故 $O_2$ 前写 3；左边钾、氯原子各有 2 个，故 $KCl$ 前写 2：

$$2KClO_3 \xrightarrow{MnO_2、加热} 2KCl + 3O_2\uparrow$$

这里二氧化锰是催化剂，加热是反应条件。奇偶法并非所有题目都适用；调整后仍要检查全部元素。

### 4. 设 1 法（可用分数作中间步骤）

**适用：**某种物质组成较复杂，但先确定它的系数后，其他系数容易依次推出；常用于燃烧反应。

**思路：**先把选中物质的系数设为 1，依次配平其他元素。如果出现分数，最后将所有系数同时乘以适当的整数，化为最简整数比。

**例：乙炔在氧气中完全燃烧。**

1. 写出未配平的式子：$C_2H_2 + O_2 \rightarrow CO_2 + H_2O$，先设 $C_2H_2$ 的系数为 1。
2. 根据碳原子守恒，在 $CO_2$ 前写 2；根据氢原子守恒，水的系数为 1：

   $$C_2H_2 + O_2 \rightarrow 2CO_2 + H_2O$$

3. 右边共有 $2\times2+1=5$ 个氧原子，因此氧气的系数暂时为 $\frac{5}{2}$。
4. 将所有系数同时乘以 2，得到最简整数比：

$$2C_2H_2 + 5O_2 \xrightarrow{点燃} 4CO_2 + 2H_2O$$

分数只用于推算过程；初中书写化学方程式时，最终系数通常写成最简正整数比。

### 5. 待定系数法

**适用：**直接观察不容易确定系数，或希望用列式的方法检查结果。

**思路：**用字母表示各物质的系数，分别根据每种元素的原子守恒列等式，再求出最简正整数比。

**例：乙醇在氧气中完全燃烧。**

设系数为 $a、b、c、d$：

$$aC_2H_5OH + bO_2 \rightarrow cCO_2 + dH_2O$$

根据原子守恒：

| 元素 | 守恒关系 | 说明 |
| --- | --- | --- |
| 碳 | $2a=c$ | 每个乙醇分子含 2 个碳原子 |
| 氢 | $6a=2d$ | 每个乙醇分子共含 6 个氢原子 |
| 氧 | $a+2b=2c+d$ | 乙醇中也含有氧，不能漏算 |

取 $a=1$，得到 $c=2$、$d=3$；代入氧的等式得 $1+2b=4+3$，所以 $b=3$。最终：

$$C_2H_5OH + 3O_2 \xrightarrow{点燃} 2CO_2 + 3H_2O$$

取 $a=1$ 只是为了求系数之比；若算出分数，需要再将所有系数同时乘以适当整数。

## 三、做题时怎么选？

| 看到的特点 | 可以先试 |
| --- | --- |
| 方程式简单，系数容易看出 | 观察法 |
| 某元素在两边各只出现于一种物质中，原子数不同 | 最小公倍数法 |
| 某元素一边为奇数、一边为偶数 | 奇偶法 |
| 组成复杂的物质先设为 1 后容易依次确定其他系数 | 设 1 法 |
| 观察较困难，需要按原子守恒列式 | 待定系数法 |

这些方法可以组合使用；同一道题往往有不止一种解法。对于常见的含碳、氢物质的完全燃烧，可先配碳、再配氢、最后配氧，注意燃料中可能已经含氧。

## 四、检查清单与常见错误

1. **先写对化学式。**配平不能修正错误的反应物或生成物，也不能凭配平结果证明反应一定能发生。
2. **只改前面的系数。**不要改化学式中的下标，也不要漏掉括号对原子个数的影响。
3. **系数乘整个化学式。**例如 $3Ca(OH)_2$ 中有 3 个钙原子、6 个氧原子和 6 个氢原子。
4. **每种元素都要检查。**不能只看一种元素或只看等号两边的原子总数。
5. **系数化为最简正整数比。**如 $4H_2+2O_2\rightarrow4H_2O$ 虽然守恒，但应全部除以 2；系数为 1 时省略。
6. **完整书写方程式。**按题目和教材要求标注点燃、加热、催化剂等条件，以及必要的气体 $\uparrow$、沉淀 $\downarrow$ 符号。这些符号不能代替配平；是否标注还要看反应物和生成物的状态。

## 五、练一练

先独立配平，写出最简整数系数，并按题目要求补充条件和必要的气体、沉淀符号。

1. $Mg + O_2 \rightarrow MgO$
2. $Al + O_2 \rightarrow Al_2O_3$
3. $Fe + O_2 \rightarrow Fe_3O_4$
4. $H_2O_2 \rightarrow H_2O + O_2$（二氧化锰作催化剂）
5. $Fe + HCl \rightarrow FeCl_2 + H_2$
6. $NaOH + H_2SO_4 \rightarrow Na_2SO_4 + H_2O$
7. $Fe_2O_3 + CO \rightarrow Fe + CO_2$（高温）
8. $CH_4 + O_2 \rightarrow CO_2 + H_2O$（完全燃烧）
9. $C_2H_5OH + O_2 \rightarrow CO_2 + H_2O$（完全燃烧）
10. $FeS_2 + O_2 \rightarrow Fe_2O_3 + SO_2$（高温）

### 参考答案

1. $2Mg + O_2 \xrightarrow{点燃} 2MgO$
2. $4Al + 3O_2 \xrightarrow{点燃} 2Al_2O_3$
3. $3Fe + 2O_2 \xrightarrow{点燃} Fe_3O_4$
4. $2H_2O_2 \xrightarrow{MnO_2} 2H_2O + O_2\uparrow$
5. $Fe + 2HCl \rightarrow FeCl_2 + H_2\uparrow$
6. $2NaOH + H_2SO_4 \rightarrow Na_2SO_4 + 2H_2O$
7. $Fe_2O_3 + 3CO \xrightarrow{高温} 2Fe + 3CO_2$
8. $CH_4 + 2O_2 \xrightarrow{点燃} CO_2 + 2H_2O$
9. $C_2H_5OH + 3O_2 \xrightarrow{点燃} 2CO_2 + 3H_2O$
10. $4FeS_2 + 11O_2 \xrightarrow{高温} 2Fe_2O_3 + 8SO_2$

第 10 题可先将 $Fe_2O_3$ 的系数设为 2，使右边有 4 个铁原子，得出 $FeS_2$ 的系数为 4；再由硫原子守恒得到 $SO_2$ 的系数为 8，最后由氧原子守恒得到 $O_2$ 的系数为 11。
