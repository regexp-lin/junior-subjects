# 《醉翁亭记》知识点与中考考点详解

> 适用对象：初中九年级上册  
> 资料定位：课内精讲 + 中考一轮复习  
> 说明：本文以统编教材常见注释和课内重点为依据。文言基础、翻译、默写、内容赏析与比较阅读均是高频考查方向；更细的逐句讲解可配合阅读[课文详解](课文详解.md)。

## 一、文学常识与写作背景

| 项目 | 内容 |
|---|---|
| 作者 | 欧阳修（1007—1072），字永叔，号醉翁，晚号六一居士，北宋政治家、文学家；“唐宋八大家”之一。 |
| 篇名 | 《醉翁亭记》，“记”是古代一种散文体裁，可记事、写景、状物，也可抒情、议论。 |
| 写作时间 | 北宋庆历六年（1046）前后。 |
| 写作缘由 | 欧阳修因支持庆历新政而被贬，任滁州太守期间常游琅琊山、醉翁亭，写下此文。 |
| 核心内容 | 写醉翁亭周围秀美山水和太守与滁人游宴的场面。 |
| 主旨关键词 | 山水之乐、百姓安乐、与民同乐、旷达亲民。 |

> **易错提醒：** 被贬并不等于消沉。文中确有寄情山水、排遣失意的一面，但落脚点是太守以百姓的快乐为快乐的政治情怀。

## 二、逐段解释、译文与作用

### 第一段：交代亭的环境、得名和“醉翁之意”

**段意：** 作者由远到近写醉翁亭的位置，交代建亭者、命名者和“醉翁”自号，点出全文的总线索——“乐”。

**译文：** 环绕着滁州城的都是山。它西南方向的许多山峰中，树林和山谷尤其优美；远望树木茂盛、幽深秀丽的，是琅琊山。沿山路走六七里，渐渐听到潺潺水声；从两座山峰之间飞泻而出的，是酿泉。山势回环、道路转弯的地方，有一座像鸟张开翅膀一样、居高临下临着泉水的亭子，是醉翁亭。建亭的是山中的僧人智仙；给亭子命名的是太守用自己的别号。太守和宾客到这里饮酒，喝一点儿就醉，加上年纪最大，所以自号“醉翁”。醉翁的意趣不在酒，而在山水之间；欣赏山水的乐趣，领会在心中，寄托在饮酒中。

**理解要点：**

- 写景顺序是“环滁 → 西南诸峰 → 琅琊山 → 酿泉 → 醉翁亭”，视野由远及近，按游踪层层推进。
- “峰回路转”“翼然”既写山路曲折、亭子轻盈，又自然引出醉翁亭。
- “醉翁之意不在酒”中的“意”是**意趣、情趣**；酒只是寄托山水之乐的媒介。
- “作亭者谁？……名之者谁？”连续设问、自答，交代相关人物，使行文活泼有波折。

### 第二段：写朝暮、四时之景及山水之乐

**段意：** 写山间朝暮晦明和春夏秋冬的不同景象，表现山水之乐无穷。

**译文：** 像那太阳出来，林间雾气消散；云雾聚拢，山谷昏暗下来，明暗交替变化的，是山间早晨和傍晚的景象。野花开放，散发清幽香气；美好的树木枝叶繁茂，形成浓密绿阴；秋风高爽，霜色洁白；冬天水位下降，石头显露出来，这些是山中四季的景色。早晨前往，傍晚归来，四季景色各不相同，乐趣也无穷无尽。

**理解要点：**

- 朝暮以“日出而林霏开”与“云归而岩穴暝”相对，突出“晦明变化”。
- 四时按**春、夏、秋、冬**的顺序写：野芳、佳木、风霜、水石；每季只抓一个最鲜明特征，笔法简练。
- “水落石出”在文中写冬景本义，不可直接解释成“真相大白”。
- 本段以“景不同”写出“乐无穷”，景物变化正是太守乐游山水的原因。

### 第三段：写滁人游、太守宴、众宾欢和太守醉

**段意：** 由自然景观转入社会生活，写百姓安闲、宾主尽欢的游宴图，为表现“与民同乐”蓄势。

**译文：** 至于背着东西的人在路上唱歌，赶路的人在树下休息，前面的人呼喊，后面的人应答；老人弯着腰走，小孩子由大人领着，来来往往不断的，是滁州人出游。到溪边捕鱼，溪水深，鱼儿肥；用酿泉水酿酒，泉水香，酒也清；山中野味和野菜杂乱地摆在面前的，是太守的宴席。宴饮尽兴的乐趣，不在音乐；投壶的人投中，下棋的人取胜，酒杯和酒筹交互错杂，时而站起、时而坐下而大声喧哗的，是宾客们欢乐的样子。容颜苍老、头发花白，醉醺醺地坐在众人中间的，是太守喝醉了。

**理解要点：**

- 场面依次为“滁人游 → 太守宴 → 众宾欢 → 太守醉”，层次清晰。
- “伛偻提携”分别借指老人和儿童；“射”是宴饮时的**投壶**，不是射箭；“丝竹”代指音乐。
- 宴席有溪鱼、泉酒、山肴、野蔌，取材本地而不求奢华，体现山野情趣和太守的亲民。
- 滁人扶老携幼、往来不绝，侧面表现政通人和、百姓生活安适。

### 第四段：点明禽鸟之乐、人之乐和太守之乐

**段意：** 写游宴结束后的山林，借“禽鸟—游人—太守”三层“乐”的比较，揭示“与民同乐”的主旨。

**译文：** 不久，夕阳挂在山上，人影散乱，太守回去，宾客跟随。树林枝叶茂密成阴，鸟鸣声在树林上上下下回荡；游人离开后，禽鸟快乐起来。然而禽鸟只知道山林的乐趣，却不知道人们游玩的乐趣；人们只知道跟从太守游玩而快乐，却不知道太守以他们的快乐为快乐。醉了能同大家一起快乐，醒来能用文章记述这件乐事的人，是太守。太守是谁？是庐陵人欧阳修。

**理解要点：**

- “夕阳在山”照应上文“暮而归”，使时间推进，游宴自然收束。
- “鸣声上下”指鸟鸣在树林高低处回荡；游人散去后鸟声更清晰，动中有静。
- “禽鸟之乐”是自然之乐，“人之乐”是游宴之乐，“太守之乐”是以百姓之乐为乐，内涵逐层加深。
- “醉能同其乐，醒能述以文者”照应“醉翁之意”和“太守自谓”，首尾圆合。

## 四、重点句翻译与翻译方法

| 原句 | 关键词 | 参考译文 |
|---|---|---|
| 醉翁之意不在酒，在乎山水之间也。 | 意：意趣；在乎：在于 | 醉翁的意趣不在酒上，而在山水之间。 |
| 山水之乐，得之心而寓之酒也。 | 得：领会；寓：寄托 | 欣赏山水的乐趣，领会在心中，寄托在饮酒中。 |
| 日出而林霏开，云归而岩穴暝。 | 开：消散；归：聚拢；暝：昏暗 | 太阳出来，林间雾气消散；云雾聚拢，山谷昏暗下来。 |
| 野芳发而幽香，佳木秀而繁阴。 | 芳：花；发：开放；秀：茂盛 | 野花开放，散发清幽香气；好树枝叶繁茂，形成浓密绿阴。 |
| 负者歌于途，行者休于树。 | 负：背；于：在 | 背着东西的人在路上唱歌，赶路的人在树下休息。 |
| 山肴野蔌，杂然而前陈者，太守宴也。 | 蔌：菜蔬；陈：陈列 | 山中野味和野菜杂乱地摆在面前的，是太守的宴席。 |
| 苍颜白发，颓然乎其间者，太守醉也。 | 苍颜：苍老容颜；颓然：醉醺醺 | 容颜苍老、头发花白，醉醺醺地坐在众人中间的，是太守喝醉了。 |
| 人知从太守游而乐，而不知太守之乐其乐也。 | 从：跟随；乐其乐：以他们的快乐为乐 | 人们知道跟随太守游玩而快乐，却不知道太守以他们的快乐为快乐。 |

**翻译四步法：**

1. 先圈出实词、古今异义、活用词，如“意、发、秀、射、乐”。
2. 补全省略的主语或宾语，如“醒能述以文”后补“游乐之事”。
3. 调整后置语序，如“歌于途”译为“在路上唱歌”。
4. 译出虚词关系，最后让全句符合现代汉语语序，不能只逐字硬译。

## 五、内容结构、主旨与写法

### （一）结构和两条线索

| 段落 | 内容 | 作用 |
|---|---|---|
| 第1段 | 亭的环境、得名与醉翁之意 | 点出山水之乐，定下“乐”的线索。 |
| 第2段 | 朝暮、四时山景 | 展示山水之乐的丰富无穷。 |
| 第3段 | 滁人游、太守宴、众宾欢、太守醉 | 展示百姓安乐和游宴之乐。 |
| 第4段 | 游宴结束与三层“乐” | 点明太守与民同乐，收束全文。 |

- **游踪线索：** 环滁皆山 → 琅琊山 → 酿泉 → 醉翁亭 → 朝暮四时 → 滁人游宴 → 夕阳归去。
- **情感线索：** 山水之乐 → 朝暮四时之乐 → 滁人和宾客之乐 → 太守与民同乐。

### （二）中心思想

文章描写醉翁亭周围的优美山水和太守与滁州百姓游山宴饮的场面，表现了欧阳修寄情山水、旷达自适的情怀，更表现了他以百姓安乐为乐、与民同乐的政治理想。

### （三）写法赏析

| 手法 | 原文依据 | 表达效果 |
|---|---|---|
| 移步换景、由远及近 | 环滁—琅琊—酿泉—醉翁亭 | 空间层次分明，读者如随作者山行。 |
| 抓特征写景 | 野芳、佳木、风霜、水石 | 用最典型景物概括四季，画面鲜明。 |
| 对偶、短句 | 前者呼，后者应；射者中，弈者胜 | 句式整齐，节奏明快，写出游宴的热闹。 |
| 动静结合 | 日出云归、鸟鸣山林 | 使山林景物富有变化和生机。 |
| 设问、自答 | 作亭者谁？名之者谁？太守谓谁？ | 推进内容，行文活泼，首尾照应。 |
| 层层比较 | 禽鸟之乐—人之乐—太守之乐 | 由自然之乐推进到与民同乐，深化主旨。 |

## 七、中考高频考点与答题提示

| 高频考点 | 常见问法 | 作答关键 |
|---|---|---|
| 实词、古今异义 | “意、秀、去、颓然”的意思是什么？ | 回到句中，不用现代常用义替代。 |
| 一词多义、活用 | “乐、归、临”的不同意思；“名、渔、乐”的用法 | 写明具体义项和语境；意动要译成“以……为……”。 |
| 句子翻译 | 翻译写景句、主旨句 | 关键词落实、补省略、调语序、译虚词。 |
| 理解性默写 | 根据季节、游宴、主旨填句 | 先抓题干提示词，再注意“霏、暝、伛偻、觥筹、阴翳”等字形。 |
| 景情关系 | 四时之景有何特点？写景有何作用？ | 写出景物特点，再落到山水之乐和作者感情。 |
| 炼字赏析 | “翼然”“泻”“秀”等好在哪里？ | 词义 + 手法 + 画面特点 + 情感/效果。 |
| 人物形象 | 太守、滁人各有什么特点？ | 用“观点 + 原文依据”作答：太守旷达亲民、与民同乐；滁人安闲和乐。 |
| 主旨探究 | 如何理解“太守之乐其乐”？ | 不能说太守只图饮酒；要指出以百姓快乐为快乐。 |
| 比较阅读 | 与《岳阳楼记》的“乐”有何异同？ | 相同：关心百姓、胸怀社会；不同：欧阳修重共享欢乐，范仲淹重先忧后乐的担当。 |

**建议复习顺序：** 先熟读、默写全文；再归纳实词和句式；随后练重点句翻译；最后围绕“景—人—乐”的结构练赏析、主旨和比较阅读。
