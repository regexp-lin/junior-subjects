## 二、原文与逐句翻译

### 第一层：鲲鹏变化

> 北冥有鱼，其名为鲲。鲲之大，不知其几千里也；化而为鸟，其名为鹏。鹏之背，不知其几千里也；怒而飞，其翼若垂天之云。

**译文：** 北方的大海里有一条鱼，它的名字叫鲲。鲲的体积巨大，不知道有几千里；变化成为鸟，它的名字叫鹏。鹏的脊背，不知道有几千里；当它奋起而飞的时候，展开的翅膀就像悬挂在天空的云。

**讲解：**
- “鲲”“鹏”都是庄子想象中的巨大形象，体现文章开篇的奇幻想象。
- “不知其几千里也”反复出现，运用夸张，突出鲲鹏之大。
- “怒而飞”中的“怒”不是“生气”，而是“振奋、奋起”，指用力鼓动翅膀。
- “其翼若垂天之云”用比喻写鹏翼巨大，画面感强。

### 第二层：大鹏迁徙

> 是鸟也，海运则将徙于南冥。南冥者，天池也。

**译文：** 这只鸟，海水运动时就要迁徙到南方的大海。南方的大海，是天然形成的大池子。

**讲解：**
- “是鸟也”中的“是”是代词，意思是“这”，不是判断词“是”。
- “徙于南冥”即“向南海迁徙”，“于”表到、向。
- “南冥者，天池也”是判断句，“……者，……也”表判断。

### 第三层：引用《齐谐》证明大鹏南飞

> 《齐谐》者，志怪者也。《谐》之言曰：“鹏之徙于南冥也，水击三千里，抟扶摇而上者九万里，去以六月息者也。”

**译文：** 《齐谐》这本书，是记载怪异事物的书。《齐谐》上的话说：“鹏迁徙到南方的大海时，翅膀拍打水面，激起三千里的波涛，乘着旋风盘旋飞到九万里的高空，凭借六月的大风离开北海。”

**讲解：**
- “志怪”中的“志”是“记载”；“怪”指怪异的事物。
- “水击三千里”“抟扶摇而上者九万里”都是夸张，突出大鹏起飞气势雄伟。
- “抟”读 **tuán**，意思是盘旋飞翔。
- “扶摇”指旋风。
- “去以六月息”可理解为“凭借六月的大风离开”，“以”是凭借，“息”指风。
- 引用《齐谐》的作用：增强故事的神秘感和可信度，也借“志怪”色彩表现庄子想象的奇崛。

### 第四层：由大鹏俯视引出哲理思考

> 野马也，尘埃也，生物之以息相吹也。天之苍苍，其正色邪？其远而无所至极邪？其视下也，亦若是则已矣。

**译文：** 山野中的雾气，空气中的尘埃，都是生物用气息相互吹拂的结果。天空苍茫，难道这是它真正的颜色吗？还是因为天空高远而看不到尽头呢？大鹏从天空向下看，也不过像人在地面上看天一样罢了。

**讲解：**
- “野马”不是野生的马，而是山野中浮动的雾气。
- “生物之以息相吹也”说明微小事物也依赖气息、风力而动。
- “其正色邪？其远而无所至极邪？”用设问引发思考：人的视角有限，所见未必是真相。
- “其视下也，亦若是则已矣”说明大鹏看地面，也像人看天空一样模糊。这体现庄子对认识局限的思考。

## 六、重点句翻译与赏析

### 1. 北冥有鱼，其名为鲲。

**翻译：** 北方的大海里有一条鱼，它的名字叫鲲。  
**考点：** “冥”同“溟”，海；“其”代词，它的；“为”译为“叫作”。

### 2. 鲲之大，不知其几千里也；化而为鸟，其名为鹏。

**翻译：** 鲲的体积巨大，不知道有几千里；变化成为鸟，它的名字叫鹏。  
**考点：** “之”结构助词，“的”；“而”表承接；“为”译为“成为”。

### 3. 怒而飞，其翼若垂天之云。

**翻译：** 当它奋起而飞的时候，展开的翅膀就像悬挂在天空的云。  
**考点：** “怒”是“振奋、用力鼓动翅膀”；“若”是“像”；句中有比喻。

### 4. 是鸟也，海运则将徙于南冥。

**翻译：** 这只鸟，海水运动时就要迁徙到南方的大海。  
**考点：** “是”是“这”；“徙”是“迁徙”；“于”表到、向。

### 5. 《齐谐》者，志怪者也。

**翻译：** 《齐谐》这本书，是记载怪异事物的书。  
**考点：** 判断句；“志”是“记载”；“怪”是怪异的事物。

### 6. 鹏之徙于南冥也，水击三千里，抟扶摇而上者九万里，去以六月息者也。

**翻译：** 鹏迁徙到南方的大海时，翅膀拍打水面，激起三千里的波涛，乘着旋风盘旋飞到九万里的高空，凭借六月的大风离开北海。  
**考点：** “之”用于主谓之间，不译；“抟”是盘旋飞翔；“扶摇”是旋风；“以”是凭借；“息”指风。

### 7. 野马也，尘埃也，生物之以息相吹也。

**翻译：** 山野中的雾气，空气中的尘埃，都是生物用气息相互吹拂的结果。  
**考点：** “野马”是古今异义；“以”是“用”；“息”是“气息”。

### 8. 天之苍苍，其正色邪？其远而无所至极邪？

**翻译：** 天空苍茫，难道这是它真正的颜色吗？还是因为天空高远而看不到尽头呢？  
**考点：** “其……邪？其……邪？”表选择或推测；“极”是尽头。

### 9. 其视下也，亦若是则已矣。

**翻译：** 大鹏从天空向下看，也不过像人在地面上看天一样罢了。  
**考点：** 第一个“其”代大鹏；“若是”是“像这样”；“已矣”是“罢了”。

## 七、内容理解

### （一）鲲鹏形象

| 角度 | 表现 | 原文依据 |
|------|------|----------|
| 体形巨大 | 不知几千里 | 鲲之大 / 鹏之背 |
| 变化神奇 | 鱼化为鸟 | 化而为鸟 |
| 飞翔壮阔 | 翼如云，水击三千，扶摇九万 | 其翼若垂天之云 / 水击三千里 / 抟扶摇而上者九万里 |
| 迁徙高远 | 从北冥到南冥 | 将徙于南冥 |

### （二）文章主旨

本文通过奇特的想象和夸张的笔法，描绘鲲鹏变化、展翅南飞的壮阔景象，表现庄子追求精神自由、突破狭小经验世界的思想；同时通过“大鹏借海运、扶摇、六月息而飞”和“野马尘埃也依气息而动”，暗示世间万物都需要凭借一定条件，即“有所待”。

### （三）为什么写“野马”“尘埃”？

1. 与巨大无比的鲲鹏形成对照：一个极大，一个极小。
2. 说明无论大鹏还是微尘，都要凭借气息、风力而动。
3. 引出哲理：万物都有依凭，人的认识也受视角限制。

### （四）“天之苍苍，其正色邪？其远而无所至极邪？”有什么作用？

1. 运用设问，引发读者思考。
2. 表明人对天空颜色的认识可能受距离限制。
3. 为下文“大鹏向下看也一样”作铺垫。
4. 体现庄子善于从自然现象中引出哲理。

### （五）“其视下也，亦若是则已矣”怎样理解？

大鹏从高空往下看地面，也像人从地面往上看天空一样模糊。庄子借此说明：不同位置、不同视角会造成不同认识，人类所见未必就是事物本相。因此，学习本文不能只停留在“鹏很大、飞很高”，还要理解其中“认识有限、万物有待”的哲理。

## 十、中考高频考点总结

### 考点一：重点实词解释

高频词：冥、鲲、鹏、怒、垂天、是、海运、徙、天池、志、怪、水击、抟、扶摇、去、以、息、野马、苍苍、正色、极、若是、已矣。

### 考点二：通假字与古今异义

- 通假字：冥同“溟”；邪同“耶”。
- 古今异义：怒、是、去、息、野马、志、正色。
- 易错点：“怒”不要解释为“愤怒”；“野马”不要解释为“野生的马”；“去”不要解释为“前往”。

### 考点三：一词多义和虚词用法

重点关注：
1. “之”：结构助词“的”；用于主谓之间取消独立性。
2. “其”：代词；也可表选择、推测。
3. “为”：叫作；成为。
4. “以”：凭借；用。
5. “而”：表承接或修饰。

### 考点四：句子翻译

高频翻译句：
1. 怒而飞，其翼若垂天之云。
2. 是鸟也，海运则将徙于南冥。
3. 《齐谐》者，志怪者也。
4. 水击三千里，抟扶摇而上者九万里，去以六月息者也。
5. 野马也，尘埃也，生物之以息相吹也。
6. 天之苍苍，其正色邪？其远而无所至极邪？
7. 其视下也，亦若是则已矣。

### 考点五：内容理解

常考问题：
1. 鲲鹏形象有什么特点？
2. 作者为什么反复写“不知其几千里也”？
3. 引用《齐谐》有什么作用？
4. “水击三千里，抟扶摇而上者九万里”表现了怎样的画面？
5. 为什么写“野马”“尘埃”？
6. 文章表达了怎样的思想？

### 考点六：写法赏析

常考手法：
- 夸张：写鲲鹏体形和飞翔高度。
- 比喻：鹏翼像悬挂在天空的云。
- 引用：引用《齐谐》。
- 对比：鲲鹏与野马尘埃。
- 设问：追问天空本色。
- 寓言说理：用奇特故事表达哲理。

### 考点七：比较阅读

常与以下篇目比较：

| 篇目 | 比较角度 |
|------|----------|
| 《庄子与惠子游于濠梁之上》 | 庄子的语言智慧、自由精神、万物观 |
| 《虽有嘉肴》 | 课内短文说理方式：寓理于事、由现象到道理 |
| 《大道之行也》 | 理想世界与精神追求 |
| 《马说》 | 借物寓意、托物说理 |
| 《小石潭记》 | 景物描写与情感表达；课内文言词义迁移 |
| 《逍遥游》其他节选 | 大小之辨、有所待与无所待 |

### 考点八：开放探究

可能设问：
1. “鲲鹏”形象对今天的青少年有什么启示？
2. 你如何理解庄子笔下的“自由”？
3. 大鹏飞到九万里高空仍要凭借风，这给你什么启发？
4. 结合现实谈谈“人的认识受视角限制”。

答题建议：
- 先回到文本：鲲鹏巨大、奋飞、借风而上。
- 再提炼观点：志向远大、主动蓄力、善借条件、突破局限。
- 最后联系现实：学习成长也需要目标、积累和方法。

## 十二、答题模板

### 1. 赏析夸张句

**模板：** 这句话运用了夸张的手法，通过“______”写出______，表现了______，使文章具有______的艺术效果。

**示例：** “水击三千里，抟扶摇而上者九万里”运用夸张，通过“三千里”“九万里”写出大鹏起飞时水浪浩大、飞升极高，表现了大鹏气势磅礴，使文章具有雄奇壮阔的艺术效果。

### 2. 分析引用作用

**模板：** 引用“______”，一方面写出______，另一方面增强了______，同时为表达______服务。

**示例：** 引用《齐谐》之言，一方面具体描绘大鹏南飞的壮阔景象，另一方面增强神秘感和可信度，同时为表达万物有所凭借的哲理服务。

### 3. 概括鲲鹏形象

**模板：** 鲲鹏具有______、______、______的特点。从“______”可见其______；从“______”可见其______。

**示例：** 鲲鹏具有体形巨大、变化神奇、气势雄伟的特点。从“不知其几千里也”可见其巨大；从“化而为鸟”可见其神奇变化；从“抟扶摇而上者九万里”可见其飞翔气势雄伟。

### 4. 开放题答法

**模板：** 我认为______。文中“______”写出______，这启示我们______。联系现实，______。

**示例：** 我认为大鹏南飞启示我们要有远大目标，也要善于借助条件。文中“抟扶摇而上者九万里，去以六月息者也”写出大鹏凭借大风高飞，这启示我们成长既需要志向，也需要积累能力、把握时机。联系现实，学习中也要借助好方法和好资源，持续努力。
