# 《岳阳楼记》知识点与中考考点详解

> 适用对象：初中九年级上册  
> 资料定位：课内精讲 + 中考一轮复习  
> 说明：本资料以统编教材课文为依据，突出文言实词、句式翻译、理解性默写和内容赏析等高频考点。

---

## 一、文学常识

| 项目 | 内容 |
|---|---|
| 篇名 | 《岳阳楼记》 |
| 作者 | 范仲淹（989—1052），字希文，谥号文正，北宋政治家、文学家、军事家 | 
| 代表作 | 《岳阳楼记》《渔家傲·秋思》《苏幕遮·怀旧》等 |
| 体裁 | “记”，一种以记叙、描写为主，可兼有议论、抒情的散文体裁 |
| 写作缘由 | 庆历六年（1046），滕子京重修岳阳楼，请范仲淹写记；范仲淹当时在邓州任职，写成此文 |
| 写作背景 | 范仲淹因支持改革、整顿吏治而被贬邓州。文章借洞庭景色和迁客骚人的悲喜，表达忧国忧民、先人后己的政治抱负 |
| 核心名句 | “先天下之忧而忧，后天下之乐而乐” |

> **易错点：** “记”不是单纯记事。本文叙事简明，写景壮阔，议论深刻，三者融为一体。

## 二、原文与逐段翻译

### 第一段：交代重修岳阳楼和作记缘由

> 庆历四年春，滕子京谪守巴陵郡。越明年，政通人和，百废具兴。乃重修岳阳楼，增其旧制，刻唐贤今人诗赋于其上。属予作文以记之。

**译文：** 庆历四年春天，滕子京被贬官，担任巴陵郡的太守。到了第二年，政事顺利，百姓和乐，各种被废置的事业全都兴办起来。于是重新修建岳阳楼，扩大它原有的规模，把唐代贤士和当代人的诗文刻在楼上。（他）嘱托我写一篇文章来记述这件事。

**段意：** 交代滕子京被贬后的政绩、重修岳阳楼之事及作者作记缘由。

### 第二段：总写洞庭湖的大观，引出“览物之情”

> 予观夫巴陵胜状，在洞庭一湖。衔远山，吞长江，浩浩汤汤，横无际涯；朝晖夕阴，气象万千。此则岳阳楼之大观也，前人之述备矣。然则北通巫峡，南极潇湘，迁客骚人，多会于此，览物之情，得无异乎？

**译文：** 我看那巴陵郡的美好景色，全在洞庭湖上。（洞庭湖）连接着远方的群山，吞吐着奔流的长江，水势浩大无边；早晨日光明媚，傍晚天色阴暗，景象变化万千。这就是岳阳楼雄伟壮丽的景象，前人的记述已经很详尽了。既然这样，那么这里北面通向巫峡，南面直到潇水、湘水一带，被贬的官员和失意的诗人，大多在这里聚会，他们观赏景物时的心情，难道会没有不同吗？

**段意：** 概写洞庭湖的壮阔多变，提出“览物之情，得无异乎”的问题，领起下文的阴晴悲喜。

### 第三段：写阴雨洞庭之景和迁客骚人的悲情

> 若夫霪雨霏霏，连月不开，阴风怒号，浊浪排空；日星隐曜，山岳潜形；商旅不行，樯倾楫摧；薄暮冥冥，虎啸猿啼。登斯楼也，则有去国怀乡，忧谗畏讥，满目萧然，感极而悲者矣。

**译文：** 像那连绵不断的雨纷纷地下，接连几个月天气不放晴，阴冷的风怒吼，浑浊的浪冲向天空；太阳和星星隐藏了光辉，山岳隐没了形体；商人和旅客不能通行，桅杆倒下，船桨折断；傍晚天色昏暗，老虎长啸，猿猴悲啼。（这时）登上这座楼，就会产生离开京城、怀念家乡，担心谗言、害怕讥讽的心情；满眼都是萧条的景象，感伤到了极点而悲哀。

**段意：** 写阴雨凄凉之景，烘托迁客骚人因仕途失意而悲伤的心情。

### 第四段：写晴明洞庭之景和迁客骚人的喜情

> 至若春和景明，波澜不惊，上下天光，一碧万顷；沙鸥翔集，锦鳞游泳；岸芷汀兰，郁郁青青。而或长烟一空，皓月千里，浮光跃金，静影沉璧，渔歌互答，此乐何极！登斯楼也，则有心旷神怡，宠辱偕忘，把酒临风，其喜洋洋者矣。

**译文：** 至于春风和煦、阳光明媚的时候，湖面平静，没有风浪，天色和湖光相接，一片碧绿，广阔无际；沙洲上的鸥鸟时而飞翔，时而停歇；美丽的鱼在水中游来游去；岸边的白芷和小洲上的兰草，茂盛而青翠。有时大片烟雾完全消散，皎洁的月光照耀千里，浮动的月光像跳动的金子，静静的月影像沉入水中的玉璧，渔歌一唱一和，这种乐趣哪有尽头！登上这座楼，就会感到心胸开阔，精神愉快，荣耀和屈辱一并忘掉，端着酒杯面对清风，那真是喜气洋洋啊。

**段意：** 写晴明明丽之景，烘托迁客骚人因景物美好而喜悦的心情。

### 第五段：议论古仁人之心，提出“先忧后乐”

> 嗟夫！予尝求古仁人之心，或异二者之为，何哉？不以物喜，不以己悲；居庙堂之高则忧其民；处江湖之远则忧其君。是进亦忧，退亦忧。然则何时而乐耶？其必曰“先天下之忧而忧，后天下之乐而乐”乎！噫！微斯人，吾谁与归？

**译文：** 唉！我曾经探求古代品德高尚的人的思想感情，（他们）或许不同于上述两种表现，这是为什么呢？（他们）不因为外物和环境的好坏而高兴，也不因为个人遭遇的好坏而悲伤；在朝廷做官就忧虑百姓，远离朝廷、退居江湖就忧虑君主。这样，在朝为官也忧虑，退居江湖也忧虑。那么什么时候才快乐呢？他们一定会说“在天下人忧愁之前先忧愁，在天下人快乐之后才快乐”吧！唉！如果没有这样的人，我同谁一道呢？

**段意：** 将“古仁人”与迁客骚人对比，揭示“不以物喜，不以己悲”的思想境界，提出“先忧后乐”的忧乐观，点明全文主旨。

## 四、重点句式与翻译方法

### （一）特殊句式

| 句式 | 例句 | 说明 |
|---|---|---|
| 判断句 | 此则岳阳楼之大观也 | “……也”表判断，译为“这就是……” |
| 宾语前置 | 吾谁与归 | 正常语序为“吾与谁归” |
| 省略句 | 属予作文以记之 | 省略主语“滕子京” |
| 省略句 | 登斯楼也，则有……者矣 | 省略主语“迁客骚人” |
| 省略句 | 居庙堂之高则忧其民 | 省略主语“古仁人” |

### （二）高频翻译句

| 原句 | 翻译要点 |
|---|---|
| 政通人和，百废具兴 | 通：顺利；和：和乐；具：全、都；兴：兴办 |
| 衔远山，吞长江，浩浩汤汤，横无际涯 | 衔、吞用拟人；汤汤读 *shāng*；际涯：边际 |
| 览物之情，得无异乎 | 得无……乎：恐怕……吧；怎能没有……呢 |
| 去国怀乡，忧谗畏讥 | 国：国都；谗：说坏话；讥：讥讽 |
| 浮光跃金，静影沉璧 | 浮光：浮动的月光；璧：圆形玉器；注意比喻意象 |
| 不以物喜，不以己悲 | 以：因为；物：外物、环境；己：个人遭遇 |
| 居庙堂之高则忧其民；处江湖之远则忧其君 | 庙堂：朝廷；江湖：远离朝廷；居、处的主语是古仁人 |
| 微斯人，吾谁与归 | 微：如果没有；宾语前置，译为“我同谁一道呢” |

### （三）翻译答题方法

1. **先落实关键词。** 通假字、古今异义、活用词必须译准确，如“具”“属”“国”“微”。
2. **补出省略成分。** 如“登斯楼也”前要补“迁客骚人”，“居庙堂之高”前要补“古仁人”。
3. **调整特殊语序。** “吾谁与归”要调整为“吾与谁归”。
4. **译出虚词关系。** “以”在“不以物喜”中译“因为”，在“以记之”中译“来”；“则”常译“就”。
5. **保持句意通顺。** 写景句可适当补出主语“洞庭湖”，但不能擅自增添原文没有的情节。

## 五、内容理解与主旨

### （一）文章结构

| 段落 | 内容概括 | 作用 |
|---|---|---|
| 第1段 | 滕子京政绩、重修岳阳楼及作记缘由 | 开篇叙事，交代写作背景 |
| 第2段 | 总写洞庭湖壮阔多变，设问引出“览物之情” | 承上启下，总领下文 |
| 第3段 | 阴雨洞庭与悲情 | 写“迁客骚人”因景悲伤 |
| 第4段 | 晴明洞庭与喜情 | 写“迁客骚人”因景喜悦，与上段对比 |
| 第5段 | 古仁人之心与先忧后乐 | 议论点题，揭示主旨 |

### （二）“迁客骚人”与“古仁人”对比

| 人物 | 面对景物与遭遇 | 情感表现 | 思想境界 |
|---|---|---|---|
| 迁客骚人 | 阴雨凄凉或春和景明 | “感极而悲”或“其喜洋洋” | 情绪受外物、个人得失影响 |
| 古仁人 | 无论在朝或在野 | “不以物喜，不以己悲” | 心系百姓与国家，超越个人荣辱 |

### （三）中心思想

本文通过记叙重修岳阳楼的缘由，描写洞庭湖阴晴不同的景象，表现迁客骚人“以物悲”“以物喜”的不同心情；进而赞美古仁人“不以物喜，不以己悲”的胸襟，表达了作者“先天下之忧而忧，后天下之乐而乐”的政治理想和忧国忧民、先人后己的责任担当。

### （四）“先忧后乐”的现代启示

- 面对个人顺逆，不应只随环境和得失起伏，要保持理性、坚守责任。
- 青少年应把个人成长与集体、社会需要联系起来，培养关心他人、服务社会的意识。
- 这句话的核心是先人后己、担当负责，不是要求人放弃正常生活中的快乐。

## 六、写作手法赏析

| 手法 | 原文依据 | 表达作用 |
|---|---|---|
| 叙事、写景、抒情、议论结合 | 从“属予作文以记之”写到“先天下之忧而忧” | 由记楼自然过渡到写景、抒情和议论，层层推进 |
| 对比 | 阴雨图与晴明图；迁客骚人与古仁人 | 突出古仁人不以物喜、不以己悲的高尚境界 |
| 借景抒情、情景交融 | 阴雨景烘托悲，晴明景烘托喜 | 景物成为人物心情的外化，增强感染力 |
| 先总后分 | 先写“岳阳楼之大观”，后写阴晴之景 | 层次清楚，结构严谨 |
| 设问 | “览物之情，得无异乎？”“何时而乐耶？” | 引出下文，推动思路，增强议论力量 |
| 对偶、排比 | “居庙堂之高……处江湖之远……” | 句式整齐，气势充沛，突出忧乐观 |
| 拟人、夸张 | “衔远山，吞长江”“浊浪排空” | 写出洞庭湖的宏大气势和风浪的险恶 |
| 动静结合 | “浮光跃金，静影沉璧” | “跃”写动景，“沉”写静景，月夜洞庭画面优美 |

## 七、理解性默写（高频考点）

| 考查角度 | 默写内容 |

## 八、中考高频考点总结

### 考点一：重点实词、虚词与通假字

重点掌握：谪、守、越、具、制、属、衔、汤汤、备、极、迁客、得无、开、薄、国、景、偕、微；通假字“具”“属”；虚词“以”“之”“而”“则”。

### 考点二：古今异义与一词多义

常考古今异义：明年、气象、去国、不行、进、退、微。  
常考一词多义：观、极、或、以、之、而。

### 考点三：句子翻译

翻译题常集中在以下句子：

1. 衔远山，吞长江，浩浩汤汤，横无际涯。
2. 览物之情，得无异乎？
3. 去国怀乡，忧谗畏讥。
4. 浮光跃金，静影沉璧。
5. 不以物喜，不以己悲。
6. 微斯人，吾谁与归？

### 考点四：写景名句赏析

- “衔远山，吞长江”中的“衔”“吞”使用拟人，写出洞庭湖的博大气势。
- “浮光跃金，静影沉璧”以“跃”“沉”写月光月影，动静相生，意境优美。
- 阴雨景与晴明景形成对比，服务于悲喜两种心情的抒写。

### 考点五：内容理解与人物形象

1. 滕子京：虽遭贬谪，仍勤政有为，体现积极进取的精神。
2. 迁客骚人：情绪随景物和个人得失变化，易悲易喜。
3. 古仁人：不以物喜，不以己悲，无论进退都忧国忧民。
4. 范仲淹：具有博大胸襟、忧患意识和以天下为己任的政治抱负。

### 考点六：主旨与现实启示

答题时应抓住“忧国忧民、先人后己、责任担当、超越个人得失”几个核心词，并结合文中“不以物喜，不以己悲”“先天下之忧而忧，后天下之乐而乐”作答。

### 考点七：比较阅读方向

| 比较篇目 | 可比较角度 |
|---|---|
| 《醉翁亭记》 | 都写山水、寄寓政治理想；范仲淹强调忧乐担当，欧阳修强调与民同乐 |
| 《桃花源记》 | 都寄托理想追求；范仲淹关注天下忧乐，陶渊明向往安宁和乐的理想社会 |
| 《小石潭记》 | 都有借景抒情；柳宗元借冷清之景寄寓孤凄，范仲淹由景提升到忧乐观 |
| 《大道之行也》 | 都体现对社会理想的思考；前者重忧乐责任，后者重大同社会的制度理想 |
