# 《湖心亭看雪》知识点与中考考点详解

> 适用对象：初中九年级上册  
> 资料定位：课内精讲 + 中考一轮复习  
> 学习重点：积累文言实词和虚词，读懂白描雪景，理解“痴”字及作者的复杂心境。

---

## 一、文学常识与背景

| 项目 | 内容 |
|---|---|
| 作者 | 张岱（1597—约1689），字宗子，号陶庵，明末清初文学家，山阴（今浙江绍兴）人。 |
| 作品 | 选自《陶庵梦忆》；张岱另有《西湖梦寻》等作品。 |
| 文体 | 山水小品。篇幅短小，以叙事、写景、抒情融为一体。 |
| 内容 | 写作者雪后夜往湖心亭赏雪，偶遇两位金陵人并同饮的经历。 |
| 时代信息 | 文中用“崇祯五年”纪年。张岱在明亡后追忆往事时仍用明朝年号，常被视为其故国之思的含蓄流露；答题时须立足文本，不宜把它说成全文唯一情感。 |
| 核心情感 | 痴迷山水、追求高雅情趣、清高孤傲；雪夜的清寂中也含有难言的孤寂与淡淡惆怅。 |

> **易错提醒：** “更定”是晚上八时左右，不是“凌晨”。“独往”强调作者不与俗人结伴、精神上的独立，不等于船上绝无舟子。

## 二、原文朗读、译文与逐层理解

### 1. 朗读停顿

> 崇祯五年十二月，余/住西湖。大雪三日，湖中/人鸟声俱绝。  
> 是日/更定矣，余/拏一小舟，拥/毳衣炉火，独往/湖心亭看雪。  
> 雾凇沆砀，天/与云/与山/与水，上下/一白。  
> 湖上影子，惟/长堤一痕、湖心亭一点、与余舟一芥、舟中人两三粒/而已。  
> 到亭上，有两人/铺毡对坐，一童子/烧酒炉正沸。  
> 见余/大喜曰：“湖中/焉得更有此人！”拉余/同饮。余/强饮三大白/而别。  
> 问其姓氏，是金陵人，客此。及下船，舟子喃喃曰：“莫说相公痴，更有痴似相公者！”

### 2. 全文译文

崇祯五年十二月，我住在西湖边。接连下了三天大雪，湖中行人、飞鸟的声音都消失了。这一天晚上八时左右，我撑着一叶小船，穿着毛皮衣服、带着火炉，独自前往湖心亭看雪。冰花一片弥漫，天空、云层、山峦和湖水，天上地下全是白色。湖上（能看见的）影子，只有长堤隐约的一道痕迹、湖心亭小小的一点、我的小船像一片小草叶，船中的两三个人像米粒罢了。

到了湖心亭上，有两个人铺着毡子相对而坐，一个书童正把酒炉烧得沸腾。他们看见我，非常高兴地说：“想不到湖中还会有这样的人！”便拉着我一同喝酒。我尽力喝了三大杯酒，告辞离开。（我）问他们的姓名，（得知他们）是金陵人，客居在这里。等到下船时，船夫小声嘀咕说：“不要说相公您痴，还有像相公一样痴的人呢！”

### 3. 逐句精讲

#### 第一层：交代时间、地点与雪后环境

**原文：** 崇祯五年十二月，余住西湖。大雪三日，湖中人鸟声俱绝。

- “崇祯五年十二月”交代时间，“余住西湖”交代地点和人物。
- “大雪三日”写连续大雪；“人鸟声俱绝”从**听觉**写湖上万籁俱寂，也暗示天气严寒、游人稀少。
- 开篇简洁，却为下文“独往”和偶遇知音营造了清冷、空阔的氛围。

#### 第二层：雪夜独行

**原文：** 是日更定矣，余拏一小舟，拥毳衣炉火，独往湖心亭看雪。

- “是日”承上，指这一天；“更定”点明夜深。“拏”同“桡”，撑（船）。
- “一小舟”“毳衣炉火”写出舟小、天寒、出行艰难；“独”突出作者特立独行的雅趣。
- 这一句叙事简练，写出了在常人避寒静卧时，作者反而冒雪夜游的“痴”。

#### 第三层：写湖中雪景

**原文：** 雾凇沆砀，天与云与山与水，上下一白。湖上影子，惟长堤一痕、湖心亭一点、与余舟一芥、舟中人两三粒而已。

- “雾凇沆砀”写冰花、水汽弥漫的朦胧景象；“天与云与山与水”连用三个“与”，展现天、云、山、水浑然相接。
- “上下一白”从整体写天地的白茫、纯净、辽阔。
- 后一句从整体转到局部，按视野所及列出堤、亭、舟、人；“痕、点、芥、粒”把景物写得极小，与天地之大形成对照，突出人的渺小和湖面的空阔。
- 这段写景用笔极省，不作细密铺陈，只点出景物的轮廓、数量和位置，是典型的**白描**。

#### 第四层：亭中奇遇

**原文：** 到亭上，有两人铺毡对坐，一童子烧酒炉正沸。见余大喜曰：“湖中焉得更有此人！”拉余同饮。余强饮三大白而别。

- 在寂静雪夜中忽然出现温酒、对坐、交谈的画面，给清冷的雪景添了温度与生气。
- “大喜”“拉余同饮”写金陵人因遇见同好而惊喜；“焉得更有此人”意为“哪能还有这样的人”，包含赞赏。
- “强饮三大白”中的“强”是尽力；作者本不以饮酒为目的，却为珍惜知音之会而尽力喝酒，写出率真豪爽。

#### 第五层：舟子评“痴”收束全文

**原文：** 问其姓氏，是金陵人，客此。及下船，舟子喃喃曰：“莫说相公痴，更有痴似相公者！”

- “金陵”是明朝故都。作者到分别时才问姓氏，说明他看重的是性情相投，而非世俗身份。
- 舟子的话看似不解，实则从侧面衬托三人同样痴迷山水、不同流俗；“痴”是全文的文眼。
- 以舟子的喃喃之语结尾，含蓄、诙谐，给读者留下回味，也使作者的孤高与知音相遇的欣喜交织在一起。

### （六）特殊句式与虚词

| 类型 | 例句 | 要点 |
|---|---|---|
| 判断句 | 是金陵人 | “是”表判断，译为“（他们）是金陵人”。 |
| 倒装句 | 湖中焉得更有此人 | 可调整为“湖中哪能更有这样的人”。 |
| 省略句 | 到亭上 | 省略主语“余”。 |
| 省略句 | 问其姓氏，是金陵人，客此 | 省略主语“余”“他们”；译文要补出。 |

| “而” | 强饮三大白而别 | 表承接，可译为“然后、就”。 |
| “于” | 余住西湖 | 介词，在。 |

## 四、重点句翻译与方法

| 原句 | 关键词 | 参考译文 |
|---|---|---|
| 大雪三日，湖中人鸟声俱绝。 | 大雪：下大雪；俱：都；绝：消失 | 接连下了三天大雪，湖中行人、飞鸟的声音都消失了。 |
| 是日更定矣，余拏一小舟，拥毳衣炉火，独往湖心亭看雪。 | 是：这；拏：撑；拥：裹；独：独自 | 这一天晚上八时左右，我撑着一叶小船，穿着毛皮衣服、带着火炉，独自前往湖心亭看雪。 |
| 雾凇沆砀，天与云与山与水，上下一白。 | 沆砀：白气弥漫；一：全 | 冰花一片弥漫，天空、云层、山峦和湖水，天上地下全是白色。 |
| 湖上影子，惟长堤一痕、湖心亭一点、与余舟一芥、舟中人两三粒而已。 | 惟：只；芥：小草；而已：罢了 | 湖上（能看见的）影子，只有长堤的一道痕迹、湖心亭的一点、我的小船像一片小草叶、船中两三个人像米粒罢了。 |
| 湖中焉得更有此人！ | 焉得：哪能；更：还 | 想不到湖中还会有这样的人！ |
| 余强饮三大白而别。 | 强：尽力；白：酒杯 | 我尽力喝了三大杯酒，然后告辞离开。 |
| 莫说相公痴，更有痴似相公者！ | 莫：不要；似：像 | 不要说相公您痴，还有像相公一样痴的人呢！ |

**翻译四步法：**

1. 先锁定关键词，如“绝、拏、一、强、客”。
2. 补出省略成分，如“问其姓氏”前补“我”。
3. 调整倒装语序，如“焉得更有此人”译为“哪能还有这样的人”。
4. 检查是否译出了虚词关系，最后使句子合乎现代汉语习惯。

## 五、内容结构、主旨与写法

### （一）结构梳理

| 层次 | 内容 | 作用 |
|---|---|---|
| 开头 | 交代时间、地点和大雪后万籁俱寂的环境 | 营造清冷空阔的氛围，引出赏雪。 |
| 雪夜出行 | 写夜深独往湖心亭 | 突出作者不随流俗的“痴”。 |
| 湖中雪景 | 总写天地一白，点写堤、亭、舟、人 | 写出西湖雪景的空阔、纯净、朦胧。 |
| 亭中相遇 | 写与金陵人相逢、同饮 | 以人的温情打破清寂，表现知音相遇之喜。 |
| 舟子评论 | 用“痴”字收束 | 点明文眼，含蓄表现作者的志趣和性情。 |

**叙事线索：** 交代背景 → 雪夜独往 → 湖中观雪 → 亭上遇人 → 舟子评痴。  
**情感线索：** 清冷孤寂 → 痴迷欣赏 → 知音惊喜 → 含蓄回味。

### （二）中心思想

本文通过写雪夜独往湖心亭赏雪、偶遇金陵人同饮的经历，描绘了空阔纯净、清寂朦胧的西湖雪景，表现了作者痴迷山水、特立独行、追求高雅情趣的性情；雪夜独行和明亡后的追忆背景，又使文章带有孤寂和淡淡的故国之思。

> **主旨题答题边界：** “故国之思”是结合作者、纪年与作品背景作出的深入理解。若题目只问“从文本看张岱的性情”，优先答“痴迷山水、孤高不俗、追求知音”；若题目问“深层情感”或给出背景，再补“孤寂、故国之思”。

### （三）写法赏析

| 手法 | 原文依据 | 表达效果 |
|---|---|---|
| 白描 | “一痕、一点、一芥、两三粒” | 不加渲染，只勾勒轮廓，简洁传神地写出雪景的空阔、朦胧。 |
| 总写与点写 | “上下一白”与堤、亭、舟、人 | 先写天地整体，再写眼前细部，层次分明。 |
| 量词炼字 | 痕、点、芥、粒 | 景物由大到小、由实到虚，突出天地辽阔与人的渺小。 |
| 动静结合 | “人鸟声俱绝”与亭中烧酒、对坐、同饮 | 以静写雪夜的空寂，以人的活动添生气，形成反差。 |
| 对比衬托 | 作者、金陵人的“痴”与舟子的不解 | 以俗人眼光反衬雅士的特立独行。 |
| 侧面描写 | 舟子“莫说相公痴” | 不直说作者性情，借舟子之口点出“痴”，含蓄有余味。 |
| 叙事写景结合 | 观雪、遇人、同饮 | 景因人显，人与景相映，使山水小品富有情趣。 |

### （四）“痴”字深解

“痴”不是愚笨、糊涂，而是**痴迷、痴情、不同流俗**。它至少包含三层意思：

1. **行为之痴：** 天寒夜深、万籁俱寂时仍冒雪乘舟赏雪。
2. **审美之痴：** 能欣赏“上下一白”的空灵雪景，追求自然之美。
3. **性情之痴：** 不重身份名利，重视性情相投；与金陵人相逢即同饮。

答题时宜写成“词义 + 文中依据 + 性格/情感”，例如：“‘痴’是痴迷、不同流俗，写张岱在雪后夜深独往湖心亭赏雪，表现了他痴迷山水、孤高雅致的性情。”

## 七、中考高频考点与答题提示

| 高频考点 | 常见问法 | 作答关键 |
|---|---|---|
| 实词、通假字 | “绝、拏、白、客、强”怎么解释？ | 放回语境解释；“拏”可注明通“桡”。 |
| 一词多义 | “一、白、更、是”的意思是否相同？ | 分别写清具体句中的义项。 |
| 句子翻译 | 翻译雪景句、亭中对话、舟子的话 | 关键词、补省略、调倒装一个也不能漏。 |
| 理解性默写 | 根据雪景、独行、文眼填写句子 | 留意“凇、沆砀、堤、芥、毳、喃”等字形。 |
| 白描与炼字 | “痕、点、芥、粒”有何作用？ | 词义/画面 + 景物特点 + 情感或结构作用。 |
| “独”与“痴” | 作者为何“独往”？“痴”有何内涵？ | 不能只说“孤独”；要答不随俗、痴迷山水、性情高雅。 |
| 景情关系 | 雪景有哪些特点？有何作用？ | 空阔、纯净、清寂、朦胧；烘托人物心境、为遇知音蓄势。 |
| 人物与侧面描写 | 舟子的话有何作用？ | 交代舟子的不解，反衬作者与金陵人的雅趣，点明文眼。 |
| 比较阅读 | 与《记承天寺夜游》《岳阳楼记》等比较 | 先找共同的写景/心境，再结合文本说清不同。 |

**建议复习顺序：** 先熟读、默写全文；再整理“绝、拏、一、白、强、客”和“更、是”的用法；接着逐句翻译；最后练“白描”“痴”“舟子评论”三类赏析题。复习时始终做到“观点 + 原文依据 + 表达效果/情感”。
