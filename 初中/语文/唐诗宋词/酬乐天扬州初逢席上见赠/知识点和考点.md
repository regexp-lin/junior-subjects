# 《酬乐天扬州初逢席上见赠》知识点与中考考点详解

> 适用对象：初中九年级上册
> 资料定位：课内精讲 + 中考一轮复习
> 说明：本资料以统编教材篇目为依据，重点训练诗句默写、炼字赏析、典故理解、情感把握和名句的语境运用。

## 一、文学常识与题目解读

| 项目 | 内容 |
|---|---|
| 作者 | 刘禹锡（772—842），字梦得，唐代文学家、哲学家。其诗风刚健明朗，后人称其为“诗豪”。 |
| 体裁 | 七言律诗。全诗八句，四联依次为首联、颔联、颈联、尾联。 |
| 乐天 | 白居易的字。 |
| 酬 | 以诗相答、酬谢。 |
| 席上见赠 | 宴席上（白居易）赠给我诗。“见”用在动词前，表示动作涉及自己，可译为“我”。 |
| 写作背景 | 唐敬宗宝历二年（826），刘禹锡奉调还京途中与白居易在扬州相逢。刘禹锡因政治改革失败，长期被贬，前后约二十三年。白居易作诗慰问，刘禹锡便写此诗答谢。 |

**题目直译：** 在扬州初次相逢的宴席上，答谢乐天（白居易）赠给我的诗。

> **易错点：** “乐天”不是泛指“乐观的人”，而是白居易的字；“酬”不是报酬，而是以诗答赠。

## 二、原文、朗读节奏与译文

> 巴山楚水凄凉地，二十三年弃置身。
> 怀旧空吟闻笛赋，到乡翻似烂柯人。
> 沉舟侧畔千帆过，病树前头万木春。
> 今日听君歌一曲，暂凭杯酒长精神。

**朗读提示：** 七言诗通常可按“四三”节奏朗读，如“巴山楚水／凄凉地”“沉舟侧畔／千帆过”。要读出前两联低回、颈联开阔、尾联振作的感情变化。

### 逐联翻译与理解

| 联次 | 诗句 | 译文 | 内容要点 |
|---|---|---|---|
| 首联 | 巴山楚水凄凉地，二十三年弃置身。 | 我被贬谪在巴山楚水这些凄清荒远的地方，二十三年来像被朝廷抛弃、搁置在一旁的人。 | 概写贬谪之地偏远、时间漫长和遭遇冷落，奠定感伤基调。 |
| 颔联 | 怀旧空吟闻笛赋，到乡翻似烂柯人。 | 怀念故去的朋友，只能徒然吟诵《思旧赋》；回到故乡（旧地），反而觉得自己像斧柄已烂的樵夫一样，恍如隔世。 | 借典写故友零落与世事变迁，感慨深沉。 |
| 颈联 | 沉舟侧畔千帆过，病树前头万木春。 | 沉没的船只旁边，许多帆船正在驶过；枯病的树木前面，许多树木在春天里焕发生机。 | 由低沉转向开阔，表达对新生与前进的信心。 |
| 尾联 | 今日听君歌一曲，暂凭杯酒长精神。 | 今天听了您赠给我的一首诗，暂且借这一杯酒来振作精神。 | 点明酬答之意，感谢友人慰勉，以自励收束全诗。 |

**全诗译文：** 我被贬谪在巴山楚水这些凄清荒远的地方，二十三年来像被朝廷抛弃、搁置在一旁的人。怀念故去的朋友，只能徒然吟诵《思旧赋》；回到故乡（旧地），反而觉得自己像斧柄已烂的樵夫一样，恍如隔世。沉没的船只旁边，许多帆船正在驶过；枯病的树木前面，许多树木在春天里焕发生机。今天听了您赠给我的一首诗，暂且借这一杯酒来振作精神。

## 三、重点字词、句式与易错点

### （一）重点词语

| 词语 | 课内义项 | 所在诗句 | 易错提醒 |
|---|---|---|---|
| 巴山楚水 | 泛指巴地、楚地一带，代指诗人长期贬谪的偏远地区 | 巴山楚水凄凉地 | 不必机械落实为一座山、一条水。 |
| 凄凉地 | 凄清荒凉的地方 | 巴山楚水凄凉地 | 既写环境，也写内心的悲凉。 |
| 弃置 | 抛弃、搁置；这里指被朝廷长期贬谪、不被任用 | 二十三年弃置身 | 不要只译为“把东西放下”。 |
| 怀旧 | 怀念故友 | 怀旧空吟闻笛赋 | “旧”主要指旧友，不宜笼统答“怀念过去”。 |
| 空 | 徒然、白白地 | 怀旧空吟闻笛赋 | 写出想念故友却无从相见的无奈。 |
| 吟 | 吟诵 | 怀旧空吟闻笛赋 | |
| 到乡 | 回到故乡、重返旧地 | 到乡翻似烂柯人 | 结合久别归来的语境理解。 |
| 翻 | 反而 | 到乡翻似烂柯人 | 古今异义色彩明显，不译为“翻转”。 |
| 烂柯人 | 斧柄腐烂的樵夫，借指久别归来、恍如隔世的人 | 到乡翻似烂柯人 | 要结合典故说明“世事变迁”。 |
| 侧畔 | 旁边 | 沉舟侧畔千帆过 | “畔”不要写成“伴”。 |
| 千帆、万木 | 许多帆船、许多树木 | 千帆过／万木春 | “千”“万”是概数，表数量多。 |
| 病树 | 枯病的树 | 病树前头万木春 | 诗中带有诗人自况的意味。 |
| 凭 | 凭借、依靠 | 暂凭杯酒长精神 | |
| 长精神 | 振作精神 | 暂凭杯酒长精神 | “长”读 **zhǎng**，这里是使精神增长、振作。 |

### （二）古今异义与特殊用法

| 词语 | 古义或诗中义 | 今义或常见误解 |
|---|---|---|
| 弃置 | 被抛弃、被搁置，指不被任用 | 丢弃、放置物品 |
| 空吟 | 徒然吟诵 | 空着、天空 |
| 翻似 | 反而好像 | 翻转、翻译 |
| 长精神 | 使精神振作 | 保持长久的精神状态 |
| 春（万木春） | 树木在春天复苏，呈现蓬勃生机 | 单指季节名称 |

### （三）炼字速记

| 字词 | 表达效果 |
|---|---|
| “凄凉” | 双关环境与心境，点出贬谪生活的冷落、悲苦。 |
| “二十三年” | 用确数突出被贬时间之长，强化辛酸感。 |
| “空” | 写徒然、无可奈何，突出故友不在的悲痛。 |
| “翻” | 写本以为归来应感亲切，结果反而恍如隔世，加深世事变迁之感。 |
| “过” | 写千帆不断驶过，富有动态感，显示事物不断前进。 |
| “春” | 写万木复苏、生机勃勃，画面明朗，象征新生力量。 |
| “暂” | 表示暂且，并非消沉；写出诗人接受慰勉、借酒自励的当下状态。 |

## 四、两个典故：内容、作用、答题模板

| 典故 | 典故内容 | 对应诗句 | 诗中表达的情感 |
|---|---|---|---|
| 闻笛赋 | 西晋向秀路过嵇康、吕安旧居，听到笛声，怀念亡友而作《思旧赋》。 | 怀旧空吟闻笛赋 | 怀念因政治遭际而逝去的故友，表达物是人非的悲痛与无奈。 |
| 烂柯人 | 传说樵夫王质进山砍柴，观看仙人下棋；一局棋后斧柄已烂，回到人间才知岁月已过去很久。 | 到乡翻似烂柯人 | 感叹贬谪时间漫长、世事变迁，写出久别归来的恍惚感。 |

**用典作用概括：** 诗人连用两个典故，分别从“故友不在”和“世事全非”两方面写出二十三年贬谪带来的悲凉；典故使情感表达更含蓄、凝练而有历史纵深感。

**答题模板：** 诗句运用“____”典故，写了____的故事；诗人借此表达了对____的____之情，含蓄而深沉地表现了____。

> **易错点：** “闻笛赋”侧重怀念故友；“烂柯人”侧重感叹时光流逝、世事变迁。答题时不要把两者混为一谈。

## 五、结构、情感与主旨

### （一）情感与结构变化

| 联次 | 内容 | 情感 | 结构作用 |
|---|---|---|---|
| 首联 | 回顾贬谪之地、贬谪之久 | 凄凉、辛酸 | 开篇交代长期遭遇，奠定感伤基调。 |
| 颔联 | 怀念故友，感叹恍如隔世 | 悲痛、怅惘 | 承接“弃置”，把个人遭遇写得更深。 |
| 颈联 | 写千帆竞发、万木争春 | 开阔、乐观、进取 | 由悲凉转为昂扬，是全诗的情感转折。 |
| 尾联 | 答谢白居易，借酒自励 | 感激、振作 | 紧扣题目，收束全诗，深化积极精神。 |

**情感线索：** 贬谪的辛酸凄凉 → 怀念故友、感叹变迁 → 对新生和前进的信心 → 接受友人慰勉后的振作。

### （二）中心思想

这首酬答诗先回顾诗人长期贬谪的凄凉遭遇，借典抒发对故友的怀念以及对岁月流逝、世事变迁的感慨；继而以“千帆过”“万木春”表现不因个人失意而否定未来的开阔胸襟，最后答谢友人并自我激励。全诗表现了诗人虽历经挫折却仍乐观豁达、积极进取的精神。

### （三）名句的原意与引申义

> 沉舟侧畔千帆过，病树前头万木春。

| 角度 | 理解 |
|---|---|
| 原诗语境 | “沉舟”“病树”含有诗人对久遭贬谪、身心困顿处境的自况；“千帆”“万木”描绘不断前进、充满生机的景象。诗人由此自我勉励，显示开阔胸怀。 |
| 常用引申义 | 新事物必将取代旧事物，社会总会向前发展；要以发展眼光看待新生力量。 |
| 运用提醒 | 回答诗歌阅读题时优先联系原诗语境；做开放性题或名句运用题时，可说明其引申义，但不能只写引申义而忽略诗人的遭遇。 |

## 六、写作手法赏析

| 手法 | 诗句或依据 | 表达作用 |
|---|---|---|
| 先抑后扬 | 前两联悲凉，颈联、尾联昂扬 | 形成鲜明转折，使诗人不屈、进取的精神更加突出。 |
| 用典抒情 | “闻笛赋”“烂柯人” | 含蓄地写怀友与感时，增加诗歌的文化意蕴。 |
| 比喻、象征 | “沉舟”“病树”“千帆”“万木” | 以具体形象表现困顿与新生，诗意鲜明，富有哲理。 |
| 对偶 | “沉舟侧畔”对“病树前头”，“千帆过”对“万木春” | 句式整齐，节奏铿锵，增强了画面的开阔感和语言气势。 |
| 对比、反衬 | “沉舟”“病树”与“千帆”“万木” | 以沉寂、衰败衬托前进、新生，突出积极乐观的态度。 |
| 借景抒情、寓理于景 | 颈联 | 景象中自然蕴含发展变化的道理，不显说教。 |
| 照应题目 | “听君歌一曲”“杯酒” | 照应“酬”“席上见赠”，交代作诗缘由，使结构完整。 |

## 七、中考高频考点与答题策略

| 考点 | 常见问法 | 答题关键 |
|---|---|---|
| 文学常识 | “乐天”是谁？“酬”是什么意思？ | 白居易的字；以诗相答。 |
| 理解性默写 | 写贬谪之久、怀友、感叹世事、积极自励的诗句。 | 准确书写“弃置、笛、柯、侧畔、暂凭”等易错字。 |
| 重点词义 | 解释“空”“翻”“长”。 | 分别答“徒然”“反而”“使……振作/增长”。 |
| 典故理解 | 两个典故各写什么，表达什么。 | “闻笛赋”写怀友；“烂柯人”写变迁；再答含蓄深沉的作用。 |
| 名句赏析 | 赏析颈联的画面、手法、哲理。 | 写“对偶/比喻（象征）+ 动态与生机 + 乐观进取”，至少包含两层。 |
| 情感变化 | 全诗情感如何变化？ | 从凄凉、怅惘转为乐观、振作，要结合具体诗句。 |
| 主旨概括 | 概括诗人形象或思想感情。 | 不只答“乐观”；还要写贬谪之苦、怀友感时及自我激励。 |
| 比较阅读 | 与其他贬谪诗、酬赠诗比较情感。 | 先找共同点，再结合具体词句写差异，避免空泛。 |
| 开放运用 | 用颈联劝慰受挫者是否恰当。 | 说明新生力量、发展眼光和个人振作，联系语境作答。 |

## 八、诗歌鉴赏答题模板

### 1. 炼字题

“____”字在句中意为____，写出了____的情景/状态；它还表达了诗人____的情感（或使诗句具有____的表达效果）。

### 2. 名句赏析题

这两句运用____手法，描绘了____的画面；“____”与“____”形成____，表现了____，表达了诗人____的情感/精神。

### 3. 思想感情题

诗歌先写____，表达____；再写____，表现____；最后以____收束，抒发了诗人____。

### 4. 典故题

诗句引用____的典故，写____；诗人借此表达对____的____，使情感表达更____。

> **答题提醒：** 诗歌赏析不能只贴标签。如写“运用对偶”，后面还应具体说明对偶写了什么、怎样服务于情感；如答“乐观”，应落到“千帆过”“万木春”或“长精神”等诗句。
