# 《行路难（其一）》知识点与中考考点详解

> 适用对象：九年级上册古诗词复习\
> 课文版本：以统编教材“金樽清酒斗十千，玉盘珍羞直万钱”为准。不同选本偶有“珍馐”等异文，默写时应以本校教材为准。

---

## 一、文学常识与写作背景

| 项目 | 内容 |
|---|---|
| 作者 | 李白，字太白，号青莲居士，唐代诗人；诗歌想象奇特、气势豪迈，后人常称其为“诗仙”。 |
| 体裁 | 乐府旧题诗。“行路难”原是乐府古题，本写世路艰难；李白借“行路”写人生和仕途理想受阻。 |
| 题目 | “其一”说明《行路难》不止一首，此诗是其中第一首。 |
| 创作背景 | 一般认为作于李白在长安受权贵排挤、政治抱负难以施展，离开长安前后。具体写作时间有不同说法，答题应抓住“仕途受挫、理想受阻”这一背景。 |
| 主旨句 | “长风破浪会有时，直挂云帆济沧海。” |

> **理解背景的边界：** 诗中并没有直接叙述具体的政治事件。分析情感时，应从“不能食”“心茫然”“冰塞川”“雪满山”等诗句出发，再联系“抱负受阻”，不要臆测具体人物或事件。

## 二、原文、逐层解释与全诗译文

> 金尊清酒斗十千，玉盘珍羞直万钱。\
> 停杯投箸不能食，拔剑四顾心茫然。\
> 欲渡黄河冰塞川，将登太行雪满山。\
> 闲来垂钓碧溪上，忽复乘舟梦日边。\
> 行路难，行路难，多歧路，今安在？\
> 长风破浪会有时，直挂云帆济沧海。

| 诗句 | 字面意思 | 内容与情感 |
|---|---|---|
| 金尊清酒斗十千，玉盘珍羞直万钱。 | 金杯中的清醇美酒，一斗价值一万钱；玉盘里的珍贵菜肴，价值一万钱。 | 写酒器华美、酒菜珍贵，营造盛宴的外在欢乐，为下文写“不能食”蓄势。 |
| 停杯投箸不能食，拔剑四顾心茫然。 | （我）放下酒杯，丢下筷子，吃不下去；拔出剑来，环顾四周，心中迷惘。 | “停、投、拔、顾”连用，直写苦闷、焦灼和无所适从。 |
| 欲渡黄河冰塞川，将登太行雪满山。 | 想渡过黄河，冰雪却堵塞河道；打算登上太行山，大雪却盖满山岭。 | 表面写自然险阻，深层象征（或比喻）人生、仕途上的重重阻碍。 |
| 闲来垂钓碧溪上，忽复乘舟梦日边。 | （我盼望能）像姜尚闲居时在溪边垂钓，又像伊尹梦见乘船从日月旁边经过那样，后来得到明主重用。 | 连用典故，自比古代先困顿、后受任的贤臣，表现仍期待施展抱负。 |
| 行路难，行路难，多歧路，今安在？ | 人生道路艰难啊，艰难啊！岔路这样多，如今我的路在哪里？ | 反复、短句、设问（疑问）叠加，突出前路迷惘、内心激愤。 |
| 长风破浪会有时，直挂云帆济沧海。 | 总会有一天，我要乘着长风破开巨浪，高高挂起云帆，渡过苍茫大海。 | 以壮阔想象收束全诗，表达不甘沉沦、坚信终能冲破阻碍的豪迈信念。 |

**全诗译文：** 金杯中的清醇美酒一斗价值一万钱，玉盘中的珍贵菜肴价值一万钱。（我）却放下酒杯、丢下筷子，吃不下去；拔出剑来环顾四周，心中一片迷惘。想渡过黄河，冰雪却堵塞了河道；打算登上太行山，大雪却盖满了山岭。（我盼望）像姜尚闲居时在碧溪边垂钓、后来受到周文王重用，又像伊尹梦见乘船从日月旁经过、后来受到商汤任用。人生的道路艰难啊，艰难啊，岔路这么多，如今我的路在哪里？总会有一天，我要乘着长风破开巨浪，高高挂起云帆，渡过苍茫的大海。

## 三、重点字词、通假与句式

### （一）重点实词

| 词语 | 课内义 | 说明 |
|---|---|---|
| 樽（zūn） | 盛酒的器具 | “金樽”指金制的酒杯。 |
| 斗（dǒu） | 古代容量单位 | “斗十千”即一斗酒价值一万钱。 |
| 珍羞 | 珍贵的菜肴 | “羞”同“馐”，美味的食物。 |
| 直 | 价值 | “直万钱”的“直”同“值”。 |
| 投 | 丢下、扔下 | “投箸”不是“投放”。 |
| 箸（zhù） | 筷子 | 易误写成“著”。 |
| 四顾 | 向四周看、环顾 | “顾”在此为“看”。 |
| 茫然 | 心中迷惘、不知怎么办的样子 | 写内心状态，不是单指“空旷”。 |
| 塞（sè） | 堵塞 | “冰塞川”即冰雪堵塞河道。 |
| 川 | 河流 | “冰塞川”中的“川”不能只译成山川。 |
| 将 | 将要、打算 | “将登太行”。 |
| 闲来 | 闲居时、不得志时 | 结合姜尚典故理解。 |
| 复 | 又 | “忽复”意为忽然又。 |
| 歧路 | 岔路 | 比喻人生道路上的复杂处境、不同选择。 |
| 安 | 哪里 | “今安在”即如今在哪里。 |
| 会 | 终将、一定 | 表示坚定的预期。 |
| 云帆 | 高耸入云的帆 | “云”形容帆很高。 |
| 济 | 渡过 | “济沧海”不是“救济大海”。 |
| 沧海 | 大海 | “沧”指青绿色。 |

### （二）通假字与易混义项

| 原字 | 通假字 | 含义 | 例句 |
|---|---|---|---|
| 羞 | 馐 | 美味的食物、菜肴 | 玉盘珍羞直万钱 |
| 直 | 值 | 价值 | 玉盘珍羞直万钱 |

| 易混词 | 在本诗中的意思 | 另一处常见意思 | 提醒 |
|---|---|---|---|
| 直 | 价值（“直万钱”） | 径直、高高地（“直挂云帆”） | 同一首诗中词义不同，需随语境判断。 |
| 顾 | 看（“四顾”） | 顾念、照顾 | 不可一概译为“照顾”。 |
| 济 | 渡过（“济沧海”） | 救济、成就（如“同舟共济”） | 本诗取“渡过”。 |
| 安 | 哪里（“今安在”） | 安定、安稳 | 疑问句中常译为“哪里”。 |

### （三）句式与翻译提示

| 类型 | 例句 | 翻译要点 |
|---|---|---|
| 省略句 | 停杯投箸不能食 | 补出主语“我（诗人）”。 |
| 省略句 | 欲渡黄河冰塞川，将登太行雪满山 | 补出转折关系：“想要……却……；打算……却……”。 |
| 省略句 | 闲来垂钓碧溪上，忽复乘舟梦日边 | 补出诗人借姜尚、伊尹自况及“后来受任”的典故含义。 |
| 宾语前置 | 今安在 | “安”意为“哪里”，可译为“如今在哪里”。 |

**翻译原则：** 先落实关键词（如“直”“塞”“济”），再补省略成分，最后把转折、疑问等关系译顺；赏析诗句时还要说明其深层象征义。

## 四、典故、意象与情感线索

### （一）三个典故

| 诗句/短语 | 典故内容 | 在诗中的作用 |
|---|---|---|
| 垂钓碧溪 | 相传姜尚（吕尚）未受重用时曾在渭水一带垂钓，后受周文王重用，辅佐周朝建立功业。 | 借姜尚自比，表达虽暂时不得志仍期待被赏识的愿望。 |
| 乘舟梦日边 | 相传伊尹曾梦见自己乘船从日月旁经过，后受商汤任用，辅佐商朝建立。 | 与姜尚典故并列，强化诗人希望遇到明主、实现政治抱负的期待。 |
| 长风破浪 | 化用南朝宋宗悫“愿乘长风破万里浪”的志向。 | 表明不畏艰难、终将有所作为的决心，使结尾更显豪迈。 |

> **用典题答题公式：** 写出“典故人物/经历” + “诗人借古人自比或自励” + “表达的情感（渴望受任、建功立业、坚持理想）”。只解释故事、不联系诗人情感，得分不完整。

### （二）核心意象

| 意象 | 表层画面 | 深层含义/作用 |
|---|---|---|
| 金尊、玉盘、清酒、珍羞 | 华美丰盛的宴席 | 以外在的欢乐反衬内心的愁苦。 |
| 黄河、太行、冰雪 | 渡河登山却受冰雪阻隔 | 将抽象的仕途困境化为具体可感的险阻。 |
| 碧溪、日边 | 古人等待或受到重用的联想 | 从眼前困境转向历史上的转机。 |
| 长风、巨浪、云帆、沧海 | 乘风扬帆、横渡大海的壮阔图景 | 象征远大志向和冲破阻碍的行动，营造雄奇豪迈的意境。 |

### （三）情感变化：不是直线，而是跌宕起伏

**盛宴反衬愁闷** → **停杯拔剑的焦灼迷惘** → **冰塞雪满的困顿** → **借古人自比的期待** → **反复叹路难的迷惘再起** → **破浪济海的坚定豪迈**

这首诗的可贵处在于：诗人没有回避“难”，却也没有被“难”压倒。答主旨题时要同时答出前半部分的苦闷、迷惘和结尾处的自信、进取，不能只答其中一面。

## 五、表现手法与炼字赏析

| 手法 | 例句 | 表达效果 |
|---|---|---|
| 夸张 | “斗十千”“直万钱” | 极写酒菜的昂贵丰盛，增强盛宴的华美感。 |
| 反衬（以乐景衬哀情） | 盛宴与“不能食” | 酒菜越美，越显诗人因壮志难酬而无心享用、内心苦闷。 |
| 动作描写、动词连用 | “停、投、拔、顾” | 一连串急促动作，传神地写出愤懑、焦灼和茫然。 |
| 象征（或比喻） | “冰塞川”“雪满山” | 以自然险阻象征人生、仕途受阻，使抽象困境形象可感。 |
| 用典 | 姜尚、伊尹、宗悫相关典故 | 含蓄丰富地表达希望受任、自我激励和进取志向。 |
| 反复、短句 | “行路难，行路难” | 加强语气；连续三言短句使节奏短促顿挫，突出迷惘和激愤。 |
| 设问（疑问） | “今安在？” | 直面“路在何方”的问题，强化前路未卜的焦灼。 |
| 想象与雄奇意象 | “直挂云帆济沧海” | 展现宏阔画面，表现冲破险阻的自信与豪迈。 |

### 高频炼字示例

1. **“停、投、拔、顾”好在哪里？** 四个动词连续出现，写出诗人从无心饮食到拔剑四望的动作过程，节奏急促，表现其理想受阻后的愤懑、焦灼和茫然。
2. **“塞”“满”好在哪里？** “塞”写冰雪堵住河道，“满”写大雪覆盖山岭，程度强、画面冷峻；二字具体表现前行无路，也象征现实阻碍重重。
3. **“破、挂、济”好在哪里？** 三个富有力度的动词写出破浪、扬帆、渡海的主动行动，展现勇往直前的气势和坚定信念。

## 六、理解性默写与易错字

| 考查角度 | 应答诗句 |
|---|---|
| 写华美宴席，反衬诗人内心苦闷 | 金尊清酒斗十千，玉盘珍羞直万钱。 |
| 以动作写诗人愤懑、迷惘 | 停杯投箸不能食，拔剑四顾心茫然。 |
| 用冰雪阻塞象征仕途受阻 | 欲渡黄河冰塞川，将登太行雪满山。 |
| 借姜尚、伊尹典故表达希望受任 | 闲来垂钓碧溪上，忽复乘舟梦日边。 |
| 反复感叹道路艰难、前途迷惘 | 行路难，行路难，多歧路，今安在？ |
| 表达不畏艰险、坚信理想终会实现 | 长风破浪会有时，直挂云帆济沧海。 |

**易错字提醒：** 金尊（不是“金尊”）、投箸（不是“投著”）、茫然、冰塞川、太行（háng）、歧路（不是“岐路”）、云帆、济沧海（不是“挤沧海”）、沧海（不是“苍海”）。

## 七、中考高频考点与答题策略

| 高频考点 | 常见问法 | 作答关键 |
|---|---|---|
| 直接性默写 | “表达……的诗句是？” | 理解情境后准确书写，注意“樽、箸、歧、济、沧”等字。 |
| 词义、通假 | “直”“羞”“安”“济”是什么意思？ | 结合句子，不以今义替代古义；“直”在前后两处含义不同。 |
| 诗句翻译 | 翻译“欲渡黄河……”等 | 译出“却”的转折关系和象征义；翻译题先求字面通顺。 |
| 炼字赏析 | “停、投、拔、顾”或“破、挂、济”有何表达效果？ | 词义/画面 + 手法或节奏 + 情感，三层作答。 |
| 意象、手法 | 冰雪险阻、盛宴反衬有何作用？ | 指明“表层画面—深层象征/反衬—情感”三层关系。 |
| 用典 | 两个典故有何作用？ | 典故人物 + “先困后显”经历 + 诗人的受任期待。 |
| 情感起伏 | 为什么说诗歌结尾并非突兀乐观？ | 联系前文多次受阻与迷惘，说明结尾是坚持理想后的主动选择。 |
| 主旨概括 | 概括诗人情感或人生观 | “苦闷迷惘”与“乐观进取”必须兼顾。 |
| 比较阅读 | 与其他励志/贬谪诗比较 | 先分别写情感，再比较表达方式或精神底色；不可只罗列名句。 |
| 开放表达 | 面对挫折得到什么启示？ | 紧扣诗句和现实：承认困难、明确目标、采取行动、保持信心。 |

### 诗歌赏析简答模板

**手法题：** “……运用______手法，写出了______的画面/情境；突出了______，表达了诗人______的情感（或使诗歌______）。”

**情感题：** “诗人先因______而______，又借______表现______；最后以______表明______。全诗表现了______。”

**主旨题参考答案：** 本诗写诗人在盛宴中无心进食、前行时遭遇冰雪阻隔的处境，表现政治理想受阻、壮志难酬时的苦闷和迷惘；又借古人典故和“长风破浪”的想象，表达了不甘沉沦、坚持理想、勇于进取的豪迈信念。

## 八、复习清单（考前一分钟）

- 通假：**羞通“馐”**，**直通“值”**（“直万钱”）。
- 两处“直”：**直万钱＝价值**；**直挂＝径直、高高地**。
- 两层象征：**冰塞川、雪满山**表面写险景，深层写仕途/人生受阻。
- 两个“先困后显”典故：**姜尚、伊尹**；结尾还化用**宗悫**“乘长风破万里浪”。
- 情感主线：**苦闷—迷惘—期待—再度迷惘—坚定**。
- 默写易错：**樽、羞、箸、茫、塞、行、歧、帆、济、沧**。
