# 《石壕吏》知识点与中考考点详解

## 一、文学常识

| 项目 | 内容 |
|------|------|
| 作者 | 杜甫（712—770），字子美，自号少陵野老，河南巩县（今河南巩义）人 |
| 朝代 | 唐代 |
| 身份 | 伟大的现实主义诗人，被后世尊称为"诗圣"，其诗被称为"诗史" |
| 代表作 | "三吏"（《石壕吏》《新安吏》《潼关吏》）、"三别"（《新婚别》《无家别》《垂老别》）、《春望》《茅屋为秋风所破歌》《望岳》等 |
| 体裁 | 五言古诗（叙事诗） |
| 写作背景 | 唐肃宗乾元二年（759年）春，杜甫由左拾遗贬为华州司功参军。当时安史之乱尚未平定，唐军在邺城（今河南安阳）大败，朝廷为补充兵力，沿途强行拉壮丁。杜甫从洛阳返回华州途中，亲眼目睹了这一惨状，写下了"三吏三别"组诗 |
| 出处 | "三吏三别"组诗之一 |

## 二、原文及逐句翻译

### 第一层（第1—4句：投宿遇捉人）

> 暮投石壕村，有吏夜捉人。老翁逾墙走，老妇出门看。

**逐句翻译：**
- **暮投石壕村** —— 傍晚（我）投宿到石壕村。
- **有吏夜捉人** —— 有差役在夜里来抓人（充军）。
- **老翁逾墙走** —— 老翁翻过墙逃走了。
- **老妇出门看** —— 老妇人出门去查看（应对）。

### 第二层（第5—16句：老妇致词）

> 吏呼一何怒！妇啼一何苦！

**翻译：** 差役吼叫得多么凶狠！老妇人哭泣得多么悲苦！

> 听妇前致词：三男邺城戍。一男附书至，二男新战死。存者且偷生，死者长已矣！

**翻译：** （我）听到老妇人走上前去对差役说：我的三个儿子都去邺城防守了。一个儿子捎信回来（说），另外两个儿子最近战死了。活着的人姑且苟活着，死了的人就永远完了！

> 室中更无人，惟有乳下孙。有孙母未去，出入无完裙。

**翻译：** 家里再也没有别的男人了，只有一个还在吃奶的孙子。（因为）有孙子，他的母亲还没有离去，（但她）出出进进没有一件完整的衣服。

> 老妪力虽衰，请从吏夜归，急应河阳役，犹得备晨炊。

**翻译：** 老妇人我虽然年老力衰，但请让我跟你连夜赶回去，赶快到河阳去服役，还来得及为军队准备明天的早饭。

### 第三层（第17—20句：凄惨结局）

> 夜久语声绝，如闻泣幽咽。天明登前途，独与老翁别。

**翻译：** 夜深了，说话的声音消失了，隐约听到有人低声哭泣。天亮后（我）登程赶路，只能与老翁一个人告别。

## 四、诗歌结构与层次

| 层次 | 诗句 | 内容概括 | 叙事角度 |
|------|------|---------|---------|
| 第一层（1—4句） | 暮投石壕村……老妇出门看 | 投宿石壕村，遇到差役夜间抓人 | 诗人（目击者）叙述 |
| 第二层（5—16句） | 吏呼一何怒……犹得备晨炊 | 老妇人悲苦致词，自请服役 | 诗人"听"——老妇人自述 |
| 第三层（17—20句） | 夜久语声绝……独与老翁别 | 深夜凄凉，天明独别 | 诗人（感受者）叙述 |

**全诗线索：** 以诗人的**见闻感受**为线索（暮—夜—夜久—天明），按时间顺序展开叙事。

## 五、内容理解

### （一）人物形象分析

#### 1. 老妇人形象

| 特征 | 原文依据 | 分析 |
|------|---------|------|
| 家庭悲惨 | "三男邺城戍""二男新战死" | 三个儿子全部被征兵，两个已战死，家破人亡 |
| 极度贫困 | "出入无完裙" | 儿媳连完整的衣服都没有，家境极其贫困 |
| 善良坚韧 | "有孙母未去" | 为了孙子留住儿媳，承受着巨大的悲痛 |
| 自我牺牲 | "老妪力虽衰，请从吏夜归" | 年老力衰仍主动请缨服役，牺牲自己保全家人 |

#### 2. 差役形象

| 特征 | 原文依据 | 分析 |
|------|---------|------|
| 凶狠蛮横 | "吏呼一何怒" | 深夜抓人，大声呵斥，毫无人性 |
| 冷酷无情 | 最终带走老妇 | 面对老妇人的血泪哭诉，仍然不肯放过 |

#### 3. 诗人（杜甫）形象

| 特征 | 原文依据 | 分析 |
|------|---------|------|
| 同情百姓 | "如闻泣幽咽" | 深夜难眠，听到哭声，内心充满悲痛和同情 |
| 无奈沉痛 | "独与老翁别" | 一个"独"字饱含无限凄凉和无奈 |
| 忠实记录 | 全诗以目击者身份叙述 | 如实记录战乱中百姓的苦难，体现"诗史"本色 |

### （二）主旨与思想

**中心思想：** 本诗通过叙述诗人亲眼所见的石壕村差役趁夜捉人、老妇人被迫自请服役的悲惨遭遇，深刻揭露了安史之乱给人民带来的深重灾难，表达了诗人对劳动人民的深切同情，对战乱的强烈控诉。

**深层理解：**
- 诗人的矛盾心理：杜甫一方面深切同情人民的苦难，另一方面又理解朝廷平叛的需要（当时唐军确实急需兵力），因此全诗只叙事不议论，将复杂的情感蕴含在客观叙述之中，让读者自己去感受和思考。
- "诗史"价值：全诗以真实事件为基础，用叙事诗的形式反映了安史之乱中人民被强征入伍的社会现实，具有极高的历史文献价值。
- 诗中没有一句直接议论或抒情，完全靠叙事和描写来传达思想感情，这是"寓情于叙"的典范。

## 六、写作手法

| 手法 | 分析 |
|------|------|
| 叙事为主，融情于事 | 全诗以叙事为主，不直接议论或抒发感情，将深沉的悲愤之情融入客观叙述之中，使读者在了解事件的同时感受到强烈的情感冲击 |
| 明暗线交织（藏问于答） | 明线是老妇人的致词，暗线是差役的步步逼问。诗中只写老妇的回答，差役的追问隐含其中（如"室中更无人"是回答差役追问还有没有别人），手法巧妙 |
| 对比手法 | ①"吏呼一何怒！妇啼一何苦！"——差役的凶狠与老妇的悲苦形成鲜明对比；②开头"暮投"的平静与夜间抓人的惊恐对比；③"独与老翁别"——来时一家人，走时只剩老翁，前后对比凄凉 |
| 侧面描写（间接描写） | 差役的凶残不直接描写，而是通过老妇人的致词和行为侧面表现；老翁翻墙逃走侧面表现捉人之恐怖 |
| 以时间为序 | "暮—夜—夜久—天明"，时间线清晰，叙事紧凑 |
| 语言质朴自然 | 不用华丽辞藻，如实描述，朴素中见深情，体现杜甫"沉郁顿挫"的风格 |
| 首尾照应 | 开头"暮投石壕村"交代故事背景，结尾"天明登前途，独与老翁别"收束全文，首尾呼应，结构完整 |

## 七、"藏问于答"手法详解

这是本诗最突出的艺术特色，也是中考高频考点。

全诗只写了老妇人的回答，差役的追问虽然没有直接写出来，但从老妇人的应答中可以推断出来：

| 老妇人的致词 | 暗含差役的追问 |
|-------------|---------------|
| "三男邺城戍" | （差役：你家有男丁吗？） |
| "一男附书至，二男新战死" | （差役：他们在哪？让他们出来！） |
| "存者且偷生，死者长已矣" | （老妇悲痛哀求：他们已经死了啊！） |
| "室中更无人，惟有乳下孙" | （差役：家里还有别人吗？把人交出来！） |
| "有孙母未去，出入无完裙" | （差役：那个女的呢？让她去！） |
| "老妪力虽衰，请从吏夜归" | （差役仍不罢休，老妇被迫自请服役） |

**艺术效果：** 这种写法省去了差役的话，让读者自行想象差役的凶狠逼问，留下了巨大的想象空间，比直接描写差役更加深刻有力。

## 九、中考高频考点总结

### 考点一：重点字词解释
常考词：投、逾、走（古今异义）、一何、前（词类活用）、致词、戍、附书、新、且、偷生、已、更、惟、妪、裙（古今异义）、犹得、绝、幽咽、前途（古今异义）、独。

### 考点二：古今异义辨析
常考词：走、致词、裙、前途、已、新。

### 考点三：内容理解
1. **"有吏夜捉人"中"夜"和"捉"反映了什么？**（"夜"说明差役趁人不备，"捉"说明强制性，不给百姓选择，揭露了官吏的凶残和百姓的恐惧。）
2. **老妇人致词的内容可分为几层？**（三层：家中男丁全部上阵且大部分战死→家中穷困至极→自请服役。）
3. **"独与老翁别"的"独"字有什么深意？**（来时老翁、老妇都在，走时只能与老翁一人告别，说明老妇已被带走，"独"字凝聚了凄凉、悲愤和无奈。）

### 考点四：写作手法赏析
- **藏问于答**：全诗只写老妇的回答，暗含差役的逼问。
- **对比**："吏呼一何怒！妇啼一何苦！"
- **侧面描写**：通过老妇致词侧面表现差役凶残。
- **融情于事**：全诗无一句议论抒情，情感全部融入叙事中。

### 考点五：人物形象分析
- 老妇人：悲苦、善良、坚韧、自我牺牲。
- 差役：凶残、蛮横、冷酷无情。
- 杜甫：同情人民、忠实记录、沉痛无奈。

### 考点六：句子赏析
高频赏析句：
1. "吏呼一何怒！妇啼一何苦！"——对比、感叹，揭示矛盾冲突。
2. "夜久语声绝，如闻泣幽咽。"——以声衬静，渲染凄凉氛围。
3. "天明登前途，独与老翁别。"——"独"字含义深远，收束全文。

### 考点七：开放性探究
- 你如何看待老妇人"自请服役"这一行为？
- 杜甫在诗中为什么不直接站出来阻止差役？
- 本诗被称为"诗史"，你如何理解这一评价？
- 结合当时背景，谈谈杜甫的矛盾心理。

### 考点八：比较阅读
常与以下篇目对比：
- 《茅屋为秋风所破歌》（杜甫）——忧国忧民思想
- 《春望》（杜甫）——安史之乱背景
- 《新安吏》《潼关吏》——"三吏"对比
- 《卖炭翁》（白居易）——底层人民苦难
