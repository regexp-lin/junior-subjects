# 《水调歌头·明月几时有》知识点与中考考点详解

> 适用对象：初中九年级上册  
> 资料定位：课内精讲 + 中考一轮复习  
> 说明：本资料以统编版课文《水调歌头（明月几时有）》为依据整理。中考考点是对常见命题方式的归纳，不把推测性理解当作唯一答案。

---

## 一、先读懂全词

### 1. 题目、作者与背景

| 项目 | 内容 |
|---|---|
| 作者 | 苏轼（1037—1101），字子瞻，号东坡居士，北宋文学家、书画家。 |
| 体裁 | 词。词一般有词牌名；“水调歌头”是词牌名，“明月几时有”常用来作为这首词的题目或首句提示。 |
| 写作时间 | 丙辰年中秋，即宋神宗熙宁九年（1076）。 |
| 写作地点与处境 | 苏轼当时在密州任职；中秋对月，思念长期不能相见的弟弟苏辙（字子由），写下此词。 |
| 小序 | “丙辰中秋，欢饮达旦，大醉，作此篇，兼怀子由。”交代作词时间、饮酒情境和“怀子由”的缘由，是理解全词情感的重要钥匙。 |
| 名句 | “人有悲欢离合，月有阴晴圆缺，此事古难全。”“但愿人长久，千里共婵娟。” |

> **易错提醒：** 苏轼是北宋人，不是南宋人；“子由”是苏轼弟弟苏辙的字。“水调歌头”是词牌名，不能答成文章题目或作者字号。

### 2. 原文、朗读停顿与整体译文

> 丙辰中秋，欢饮达旦，大醉，作此篇，兼怀子由。  
> 明月/几时有？把酒/问青天。不知/天上宫阙，今夕/是何年。  
> 我欲/乘风归去，又恐/琼楼玉宇，高处/不胜寒。  
> 起舞/弄清影，何似/在人间。  
> 转/朱阁，低/绮户，照/无眠。  
> 不应/有恨，何事/长向/别时圆？  
> 人有/悲欢离合，月有/阴晴圆缺，此事/古难全。  
> 但愿/人长久，千里/共婵娟。

**整体译文：**

丙辰年中秋节，我高兴地喝酒直到天亮，喝得大醉，写下这首词，同时思念弟弟子由。明月从什么时候才有的呢？我端着酒杯问青天。不知道天上的宫殿，今晚又是哪一年。我想要乘着清风回到天上去，却又担心月宫中美玉砌成的楼宇太高太冷，自己经受不住那里的寒冷。起身跳舞，玩赏自己在月光下清朗的影子，哪里比得上在人间呢？

月光转过朱红的楼阁，低低地照进雕花的门窗，照着不能入睡的人。月亮本不该有什么怨恨，为什么总是在亲人离别时圆满呢？人本来就有悲伤、欢乐、离别、团聚，月亮也有阴晴圆缺，这样的事情自古以来就难以十全十美。只希望人们能够长久平安，即使相隔千里，也能共同欣赏这美好的月光。

> **译文提醒：** “归去”在这里是回到天上，并非简单地“回家”；“无眠”可理解为因离愁等而不能入睡的人；“婵娟”本指姿态美好，这里指明月。

## 二、逐句精讲

### 1. 小序：交代写作缘由，定下“怀人”基调

**原文：** 丙辰中秋，欢饮达旦，大醉，作此篇，兼怀子由。

- “丙辰”是干支纪年；“达旦”是到天亮。
- “欢饮”“大醉”写饮酒的外在状态；“兼怀子由”直接点出思念弟弟，是全词情感的落点。
- 小序看似简短，却补足了时间、节日、情境和写作缘由。答“为何写此词”“词中主要思念谁”时，应优先使用小序信息。

### 2. “明月几时有？把酒问青天”：由月发问，开阔奇崛

- 中秋望月，词人不直接说“我想念弟弟”，而向“青天”发问，想象从人间伸向宇宙。
- “几时有”不是求科学答案，而是借问表达对明月和宇宙的好奇、对人生的感慨。
- “把酒问青天”化用李白《把酒问月》“青天有月来几时？我今停杯一问之”的问月构思；中考答题可写“化用前人诗意”，不要把它误说成照抄。

### 3. “不知天上宫阙，今夕是何年”：想象天上，亦含人间感慨

- “宫阙”指宫殿；“今夕是何年”表面上问天上岁月，实际写出词人对现实人生的感触和恍惚感。
- 连续设问使开篇带有浪漫的想象色彩，也为下文“欲归去”作铺垫。

### 4. “我欲乘风归去，又恐琼楼玉宇，高处不胜寒”：向往与犹疑

- “乘风归去”承接前文天上想象，写词人想摆脱尘世、飞向天上的愿望。
- “又恐”陡转：天上虽美，却“高处不胜寒”。“不胜”是经受不住、承受不了。
- 这里首先可按字面理解为高空严寒；联系苏轼的仕途处境，有些赏析会把“高处”进一步理解为高位或政治环境的象征。若题目只要求概括文本情感，答“对天上世界的向往与担忧交织”即可；只有题目要求结合背景时，再谨慎补充“隐约寄寓仕途感受”。

### 5. “起舞弄清影，何似在人间”：由矛盾到自我安顿

- “弄”是玩赏；“清影”是月光下清晰的身影。
- “何似”意为“哪里比得上”。词人起舞赏影，最终发现人间生活自有温暖和真实可亲之处。
- 此句是上阕的转折和收束：从想“归去”转为肯定“在人间”，表现出旷达、自我调适的力量。

### 6. “转朱阁，低绮户，照无眠”：月移人未眠，景中含情

- “朱阁”是朱红色的楼阁；“绮户”是雕饰华美的门窗。“转”“低”从月光移动的角度写时间流逝。
- 三个动词“转、低、照”连用，写月光由高到低、穿楼入户的动态，也写出月色无处不在。
- “无眠”不必只限定为苏轼一人，可理解为词人与一切因离愁而不能入睡的人。月光照人，也照出怀人之情。

### 7. “不应有恨，何事长向别时圆？”：表面怨月，实为怀人

- “不应有恨”并非真的认为月亮有情有恨，而是把月亮人格化，故意责问。
- “何事长向别时圆”是反问：为什么偏在亲人离别时圆满呢？
- 这两句运用**拟人、反问、移情于物**：词人把不能团聚的遗憾投射到月亮上，含蓄而强烈地表现思念和离愁。

### 8. “人有悲欢离合，月有阴晴圆缺，此事古难全”：由个人愁绪升华为人生哲理

- “悲欢离合”概括人生中的情感变化，“阴晴圆缺”概括月亮的自然变化。
- 两组并列短语形成对偶，把人事与自然相联结，说明人生有缺憾是普遍规律。
- “古难全”不是悲观消沉，而是承认“难以两全”的现实，为下文自我劝慰、宽慰他人作铺垫。

### 9. “但愿人长久，千里共婵娟”：以祝愿收束，情感由小我走向众人

- “但愿”表示真诚的希望；“人长久”指亲人朋友平安长久，并非单指长生不老。
- “共婵娟”指虽相隔千里，仍可共同欣赏一轮明月，获得精神上的相通。
- 结尾把对弟弟的思念转化为对天下离别之人的美好祝愿，情感由低回转为温暖、旷达，使全词余味悠长。

## 三、重点字词、句式与易错点

### （一）重点词语

| 词语 | 课内义项 | 易错提醒 |
|---|---|---|
| 丙辰 | 干支纪年 | 不必硬译为具体日期，但要知道是1076年。 |
| 达旦 | 到天亮 | “旦”是天亮、早晨。 |
| 把酒 | 端起酒杯 | “把”是持、执，不是量词。 |
| 宫阙 | 宫殿 | “阙”读 *què*。 |
| 归去 | 回到天上去 | 承接“天上宫阙”，不能译成回故乡。 |
| 琼楼玉宇 | 美玉砌成的楼宇，指想象中的月中宫殿 | 形容华美、清冷的天上世界。 |
| 不胜 | 经受不住、承受不了 | 读 *shēng*，不是“胜利”。 |
| 弄 | 玩赏 | “弄清影”不是“使影子清楚”。 |
| 何似 | 哪里比得上 | 表反问语气。 |
| 朱阁 | 朱红色的楼阁 | “朱”写颜色。 |
| 绮户 | 雕饰华美的门窗 | “绮”读 *qǐ*。 |
| 无眠 | 不能入睡的人 | 可泛指离愁中的人。 |
| 何事 | 为什么 | 不是“什么事情”。 |
| 长向 | 总是朝着、偏向 | “向”在这里是“朝着”。 |
| 此事 | 人有悲欢离合、月有阴晴圆缺这类事 | 指代前文，不可漏译。 |
| 难全 | 很难十全十美 | “全”是圆满、齐全。 |
| 人长久 | 人平安长久 | 不等同于“永远不死”。 |
| 婵娟 | 美好的样子；这里指明月 | 读 *chán juān*。 |

### （二）常见句式和修辞

| 类型 | 例句 | 理解或表达作用 |
|---|---|---|
| 设问 | 明月几时有？把酒问青天。 | 引出对月的遐想，开篇奇崛。 |
| 反问 | 何似在人间。 | 突出人间胜过清冷天宫的选择。 |
| 反问、拟人 | 不应有恨，何事长向别时圆？ | 怨月实为思人，写离愁。 |
| 对偶 | 人有悲欢离合，月有阴晴圆缺。 | 句式整齐，把人事与自然相联结。 |
| 想象 | 天上宫阙、琼楼玉宇 | 拓展意境，形成浪漫色彩。 |
| 借景抒情 | 转朱阁，低绮户，照无眠。 | 月色移动烘托不眠人的离愁。 |
| 移情于物 | 月亮“有恨”“向别时圆” | 把人的情感投射给月亮，含蓄地写相思。 |

### （三）需要准确翻译的句子

| 原句 | 翻译要点 |
|---|---|
| 明月几时有？把酒问青天。 | 把：端起；青天：青色的天空。 |
| 我欲乘风归去，又恐琼楼玉宇，高处不胜寒。 | 欲：想要；归去：回到天上；恐：担心；不胜：经受不住。 |
| 起舞弄清影，何似在人间。 | 弄：玩赏；何似：哪里比得上。 |
| 转朱阁，低绮户，照无眠。 | 转、低、照的主语均是月光/月亮；无眠：不能入睡的人。 |
| 不应有恨，何事长向别时圆？ | 何事：为什么；长向：总是朝着；别时：离别的时候。 |
| 人有悲欢离合，月有阴晴圆缺，此事古难全。 | 此事：人世与自然难得圆满的情形；全：圆满。 |
| 但愿人长久，千里共婵娟。 | 但愿：只希望；长久：平安长久；婵娟：明月。 |

> **翻译方法：** 先找出每句的主语和关键词，再补足省略内容。如“转朱阁，低绮户，照无眠”的主语不是“人”，而是月亮或月光；译为“月光转过朱红的楼阁，低低地照进雕花的门窗，照着不能入睡的人”。

## 四、结构、情感与主旨

### （一）上下阕层次

| 部分 | 内容层次 | 情感变化 |
|---|---|---|
| 上阕前四句 | 问月、想象天上宫阙 | 对宇宙和人生的好奇、感慨。 |
| 上阕中三句 | 想“归去”，又怕高处寒冷 | 向往与犹疑、矛盾交织。 |
| 上阕结尾 | 起舞赏影，问“何似在人间” | 自我排遣，转向对人间生活的肯定。 |
| 下阕前三句 | 月光照楼入户，照见无眠人 | 由写景转入怀人，离愁加深。 |
| 下阕中两句 | 怨月、问月 | 思念亲人而不能相聚的惆怅。 |
| 下阕后两句 | 认识缺憾、送出祝愿 | 由感伤走向旷达，以祝福超越离别。 |

### （二）全词的情感脉络

可以用下面这条线索概括：

`中秋对月、思念子由 → 由月问天、向往天上 → 欲去又恐、回到人间 → 月照无眠、离愁难遣 → 理解人生难全 → 祝愿亲人、旷达收束`

答情感题时，不宜只答“思念弟弟”或只答“旷达乐观”。更完整的答案应写出：词人有中秋不能与亲人团聚的思念和惆怅，也能主动排遣愁绪、认识人生难以十全十美，最后以祝愿表现出旷达、乐观和对亲人的深厚情意。

### （三）中心思想

这首词以中秋明月为线索，先写对月问天和天上人间的想象，再写月光照无眠者、因离别而怨月，最后由月的圆缺联想到人生的悲欢离合。作品表达了对弟弟子由的深切思念，也表现了词人在面对人生缺憾时能够自我开解、旷达乐观的胸襟，以及对天下离别之人的美好祝愿。

### （四）赏析中的“答题边界”

| 常见说法 | 是否可用 | 更稳妥的表达 |
|---|---|---|
| 全词只写思念弟弟 | 不完整 | 思念子由是直接缘由，还写人生感慨和旷达祝愿。 |
| “高处不胜寒”一定是仕途失意 | 表述过满 | 可先解释字面“天上高处寒冷”；结合背景时，可说“也常被理解为隐约寄寓对高位、仕途环境的感受”。 |
| “何似在人间”是厌弃人间 | 错误 | 反问表示“哪里比得上人间”，是对人间生活的肯定。 |
| “不应有恨”是词人真的责怪月亮 | 不准确 | 月本无情，词人借拟人化的怨月寄托不能团聚的遗憾。 |
| “人长久”就是长生不老 | 片面 | 在祝愿语境中，应理解为亲人平安、长久。 |

## 五、写作特色与赏析模板

### （一）写作特色

| 手法 | 词句依据 | 表达效果 |
|---|---|---|
| 想象瑰丽、境界开阔 | “把酒问青天”“琼楼玉宇” | 从中秋小我之愁写到天上人间、宇宙人生，意境宏阔。 |
| 情景交融 | “转朱阁，低绮户，照无眠” | 月光的移动与人的无眠相映衬，景物承载离愁。 |
| 叙述、抒情、议论结合 | 从饮酒问月到“此事古难全” | 由个人情绪自然提升为人生思考，感情真挚而不消沉。 |
| 转折起伏 | “我欲……又恐……何似……” | 写出向往、犹疑、选择的心理过程，增强词意的张力。 |
| 比照联想 | “人有……月有……” | 将人事的聚散和月相变化并列，说明人生难全的普遍性。 |
| 以祝愿作结 | “但愿人长久，千里共婵娟” | 将私人思念扩展为普遍祝愿，意境温暖、余味悠长。 |

### （二）常用赏析答题句式

1. **炼字题：** “`×`”字写出……（画面/动态），表现了……，烘托或表达了……。
2. **写景题：** 这几句写……景，运用……手法，营造……氛围，衬托词人……心情。
3. **情感题：** 词句先写……，再写……；既表现……，又表现……。其中“……”是判断的文本依据。
4. **哲理题：** 句子把……与……相联结，说明……；它启示我们……，但不等于……。
5. **名句题：** 先准确解释字面，再写“在本词中”表达的情感或思想，最后结合生活简要说明。

## 七、背诵、默写与答题易错提醒

1. **字形：** “宫阙”的“阙”不要写成“缺”；“绮户”的“绮”不要写成“倚”；“婵娟”不要写成“蝉娟”。
2. **词序：** 是“转朱阁，低绮户，照无眠”，不是“照朱阁”；是“月有阴晴圆缺”，不要漏“阴晴”。
3. **上下阕：** “我欲乘风归去”属于上阕；“人有悲欢离合”属于下阕。
4. **情感：** “欢饮达旦”不能证明全词只有欢乐；“欢饮”之后仍有“兼怀子由”的思念和“无眠”的离愁。
5. **赏析：** 写“借景抒情”后要具体说明借了什么景、抒了什么情，不能只套术语。
6. **开放题：** 使用“人有悲欢离合……”时，要写清它劝人正视缺憾、珍惜情感，不可曲解为面对遗憾就什么也不做。

## 八、考前一分钟自测

- 我能说清“水调歌头”与“明月几时有”分别是什么吗？
- 我能把“何似”“不胜”“婵娟”解释准确吗？
- 我能翻译“转朱阁，低绮户，照无眠”并补出主语吗？
- 我能用“思念 + 自我排遣 + 旷达祝愿”概括全词情感吗？
- 我默写“人有悲欢离合……”时会不会漏掉“阴晴”或“此事古难全”？
