# 《茅屋为秋风所破歌》知识点与中考考点详解

## 一、文学常识

| 项目 | 内容 |
|------|------|
| **作者** | 杜甫（712—770），字子美，自号少陵野老，世称“杜工部”“杜少陵”等。 |
| **生平要点** | 生于河南巩县；早年漫游，困居长安十年；安史之乱中颠沛流离，曾被俘又脱险；后入蜀依附严武等，晚年漂泊湘鄂一带，病逝于舟中。其诗深刻反映时代，被誉为“诗史”。 |
| **朝代** | 唐代（盛唐向中唐过渡时期，此诗作于唐肃宗上元二年，即761年）。 |
| **身份** | 现实主义诗人；与李白并称“李杜”；被尊为“诗圣”。 |
| **代表作** | 《三吏》《三别》《春望》《登高》《望岳》《石壕吏》《闻官军收河南河北》等。 |
| **体裁** | **古体诗**中的**歌行体**（乐府歌行一类，题目常带“歌”“行”“吟”等）。 |
| **歌行体特点** | ①篇幅可长可短，句式灵活，多用七言，杂以三言、九言等；②押韵较自由，可换韵；③叙事、抒情、议论结合，气势跌宕；④语言质朴自然，便于铺陈事件、抒发胸臆。本诗即典型歌行：以叙事开篇，层层推进，末段直抒理想，情感由抑到扬。 |
| **写作背景（成都草堂）** | 759年冬，杜甫携家避乱入蜀，次年春在成都西郊浣花溪畔营建**草堂**（即后世所称“杜甫草堂”），得亲友资助，暂得栖身。上元元年（760）春草堂落成，诗人一度生活稍安，仍清贫。761年八月，一场大风掀去屋顶茅草，又逢夜雨，屋漏床湿，全家难以安眠。诗人由自身饥寒想到战乱中流离的百姓，遂作此诗。背景要点：**①草堂是诗人入蜀后相对稳定的居所，但经济上仍拮据；②“安史之乱”余波未平，社会动荡，“丧乱”之痛仍在；③由“茅屋被破”这一具体生活灾难，升华为“大庇天下寒士”的博大情怀。** |

## 二、原文及逐句翻译

### 第一段：秋风卷茅，茅飞四散

> 八月秋高风怒号，卷我屋上三重茅。茅飞渡江洒江郊，高者挂罥长林梢，下者飘转沉塘坳。

**逐句翻译**

| 诗句 | 译文 |
|------|------|
| 八月秋高风怒号 | 八月秋深，天空高远，狂风怒吼呼啸。 |
| 卷我屋上三重茅 | （狂风）把我屋顶上多层茅草卷走。 |
| 茅飞渡江洒江郊 | 茅草飞过江去，散落在江边原野上。 |
| 高者挂罥长林梢 | 飞得高的（茅草）缠绕挂在高高的树梢上。 |
| 下者飘转沉塘坳 | 飞得低的（茅草）飘飘转转，沉落在低洼的水塘里。 |

### 第二段：群童抱茅，诗人无奈

> 南村群童欺我老无力，忍能对面为盗贼。公然抱茅入竹去，唇焦口燥呼不得，归来倚杖自叹息。

**逐句翻译**

| 诗句 | 译文 |
|------|------|
| 南村群童欺我老无力 | 南村的一群孩子欺负我年老体弱、没有力气。 |
| 忍能对面为盗贼 | （他们）竟忍心当着我的面像做贼一样（抢茅草）。 |
| 公然抱茅入竹去 | 明目张胆地抱着茅草跑进竹林去了。 |
| 唇焦口燥呼不得 | （我）喊得唇干舌燥也喝止不住他们。 |
| 归来倚杖自叹息 | 只好回来拄着拐杖，独自叹息。 |

### 第三段：夜雨屋漏，长夜难眠

> 俄顷风定云墨色，秋天漠漠向昏黑。布衾多年冷似铁，娇儿恶卧踏里裂。床头屋漏无干处，雨脚如麻未断绝。自经丧乱少睡眠，长夜沾湿何由彻！

**逐句翻译**

| 诗句 | 译文 |
|------|------|
| 俄顷风定云墨色 | 不一会儿风停了，天空乌云如墨。 |
| 秋天漠漠向昏黑 | 深秋的天空阴沉迷蒙，渐渐逼近昏黑。 |
| 布衾多年冷似铁 | 布被盖了多年，冰冷得像铁块一样。 |
| 娇儿恶卧踏里裂 | 小孩子睡相不好，把被里蹬破了。 |
| 床头屋漏无干处 | 床头屋顶漏雨，没有一处是干的。 |
| 雨脚如麻未断绝 | 雨点密得像麻线一样，连绵不断。 |
| 自经丧乱少睡眠 | 自从经历战乱以来就很少能安稳睡觉。 |
| 长夜沾湿何由彻 | 在这漫漫长夜里浑身湿透，怎样才能熬到天亮！ |

### 第四段：广厦之愿，舍己为人

> 安得广厦千万间，大庇天下寒士俱欢颜！风雨不动安如山。呜呼！何时眼前突兀见此屋，吾庐独破受冻死亦足！

**逐句翻译**

| 诗句 | 译文 |
|------|------|
| 安得广厦千万间 | 怎样才能得到千万间宽敞的大屋。 |
| 大庇天下寒士俱欢颜 | 普遍庇护天下贫寒的读书人，让他们都露出欢喜的容颜。 |
| 风雨不动安如山 | （让他们住在里面）风吹雨打都安稳得像山一样。 |
| 呜呼 | 唉——（感叹词，抒愤激与深情）。 |
| 何时眼前突兀见此屋 | 什么时候眼前能突然出现这样的房屋。 |
| 吾庐独破受冻死亦足 | 即使只有我的茅屋独自破损、我受冻而死，也心甘情愿！ |

## 四、诗歌结构与层次

| 层次 | 诗句（节选） | 内容概括 | 表达方式 |
|------|----------------|----------|----------|
| 第一层 | 八月秋高……沉塘坳 | 秋风破屋，茅草被卷、四散难收 | 叙事、描写（景物与动作） |
| 第二层 | 南村群童……自叹息 | 群童抱茅，诗人年老无力、无可奈何 | 叙事、描写，暗含抒情 |

| 第四层 | 安得广厦……死亦足 | 由己及人，抒发广厦庇寒士之愿 | 抒情、议论，升华主旨 |

## 五、内容理解

### （一）各段内容分析

1. **第一段**：以“风怒号”起势，写风之狂、茅之飞、落点之高下悬殊，渲染灾难突至的紧张与诗人的无力，为全诗奠定悲凉的叙事基调。  
2. **第二段**：由自然之灾写到“人”——群童“抱茅入竹”。诗人用“欺”“盗贼”等语，表面似责童，实则反映民生困苦（童亦贫）；“呼不得”“自叹息”突出老弱之悲。  
3. **第三段**：风定云墨、向昏黑，氛围转压抑；布衾冷铁、屋漏床湿、雨脚如麻，层层写寒苦之状；“自经丧乱少睡眠”把个人苦难与时代战乱联系，深化悲剧内涵。  
4. **第四段**：情感陡转升华，由“吾庐之破”扩展到“天下寒士”，提出“广厦千万间”的理想，并以“吾庐独破受冻死亦足”作结，表现舍己为人的人道主义精神。

### （二）主旨与思想

- **表层**：记叙茅屋为秋风所破、夜雨难眠的经历。  
- **深层**：反映战乱年代底层知识分子与百姓的苦难生活；表达诗人忧国忧民的情怀与推己及人的博大胸襟。  
- **核心名句的思想**：由个人不幸上升到对社会公平的呼唤，体现了杜甫**仁爱精神**与**现实主义**关怀，是中华传统文化中“民胞物与”思想的生动体现。

## 六、写作手法

| 手法 | 说明 | 文中体现（举例） |
|------|------|------------------|
| 叙事抒情结合 | 以真实事件为线索，寓情于事 | 从卷茅、群童抱茅到屋漏、抒怀，一线贯穿 |
| 铺陈渲染 | 层层加码写困境 | 风→茅飞→童抱茅→云墨→衾冷→屋漏→雨脚如麻 |
| 比喻 | 化抽象为具体 | 布衾多年**冷似铁**；雨脚如**麻** |
| 夸张 | 强化情感与理想 | **广厦千万间**；吾庐独破受冻死亦**足** |
| 双关/跌宕 | 情感起伏 | 由叹息到“呜呼”，再振起博大之愿 |
| 直抒胸臆 | 篇末点破情怀 | 安得广厦千万间……大庇天下寒士俱欢颜 |
| 环境描写 | 烘托气氛 | 风怒号、云墨色、秋天漠漠向昏黑 |
| 细节描写 | 增强真实感 | 娇儿恶卧踏里裂；唇焦口燥呼不得 |

## 八、中考高频考点总结

### 考点一：文学常识

作者、朝代、尊称（诗圣）、作品集称（诗史）、体裁（古体诗·歌行体）、创作年代与**成都草堂**背景。

### 考点二：默写与字词

全文关键句默写；易错字：**罥、坳、盗贼、俄顷、漠漠、布衾、恶卧、丧乱、庇、突兀、见（通现）** 等。

### 考点三：句子翻译

尤其：**忍能对面为盗贼**、**归来倚杖自叹息**、**自经丧乱少睡眠，长夜沾湿何由彻**、**大庇天下寒士俱欢颜**、**吾庐独破受冻死亦足**。

### 考点四：内容与层次

四段各写什么；情感由**悲苦无奈**到**忧国忧民、舍己为人**的变化。

### 考点五：主旨情感

由己及人；对天下寒士的关怀；反映战乱现实；博大胸襟与高尚人格。

### 考点六：名句赏析

“安得广厦千万间，大庇天下寒士俱欢颜！风雨不动安如山”——理想、忧民、修辞（夸张、感叹）。  
“吾庐独破受冻死亦足”——对比、直抒胸臆、精神境界。

### 考点七：写作手法

叙事线索、环境烘托、比喻夸张、铺陈与篇末升华等，能结合诗句简析。

### 考点八：拓展与对比

与《石壕吏》《春望》等**现实主义**名篇在题材、情感上的联系；对“仁政”“民生”主题的理解（言之成理、结合文本）。
