## 三、综合性学习：逐题诊断

### （1）选择完全契合“君子自强不息”主题的名言组合（2分）

**学生答案：A，即①④⑤。**

**判断：正确。参考答案：A。**

逐句判断如下：

| 序号与名言 | 核心含义 | 与主题的关系 |
|---|---|---|
| ①君子求诸己，小人求诸人。 | 君子从自身寻找原因、提出要求 | 强调自省、自我要求，符合自强精神 |
| ②知之者不如好之者，好之者不如乐之者。 | 学习中兴趣与乐趣的重要性 | 主要谈学习态度，不直接突出自强不息 |
| ③人不知而不愠，不亦君子乎？ | 别人不了解自己也不恼怒 | 主要谈修养与豁达，不是本题最贴切的主题 |
| ④士不可以不弘毅，任重而道远。 | 志向远大、意志坚强，承担责任 | 符合自强不息、坚毅担当 |
| ⑤不怨天，不尤人。 | 不抱怨上天，不责怪他人 | 强调不推卸、不抱怨，与自强精神契合 |

**如何思考：**

1. 先将主题转化为关键词：**自我要求、意志坚定、主动担当、不怨天尤人**。
2. 判断每句话的中心意思，不要因为一句话“积极向上”或出现“君子”就选入。
3. 本题要求“完全契合”，因此要选每一句都能对应主题的组合。

**遗漏检查：**选择题答案完整，无需另补理由。

### （2）仿照示例补充活动形式（2分）

题目示例：

- 自强标语我来拟
- 自强名言我来读

**学生答案：**

- 自强海报我来画
- 自强歌曲我来唱

**判断：正确，可原样保留。**

两项活动都围绕“自强”，活动明确、可以开展；“海报—画”“歌曲—唱”搭配合理，句式也与示例一致。

**参考答案：**

> 形式三：自强海报我来画。  
> 形式四：自强歌曲我来唱。

也可写“自强故事我来讲”“自强人物我来评”等，但学生现有答案已经符合要求，不必为了不同而改写。

**如何思考：**套用“**自强＋活动对象＋我来＋相应动作**”的结构，同时检查两项活动是否重复、名词和动词是否搭配。

### （3）结合画线内容补写宣传标语下句（2分）

上句：**追求理想彰显爱国精神**。

画线内容主要写：传承伟大使命，先天下之忧而忧，后天下之乐而乐，勇做开拓、进取的时代先锋。

**学生答案：传承使命勇做时代先锋。**

**判断：正确，既概括了材料，也符合仿写要求。**

| 对应部分 | 上句 | 学生下句 |
|---|---|---|
| 前半部分 | 追求理想 | 传承使命 |
| 后半部分 | 彰显爱国精神 | 勇做时代先锋 |
| 字数 | 4字＋6字 | 4字＋6字 |

**参考答案：**

> 传承使命勇做时代先锋。

**如何思考：**

1. 先圈出画线内容的两个核心：**使命、时代先锋**。
2. 将其压缩为“传承使命”“勇做时代先锋”。
3. 与上句检查字数和结构，不能只写内容正确却句式完全不同的长句。

**遗漏检查：**无须把“先天下之忧而忧”等材料内容全部塞进标语，概括到主要意思即可。

### （4）仿照示例列举教材中的自强不息人物（2分）

题目要求：人物限七至九年级语文课本；仿照“邓稼先心怀祖国，鞠躬尽瘁，无愧‘两弹元勋’”举一例。

**学生作答要旨：**鲁迅先生心系国家、以笔为剑，无愧“民族魂”。

**判断：基本正确，可以保留人物和主要表达。**

- 鲁迅属于初中语文教材涉及的人物，人物选择符合范围。
- “以笔为剑”能表现其以写作进行斗争的精神。
- “民族魂”与鲁迅相符，表达方式也与示例基本一致。

**可以优化的地方：**“心系国家”“以笔为剑”偏概括，如果补上一项具体事迹，人物精神会更有支撑。这是提高答案稳妥度的建议，不等于现有答案必定失分。

**参考答案：**

> 鲁迅先生弃医从文，以笔为剑，致力于唤醒国民，无愧“民族魂”。

**如何思考：**

按照“**教材人物＋具体事迹或行动＋精神评价**”组织答案。先想“他具体做了什么”，再提炼“他体现了什么精神”，避免只有“伟大、坚强、爱国”等空泛评价。

### （5）A：修改第①句的标点错误（2分）

原句以“党的二十大报告指出：”引出完整引文，结尾写为：

> ……实现梦想的前景无比光明”。

**学生答案：应去掉双引号。**

**判断：错误。问题不是引号多余，而是句号位置错误。**

**正确修改意见：**

> 将句末的句号移到后引号里面。

也就是：

```text
原来：……实现梦想的前景无比光明”。
改为：……实现梦想的前景无比光明。”
```

这里是冒号后直接引用报告中的完整话语，引号应当保留，完整引文的句末句号放在后引号之前。

**如何思考：**

1. 看前面有没有“说、指出”等提示语及冒号。
2. 看引文是不是独立、完整的句子。
3. 本题属于“提示语＋冒号＋完整引文”，应保留引号，把句号放进引号内。

**要记住：**不能死记“句号永远在引号里”。完整独立引用与作为句子成分的引用，处理不同；本题根据具体结构判断即可。

### （5）B：修改第②句的语病（2分）

原句：

> 许多快递小哥这样的普通劳动者，他们靠自己的勤劳风雨无阻地奔波在路上，提升了千家万户的生活。

**学生修改：**将“提升了千家万户的生活”改为“千家万户的生活得到提升”。

**判断：修改未到位。主动、被动形式变了，但搭配不当仍然存在。**

原句的关键问题是“**提升生活**”搭配不当。改成“**生活得到提升**”，仍然是同一组词搭配，病因没有消除。

**正确修改意见，任选一种即可：**

1. 将“提升”改为“改善”：**改善了千家万户的生活**。
2. 在“生活”后加“质量”：**提升了千家万户的生活质量**。

**推荐订正：**

> 将“提升”改为“改善”。

修改后的句子：

> 许多快递小哥这样的普通劳动者，他们靠自己的勤劳风雨无阻地奔波在路上，改善了千家万户的生活。

**如何思考：**

1. 提取句子主干，重点看“动词＋宾语”：**提升＋生活**。
2. 判断搭配是否合适：“改善生活”合适；“提升生活质量”合适。
3. 按“改动最少、意思不变、病因消除”的原则修改。
4. 改完重读：若原来不搭配的两个词仍在直接搭配，就不能算改好了。

## 四、非连续性文本阅读：先整理材料信息

这组阅读不能只凭对无人机的印象回答，必须以试卷提供的信息为依据。

### 材料一：市场结构图

图表标题为“2025年中国民用无人机细分领域市场规模”。

| 大类 | 细分领域 | 占比 |
|---|---|---:|
| 消费级 | 个人航拍 | 40% |
| 工业级 | 农林植保 | 27% |
| 工业级 | 安防 | 20% |
| 工业级 | 电力巡查 | 7% |
| 工业级 | 其他 | 6% |
| 工业级合计 | 27%＋20%＋7%＋6% | **60%** |

注意：“民用”是这张图的大范围，其中既有消费级，也有工业级，不能把“民用”与“消费级”等同。

### 材料二：创新应用与效率提升

- **高速公路巡查：**能够自动巡查，短时间内完成指定区域任务，提高效率，保障出行安全。
- **无人机＋无人车：**运输衔接更便捷；原来往返3小时的搬运任务，现在大约10分钟即可完成。
- **智慧校园：**针对放学时段监控盲区、夜间光线不足造成的巡查疏漏，使用无人机与热成像技术及时发现异常；还可拓展至运输、活动航拍等方面。

### 材料三：应用和监管短板

- **民用方面：**失联或电池故障可能导致失控坠落；禁飞区信息无法提前充分获知，容易违规并被处罚。
- **管理执法方面：**隐私保护和数据安全存在风险；不同部门系统独立、数据格式不兼容，影响实时共享和协同指挥。

## 五、非连续性文本阅读：逐题诊断

### （1）选择对材料理解和分析“不正确”的一项（2分）

**学生答案：A。**

**判断：正确。参考答案：A。**

| 选项 | 判断与依据 |
|---|---|
| A：消费级领域占比高于工业级领域占比总和 | 错误。消费级为40%，工业级合计为60%，40%＜60% |
| B：材料二的两个加点词体现语言特点，突出效率高 | 按本题语境成立。“短短”突出耗时少；“大约”表明是估计时间，避免说得过于绝对 |
| C：不同部门系统和数据格式不相通，降低执法效率 | 正确，与材料三关于不兼容、难共享、难协同的内容相符 |
| D：三则材料分别介绍市场规模、创新应用、监管短板 | 正确，与三则材料的主要内容相符 |

补充辨析：B项中的“短短”主要起强调作用，“大约”主要体现估计性及表述的严谨，两个词的具体作用不能完全混同。

**如何思考：**

1. 先圈出“不正确”，防止选反。
2. 看图时先分大类、再看细分领域。
3. 选项说“总和”，就必须把所有工业级细分比例相加。
4. “消费级高于任一工业级单项”不等于“消费级高于工业级总和”。本题就错在后者。

### （2）结合材料三，概括民用与管理执法领域存在的短板（4分）

#### 1. 学生作答的主要内容

学生按“民用”“执法”两个方面作答，提到：

- 机器故障或条件限制会危害公共安全；
- 飞行使用范围过小，达不到使用效果；
- 市民不知道禁飞区域有多大，容易泄露隐私信息；
- 管理不当容易侵犯个人隐私；
- 不同部门无人机的功能、参数、性能不同，降低执法效率。

#### 2. 判断：部分正确，但存在添写、错位和核心信息不准确

| 学生表达 | 诊断 | 应怎样订正 |
|---|---|---|
| 故障会危害公共安全 | 抓住了主要方向，但比较笼统 | 写清“信号丢失或电池故障，可能失控坠落” |
| 使用范围过小，达不到使用效果 | 材料没有这一结论 | 删除，不要把禁飞区问题解释为应用效果差 |
| 不知道禁飞区域有多大 | 没有准确概括材料 | 应为“无法提前获知该区域属于临时禁飞区” |
| 禁飞问题后接“容易泄露隐私信息” | 因果关系不成立 | 禁飞信息不明对应的后果是“容易违规飞行并被处罚” |
| 管理不当容易侵犯个人隐私 | 正确，抓住一项风险 | 可补充“数据安全风险”，保留在管理执法方面 |
| 功能、参数、性能不同影响执法效率 | 抓到了部门差异，但没有说准技术和管理障碍 | 应写“系统各自独立、数据格式互不兼容，难以实时共享数据和协同指挥” |

**关键区别：**

- “无法提前知道某地是临时禁飞区”≠“不知道禁飞区有多大”。
- “数据格式不兼容”≠一般性的“机器性能不同”。
- 题目要求“概括”，可以压缩原文，但不能改变原文的因果关系。

#### 3. 参考答案

> ①民用方面：部分无人机在信号丢失或电池故障时可能失控坠落，威胁公共安全；临时禁飞区信息告知不足，使用者难以提前获知，容易违规受罚。  
> ②管理执法方面：高清摄像可能采集个人行踪等敏感信息，存在隐私保护和数据安全风险；不同部门的无人机系统独立、数据格式不兼容，难以实现数据实时共享和协同指挥，降低执法效率。

这份答案包含四个核心信息块：

1. 飞行安全风险。
2. 禁飞区信息告知不足。
3. 隐私保护与数据安全风险。
4. 系统、数据不兼容造成协同困难。

#### 4. 如何思考

**第一步：按题目给的两个领域分组。**

材料已用“在民用无人机方面”“在管理执法无人机方面”提示了结构，直接利用这两个层次，不必自行重分。

**第二步：每段找不同的问题，不只找一个。**

“还有市民指出”“此外”都在引出新的信息点。每读到这样的词，就检查是否需要另列一个要点。

**第三步：按“问题＋后果”压缩。**

- 信号、电池问题 → 失控坠落 → 公共安全风险。
- 临时禁飞区信息不足 → 难提前获知 → 违规受罚。
- 敏感信息采集、管理不当 → 隐私和数据安全风险。
- 系统独立、格式不兼容 → 难共享、难协同 → 效率下降。

**第四步：删掉原文没有依据的话。**

“使用范围过小”“达不到使用效果”不是材料给出的短板，应删除，而不是用它们填满答题空间。

### （3）分析推广“无人机＋智慧校园”的优势与挑战（4分）

#### 1. 学生答案

续页可见的作答为：

> 优势：①使学校管理提升档次，提升入学率。②更加便捷地管理校园，使校园更好发展。  
> 挑战：未填写。

#### 2. 判断：有管理便捷的方向，但表述空泛且漏掉半个任务

| 学生表达 | 判断 |
|---|---|
| 管理提升档次 | 过于笼统，没有解释具体改善了什么 |
| 提升入学率 | 三则材料没有提供依据，不能作为本题的有效结论 |
| 更加便捷地管理校园 | 与材料方向相符，但缺少热成像、夜间巡查、盲区监控等支撑 |
| 使校园更好发展 | 表述宽泛，与上一条内容重叠，不能代替新的具体优势 |
| 挑战空白 | 明显漏答；题目要求“优势与挑战”两个方面 |

**最需要改的不是多写几句，而是：去掉无依据的“提升入学率”，把“管理方便”写具体，再补上挑战。**

#### 3. 应从三则材料提取哪些信息

| 材料 | 可用信息 | 转化为校园推广分析 |
|---|---|---|
| 材料一 | 安防占20%，工业级合计60% | 无人机安防已有一定的市场应用基础，可以考虑借鉴相关应用经验 |
| 材料二 | 热成像不依赖可见光，能够及时发现异常 | 有助于弥补夜间巡查、放学时段监控的不足，提高安全管理效率 |
| 材料二 | 还可用于运输、活动航拍 | 应用场景多，校园服务可以进一步拓展 |
| 材料三 | 失联、电池故障可能失控坠落 | 校园人员密集，推广时需防范对师生的安全风险 |
| 材料三 | 临时禁飞区信息不足 | 需提前核实飞行限制，避免违规 |
| 材料三 | 敏感信息采集、隐私与数据安全问题 | 需保护师生隐私，保障影像等数据安全 |
| 材料三 | 系统独立、数据格式不兼容 | 若接入多个管理系统，可能面临数据共享和协同困难 |

注意：材料一只能支持“已有一定的市场应用基础”这样的有限推断，**不能据此断言技术已完全成熟、采购成本低、学校一定有资金，或能提高入学率**。

#### 4. 可直接用于订正的参考答案

> **优势：**①材料一显示无人机安防已有一定的应用基础；结合热成像技术，无人机可弥补校园监控盲区和夜间巡查不足，及时发现异常，提高校园安全管理效率。②应用还可拓展到运输、活动航拍等方面，提升校园服务与管理水平。  
> **挑战：**①失联、电池故障可能导致失控坠落，威胁师生安全；禁飞区信息不充分，也可能带来违规飞行风险。②拍摄影像涉及师生隐私和数据安全；若不同管理系统不兼容，还会影响数据共享与协同管理。

这是一份覆盖较充分的参考答案，不是要求逐字背诵的唯一答案。“优势”和“挑战”要分别写清，不要把所有内容混成一段，也不要机械地认为“写了四句话就一定有四个得分点”。

#### 5. 如何思考

**第一步：拆题，先在草稿上写出两个小标题。**

```text
优势：能解决什么问题？为什么能解决？
挑战：可能出现什么风险？推广会遇到什么障碍？
```

**第二步：按材料分工找信息。**

- 材料一看“应用基础”。
- 材料二找“具体功能与效果”。
- 材料三找“风险与推广障碍”。

**第三步：将原有场景转成校园场景。**

例如，材料三说“可能侵犯个人隐私”，转到校园就是“可能侵犯师生隐私”；材料说“失控坠落威胁公共安全”，转到校园就是“可能威胁师生安全”。主体可以转换，问题的实质不能改变。

**第四步：每一点用依据支撑结论。**

不要只写：

> 管理更方便。

应写：

> 热成像技术不依赖可见光，有助于弥补夜间巡查不足，及时发现异常，提高校园管理效率。

前者只有评价，后者包含“技术或功能—解决的问题—产生的效果”。

## 六、建议学生直接订正的四项内容

以下集中列出需要真正改写的题目，已答对的题目不必重抄。

### 1. 标点修改

> 将句末的句号移到后引号里面，即改为“……实现梦想的前景无比光明。”

### 2. 病句修改

> 将“提升”改为“改善”，即“改善了千家万户的生活”。

### 3. 概括无人机应用短板

> 民用方面：失联或电池故障可能导致失控坠落，危害公共安全；临时禁飞区信息告知不足，使用者难以提前获知，容易违规受罚。管理执法方面：存在隐私保护和数据安全风险；不同部门系统独立、数据格式不兼容，影响数据实时共享和协同指挥，降低执法效率。

### 4. 分析智慧校园推广的优势与挑战

> 优势：无人机安防已有一定应用基础；结合热成像可弥补校园监控盲区和夜间巡查不足，及时发现异常，提高管理效率，还能拓展运输、活动航拍等服务。挑战：失控坠落可能威胁师生安全，禁飞区信息不足可能导致违规；拍摄涉及师生隐私和数据安全，不同管理系统不兼容还可能影响共享与协同。

## 七、后续答题最值得养成的习惯

### 1. 审题时圈出“任务词”

- 选“正确”还是“不正确”？
- 要“概括”还是“分析”？
- 是“优势”，还是“优势**与挑战**”？
- 依据“一则材料”，还是“**三则材料**”？

本次阅读最后一题，应在动笔前就写出“优势：”“挑战：”，避免漏掉后一半。

### 2. 概括时不改变原文的因果关系

采用“**发生什么问题 → 导致什么后果**”的方式提炼。不要把相邻出现但无因果关系的信息拼起来，例如不能把“禁飞区不明”接成“容易泄露隐私”。

### 3. 分析时避免只有空泛评价

“提升档次”“更好发展”“管理方便”通常不够具体。尽量写成：

> **材料中的技术或事实＋它解决的问题＋产生的效果。**

### 4. 修改题要检查“病因是否真的消失”

句子换一种说法，不等于病句改对。“提升生活”变成“生活得到提升”，原有搭配仍然存在。修改后应再次检查关键搭配。

### 5. 交卷前做一次30秒检查

- [ ] 选择题有没有选反？
- [ ] 题目要求的几个方面是否全部回答？
- [ ] 每个要点都能在材料中找到依据吗？
- [ ] 是否写了两个意思重复的要点？
- [ ] 是否加入了“提升入学率”一类材料没有支持的判断？
- [ ] 修改后标点或语病是否真正改正？

**本次最重要的进步方向：把“有大概想法”变成“按题目要求，准确、具体、分点、有依据地回答”。**
