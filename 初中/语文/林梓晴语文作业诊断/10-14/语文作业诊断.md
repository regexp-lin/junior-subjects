## 二、第4题（1）：黑笔答案有没有问题？

### 1. 题目到底在问什么

原句：

> 我似乎打了一个寒噤；我就知道，我们之间已经隔了一层可悲的厚障壁了。我也说不出话。

问题提示要求回答：

1. “厚障壁”比喻什么？
2. 为什么这种“障壁”是“可悲”的？
3. 对比少年与中年闰土的语言，特别是“迅哥儿”变成“老爷”，进行说明。

**这不是单纯问“我为什么怀念童年”，而是要分析友情如何被社会中的尊卑观念阻隔。**

### 2. 对黑笔作答的核对

照片中可以辨认出“由亲到疏”“身份”“童年”“随时间消逝的悲伤”等意思。中间个别词笔迹较连，不把整段强行转写成逐字原话；以下诊断只依据能够辨认的内容和题干要求。

**答对的部分：**

- 注意到了两人的关系由亲密变为疏远，抓住了前后对比。
- 提到了身份差异，已经接近“厚障壁”的社会原因。
- 能感受到“我”的悲伤，而不是把重逢理解成单纯的喜悦。

**主要问题：**

| 问题 | 为什么不够 | 应怎样补上 |
| --- | --- | --- |
| 没有明确解释“厚障壁” | 只说“生疏”仍是现象，没有指出阻碍交流的是什么 | 明确写出：等级观念、尊卑意识造成的精神隔膜。 |
| 没有落实题目要求的语言对比 | “由亲到疏”缺少具体证据，不能替代“迅哥儿”与“老爷” | 写出昔日哥弟相称，重逢却恭敬地叫“老爷”，再解释称呼背后的关系变化。 |
| 将悲伤主要落在童年、时光流逝上 | 怀念童年可以是情感的一部分，但不能解释“可悲”的核心 | 核心是本来可以真诚交往的人，被尊卑观念隔开，昔日友情受到破坏。 |
| 因果关系没有讲透 | “身份不同”不等于必然没有友情：童年时两人的家庭身份也不同 | 应强调身份差异被内化成尊卑“规矩”，使闰土不敢再平等交往。 |

**总体判断：不是完全答错，而是“有方向，缺证据、缺深层原因”。**原答案可以保留“由亲到疏”的认识，但需要重写后半段。

### 3. 可直接填写的订正答案

> “厚障壁”比喻等级观念造成的精神隔膜。少年时两人哥弟相称，亲密交谈；中年闰土却恭敬地称“我”为“老爷”，把昔日朋友看作地位高于自己的“老爷”。尊卑意识使两人难以再平等、真诚地交流，破坏了原有的友情，因此“可悲”。这表现了“我”的悲哀，也揭示了旧社会等级观念对人性的束缚。[^故乡]

### 4. 应该如何一步步想到要点

1. **先把比喻还原。**墙能挡住人的通行；这里没有真的墙，挡住的是两人的平等交流。
2. **圈出两组称呼。**“迅哥儿”“哥弟称呼”对应亲近；“老爷”对应尊卑距离。
3. **追问：童年时没有身份差异吗？**有，但孩子尚能自然交往。这说明不能只答“他们身份不同”。
4. **找闰土对“规矩”的态度。**他把童年哥弟相称解释为孩子“不懂事”，说明已经把尊卑差别当作不可违反的规矩。[^故乡]
5. **再答“可悲”。**两人并非没有感情，却被观念阻隔，越能看见旧日情谊，就越能感到这种变化可悲。

把思考落成四层：

**比喻含义 → 称呼对比 → 隔膜的原因 → 友情受损与作者态度。**

### 5. 知识点详解：不能把闰土简单说成“冷漠”

原文写他见到“我”时，脸上有“欢喜和凄凉”的神情；他还带来自家晒的干青豆。说明他仍有重逢的喜悦和旧日情谊。[^故乡]

因此，更准确的说法是：

- 他仍然惦记“我”，但精神上受尊卑意识束缚。
- 他的“恭敬”看似礼貌，在此处却暴露出不能平等相处的距离。
- “我”打寒噤、说不出话，写出受到震动后的悲凉。

不要写成“闰土不再喜欢‘我’”“他嫌弃‘我’”，也不要把“我”的悲伤简化为“长大了，童年回不来了”。

## 三、第4题（2）：闰土的“偶像”（空白）

### 1. 题目要求

原句：

> 闰土要香炉和烛台的时候，我还暗地里笑他，以为他总是崇拜偶像，什么时候都不忘却。

问题提示有两个任务：

- 解释“偶像”与闰土的生存困境，如多子、饥荒，有什么关联。
- 结合杨二嫂的变化，分析当时社会对底层群体的双重压迫。

这里的“偶像”首先指闰土崇拜的神像及寄托于其中的愿望，**不是今天所说的明星偶像**。

### 2. 可直接填写的参考答案

> 多子、饥荒、苛税等使闰土生活艰难，他把改善生活的愿望寄托于神灵，香炉和烛台体现了这种精神寄托。杨二嫂从“豆腐西施”变得尖刻、贪占，也反映了生活困境和社会环境对人的侵蚀。二人的变化揭示了底层民众既受贫困、剥削等物质压迫，又受等级观念、迷信等精神束缚；作者既批判旧社会，也同情其受害者。[^故乡]

这是结合题目提示作出的解读。分析杨二嫂时，应说社会环境影响了她的变化，不能断言小说已经逐项交代了她变得贪占的全部原因。

### 3. 如何从题干找到要点

1. **看到“多子、饥荒”，先想现实需要。**孩子多、收成差、生活负担重，他最切近的愿望是能够维持生活。
2. **看到“香炉和烛台”，再想精神寄托。**现实中没有把握，便希望神灵保佑，借此安慰自己。
3. **看到“杨二嫂的变化”，必须补另一个人物。**不能整段只写闰土。
4. **看到“双重压迫”，答案要分两层。**一层是生活和经济重压，一层是思想、精神上的束缚。
5. **最后说作者态度。**不是单纯嘲笑穷人迷信，而是看见困境如何损伤人的生活与精神。

### 4. 知识点详解：物质压迫与精神束缚

| 层面 | 文本依据 | 怎样理解 |
| --- | --- | --- |
| 物质生活的重压 | 多子、饥荒、苛税，以及兵、匪、官、绅；闰土种出的东西卖了亏本，不卖又只能烂掉 | 劳动不能保障基本生活，普通人被多重负担挤压。 |
| 精神上的束缚 | 闰土称“我”为“老爷”，重视香炉、烛台 | 尊卑意识阻碍平等交往；把改变生活的希望寄托于神灵，也显示现实中的无力感。 |
| 人性受到侵蚀 | 闰土变得麻木；杨二嫂言语尖刻，索取木器，顺手拿走手套 | 社会困境在不同人身上造成不同变化：有人趋于麻木，有人趋于自私、算计。 |

以上人物行为可在原文中核对；“双重压迫”是依照本题提示对这些细节作出的归纳。[^故乡]

**“多子”为什么也列在其中？**它说明家庭负担重，并不等于作者认为“穷是因为生孩子多”，更不能据此责怪受苦者。要把家庭负担与饥荒、苛税等社会条件一起看。

**“同情”是否意味着杨二嫂做什么都对？**不是。既可以批评她贪占、尖刻的行为，也可以继续追问社会环境如何促使人发生这种变化。分析人物要避免只有道德标签。

### 5. 再深入一点：“我”为什么也反省自己的希望

题目所引句之后，“我”想到自己的希望，问它会不会也是自己手制的“偶像”；接着区分闰土的愿望“切近”、自己的愿望“茫远”。[^故乡]

可以这样理解：

- 闰土希望现实生活好过一些，“我”希望后辈拥有新的生活，二者都在寻找精神支撑。
- “我”开始反省：不能因自己的愿望更宏大，就轻易嘲笑闰土。
- 如果希望只是心里想象，而没有实际探索，也可能成为自我安慰。
- 结尾的“路”进一步把希望与行动联系起来，而不是停在“有一个美好愿望就够了”。

**注意：“我”是小说叙述者，不宜把他的每一个念头都直接写成作者鲁迅的最终结论。**

### 6. 易错答案

- “闰土喜欢收藏古董。”香炉和烛台在此处体现的是信仰寄托，不是收藏爱好。
- “杨二嫂也崇拜偶像。”本题材料没有这样写，不能为了凑“双重压迫”编造情节。
- “双重压迫就是多子和饥荒。”这两个都主要落在生活困难一层，没有解释精神层面。
- “作者只是在批判闰土愚昧。”忽略了他的困境，也忽略了“我”的自我反省。

## 四、第4题（3）：“我”所期待的“路”（空白）

### 1. 题目要求

原句：

> 这正如地上的路；其实地上本没有路，走的人多了，也便成了路。

问题提示要求：

- 联系“我”对未来故乡的想象，理解“路”的内涵。
- 思考：若将“路”替换为“桥”或“光”，表达效果有什么不同？

**不能只背“希望靠努力实现”，还要回答为什么这里用“路”更贴切。**

### 2. 可直接填写的参考答案

> “路”比喻通向新生活的希望和出路。“我”希望宏儿、水生不再隔膜，也不重复上一代的辛苦生活。“走的人多了，也便成了路”强调希望要靠人们共同探索、实践来实现。“桥”更侧重连接、跨越隔膜，“光”更侧重指引、光明；二者不像“路”这样贴合“走”的过程，难以同样鲜明地表现共同开辟新生活的意义。[^故乡]

### 3. 逐步思考方法

1. **先找“新生活”是对什么说的。**“我”不愿后辈重复自己的辛苦展转、闰土的辛苦麻木，以及“别人”的辛苦恣睢。[^故乡]
2. **看宏儿和水生。**两人能够自然交往，宏儿还惦记到水生家玩，这是希望的具体起点。
3. **抓住两个词：“走”“多”。**“走”强调实际行动；“多”强调不只是一个人的孤独愿望。
4. **看“本没有”与“成了”。**说明出路不是现成摆着的，而是在探索中形成。
5. **分别比较喻体。**不是泛泛说“桥和光不生动”，而是说明它们各自突出什么、相对少了什么。

### 4. “路”“桥”“光”的具体区别

| 喻体 | 通常更容易突出 | 与本文结尾比较 |
| --- | --- | --- |
| 路 | 行进、探索、方向；通过不断行走开辟出通道 | 与“走的人多了”直接配合，突出希望形成于共同实践的过程。 |
| 桥 | 连接两端，跨越阻隔 | 可以呼应“隔膜”，但侧重点转向连接与跨越，原文“走着走着形成道路”的过程不再同样突出。 |
| 光 | 指引、照亮、希望、光明 | 可以表达美好前景，但相对不突出“由许多人共同开辟出路”的过程。 |

**不要绝对化：**桥也需要人建造，光也可以来自人的行动。不是说它们“完全不能表达努力”，而是说它们与此处的上下文及“走”的措辞不如“路”贴合。

如果只替换一个字而保持“走的人多了，也便成了……”不变，还会出现搭配或逻辑上的不协调：人走得多，可以踩出路，却不能仅凭“走得多”就形成桥或光。答题时应先解释内涵，再补这一点，不要只说“不通顺”。

### 5. 知识点详解：怎样理解“希望本无所谓有，无所谓无”

这句话不是宣布“根本没有希望”，也不是保证“只要努力就一定成功”。

结合“路”的比喻，更合理的理解是：

- 不能把希望当成已经现成存在、自动会实现的东西。
- 也不能因为眼下没有现成出路，就断定未来绝无可能。
- 有人愿意探索、越来越多人参与实践，才可能把愿望变成可走的道路。

因此，小说结尾既保留了希望，也保留了探索的艰难与不确定性，并没有给出一套已经完成的社会方案。[^故乡]

## 五、课外拓展第1题：我眼中的鲁迅式童年（空白）

### 1. 先审清四项要求

- **题目：**《我眼中的鲁迅式童年》。
- **篇幅：**150字左右。
- **材料：**《社戏》《从百草园到三味书屋》《故乡》《阿长与〈山海经〉》。
- **写作：**至少引用两处文本细节，体现对“童真”“教育”或“社会批判”的理解。

“或”说明可以选择一个主要角度，不必把三个角度都塞进短文；“至少两处细节”也不等于四篇作品必须全部写到。可用简短原文片段，也可准确概述具体情节，但不能只列作品名称。

### 2. 约150字参考范文

#### 我眼中的鲁迅式童年

> 我眼中的鲁迅式童年，有探索的快乐，也需要被理解。《从百草园到三味书屋》中，“我”在雪地捕鸟，把百草园当作“乐园”；《阿长与〈山海经〉》中，阿长买来念念不忘的书，让“我”产生“新的敬意”；《社戏》里，伙伴们月夜行船、归航偷豆，留下温暖的回忆。这些细节让我懂得，童真不只是天真玩闹，更是好奇、友情与信任；真正的教育，应尊重孩子的兴趣，也珍惜普通人的善意。

范文中的具体情节、短语分别依据三篇作品；末尾关于教育的认识是由这些细节引出的个人感悟，不是作者的逐字原话。[^百草园][^阿长][^社戏]

### 3. 这段为什么符合要求

| 部分 | 具体内容 | 作用 |
| --- | --- | --- |
| 开头 | “有探索的快乐，也需要被理解” | 直接给出自己的认识，不泛泛说“童年很美好”。 |
| 细节一 | 雪地捕鸟、百草园是“乐园” | 支撑孩子对自然的兴趣和探索欲。 |
| 细节二 | 阿长买书，使“我”产生“新的敬意” | 支撑童年愿望得到理解、普通人给予关爱的认识。 |
| 细节三 | 月夜行船、归航偷豆 | 支撑伙伴间的情谊与温暖。 |
| 结尾 | 好奇、友情、信任；教育应尊重兴趣 | 从情节上升到感悟，回应题目要求。 |

### 4. 如何自己写，而不是照抄

1. **先选一个中心词。**例如“好奇”“友情”“被理解”“不愿失去童真”，不要先罗列四篇作品。
2. **再选两处最能证明它的细节。**写“好奇”，可选捕鸟、渴慕《山海经》；写“友情”，可选月夜行船、少年闰土讲新鲜事。
3. **给每处细节补一句意义。**“捕鸟”不只是一件趣事，更说明儿童喜欢观察、亲近自然。
4. **最后写自己的认识。**如“孩子的兴趣值得认真对待”“人与人应当保持真诚、平等”。
5. **压缩到约150字。**删掉作者介绍、情节长篇复述和重复赞美，留下中心、证据、感悟。

可按四句话安排篇幅：

**一句总认识 + 一处细节及含义 + 另一处细节及含义 + 一句感悟。**

### 5. 四篇作品的选材与知识点

| 作品 | 可选具体细节 | 可引出的认识 |
| --- | --- | --- |
| 《从百草园到三味书屋》 | 观察虫草，拔何首乌，雪地捕鸟；询问“怪哉”虫；在书屋后园玩耍、趁先生读书时画画 | 儿童有好奇心、求知欲和游戏天性；教育应关注兴趣，不能只看机械诵读。[^百草园] |
| 《阿长与〈山海经〉》 | 阿长不懂书名，却买来“我”渴慕的绘图《山海经》；书虽粗拙，却成为心爱的宝书 | 真正的关爱是认真对待孩子的愿望；普通人也能给予重要的精神滋养。[^阿长] |
| 《社戏》 | 双喜设法安排看戏；少年们月夜行船；阿发让大家摘自家的豆；六一公公送豆 | 难忘的不只是戏和豆，更是自由生活、真挚友情与乡人的淳朴善意。[^社戏] |
| 《故乡》 | 少年闰土讲捕鸟、看瓜等新鲜事；成年重逢出现尊卑距离；宏儿仍惦记水生 | 童年交往富有真诚和活力；与成人隔膜对比，能够思考社会如何损伤人与人的关系。[^故乡] |

### 6. 两个重要辨析

**辨析一：三味书屋是不是“一无是处”？**

不是。原文既写学习生活的规矩对儿童兴趣有所限制，也写先生方正、质朴、博学，戒尺和罚跪并不常用；孩子们仍会寻蝉蜕、画画。[^百草园]

因此，“教育应尊重童真”可以成立，但不应粗暴写成“鲁迅反对读书”“先生是残暴的人”“三味书屋里完全没有快乐”。

**辨析二：四篇里的“我”是不是都等于鲁迅本人？**

《从百草园到三味书屋》《阿长与〈山海经〉》是回忆性散文；《社戏》《故乡》是小说。小说可以有作者生活经验的影子，但叙述者和情节不能机械当作作者童年实录。作品归属与文体可据原文页面及所属文集核对。[^百草园][^阿长][^社戏][^故乡]

稳妥写法是“鲁迅笔下的童年”“作品中的‘我’”“小说中的少年闰土”，不要把四篇都说成作者的自传。

### 7. 常见失分写法

- 只写“鲁迅童年快乐、热爱生活”：没有至少两处具体细节。
- 只写两个故事梗概：有材料，却没有自己的感悟。
- 只写“要努力读书”：与选用的细节没有形成解释关系。
- 把“偷豆”解读成“作者鼓励随意偷窃”：脱离作品中的儿童活动、人情背景和情感重点。
- 超长地复述四篇：150字左右的任务需要取舍，不是作品汇总。

## 六、课外拓展第2题：《故乡》的主题（空白）

### 1. 先看题型

图片材料概括了三种解读：

| 材料中的观点 | 关注的核心 | 作答最适合抓的证据 |
| --- | --- | --- |
| 钱理群：人际关系隔膜 | 真诚交往被阻隔，以及突破隔膜的可能 | “老爷”“厚障壁”，杨二嫂与“我”的交往，宏儿和水生。 |
| 王富仁：社会批判 | 等级观念与社会重压对人性的伤害 | 闰土的外貌、语言、精神变化，生活困难，杨二嫂的尖刻与算计。 |
| 汪晖：知识分子寻找出路 | 不沉溺于故乡回忆，继续追问新的生活 | “我”对希望的反省，后辈的“新的生活”，结尾“路”的比喻。 |

**这些是作业材料对观点的概述。**照片没有提供学者原著、文章或页码，不把这些段落写成已经核实的学者逐字原话，也不补造出处。

本题没有规定字数。选择一种作为主线，给出两处以上有解释的细节即可；不必用很长篇幅复述全部材料。

### 2. 建议填写：认同“社会批判”

这一角度便于接上前面“厚障壁”和“偶像”两题，但不是唯一正确选项。

> 我较认同材料中关于社会批判的解读。闰土由活泼能干的少年变得衰老、麻木，原文将这种变化与饥荒、苛税等生活重压联系起来；他称“我”为“老爷”，说明等级观念连昔日友情也能阻隔。杨二嫂的尖刻与贪占，则呈现社会环境对人性的另一种侵蚀。因此，小说不只是感叹故乡变化，更揭示旧社会对普通人生活和精神的损害。结尾对“新的生活”的期待，又使批判指向改变现实的希望。[^故乡]

### 3. 另外两种观点也可以怎样回答

#### 选择一：认同“人际关系隔膜”

> 我较认同材料中关于人际关系隔膜的解读。少年时，“我”与闰土能亲密交谈；重逢时，闰土的一声“老爷”却使“我”感到两人之间有了“厚障壁”。杨二嫂的尖刻和算计也让交往失去真诚。这些隔膜不仅源于个人变化，还与生活困境、等级观念有关。宏儿惦记水生，则让“我”看到后辈仍能自然相处。因此，小说既写隔膜的悲哀，也期待人与人之间新的、平等真诚的关系。[^故乡]

#### 选择二：认同“知识分子寻找出路”

> 我较认同材料中关于知识分子寻找出路的解读。面对衰败的故乡和变了的旧友，“我”没有停留在童年回忆中，而是希望宏儿、水生不再隔膜，拥有上一代未曾有过的“新的生活”。“我”又反省自己的希望会不会只是“偶像”，说明他并未把愿望当成现成答案。结尾以“路”作比，将希望与人们的共同探索联系起来。因此，小说既呈现现实困境，也保留了寻求新生活的开放可能。[^故乡]

### 4. 怎样写到要点

1. **先亮观点。**开头直接说“我较认同材料中……的解读”，不让老师猜立场。
2. **找两处有区分度的证据。**选“社会批判”，就找生活重压和等级称呼；选“寻找出路”，就找新生活与路。
3. **每处证据后面解释意义。**“他叫‘老爷’”是事实；“这说明等级观念侵入旧日友情”才是论证。
4. **给结尾的希望留位置。**如果只写悲哀、压迫，容易把小说读成彻底绝望。
5. **用‘较认同’而非‘只有这个正确’。**不同主题角度并不一定相互排斥。

作答结构：

**观点 → 细节一及解释 → 细节二及解释 → 与主题相扣的结论。**

### 5. 知识点详解：多种主题解读为什么能并存

三种解读可以分别回答三个问题：

- **现象是什么？**人与人之间出现隔膜。
- **为什么出现？**生活重压与等级观念等社会因素伤害了人。
- **未来怎么办？**不能只怀念过去，要探索后辈的新生活。

这是便于理解题目材料的整理方法，不意味着三位学者原本的完整论述只有这三句话。选择一个角度，就从那个角度组织证据；也可以在主线明确的前提下兼顾另两个层面。

### 6. 这些说法要避免

| 容易写出的说法 | 问题与修正 |
| --- | --- |
| “鲁迅只想回到快乐童年。” | 忽略结尾对后辈“新生活”的期待；不是简单退回过去。 |
| “闰土天生麻木，杨二嫂天生贪婪。” | 忽略人物的前后变化，以及生活环境的影响。 |
| “《故乡》里出现了吃人的事情。” | 材料中的“吃人”是对压迫、扼杀人性的比喻性解读，不是小说发生了字面意义的吃人情节。 |
| “离开故乡就是已经找到出路。” | 离开是情节动作；精神和社会出路仍待探索。 |
| “结尾说明希望一定成功。” | 结尾强调实践和可能性，不是成功保证。 |
| “另外两种观点都是错的。” | 这是有文本依据的开放论述题，不是排除其他解读的单选题。 |

## 七、把相关知识点串起来

### 1. 比喻题：不能停在“生动形象”

分析比喻至少要回答三件事：

1. **用什么具体事物作比？**障壁、偶像、路。
2. **它在文中对应什么？**隔膜、愿望寄托、通向新生活的希望和出路。
3. **为什么这个事物贴切？**墙能阻隔，偶像能成为精神寄托，路能在行走中开辟。

再联系作者情感或小说主题。题目问表达效果时，“生动形象”只能是开头，不能是全部答案。

| 关键词 | 具体含义 | 深层思考 |
| --- | --- | --- |
| 厚障壁 | 挡住交往的墙 | 等级观念使有旧日感情的人不能平等交流。 |
| 偶像 | 崇拜对象、愿望寄托 | 人在现实困境中如何寻找精神支撑；希望若没有行动，也可能只是自我安慰。 |
| 路 | 可以行走的道路 | 希望不是现成的，需要探索与实践。 |

“偶像”一处先有闰土崇拜神像的具体含义，再有“我”把自己的希望比作“手制的偶像”的延伸；不要把两个层次混成“全文的偶像都只指神像”。[^故乡]

### 2. 对比题：从“变了”答到“为什么变、说明什么”

闰土的前后变化，不只在称呼。[^故乡]

| 少年闰土 | 中年闰土 | 分析方向 |
| --- | --- | --- |
| 紫色圆脸，红活圆实的手 | 灰黄的脸，皱纹深，手粗笨开裂 | 艰苦劳动、贫困对身体的消磨。 |
| 有许多新鲜事，能自然交谈 | 言语迟疑，只摇头，精神麻木 | 生活重压对活力与表达的损伤。 |
| 哥弟相称，离别时不舍 | 恭敬称“老爷”，认为童年不懂规矩 | 等级意识对真诚友情的阻隔。 |

作答时按题目选最有用的一组。题目要求语言差异，就优先写称呼和言语，不必把外貌全部搬进去。

### 3. 小说人物：既看行为，也看处境

人物分析不能只有“好人、坏人”的标签。

- 分析闰土，要同时看到勤劳、旧日情谊、生活困境和精神麻木。
- 分析杨二嫂，要指出尖刻、贪占的具体行为，也要注意前后变化及社会环境。
- 分析“我”，要看到他的悲哀、反省和希望，不能把他当作永远正确的旁观者。

**说明社会原因，不等于取消个人行为的责任；批评人物行为，也不等于否认他所处的困境。**

### 4. “辛苦展转”“辛苦麻木”“辛苦恣睢”怎样区分

这三个词是理解“新生活”的重要参照。[^故乡]

| 词语 | 对应对象 | 便于理解的意思 |
| --- | --- | --- |
| 辛苦展转 | “我” | 为谋生而奔波辗转，精神上又承受隔膜、孤独。 |
| 辛苦麻木 | 闰土 | 生活劳苦，长期重压使精神趋于迟钝、无力。 |
| 辛苦恣睢 | “别人”；可联系杨二嫂等人物理解 | 在生活压力中变得放纵、尖刻或损人利己。“恣睢”读作zì suī。 |

“新生活”不是简单“以后多挣钱”，还包含不再隔膜、不再麻木、不再以损伤别人来应对困境的期待。不要把“别人”机械说成只指杨二嫂一个人。

### 5. 结尾的意义：从回忆走向未来

《故乡》不是只有“美好过去”与“悲凉现在”的对比。宏儿和水生、对新生活的期待、路的比喻，把叙述进一步推向未来。[^故乡]

理解顺序可以整理为：

**记忆中的友情与活力 → 现实中的衰败与隔膜 → 反省愿望是否空想 → 在实践中寻找新的生活。**

这样，前面的“障壁”“偶像”和结尾的“路”就连起来了，不必当成三个互不相关的术语死记。

## 八、给林梓晴的订正与自测

### 1. 订正顺序

1. 先重写“厚障壁”：保留“由亲到疏”，补上称呼证据、等级观念和“可悲”的原因。
2. 再补“偶像”：至少写到现实困境、精神寄托、杨二嫂、双重压迫四个点。
3. 再补“路”：写清新生活、共同实践，以及与桥、光的区别。
4. 写童年感悟：先确定中心，再挑两处以上细节，最后检查字数。
5. 写主题观点：选一个主线，用具体情节解释，而不是复述学者观点。

### 2. 五个口头自测题

请先遮住参考答案再回答：

1. 为什么“我”和闰土的身份差异，不足以单独解释“厚障壁”？
2. 闰土为什么一面欢喜，一面又称“我”为“老爷”？
3. “双重压迫”的两个层面分别是什么？各举一个依据。
4. “桥”也要人建造，为什么本文用“路”仍然更贴切？
5. 写“鲁迅式童年”时，为什么只说“童年很美好”不够？

**核对提示：**

1. 童年时身份也不同，但仍能亲密交往；关键是尊卑观念成为精神束缚。
2. 旧日情谊仍在，但他已经把等级差别看作必须遵守的规矩。
3. 物质层面如饥荒、苛税；精神层面如尊卑意识、迷信寄托。
4. “路”与“走的人多了”配合，直接表现许多人在行动中开辟出路。
5. 缺少具体文本证据，也没有把细节转化为自己的认识。

### 3. 交作业前的检查清单

- [ ] “厚障壁”写到了“迅哥儿／哥弟相称”与“老爷”的对比。
- [ ] “可悲”不只解释为时间流逝，而解释了友情受等级观念破坏。
- [ ] “偶像”没有遗漏杨二嫂，也没有编造她崇拜神像的情节。
- [ ] “路”比较了桥、光的侧重点，没有只写“更生动”。
- [ ] 童年短文有两处以上具体细节，有自己的感悟，篇幅约150字。
- [ ] 主题题有明确立场，每处证据后都有解释，没有否定其他合理解读。
