## 二、逐题订正

### 1. 第 17 页第（2）题：四个“有……的人”可否交换顺序？

**参考答案：**不宜随意交换。四个分句用排比列举“埋头苦干”“拼命硬干”“为民请命”“舍身求法”的人，先写实干、抗争，再写为民呼告、为信念献身，语势逐渐推向“舍身”，最后归结为“中国的脊梁”。这样的安排层层蓄势，突出中华民族从古以来就有不失自信力、敢于担当的人，有力反驳“中国人失掉自信力”的笼统论断。

**要特别分清：**四类人是**并列列举**，不是按历史年代排列，也不是说后一类人一定比前一类更高尚。换序后句子在语法上仍然通顺；这里说“不宜换”，指原文由列举到收束的语势、最后“舍身”的强调会减弱，不要硬编出严格的时间或因果顺序。

**引导她自己想到要点：**

1. 圈出四个相同的句式：“有……的人”。先说出手法：排比。
2. 给四类行为贴关键词：做事、抗争、为民发声、为真理献身。
3. 问：“把‘舍身求法’放到最前面，末尾再写‘埋头苦干’，朗读时最后的分量会不会变化？”
4. 看省略号后的一句“这就是中国的脊梁”：前面的列举都在为这一判断提供事实依据。
5. 作答落成“判断 + 分句内容/次序的表达效果 + 本文论点”，不要只写“不能，语气更强”。

### 2. 第 19—20 页第 3 题（1）：赏析“总”“只”“一味”（空白）

**可直接填写的答案：**

> “总”突出有些人惯于自夸“地大物博”，讽刺其盲目自满；“只”强调把希望寄托于国联，暴露其依赖外力而不相信自身力量；“一味”写出不加反省地求神拜佛、怀古伤今，揭示其陷入自欺。三个词串联起自夸、依赖外力到迷信自欺的变化，使讽刺层层深入，说明这些人的表现不能证明全体中国人失去了自信力。

**怎样带她分析，而不是让她背答案：**

- 把词暂时删掉再比较：“自夸”与“**总**自夸”，“希望着国联”与“**只**希望着国联”，“求神拜佛”与“**一味**求神拜佛”，哪一句更能写出反复、唯一依赖、不知变通？
- 依次回答“词的通常含义 → 在句中强调什么行为 → 作者对谁持什么态度”。这里的“我们”是作者**模拟、概括当时某些人的言行并加以批驳**，不要直接说“鲁迅也主张求神拜佛”。
- 最后把三词连起来，看论证怎样从“自夸”写到“他信”，再写到“自欺”；既要分别赏析，也要写整体的讽刺效果。

### 3. 第 20 页第 3 题（2）：补全修辞表格

| 空格 | 可填写的内容 |
| --- | --- |
| ① 修辞手法 | **排比**。照片中已写对，不必改。 |
| ② 排比的表达效果 | 连用四个“有……的人”，句式整齐、语势有力，列举实干、抗争、为民发声和求索献身的中国人，证明中国自古就有勇于担当、富有自信的“脊梁”，有力反驳对方以偏概全的论断，表达对他们的敬重和赞颂。 |
| ③ 反问的原文例句 | **“这一类的人们，就是现在也何尝少呢？”**（意为“现在也并不少”。） |
| ④ 比喻的原文例句 | **“这就是中国的脊梁。”** |
| ⑤ 比喻的表达效果 | 将那些实干、抗争、为民和求真的中国人比作支撑身体的“脊梁”，形象地赞颂他们是支撑民族精神的中坚力量，突出中国人并未普遍丧失自信力，增强论证的感染力。 |

**为什么③要这样找？**“何尝少呢”用问句表达肯定的意思：“现在也不少”。作者不是真在等读者提供人数，所以是**反问**，不是“提出问题再回答”的设问。反问本身加强了反驳力度，也把“中国的脊梁”从历史推到当下。

**为什么④算比喻？**这里的“脊梁”不是实指人体骨骼，而是用承托身体的部位比作支撑民族的人。写效果时必须说清**本体是谁、比作什么、突出什么、服务什么论点**，不能只写“生动形象”四个字。

## 三、这次集中复习的知识点

1. **议论文的“立”和“驳”。**对方把部分人的自夸、依赖和自欺推广到“中国人”全体，属于以偏概全；作者举出古今“脊梁”这一类人的事实，强调不能凭表面现象否定整个民族。分析句子的作用要回到这条论证线。
2. **赏析关键词要做到三层。**词义或限制范围（“总/只/一味”）→ 写出了什么行为和变化 → 讽刺或赞美了谁、怎样为论点服务。副词往往正是语气与态度所在。
3. **排比题不能只报名称。**写“相同句式 + 列举了哪些具体内容 + 整齐而有力的语势 + 表达立场/论证作用”。
4. **反问与设问要区分。**反问的答案含在问句中（“何尝少呢”＝“并不少”）；设问通常是先问后答。只见问号不能直接判定为反问。
5. **比喻题要找准对应关系。**本题“脊梁”对应的是支撑民族精神的人，不要误写成“把中国比作脊梁”，也不要把比喻的表达效果写成“说明他们身体很强壮”。
6. **换序题先看关系。**先判定并列、递进、时间还是因果；本题形式上是并列，表达上有收束和蓄势。答题时区分“语法能否换”和“原文为何这样排”。
