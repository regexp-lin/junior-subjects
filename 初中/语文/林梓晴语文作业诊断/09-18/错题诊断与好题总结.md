# 09-18 语文错题诊断与好题总结

## 诊断说明

本次共核对四张错题图片，包含两组张岱文言文对比阅读：

- 《湖心亭看雪》与《龙山雪》；
- 《湖心亭看雪》与《自为墓志铭》。

图片中未见教师逐题勾叉，以下将能明确判断的错题、空题和易失分翻译统一订正。原卷中“敌=抵挡”“拏=撑（船）/划（船）”“焉得=哪能”“效颦=仿效”，以及“不正确的一项”选 C，均为正确作答。

## 一、《湖心亭看雪》与《龙山雪》

### 1. 解释“湖中人鸟声俱绝”中的“绝”

- 原答：都。
- 正确答案：消失、停止。

**讲解：**“俱”才是“都”，“绝”表示声音完全消失。整句意为：湖中行人、飞鸟的声音都消失了。

### 2. “而”字用法辨析

- 原选：B“从百步街旋滚而下”。
- 正确选项：D“（水声潺潺）而泻出于两峰之间者”。

**讲解：**例句“余强饮三大白而别”中的“而”表承接，可译为“然后”。D项同样表承接；B项“旋滚而下”中的“而”表修饰，可译为“翻滚着”。

### 3. 翻译“湖中焉得更有此人！”

**正确答案：**此时的湖中，怎么还能有像您这样有闲情雅致的人呢！

**讲解：**“焉得”是“怎么能、哪里能”，“更”是“还”。“此人”是“这样的人”，不能写成“同人”。翻译反问句时要保留反问语气。

### 4. 翻译“声为寒威所慑。”

**正确答案：**洞箫声被严寒的威力震慑住了。

**讲解：**“为……所……”是被动句；“寒威”是严寒的威力；“慑”是震慑、压制。结合后文“唱涩不得出”，这里写的是声音因严寒而发涩、受压制。

### 5. 雪景描写方法与思想感情（空题）

**参考答案：**

两处雪景主要运用白描。甲文用“上下一白”“一痕、一点、一芥、两三粒”简笔勾勒；乙文写“万山载雪”“雪皆呆白”，并以月色衬托雪景的清寒苍茫。雪景表现了作者对山水雪景的痴爱和孤高脱俗的情怀；联系明亡背景，还流露出孤寂、人生沧桑和故国之思。

## 二、《湖心亭看雪》与《自为墓志铭》

### 1. 翻译“雾凇沆砀，天与云与山与水，上下一白”

**规范答案：**冰花一片弥漫，天、云、山、水浑然一体，天地间全是白茫茫的。

**讲解：**“雾凇”是冰花，不只是“白雾”；“沆砀”是白气弥漫的样子；“一”作动词，译为“全、都成为”。

### 2. 翻译“尽言吾之癖错，则亦可传也。”（空题）

**正确答案：**把我的癖好和过错全都说出来，那么这些文字也可以流传下来。

**讲解：**“尽言”是全都说出；“癖错”指癖好和过失；“则”译为“那么”；“传”指流传后世。

### 3. 比较两文中的“孤独”（空题）

**参考答案：**

《湖心亭看雪》中，“湖中人鸟声俱绝”写雪夜环境的空寂，“独往湖心亭看雪”写作者行动上的孤独；舟子不理解作者的“痴”，还表现其不被世俗理解的精神孤独。乙文直写“国破家亡”“既不能觅死，又不能聊生”，表现作者明亡后无所归依、难以排遣的悲凉。两文都表现孤独：甲文借雪景含蓄表达，孤高清雅；乙文直抒胸臆，更显沉郁悲凉。

## 三、值得复习的好题与知识点

### 1. “俱”和“绝”辨析

文言实词要逐字解释，不能把相邻词的意思混在一起。看到“俱”优先想“都”，看到“绝”要结合语境判断为“消失、断绝、极”等。

### 2. “而”字用法辨析

| 句子 | “而”的用法 | 翻译提示 |
| --- | --- | --- |
| 余强饮三大白而别 | 表承接 | 然后 |
| 从百步街旋滚而下 | 表修饰 | 翻滚着 |
| 拖冰凌而归 | 表修饰 | 拖着……回来 |
| 水声潺潺而泻出于两峰之间 | 表承接 | 然后/并且 |

判断方法：把“而”分别换成“然后”“……着”“但是”“罢了”，看哪一种最通顺。

### 3. 文言文翻译方法

按“落实关键词—补全省略—调整语序”完成翻译。尤其不要漏掉“更”“尽”“一”等看似小、却关系到得分的字。

### 4. 比较阅读题的答题结构

按照“原文证据—写法或画面—思想感情”三步作答。不能只写“作者很孤独”，必须引用文本，如“人鸟声俱绝”“独往”，再说明环境空寂和精神孤独。

### 5. 选择题 C 项为什么正确

“余强饮三大白而别”中的“强饮”是尽力、勉强饮酒，并非“贪饮”。因此，把它解释成“贪饮”或单纯理解为“酒逢知己千杯少”都不严谨；原卷选择 C 为“不正确的一项”是正确的。
