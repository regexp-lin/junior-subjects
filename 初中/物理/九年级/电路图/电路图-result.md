# 九年级物理电路图题型练习

## 作图要求

每题均需完成两步：

1. 根据文字条件画出规范的电路图，元件符号、连接关系和仪表正负接线柱要标注正确。
2. 按电路图连接给定实物元件。连接前开关应断开；闭合开关前先检查电路。

以下按九年级常见的“根据条件画电路图并连接实物”题型分类，每类只给出一道代表题。

## 一、基础连接题

### 1. 单灯基本电路

有电源、开关、小灯泡各一个，导线若干。要求开关闭合时小灯泡发光，开关断开时小灯泡熄灭。

请画出电路图并连接实物。开关应接在电源的正极与小灯泡之间。

### 2. 两灯串联电路

有两节干电池、电键一个、小灯泡 L1 和 L2 各一个，导线若干。要求两只小灯泡串联，闭合电键后两灯同时发光。

请画出电路图并连接实物。

### 3. 两灯并联电路

有两节干电池、电键一个、小灯泡 L1 和 L2 各一个，导线若干。要求两只小灯泡并联，闭合电键后两灯同时发光。

请画出电路图并连接实物。电键应安装在干路中。

### 4. 串、并联混联电路

有电源、开关、小灯泡 L1、L2、L3 各一个，导线若干。要求 L1 与 L2 串联后，再与 L3 并联；开关闭合后三只灯都能发光。

请画出电路图并连接实物。

## 二、开关控制题

### 5. 一个开关控制两灯

有电源、开关 S、小灯泡 L1 和 L2 各一个，导线若干。要求 L1、L2 并联，且开关 S 闭合时两灯同时发光，断开时两灯同时熄灭。

请画出电路图并连接实物。

### 6. 两个开关分别控制两灯

有电源、开关 S1、S2、小灯泡 L1、L2 各一个，导线若干。要求 L1、L2 并联，S1 只控制 L1，S2 只控制 L2；两灯可以独立发光。

请画出电路图并连接实物。

### 7. 开关控制一灯，另一灯常亮

有电源、开关 S、小灯泡 L1、L2 各一个，导线若干。闭合总电路后，L1 始终发光；S 闭合时 L2 发光，S 断开时 L2 熄灭。

请画出电路图并连接实物。

### 8. 串联电路中的开关位置

有电源、开关 S、小灯泡 L1、L2 各一个，导线若干。要求 L1、L2 串联，S 只要断开，两只灯均熄灭；S 闭合，两只灯均发光。

请画出两种开关接在不同位置、但功能相同的电路图，并任选一种连接实物。

## 三、电流表和电压表题

### 9. 电流表测单灯电流

有两节干电池、开关 S、小灯泡 L、电流表 A、导线若干。要求用电流表测出通过小灯泡 L 的电流，估计电流不超过 0.6 A。

请画出电路图并连接实物。电流表应选用合适量程，且电流从正接线柱流入。

### 10. 电流表测干路电流

有电源、开关 S、小灯泡 L1、L2、电流表 A、导线若干。要求 L1、L2 并联，电流表 A 测量干路中的总电流。

请画出电路图并连接实物。

### 11. 电流表测支路电流

有电源、开关 S、小灯泡 L1、L2、电流表 A、导线若干。要求 L1、L2 并联，电流表 A 只测量通过 L2 的电流。

请画出电路图并连接实物。

### 12. 电压表测单灯两端电压

有两节干电池、开关 S、小灯泡 L、电压表 V、导线若干。要求用电压表测量小灯泡 L 两端的电压。

请画出电路图并连接实物。电压表应并联在小灯泡两端，且正接线柱接近电源正极的一端。

### 13. 电压表测串联电路中一只灯的电压

有电源、开关 S、小灯泡 L1、L2、电压表 V、导线若干。要求 L1、L2 串联，电压表 V 只测量 L2 两端的电压。

请画出电路图并连接实物。

### 14. 电流表和电压表同时使用

有两节干电池、开关 S、小灯泡 L、电流表 A、电压表 V、导线若干。要求电流表测通过小灯泡的电流，电压表测小灯泡两端的电压。

请画出电路图并连接实物。

## 四、滑动变阻器题

### 15. 滑动变阻器限流保护

有两节干电池、开关 S、小灯泡 L、滑动变阻器 R、电流表 A、导线若干。要求滑动变阻器接入电路后能改变小灯泡亮度，电流表测量通过小灯泡的电流。

请画出电路图并连接实物。闭合开关前，应使滑动变阻器接入电路的阻值最大。

### 16. 滑动变阻器电压分配

有电源、开关 S、定值电阻 R0、滑动变阻器 R、电压表 V、导线若干。要求 R0 与滑动变阻器串联，电压表测量滑动变阻器接入部分两端的电压；移动滑片时，电压表示数应改变。

请画出电路图并连接实物。

## 五、探究实验电路题

### 17. 探究串联电路电流规律

有电源、开关 S、小灯泡 L1、L2、电流表 A、导线若干。要探究串联电路中各处电流是否相等。

请画出电路图，并说明电流表应依次接在哪些位置测量。连接实物时，电流表先接在 L1 前的 A 点测量一次，再移动到两灯之间的 B 点和 L2 后的 C 点测量。

### 18. 探究并联电路电流规律

有电源、开关 S、小灯泡 L1、L2、电流表 A、导线若干。要探究并联电路中干路电流与各支路电流的关系。

请画出电路图，并说明电流表应依次接在哪些位置测量。连接实物时，电流表分别测量 L1 支路电流、L2 支路电流和干路电流。

### 19. 探究串联电路电压规律

有电源、开关 S、小灯泡 L1、L2、电压表 V、导线若干。要探究串联电路中总电压与各部分电压的关系。

请画出电路图，并说明电压表应依次并联在哪些元件两端测量。连接实物时，分别测量 L1 两端电压、L2 两端电压和 L1、L2 串联部分两端的总电压。

### 20. 测量小灯泡的电功率

有电源、开关 S、额定电压为 2.5 V 的小灯泡 L、滑动变阻器 R、电流表 A、电压表 V、导线若干。要求通过调节滑动变阻器，使小灯泡两端电压为 2.5 V，并测出此时通过小灯泡的电流。

请画出电路图并连接实物。电流表测量通过小灯泡的电流，电压表测量小灯泡两端的电压。

### 21. 伏安法测定值电阻

有电源、开关 S、待测定值电阻 Rx、滑动变阻器 R、电流表 A、电压表 V、导线若干。要求测出 Rx 两端的电压和通过 Rx 的电流，以计算 Rx 的阻值。

请画出电路图并连接实物。滑动变阻器既要保护电路，又要便于改变 Rx 两端的电压和通过 Rx 的电流。

## 六、特殊元件和安全连接题

### 22. 保险丝保护电路

有电源、保险丝、总开关 S、小灯泡 L、电流表 A、导线若干。要求保险丝保护整个电路，开关控制整个电路，电流表测量通过小灯泡的电流。

请画出电路图并连接实物。保险丝、总开关和电流表均应接在干路中。

### 23. 电铃和小灯泡并联

有电源、总开关 S、开关 S1、小灯泡 L、电铃各一个，导线若干。要求总开关 S 闭合后，小灯泡始终发光；S1 闭合时电铃响，S1 断开时电铃不响。

请画出电路图并连接实物。

### 24. 电动机正转的基本控制

有直流电源、开关 S、直流小电动机 M、滑动变阻器 R、导线若干。要求闭合 S 后电动机转动，调节滑动变阻器可改变电动机转速。

请画出电路图并连接实物。闭合开关前，应使滑动变阻器接入电路的阻值最大。

## 七、家庭电路题

### 25. 一个开关控制一盏灯

有火线 L、零线 N、开关 S、白炽灯（或普通灯座）各一个，导线若干。要求开关断开后，灯头的两个接线柱均不带电。

请画出家庭电路图并连接实物。开关必须接在火线上，灯泡螺旋套应接零线。

### 26. 插座、开关和电灯并联接入家庭电路

有火线 L、零线 N、三孔插座、开关 S、灯泡各一个，导线若干。要求插座和电灯能独立工作，开关只控制电灯，三孔插座的接地孔接保护地线。

请画出家庭电路图并连接实物。

### 27. 带保险装置的家庭电路

有进户火线 L、进户零线 N、总开关、保险装置、开关 S、灯泡、两孔插座各一个，导线若干。要求总开关控制全电路，保险装置对全电路起保护作用，开关 S 只控制灯泡，插座可独立使用。

请画出家庭电路图并连接实物。总开关和保险装置应安装在火线上，灯泡和插座应并联接入家庭电路。

## 参考答案

### 读图说明

以下文字电路图中，`+`、`-` 分别表示电源正、负极，`->` 表示电路中的连接顺序，`||` 表示并联，`{ }` 内为并联支路。电流表 `A` 必须串联，电压表 `V` 必须并联；仪表的正接线柱均应接近电源正极的一端。

### 一、基础连接题

#### 1. 单灯基本电路

电路图：`电源+ -> S -> L -> 电源-`

实物连接顺序为：电源正极接开关，开关接小灯泡，灯泡的另一接线柱接电源负极。开关位于电源正极与小灯泡之间。

#### 2. 两灯串联电路

电路图：`电源+ -> S -> L1 -> L2 -> 电源-`

将 L1 的一个接线柱与 L2 的一个接线柱相连，两灯首尾相接；开关与两灯串联。

#### 3. 两灯并联电路

电路图：`电源+ -> S -> { L1 || L2 } -> 电源-`

两灯的一端接在同一节点，另一端也接在同一节点；开关接在分支前的干路中。

#### 4. 串、并联混联电路

电路图：`电源+ -> S -> { (L1 -> L2) || L3 } -> 电源-`

先将 L1、L2 串联成一个支路，再使该支路与 L3 并联；开关串联在干路中。

### 二、开关控制题

#### 5. 一个开关控制两灯

电路图：`电源+ -> S -> { L1 || L2 } -> 电源-`

S 接在干路中，因此 S 断开时两个支路均无电流，S 闭合时两灯同时发光。

#### 6. 两个开关分别控制两灯

电路图：`电源+ -> { (S1 -> L1) || (S2 -> L2) } -> 电源-`

S1 与 L1 串联在一个支路中，S2 与 L2 串联在另一个支路中。闭合哪一个开关，就只有对应支路的灯发光。

#### 7. 开关控制一灯，另一灯常亮

电路图：`电源+ -> { L1 || (S -> L2) } -> 电源-`

L1 单独构成一条支路，始终与电源连通；S 与 L2 串联在另一支路中。

#### 8. 串联电路中的开关位置

两种接法如下：

1. `电源+ -> S -> L1 -> L2 -> 电源-`
2. `电源+ -> L1 -> S -> L2 -> 电源-`

开关串联在串联电路的任意位置，断开时都能切断整个电路，所以两灯均熄灭。

### 三、电流表和电压表题

#### 9. 电流表测单灯电流

电路图：`电源+ -> S -> A(0.6 A量程) -> L -> 电源-`

电流表与小灯泡串联，选用 `0~0.6 A` 量程；电流应从电流表的正接线柱流入、负接线柱流出。

#### 10. 电流表测干路电流

电路图：`电源+ -> S -> A -> { L1 || L2 } -> 电源-`

电流表接在分支前或汇合后的干路中，测得的是干路总电流。

#### 11. 电流表测支路电流

电路图：`电源+ -> S -> { L1 || (A -> L2) } -> 电源-`

电流表只与 L2 串联，不能接在干路中，因此测得的是通过 L2 的电流。

#### 12. 电压表测单灯两端电压

主电路：`电源+ -> S -> L -> 电源-`

将电压表并联在 L 的两个接线柱上。靠近电源正极的一端接电压表正接线柱，另一端接负接线柱。

#### 13. 电压表测串联电路中一只灯的电压

主电路：`电源+ -> S -> L1 -> L2 -> 电源-`

将电压表并联在 L2 两端，不要跨接在 L1 或两个灯的总两端。L2 靠近电源正极的一端接电压表正接线柱。

#### 14. 电流表和电压表同时使用

主电路：`电源+ -> S -> A -> L -> 电源-`

将电压表 V 并联在小灯泡 L 两端；电流表 A 串联在主电路中，测量通过小灯泡的电流。

### 四、滑动变阻器题

#### 15. 滑动变阻器限流保护

电路图：`电源+ -> S -> A -> L -> R -> 电源-`

滑动变阻器 R 应接一个上接线柱和一个下接线柱，使其以限流式串联接入电路。闭合开关前，滑片应移到使接入电路电阻最大的端点。

#### 16. 滑动变阻器电压分配

主电路：`电源+ -> S -> R0 -> R -> 电源-`

将电压表 V 并联在滑动变阻器接入电路的两端。R 使用一个上接线柱和滑片接线柱；移动滑片会改变接入电路的电阻和电压表示数。

### 五、探究实验电路题

#### 17. 探究串联电路电流规律

电路图：`电源+ -> S -> L1 -> L2 -> 电源-`

电流表应串联后依次接在 L1 前的 A 点、两灯之间的 B 点、L2 后的 C 点。实验结果应为：`IA = IB = IC`，即串联电路中各处电流相等。

#### 18. 探究并联电路电流规律

电路图：`电源+ -> S -> { L1 || L2 } -> 电源-`

电流表依次串联在 L1 支路、L2 支路和干路中，分别测得 `I1`、`I2`、`I`。实验结果应为：`I = I1 + I2`。

#### 19. 探究串联电路电压规律

主电路：`电源+ -> S -> L1 -> L2 -> 电源-`

电压表依次并联在 L1 两端、L2 两端和 L1、L2 串联部分两端，分别测得 `U1`、`U2`、`U`。实验结果应为：`U = U1 + U2`。

#### 20. 测量小灯泡的电功率

主电路：`电源+ -> S -> A -> L -> R -> 电源-`

将电压表 V 并联在小灯泡 L 两端。滑动变阻器使用一个上接线柱和滑片接线柱串联接入；闭合开关后，调节滑片使电压表示数为 `2.5 V`，读出电流表示数 `I`。

小灯泡两端电压为额定电压时，其额定功率为：`P额 = UI = 2.5 V x I`。

#### 21. 伏安法测定值电阻

主电路：`电源+ -> S -> A -> R -> Rx -> 电源-`

将电压表 V 并联在待测电阻 Rx 两端。调节滑动变阻器，读出 Rx 两端电压 `U` 和通过 Rx 的电流 `I`，计算：

`Rx = U / I`

滑动变阻器串联接入，既能限制电流，又能改变测量时的电压和电流。

### 六、特殊元件和安全连接题

#### 22. 保险丝保护电路

电路图：`电源+ -> 保险丝 -> S -> A -> L -> 电源-`

保险丝、总开关和电流表均串联在干路中，保险丝应能在电流过大时自动熔断，切断整个电路。

#### 23. 电铃和小灯泡并联

电路图：`电源+ -> S -> { L || (S1 -> 电铃) } -> 电源-`

总开关 S 接在干路中。S 闭合后，小灯泡所在支路始终有电流；S1 只控制电铃支路。

#### 24. 电动机正转的基本控制

电路图：`电源+ -> S -> R -> M -> 电源-`

滑动变阻器 R 使用一个上接线柱和滑片接线柱串联接入。闭合 S 前，应将滑片调至接入电阻最大的位置；移动滑片可改变电动机电流和转速。

### 七、家庭电路题

#### 25. 一个开关控制一盏灯

连接关系：`火线 L -> S -> 灯头中心触点 -> 灯泡 -> 灯头螺旋套 -> 零线 N`

开关必须串联在火线上。灯头中心触点接开关，螺旋套接零线；开关断开时，灯头两个接线柱都不带电。

#### 26. 插座、开关和电灯并联接入家庭电路

电灯支路：`火线 L -> S -> 灯头中心触点 -> 灯泡 -> 灯头螺旋套 -> 零线 N`

三孔插座支路：火线接 `L` 孔，零线接 `N` 孔，保护地线接接地孔。插座支路与电灯支路并联，因此插座和电灯可独立工作。

#### 27. 带保险装置的家庭电路

干路连接：`进户火线 L -> 总开关 -> 保险装置 -> 分支点`

从分支点引出两条支路：

1. 灯泡支路：`火线 -> S -> 灯头中心触点 -> 灯泡 -> 灯头螺旋套 -> 零线 N`
2. 两孔插座支路：正对插座时，零线接左孔，火线接右孔。

灯泡和插座并联，总开关和保险装置均装在火线上，因此总开关可控制全电路，保险装置可保护全电路。
