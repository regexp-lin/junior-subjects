# 摩擦力提高题

## 一、什么时候会产生摩擦力

摩擦力不是物体一接触就一定有，而是要满足一定条件才会产生。

### 1. 产生摩擦力的条件

两个物体之间产生摩擦力，一般需要同时满足以下条件：

1. 两个物体相互接触。
2. 接触面不光滑。
3. 两个物体之间有挤压作用。
4. 接触面之间有相对运动或有相对运动趋势。

### 2. 摩擦力的方向

摩擦力的方向总是与相对运动方向或相对运动趋势方向相反，而不是一定和物体运动方向相反。

例如：

- 人走路时，脚向后蹬地，脚有相对地面向后运动的趋势，因此地面对脚的摩擦力方向向前。
- 推箱子但箱子没动时，箱子有向前运动趋势，地面对箱子的静摩擦力方向向后。
- 箱子在地面上向右滑动时，地面对箱子的滑动摩擦力方向向左。

### 3. 摩擦力的种类

1. 静摩擦力：物体之间没有发生相对滑动，但有相对运动趋势时产生。
2. 滑动摩擦力：物体之间已经发生相对滑动时产生。
3. 滚动摩擦：物体滚动时也会受到阻碍作用，通常比滑动摩擦小。

### 4. 影响滑动摩擦力大小的因素

在初中阶段，滑动摩擦力大小主要与以下因素有关：

1. 压力大小：压力越大，滑动摩擦力通常越大。
2. 接触面的粗糙程度：接触面越粗糙，滑动摩擦力通常越大。

与接触面积大小、物体运动速度大小通常无关。

### 5. 对静摩擦力的理解

静摩擦力大小不是固定不变的，它会随着外力变化而变化，在一定范围内“自动调节”，但不会无限增大。当外力增大到一定程度，超过最大静摩擦力后，物体就会开始滑动，此时静摩擦力转化为滑动摩擦力。

## 二、摩擦力提高题与难题

### 1. 判断摩擦力是否存在

放在水平地面上的木箱，受到水平向右的推力 8N，但木箱保持静止。关于木箱所受摩擦力，下列判断正确的是：

A. 不受摩擦力  
B. 受 8N、方向向右的摩擦力  
C. 受 8N、方向向左的摩擦力  
D. 受大于 8N、方向向左的摩擦力

**答案：** C

**解析：**  
木箱静止，说明它在水平方向上受力平衡。推力向右 8N，则摩擦力必定向左，且大小等于 8N，用来平衡推力。所以选 C。这是静摩擦力，方向与木箱相对运动趋势相反。

### 2. 判断摩擦力方向

人在水平地面上匀速向前行走时，地面对人的摩擦力方向是：

A. 向后  
B. 向前  
C. 竖直向上  
D. 没有摩擦力

**答案：** B

**解析：**  
人走路时，脚向后蹬地，脚有相对地面向后运动的趋势，所以地面对脚的摩擦力方向向前。正是这个向前的摩擦力使人前进。很多学生误以为摩擦力一定阻碍运动，这是错误的。

### 3. 关于影响滑动摩擦力因素的探究

某同学用弹簧测力计拉着木块在水平桌面上做匀速直线运动，第一次拉力为 2.4N；在木块上再放一个砝码后，匀速拉动时拉力为 3.2N。该实验说明滑动摩擦力大小与什么因素有关？

**答案：** 与压力大小有关。

**解析：**  
木块匀速运动时，拉力与滑动摩擦力是一对平衡力，大小相等。第一次摩擦力为 2.4N，第二次为 3.2N。第二次在木块上加了砝码，增大了木块对桌面的压力，摩擦力随之增大，说明滑动摩擦力与压力大小有关。

### 4. 判断是否受摩擦力

一个木块放在粗糙的水平传送带上，随传送带一起向右做匀速直线运动，且木块相对传送带静止。若把木块视为研究对象，则下列说法正确的是：

A. 木块一定受向右的摩擦力  
B. 木块一定受向左的摩擦力  
C. 木块一定不受摩擦力  
D. 木块是否受摩擦力，要看木块在水平方向是否有受力不平衡的需要

**答案：** D

**解析：**  
木块与传送带相对静止，但相对静止不代表一定没有摩擦力。若木块已经随传送带匀速运动，且水平方向不需要额外外力维持，可能不受摩擦力；若木块刚放上传送带时需要加速，则会受向右的摩擦力。因此是否受摩擦力，要结合具体运动状态判断，选 D。

### 5. 静摩擦力大小变化

一个放在水平地面上的箱子，受到水平向右的拉力 F 作用。开始时 F=2N，箱子不动；后来 F 增大到 5N，箱子仍不动；再后来 F 增大到 9N，箱子开始运动。关于前两种情况下箱子受到的摩擦力大小，下列说法正确的是：

A. 一直是 9N  
B. 分别是 2N 和 5N  
C. 都是 0  
D. 分别是 2N 和 9N

**答案：** B

**解析：**  
在箱子未运动前，摩擦力为静摩擦力，大小会随着拉力变化而变化，并始终与拉力平衡。因此当拉力为 2N 时，摩擦力为 2N；当拉力为 5N 时，摩擦力为 5N。到 9N 时箱子开始运动，说明 9N 已经超过了最大静摩擦力。

### 6. 二力平衡与摩擦力

重 20N 的物块放在水平桌面上，用 6N 的水平拉力使其在桌面上做匀速直线运动，则物块受到的滑动摩擦力大小为多少？桌面对物块的支持力大小为多少？

**答案：** 滑动摩擦力为 6N，支持力为 20N。

**解析：**  
物块做匀速直线运动，说明水平方向受力平衡，故滑动摩擦力与拉力大小相等，均为 6N。  
在竖直方向上，物块静止，支持力与重力平衡，因此支持力大小等于重力，为 20N。

### 7. 增大与减小摩擦的方法

下列做法中，属于减小摩擦的是：

A. 运动员上单杠前在手上涂镁粉  
B. 鞋底做有花纹  
C. 机器转动部分加润滑油  
D. 自行车刹车时用力捏闸

**答案：** C

**解析：**  
A、B、D 都是通过增大粗糙程度或增大压力来增大摩擦。C 是在接触面之间加入润滑油，使接触面更光滑，从而减小摩擦。

### 8. 摩擦力与运动方向的关系

木块沿粗糙斜面匀速下滑，关于木块所受摩擦力的方向，下列说法正确的是：

A. 沿斜面向下  
B. 沿斜面向上  
C. 竖直向上  
D. 垂直斜面向上

**答案：** B

**解析：**  
木块相对斜面向下滑动，因此摩擦力方向与相对运动方向相反，沿斜面向上。摩擦力一定沿接触面，不能垂直于接触面。

### 9. 实验数据分析题

在“探究滑动摩擦力大小与哪些因素有关”的实验中，得到如下数据：

1. 木块放在木板上，匀速拉动时弹簧测力计示数为 1.8N。
2. 在木块上加一个重物后，匀速拉动时示数为 2.6N。
3. 木块放在毛巾表面上，其他条件与第 1 次相同，匀速拉动时示数为 3.0N。

根据实验回答：

（1）第 1 次实验中木块受到的滑动摩擦力为多少？  
（2）比较第 1、2 次实验，可得出什么结论？  
（3）比较第 1、3 次实验，可得出什么结论？

**答案：**  
（1）1.8N。  
（2）在接触面粗糙程度相同时，压力越大，滑动摩擦力越大。  
（3）在压力相同时，接触面越粗糙，滑动摩擦力越大。

**解析：**  
木块被匀速拉动时，拉力与摩擦力平衡，所以摩擦力等于测力计示数。实验 2 只改变了压力，实验 3 只改变了接触面的粗糙程度，因此可以分别得出对应结论。

### 10. 受力分析综合题

用 10N 的水平拉力拉着重 30N 的木箱在水平地面上匀速运动。若拉力突然增大到 16N，在木箱刚开始加速的瞬间，木箱受到的摩擦力大小最可能是：

A. 0N  
B. 10N  
C. 16N  
D. 30N

**答案：** B

**解析：**  
原来木箱匀速运动，说明滑动摩擦力等于 10N。当拉力突然增大到 16N 的瞬间，木箱仍在地面上滑动，因此仍受滑动摩擦力，大小主要由压力和接触面粗糙程度决定，并不会立刻变成 16N，仍最可能是 10N。此时木箱开始加速，是因为合力变为 16N-10N=6N。

### 11. 最大静摩擦力理解题

一木块静止在水平地面上，若用水平拉力拉它，拉力从 0 开始逐渐增大。已知木块刚开始滑动时，拉力为 12N；木块滑动后，保持匀速运动只需 10N 拉力。则下列说法正确的是：

A. 木块静止时不受摩擦力  
B. 木块静止时摩擦力始终为 12N  
C. 木块匀速滑动时受到的摩擦力为 10N  
D. 木块开始滑动后摩擦力增大

**答案：** C

**解析：**  
木块静止时，若受拉力就受静摩擦力，且大小等于拉力，在 0 到 12N 范围内变化。12N 是最大静摩擦力。木块滑动后变为滑动摩擦力，匀速运动所需拉力为 10N，所以滑动摩擦力为 10N。由此可知滑动摩擦力小于最大静摩擦力。

### 12. 图像信息题

某同学用水平拉力 F 拉木块，记录木块所受摩擦力 f 随 F 变化的大致关系如下：在 F 从 0 增大到 8N 的过程中，f 始终等于 F；当 F 超过 8N 后，木块开始滑动，f 保持 6N 不变。根据这些信息判断：

（1）木块受到的最大静摩擦力是多大？  
（2）木块滑动时受到的滑动摩擦力是多大？  
（3）当拉力为 5N 时，摩擦力为多大？  
（4）当拉力为 10N 时，木块所受合力为多大？

**答案：**  
（1）8N。  
（2）6N。  
（3）5N。  
（4）4N。

**解析：**  
由题意知，F 在 0 到 8N 时，木块未动，摩擦力与拉力相等，因此最大静摩擦力为 8N。超过 8N 后木块滑动，摩擦力稳定为 6N。  
当拉力为 5N 时，木块仍静止，所以摩擦力为 5N。  
当拉力为 10N 时，木块滑动，摩擦力为 6N，所以合力为 10N-6N=4N。

### 13. 传送带难题

水平传送带向右匀速运动。将一个原来静止的小木块轻放到传送带左端后的一段时间内，小木块先加速后与传送带一起匀速运动。下列关于这段过程中木块受摩擦力的说法正确的是：

A. 始终不受摩擦力  
B. 始终受向左的摩擦力  
C. 先受向右的摩擦力，后来摩擦力可能为 0  
D. 先受向左的摩擦力，后来摩擦力可能为 0

**答案：** C

**解析：**  
木块刚放到传送带上时，木块速度小于传送带速度，有相对传送带向左滑动的趋势，所以传送带给木块的摩擦力方向向右，使木块加速。当木块速度增大到与传送带相同并保持匀速时，如果不需要额外水平力，则摩擦力可能为 0。

### 14. 斜面静止分析题

质量分布均匀的木块静止在粗糙斜面上。关于木块受到的摩擦力，下列说法正确的是：

A. 一定沿斜面向下  
B. 一定沿斜面向上  
C. 一定等于木块重力  
D. 可能为 0

**答案：** B

**解析：**  
木块静止在斜面上，有沿斜面向下滑动的趋势，所以静摩擦力方向一定沿斜面向上。摩擦力大小只需与重力沿斜面向下的分力平衡，不等于整个重力，因此 C 错。若斜面粗糙且木块能静止，则通常需要摩擦力，不是 0。

### 15. 推而不动与推动后运动

同一木箱放在同一水平地面上，小明先用 15N 水平力推木箱，木箱未动；后改用 22N 水平力推木箱，木箱恰好做匀速直线运动。则下列判断正确的是：

A. 木箱未动时不受摩擦力  
B. 木箱未动时受到的摩擦力为 22N  
C. 木箱匀速运动时受到的滑动摩擦力为 22N  
D. 木箱未动时受到的最大静摩擦力一定为 15N

**答案：** C

**解析：**  
木箱未动时，若受 15N 推力，则受到 15N 的静摩擦力。改用 22N 推力时恰好匀速运动，说明木箱所受滑动摩擦力为 22N。最大静摩擦力应不小于使物体开始运动的临界值，题目并未说明 15N 已经达到最大静摩擦力，所以 D 错。

### 16. 接触面积迷惑题

把同一木块分别平放、侧放在同一粗糙水平桌面上，用弹簧测力计匀速拉动，发现两次示数相同。这说明滑动摩擦力大小与下列哪个因素无关？

**答案：** 与接触面积大小无关。

**解析：**  
平放和侧放时，木块与桌面的接触面积发生改变，但木块重力不变，桌面粗糙程度不变。实验中两次拉力相同，说明滑动摩擦力相同，因此可得出在该实验条件下，滑动摩擦力与接触面积大小无关。

### 17. 受力变化难题

重 40N 的物块在水平地面上被 12N 的水平拉力拉着做匀速直线运动。若把物块重力增大到 60N，接触面粗糙程度不变，要使物块仍做匀速直线运动，则水平拉力将：

A. 大于 12N  
B. 等于 12N  
C. 小于 12N  
D. 可能等于 0

**答案：** A

**解析：**  
在水平面上，压力等于重力。物块重力由 40N 增大到 60N，压力增大。接触面粗糙程度不变时，滑动摩擦力增大。若要继续匀速运动，则拉力仍需与摩擦力平衡，所以拉力应大于 12N。

### 18. 多状态比较题

同一物块在同一水平面上经历如下三个过程：

甲：用 4N 拉力拉，物块静止；  
乙：用 7N 拉力拉，物块仍静止；  
丙：用 10N 拉力拉，物块做匀速直线运动。

则甲、乙、丙三种情况下物块受到的摩擦力大小分别为：

**答案：** 4N、7N、10N。

**解析：**  
甲、乙中物块静止，所受静摩擦力分别与拉力平衡，所以分别为 4N、7N。  
丙中物块匀速直线运动，所受滑动摩擦力与拉力平衡，所以为 10N。  
这说明静摩擦力大小可变，滑动摩擦力在该接触条件下可视为定值。

### 19. 生活情境解释题

汽车陷入泥地后，司机常在驱动轮下垫上木板或石块，再缓慢起步。请用摩擦力知识解释这样做的原因。

**答案：**  
在驱动轮下垫木板或石块，是为了增大轮胎与地面之间的粗糙程度，从而增大摩擦力。这样驱动轮更不容易空转，地面对车轮的摩擦力增大，汽车更容易获得向前的牵引力而脱困。

**解析：**  
汽车前进依靠地面对驱动轮的摩擦力。泥地太滑时，摩擦力过小，轮胎容易打滑。垫木板或石块后，接触面变粗糙，摩擦力增大，有利于起步和脱困。

### 20. 压轴综合题

甲、乙两木块叠放在水平桌面上，如图景可想象为“甲在上，乙在下”。现用水平力 F 拉乙，使甲、乙一起向右做匀速直线运动。已知甲重 10N，乙重 20N，甲、乙之间的摩擦力大小为 3N。请回答：

（1）甲受到的摩擦力方向是什么？  
（2）乙受到甲的摩擦力方向是什么？  
（3）若甲、乙一起匀速运动，则桌面对乙的摩擦力大小与拉力 F 有什么关系？  
（4）若突然撤去拉力 F，在甲、乙尚未分离前，甲受到的摩擦力方向可能怎样变化？

**答案：**  
（1）向右。  
（2）向左。  
（3）桌面对乙的摩擦力与拉力 F 大小相等、方向相反。  
（4）撤去拉力后，甲受到的摩擦力可能变为向左。

**解析：**  
甲、乙一起向右匀速运动，说明甲没有相对乙滑动。甲受到 3N 摩擦力，若该摩擦力不存在或方向不对，题目给出的“甲、乙之间摩擦力大小为 3N”就没有意义。因为甲要与乙保持共同运动，在某些情境下甲受到乙对它的摩擦力可向右。根据力的作用是相互的，乙受到甲对它的摩擦力方向向左，大小也为 3N。  
对整体甲乙分析，整体做匀速直线运动，水平方向受力平衡，所以拉力 F 与桌面对乙的摩擦力大小相等、方向相反。  
若突然撤去 F，乙由于受桌面摩擦会减速，甲由于惯性要保持原来的运动状态，相对乙有继续向前的趋势，所以乙对甲的摩擦力可能改为向左，以阻碍甲相对乙向前滑动。

## 三、总结提升

学习摩擦力时，最容易出错的地方有三个：

1. 误以为“运动的物体一定受摩擦力，静止的物体一定不受摩擦力”。
2. 误以为“摩擦力一定与运动方向相反”。
3. 误以为“静摩擦力大小固定不变”。

解决摩擦力问题时，建议按以下步骤思考：

1. 先判断接触面之间是否有相对运动或相对运动趋势。
2. 再判断摩擦力方向，一定与相对运动或相对运动趋势方向相反。
3. 最后结合平衡条件或运动状态分析摩擦力大小。

只要把“是否有相对运动趋势”这个关键点抓住，绝大多数摩擦力难题都能突破。
