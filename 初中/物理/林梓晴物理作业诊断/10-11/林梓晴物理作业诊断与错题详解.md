## 三 错题详细讲解

### 1 图片 A 第 1 题 验电器连接时谁在移动

**题目条件**：两个相同验电器，A 带正电，B 不带电，用带绝缘柄的不带电金属棒连接，要求选出“错误”的说法。

**学生选 C，正确选 B。**

首先，A 带正电说明它相对于电中性状态**缺少电子**，不是说金属中的正电荷会自由移动。金属导体内能够自由移动的带电粒子是自由电子。

连接的一瞬间，B 中的一部分自由电子经过金属棒进入缺少电子的 A。因此：

- **自由电子运动方向：B → A。**
- **常规电流方向：A → B。**

电流方向规定为正电荷定向移动的方向。电子带负电，所以在金属导体中，电流方向与自由电子定向移动的方向相反。

逐项判断如下。

| 选项 | 题目说法 | 判断及原因 |
| --- | --- | --- |
| A | 金属棒中电流从 A 流向 B | 正确，与电子的 B → A 方向相反 |
| B | 正电荷从 A 流向 B | 错误，金属中的正电荷并没有这样自由移动 |
| C | 自由电子从 B 流向 A | 正确，电子进入缺少电子的 A |
| D | A 的金属箔张开是因为同种电荷相互排斥 | 正确，两片金属箔都带正电，互相排斥 |

所以，本题选择 **B**。选项 A 的电流方向正确，并不意味着选项 B 中真的有正电荷沿该方向流动。

**易错提醒**：先看题目要求选“正确”还是“错误”，再分别写出电子方向和电流方向。不能把“电流从 A 到 B”直接理解成“正电荷从 A 到 B”。

### 2 图片 D 第 2 题 相互吸引不能直接判定异种电荷

**题目条件**：甲与乙相互排斥，乙与丙相互吸引；已知丙带负电，问甲的电性。

**学生选 D“可能带负电”，正确选 B“一定带正电”。**

这道题要结合两个关系，不能只看乙与丙的吸引关系。

**第一步，从甲与乙相互排斥出发。**

按照本题采用的初中电荷判断规则，同种电荷相互排斥。因此，甲、乙**都带电，而且带同种电荷**。这一步已经排除了乙不带电的可能。

**第二步，分析乙与带负电的丙相互吸引。**

如果只知道乙被负电的丙吸引，乙有两种可能：

1. 乙带正电，异种电荷相互吸引。
2. 乙不带电，因为带电体也能吸引轻小的不带电物体。

但第一步已经知道乙带电，所以第二种可能被排除，只剩下：**乙带正电**。

**第三步，由乙推回甲。**

甲与乙相互排斥，电荷种类相同；乙带正电，所以甲也**一定带正电**，选 B。

完整推理链是：

**甲乙排斥 → 乙一定带电 → 乙与负电丙吸引 → 乙为正电 → 甲为正电。**

**易错提醒**：“相互吸引”不能单独证明两个物体带异种电荷；“相互排斥”在此类题中可以确定二者都带同种电荷。本题应先使用信息更确定的排斥关系。

### 3 图片 B 第 7 题 A 失去电子后带什么电

**学生答案**：带负电；电子的转移。

**正确答案**：带正电；电子的转移。第二空已经正确，只需订正第一空。

图示中 A 对应的核外电子数少于电中性时所需的电子数，B 则多出电子，表示摩擦时电子从 **A 转移到 B**。A 失去了一部分带负电的电子，原子核的正电荷并没有随之减少，因此 A 的负电荷总量变小，整体表现为**带正电**。

可以用原来不带电的物体作对比：

| 状态 | 正负电荷的关系 | 物体表现 |
| --- | --- | --- |
| 原来不带电 | 正负电荷总量大小相等 | 电中性 |
| 失去电子后 | 负电荷总量减少，正电荷占优势 | 带正电 |
| 得到电子后 | 负电荷总量增加，负电荷占优势 | 带负电 |

摩擦起电的本质是**电子的转移**，不是摩擦创造了电荷，也不是把原子核中的正电荷从一个物体搬到另一个物体。

**记忆方法**：电子是负的，失去“负”就偏“正”，得到“负”就偏“负”。判断物体带什么电，要看摩擦后电子是多了还是少了，不要把“电子带负电”理解成“失去电子的物体带负电”。

### 4 图片 C 第 10 题第 2 小问 怎样使用摩擦起电次序表

**题目规则**：表格中任意两种物体相互摩擦时，次序在前的带正电，次序在后的带负电。

本题相关次序是：

**石棉 → 玻璃 → 云母 → 化纤 → 毛皮 → 铅。**

箭头仅表示从前到后的排列，不表示电子运动方向。

**学生填“负；得到”，正确应填“正；失去”。**

石棉排在玻璃前面。严格按题目给出的规则，石棉与玻璃棒摩擦后：

- 石棉在前，带**正电**，说明石棉**失去电子**。
- 玻璃在后，带**负电**，说明玻璃**得到电子**。
- 两者之间的电子转移方向是 **石棉 → 玻璃**。

因此，石棉这一空必须填写 **“正；失去”**。

这里还要区分“常见例子”与“当前比较对象”：玻璃与丝绸摩擦时，玻璃带正电；但玻璃与表中位置更靠前的石棉摩擦时，玻璃带负电。**不能记成玻璃只要摩擦就一定带正电。**摩擦后的电性取决于它与哪种物质相互摩擦。

同一规则也能验证你已经答对的第 3 小问：云母排在毛皮前面，与毛皮摩擦时云母失去电子、毛皮得到电子，说明云母对电子的束缚能力比毛皮**弱**。

**解题步骤**：先找两种材料在表中的相对位置，再按“前正后负”判电性，最后用“正失负得”确定得失电子。

### 5 图片 E 第 6 题 电荷量的负号和金属导电的原因

本题有两个地方需要处理：电子总电荷量漏负号，最后一空没有填写。核外电子数和不显电性的解释正确。

**完整正确答案依次为**：

1. **50**。
2. **-8×10^-18 C**。
3. **原子核的正电荷与核外电子的负电荷总量大小相等，电性相互抵消**。
4. **金属中有大量自由电子**。

#### 核外为什么有 50 个电子

一个通常呈电中性的锡原子，原子核带有相当于 50 个电子电荷量大小的正电荷。要使整个原子的正负电荷总量大小相等，核外就应有 **50 个电子**。

这不是说锡原子内部没有电荷，而是说其正、负电荷相互抵消后，**净电荷为零**。

#### 电子总电荷量为什么必须带负号

一个电子的电荷量是：

**q电子 = -1.6×10^-19 C。**

50 个电子的总电荷量为：

**Q电子 = 50×(-1.6×10^-19 C) = -8.0×10^-18 C。**

你写出的 **8×10^-18** 在数值大小上正确，但题目问的是电子所带的电荷，应保留电子的负电性，所以必须加负号。

要特别区分三个量：

- 原子核所带的电荷：**+8×10^-18 C**。
- 核外全部电子所带的电荷：**-8×10^-18 C**。
- 整个电中性锡原子的净电荷：**0 C**。

如果题目明确只问“电荷量的大小”，才可以只写 **8×10^-18 C**。本题并没有这样限定。

#### 不显电性为什么不妨碍金属导电

“不显电性”说明正、负电荷总量大小相等，并不说明没有电子，也不说明电子都不能移动。

金属中有大量可以在金属内部自由移动的**自由电子**，所以容易导电。在电源作用下，这些自由电子发生定向移动，就形成电流。

最后一空可直接补写：**金属中有大量自由电子。**更完整的表述是：金属中有大量自由电子，在电源作用下能发生定向移动，从而形成电流。

## 四 已做对题目的简要说明

### 图片 A 第 2 题 持续电流条件

选 **A** 正确：电路中要有电源，还要形成闭合回路。有电源但回路断开，不能形成持续电流；只有开关或用电器也不够。

注意，这不是建议把电源两极直接用导线连接。实际电路还必须避免电源短路。

### 图片 D 第 1 题 毛皮摩擦两个橡胶气球

选 **B** 正确。两个橡胶气球分别与干燥毛皮摩擦，都得到电子、带负电。两个气球带同种电荷，相互排斥，悬线应向外张开，符合图 B。

### 图片 C 第 10 题其他小问

- 第 1 小问填 **“正”** 正确。与丝绸摩擦过的玻璃棒所带的电荷被规定为正电荷。
- 第 3 小问填 **“弱”** 正确。云母相对于毛皮更容易失去电子，说明对电子的束缚能力更弱。
- 第 4 小问填 **“同种；排斥；验电器”** 均正确。头发丝带同种电荷而相互排斥；验电器的金属箔张开也利用同种电荷相互排斥的原理。这里比较的是题目涉及的静电排斥原理，不是说静电球装置与验电器的全部结构完全相同。

## 五 订正后应掌握的判断规则

| 遇到的问题 | 应使用的规则 |
| --- | --- |
| 得到电子后带什么电 | 原来不带电的物体得到电子，带负电 |
| 失去电子后带什么电 | 原来不带电的物体失去电子，带正电 |
| 摩擦是否创造电荷 | 不创造电荷，是电子发生转移 |
| 金属中的电流方向 | 与自由电子定向移动方向相反 |
| 两物体相互排斥 | 本题模型下，两者都带同种电荷 |
| 两物体相互吸引 | 可能带异种电荷，也可能一个带电、另一个不带电 |
| 摩擦次序表怎么读 | 按题目规则：前正后负，正失负得 |
| 计算电子电荷量 | 电子电荷为负，计算时不能漏负号 |
| 物体不显电性 | 正负电荷总量大小相等，不是内部没有电荷 |
| 金属为什么导电 | 内部有大量自由电子 |

## 六 自测练习与答案

订正后先不看答案，口头说出结论和理由，再核对。

1. 两个原来不带电的物体 X、Y 摩擦，电子从 X 转移到 Y。X、Y 分别带什么电？
2. 带负电物体吸引一个轻小球，仅凭这一条件，能否确定小球一定带正电？
3. 金属导体中自由电子从右向左定向移动，电流方向是什么？
4. 两个轻小球 P、Q 相互排斥，Q 又被带正电的 R 吸引。P 带什么电？
5. 10 个电子的总电荷量是多少？

**参考答案**：

1. X 带正电，Y 带负电。X 失去电子，Y 得到电子。
2. 不能。小球可能带正电，也可能不带电。
3. 从左向右，与自由电子定向移动方向相反。
4. P 带负电。P、Q 排斥说明 Q 带电；Q 被正电 R 吸引，所以 Q 带负电；P 与 Q 同种，故 P 也带负电。
5. **-1.6×10^-18 C**。10×(-1.6×10^-19 C) = -1.6×10^-18 C。
