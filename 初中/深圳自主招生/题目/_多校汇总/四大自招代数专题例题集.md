## 模块一 · 计算与找规律

### 例题 1 · 巧算代数式

**1.**（深外自招）$\dfrac{1}{3} + \dfrac{1}{15} + \dfrac{1}{35} + \cdots + \dfrac{1}{35\times37} = \underline{\qquad}$。

**2.** $\dfrac{1}{1+\sqrt{2}} + \dfrac{1}{\sqrt{3}+\sqrt{2}} + \dfrac{1}{\sqrt{4}+\sqrt{3}} + \cdots + \dfrac{1}{\sqrt{2019}+\sqrt{2020}} + \dfrac{1}{\sqrt{2020}+\sqrt{2021}} + \dfrac{1}{\sqrt{2021}+\sqrt{2022}}$ 的整数部分是 $\underline{\qquad}$。

**3.**（深外自招）$\sqrt{6+3\sqrt{3}} + \sqrt{6-3\sqrt{3}} = \underline{\qquad}$。

**4.**（四大）设 $A = \dfrac{1^2+2^2}{1\times2} + \dfrac{2^2+3^2}{2\times3} + \dfrac{3^2+4^2}{3\times4} + \cdots + \dfrac{1003^2+1004^2}{1003\times1004} + \dfrac{1004^2+1005^2}{1004\times1005}$，求 $A$ 的整数部分。

**5.**（四大）计算 $\dfrac{1}{1\times2\times3} + \dfrac{1}{2\times3\times4} + \cdots + \dfrac{1}{98\times99\times100}$ 的和。

### 例题 2 · 代数式的恒等变形

**6.** 已知 $x$ 是实数，并且 $x^3 + 2x^2 + 2x + 1 = 0$，则 $x^{1994} + x^{1997} + x^{2000}$ 的值是 $\underline{\qquad}$。

**7.** 设 $a,b,c$ 为实数，$x = a^2 - 2b + \dfrac{\pi}{3}$，$y = b^2 - 2c + \dfrac{\pi}{6}$，$z = c^2 - 2a + \dfrac{\pi}{2}$，则 $x,y,z$ 中，至少有一个值（　）　A. 大于 0　B. 等于 0　C. 不大于 0　D. 小于 0

**8.**（实验自招）若 $\dfrac{1}{x} + \dfrac{1}{y} = 2$，则 $\dfrac{2x + 3xy + 2y}{x + 2xy + y} = \underline{\qquad}$。

**9.**（深中自招）若 $\begin{cases} \dfrac{1}{3-x} + \dfrac{1}{y-2} = 2 \\[4pt] \dfrac{2}{3-x} - \dfrac{5}{y-2} = -3 \end{cases}$，求 $17x^2 + 10y^2 = \underline{\qquad}$。

**10.** 已知 $\dfrac{x}{x^2 - x - 1} = 4$，求 $\dfrac{x^2}{x^4 + x^2 + 1}$ 的值为 $\underline{\qquad}$。

**11.** 已知 $a,b,c$ 三个数满足 $\dfrac{ab}{a+b} = \dfrac{1}{3}$，$\dfrac{bc}{b+c} = \dfrac{1}{4}$，$\dfrac{ca}{c+a} = \dfrac{1}{5}$，则 $\dfrac{abc}{ab+bc+ca}$ 的值为（　）　A. $\dfrac{1}{6}$　B. $\dfrac{1}{12}$　C. $\dfrac{2}{15}$　D. $\dfrac{1}{20}$

**12.**（深中自招·四大）已知 $xyz \ne 0$，且 $x + 2y + z = 0$，$5x + 4y - 4z = 0$。设 $\dfrac{x^2 + 6y^2 - 10z^2}{3x^2 - 4yz + 5z^2} = \dfrac{m}{n}$，其中 $m,n$ 是两个互质的正整数，则 $10m + n = \underline{\qquad}$。

**13.**（深中自招·四大）已知三个非零实数 $x,y,z$ 满足 $\sqrt{x+y} + \sqrt{y+z} = \sqrt{z+x}$，则 $\dfrac{1}{x} + \dfrac{1}{y} + \dfrac{1}{z} + 600$ 的值等于 $\underline{\qquad}$。

**14.**（深中自招·四大）已知 $a^2 + b^2 + c^2 = (a+b+c)^2$，则 $\dfrac{b+c}{a} + \dfrac{c+a}{b} + \dfrac{a+b}{c} + 100 = \underline{\qquad}$。

**15.**（四大）已知 $abc = 1$，$a + b + c = 2$，$a^2 + b^2 + c^2 = 3$，则 $\dfrac{1}{ab+c-1} + \dfrac{1}{bc+a-1} + \dfrac{1}{ca+b-1}$ 的值为（　）　A. $-1$　B. $-\dfrac{1}{2}$　C. $2$　D. $-\dfrac{2}{3}$

### 例题 3 · 恒等变形与降幂思想

**16.** 设 $x = \dfrac{1}{\sqrt{2}-1}$，$a$ 是 $x$ 的小数部分，$b$ 是 $-x$ 的小数部分，则 $a^3 + b^3 + 3ab$ 的值为（　）　A. $4\sqrt{2}+2$　B. $4\sqrt{2}+3$　C. $2$　D. $1$

**17.** 设 $a^2 + 1 = 3a$，$b^2 + 1 = 3b$，且 $a \ne b$，则代数式 $\dfrac{1}{a^2} + \dfrac{1}{b^2}$ 的值为（　）　A. 5　B. 7　C. 9　D. 11

**18.**（深中自招）设 $\dfrac{a}{b} = a + 2$，$\dfrac{a}{b} = a - 2$，则 $\dfrac{b^2}{(a-2)^2} = \underline{\qquad}$。
> 注：原图两条件均写作 $\dfrac{a}{b}$，疑为「$ab = a+2$，$\dfrac{a}{b} = a-2$」之类的笔误，🔴 以原图为准，做题时请核对。

**19.** $m = \dfrac{2020}{\sqrt{2021}-1}$，则 $m^5 - 2m^4 - 2020m^3 + m^2 - 2m - 2021$ 的值为 $\underline{\qquad}$。

### 例题 4 · 代数式与规律探索

**20.**（深中自招·四大）已知正整数 $a,b,m$，满足 $a + b = m + 2$，$ab = 4m$，则所有满足条件的 $m$ 的值的和为 $\underline{\qquad}$。

**21.**（深中自招·四大）设 $n$ 为正整数，$n^2 + n + 51$ 是完全平方数，则所有 $n$ 的可能值之和为 $\underline{\qquad}$。

**22.**（四大）若实数 $a$ 满足方程 $a = \sqrt{1 - \dfrac{1}{a}} + \sqrt{a - \dfrac{1}{a}}$，则 $[a] = $（　）（其中 $[a]$ 表示不超过 $a$ 的最大整数）　A. 0　B. 1　C. 2　D. 3

**23.** 古希腊著名的毕达哥拉斯学派把 $1,3,6,10,\cdots$ 这样的数称为「三角形数」，而把 $1,4,9,16,\cdots$ 这样的数称为「正方数」。任何一个大于 1 的「正方数」都可以看作两个相邻「三角形数」之和（如 $4=1+3$，$9=3+6$，$16=6+10$）。下列等式中，符合这一规律的是（　）　A. $20=6+14$　B. $25=9+16$　C. $36=16+20$　D. $49=21+28$

**24.** 一个纸环链，纸环按红黄绿蓝紫的顺序重复排列，被截去其中一部分，剩下部分如图所示（红黄绿蓝紫红黄绿 … 黄绿蓝紫），则被截去部分纸环的个数可能是（　）　A. 2020　B. 2019　C. 2018　D. 2017

**25.**（四大）我们将 $1\times2\times3\times\cdots\times n$ 记作 $n!$，如 $5! = 1\times2\times3\times4\times5$，$100! = 1\times2\times3\times\cdots\times100$。若设 $S = 1\times1! + 2\times2! + 3\times3! + \cdots + 2007\times2007!$，则 $S$ 除以 2008 的余数是（　）　A. 0　B. 1　C. 1004　D. 2007

**26.** 将正整数按图方式进行有规律的排列（第 2 行最后一个数是 4，第 3 行最后一个数是 7，第 4 行最后一个数是 10，…）。按此规律，若 2022 是第 $m$ 行第 $n$ 个数，则 $m,n$ 的值分别是（　）　A. $m=674,n=1346$　B. $m=674,n=1347$　C. $m=675,n=1348$　D. $m=675,n=1349$

**27.**（高级自招）将从 1 开始的连续奇数按图所示的规律排列，例如位于第 4 行第 3 列的数为 27，则位于第 32 行第 12 列的数是（　）　A. 2025　B. 2023　C. 2021　D. 2019

**28.** 甲、乙两动点分别从正方形 ABCD 的顶点 $A$、$C$ 同时沿正方形的边开始移动，甲点依顺时针方向环行，乙点依逆时针方向环行，若乙的速度是甲的速度的 4 倍，则它们第 2020 次相遇在边（　）上。　A. $AB$　B. $BC$　C. $CD$　D. $DA$

## 模块二 · 方程（组）与不等式

### 例题 5 · 绝对值方程及不等式

**29.** 对于全体实数 $x$，不等式 $|x-1| + 2|x-9| + |x-2| + |x-10| + |x-11| \ge m$ 恒成立，则 $m$ 的最大值为 $\underline{\qquad}$。

**30.**（深中自招）满足 $(|x-2|-|x-6|)(|x-6|-|x-12|)(|x-12|-|x-21|) = 0$ 的全部实数 $x$ 的乘积等于 $\underline{\qquad}$。

**31.** 已知实数 $x,y,z$ 满足 $x + y = 4$，$|z+1| = xy + 2y - 9$，求 $x + 2y + 3z$ 的值为 $\underline{\qquad}$。

**32.**（深外自招）如果 $x$ 和 $y$ 是非零实数，使得 $\begin{cases} |x| + y = 3 \\ |x|y + x^3 = 0 \end{cases}$，那么 $x + y$ 的值为 $\underline{\qquad}$。

**33.** 方程 $x^2 - 3|x-1| - 1 = 0$ 所有解的和为 $\underline{\qquad}$。

**34.**（四大）已知关于 $x$ 的方程 $\left|\dfrac{x^2}{x-1}\right| = a$ 有且仅有两个不同的实数解，则 $a$ 的取值范围为（　）　A. $a>0$　B. $a>4$　C. $2<a<4$　D. $0<a<4$

**35.**（深中自招·四大）已知 $xy$ 为非零实数，且满足 $\begin{cases} x = y + \dfrac{1012}{x} \\[4pt] y = x + \dfrac{1013}{y} \end{cases}$，则 $|x-y|$ 所有值之和为 $\underline{\qquad}$。

### 例题 6 · 整数解问题

**36.** 若直线 $x + 2y = 2m$ 与直线 $2x + y = 2m + 3$（$m$ 为常数）的交点在第四象限，则整数 $m$ 的值为（　）　A. $-3,-2,-1,0$　B. $-2,-1,0,1$　C. $-1,0,1,2$　D. $0,1,2,3$

**37.**（深中自招）在平面直角坐标系中，由抛物线 $y = 6 - x^2$ 与 $x$ 轴所围出的区域内有 $\underline{\qquad}$ 个整点（横纵坐标都是整数的点）（边界上的点不计）。

**38.** 若关于 $x$ 的分式方程 $\dfrac{1-ax}{x-4} + 1 = \dfrac{1}{x-4}$ 有整数解，其中 $a$ 为整数，且关于 $x$ 的不等式组 $\begin{cases} 2(x+1) \le 4 + 3x \\ 5x - a < 0 \end{cases}$ 有且只有 3 个整数解，则满足条件的所有 $a$ 的和是（　）　A. 8　B. 9　C. 10　D. 12

**39.**（四大）方程 $x^2 - y^2 = 1995$ 的正整数解共有 $\underline{\qquad}$ 组。

**40.**（四大）已知 $n,k$ 均为自然数，且满足不等式 $\dfrac{7}{13} < \dfrac{n}{n+k} < \dfrac{6}{11}$，若对于某一给定的自然数 $n$，只有唯一的一个自然数 $k$ 使不等式成立，则所有符合要求的自然数 $n$ 中的最大数为 $\underline{\qquad}$。
