## 核验结论及重要限制

- 旧库“79所”“已挖尽／不存在”只可作历史检索线索；2026以教育局实际附件重新建立名单。
- 2026官方简章明确有闭卷笔试/纸笔测试，不能照搬旧库统一称“不得传统笔试”。
- 17题图的整齐排版、15题PDF的标题，都不是原卷身份证明；原始出处不明、AI标记、缺漏与同题跨项目重复已单列。
- 小红书站内提示设备登录超限；民间深圳中考网下载跳手机号登录；微信原帖打不开；zizzs连接受限。商业预览明确不可保存，未下载。**受限不等于无资料。**
- 本轮网络查询、公共附件读取和题图核读已实际执行；但绝大多数学校尚未完成“逐校×项目×环节”的多渠道题目检索，尤其全部民办、体艺细项及非数学科目。已生成明确待执行队列，不假装已搜索。
- 没有抓取学生姓名、准考证、电话或成绩名册；不购买、不加群、不联系发布者、不去水印、不绕过登录与安全限制、不对外发布。
