# 深圳中考升学 · 自主招生资料库

> 面向**全体深圳初中生**的公共资料库，分「深户 / 非深户」「不同年级」「不同升学路径」整理。
> 官方来源优先，社媒经验帖一律标注「非官方·需自行核实」。

⚠️ **重要免责声明**：升学政策**逐年变化**，分数线、计划数、报名时间每年不同。本库内容为整理参考，
**任何决策务必以当年官方文件为准**（深圳市教育局 / 深圳招考网 / 各校官网）。每条信息尽量标注「数据年份」与「来源」。

## 🔖 信息可信度标注约定

- 🟢 **官方**：教育局/招考网/学校官方文件、官网、官方公众号
- 🟡 **半官方/媒体**：主流媒体报道、机构整理（需交叉验证年份）
- 🔴 **非官方/社媒**：抖音、小红书、家长论坛经验帖 — 仅供参考，必须自行核实

- 纯 Markdown，可 Git 版本管理，每年更新时保留历史版本
- 可整体喂给 `/graphify` 生成可视化知识图谱
- 每条政策/数据标注 `[年份]` 和 `[来源]`，过期内容标注而非删除
