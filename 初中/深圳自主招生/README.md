# 深圳初中升高中 · 自主招生资料库

面向深圳初中生家庭的自主招生（自招）资料库：政策解析 + 逐校真题 + 学校排名 + 2025 逐校官方计划。

> ⚠️ **免责声明**：升学政策**逐年变化**，分数线/计划数/时间每年不同。本库为整理参考，**任何决策务必以当年官方文件为准**（深圳市教育局 / 深圳招考网 / 各校官网）。真题绝大多数为**考生回忆版（🔴）**，仅供了解题型。

## 🔖 可信度标注约定

- 🟢 **官方**：教育局/招考网/学校官方文件、官网、官方公众号
- 🟡 **半官方/媒体**：主流媒体报道、机构整理（需交叉验证年份）
- 🔴 **非官方/社媒**：抖音/小红书/家长论坛/回忆版 — 仅供参考，必须自行核实

## 🔄 维护

- 纯 Markdown，按年保留历史版本；每条数据尽量标注「年份 + 来源」，过期内容标注而非删除。
- 配套 `.pdf` 为各 `.md` 的导出快照（**源以 `.md` 为准**，改 md 后 pdf 需另行重新导出）。
