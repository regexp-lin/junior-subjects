# 初中历史材料题：答题方法与学习方法

## 一、先明确要解决的问题

**原问题：**深圳初中历史应该怎么学习？材料题常有一大段文字，学生经常答不到要点上，或者不知道如何回答。

**更具体的问题：**怎样通过真实错题，判断困难来自知识缺漏、材料理解、审题还是表达，并通过针对性训练，让学生能独立完成新的材料题？

**核心原则：题目要求什么，就回答什么；每个判断有依据，需要解释时说清关系。**

不能预先认定学生只是不会组织答案，也不能只教套句式。先找出卡点，再把知识学习、材料阅读、历史思考和表达训练结合起来。

本文是学习建议，不是深圳统一评分细则。具体答题数量、材料范围和给分办法，以完整题干及对应评分标准为准。

## 二、先用真实错题定位卡点

选几道近期做错或空白的材料题，保留题干、材料、原答案和批改结果。先让学生解释自己的思路，再核对参考答案，不要一开始就告诉他应该写什么。

| 可能的卡点 | 怎样检查 | 下一步训练 |
| --- | --- | --- |
| 知识缺漏 | 能否不看书说清相关事件的时间、内容及因果联系？ | 补关键史实，建立知识框架，再闭卷复述 |
| 审题遗漏 | 能否用自己的话说清题目要求完成几个任务？ | 拆出对象、时期、范围和任务清单 |
| 材料理解或取证困难 | 能否解释关键句，并指出与问题有关的信息？ | 理解词义、辨认关系，练习找证据 |
| 信息加工困难 | 找到了句子，能否概括、比较或说明因果？ | 针对概括、比较、因果分析分别练习 |
| 表达或作答不完整 | 口头能说清，书面答案是否仍重复、含糊或漏答？ | 分点表达、去重，并对照任务检查 |

这些情况可能同时存在。比如“没写出原因”可能是知识不足，也可能是把结果误当原因，不能仅凭一个错误就确定诊断。拿不准时，请老师结合原题和评分标准确认。

## 三、考场答题：五步处理法

### 第一步：拆任务

可以先看设问，再带着问题读材料。重点圈出：

- **对象和范围：**问谁、哪个时期、哪个地区、哪个方面？
- **任务：**是指出、概括、分析、比较，还是论证？有没有“并说明”“分别”“共同”等要求？
- **依据：**根据哪则材料，是否需要结合所学，是否限定材料之外的案例？
- **数量和限制：**是否要求两点、一个案例、某个角度？分值可以提醒回答深度，但不能直接换算成点数。

例如，“概括共同之处，并分析历史作用”包含两个任务。只写共同点，即使写得多，也没有完成第二个任务。

### 第二步：围绕问题找证据

读材料时，先确认时间、地点、人物或事件，再圈与设问有关的事实和关系。

可以按意思给材料分层，但要注意：

- 一个意思可能分散在几句话中，需要合并。
- 一句话可能包含几项相关信息，需要拆开。
- 有些句子只是背景，不必写进答案。
- 因果词、转折词、时间词能帮助理解，但答案不一定在首尾句或转折词后面。

**标点是阅读提示，不是得分点边界。**

遇到不同材料，应调整读法：

- **文字或文言文：**先弄清谁做了什么、前后关系是什么；不必逐字翻译，但关键句不能误解。
- **图表：**看标题、时间、单位、图例及数据变化，区分总量、比例和增速。
- **地图或图片：**看图名、图注、位置和标识，不凭印象判断。
- **材料出处：**留意作者、写作时间及材料性质；区分事件发生的时间与材料写成的时间，区分事实叙述与作者评价。

不要把没有依据的推断写成事实。题目要求根据材料时，应以指定材料为依据；允许结合所学时，准确、相关的所学知识也可以作为依据。看到两项数据同时变化，不能仅凭这一点认定存在因果关系。

### 第三步：按任务加工信息

答案依据由完整题干决定，不能只看一个设问动词：

| 题干要求 | 怎样使用依据 |
| --- | --- |
| 根据材料 | 以指定材料为依据，筛选、提炼或解释相关信息；不要用背熟的结论替代材料 |
| 结合所学知识 | 调用相关史实、概念及联系，不是只默写性质、影响或意义 |
| 根据材料并结合所学 | 用材料信息与相关知识共同完成任务；不必把每一点机械拆成“材料一句、课本一句” |

“指出”可能需要识别，“概括”需要归并提炼，“分析”需要说明关系。这些是思考方向，不是固定答案模板。

概括可以保留准确的关键词，但应删去无关细节，把同类信息合并。目标不是把每个词都换掉，也不是照抄整段材料。

### 第四步：组织答案

先完成所有任务，再考虑表达是否清楚：

- 多个任务或多个独立观点，按题目顺序分点写。
- 同一个意思换几种说法，仍可能只是同一个观点；删去重复，不靠凑字数增加内容。
- 问事件、人物或制度名称，准确的名词可以直接回答。
- 问措施，写清做了什么；问原因或影响，写清相关因素及其关系；问论证，说明史实怎样支持观点。
- 使用准确的历史术语，不强求每一点都有“角度词 + 史实 + 结论”。

**分点是为了清晰，不是“一分一点”。** 不同题目的一个答案点可能对应不同分值，论述题还可能采用等级评分。答案数量和深度应结合题干要求及具体评分标准判断。

### 第五步：反向检查

写完后，把答案与任务清单逐项对应：

1. 是否答对了对象、时期和范围？
2. 是否完成了全部任务，有没有漏答“并说明”的部分？
3. 每一点依据是什么，是否符合题目要求，有没有把无依据的推断写成事实？
4. 有没有把措施写成成效、原因写成结果，或把某一对象的特点写成共同点？
5. 有没有重复、史实错误或不必要的扩写？

## 四、同一材料，设问不同，答案不同

以下是**自拟训练材料，不是某次深圳中考真题或真实史料**：

> 某地政府减轻赋税，兴修水利；此后，当地农业生产逐渐恢复。

| 设问 | 示例答案 | 思考过程 |
| --- | --- | --- |
| 根据材料指出政府采取的措施 | 减轻赋税；兴修水利。 | 找“做了什么”，不把生产恢复写成措施 |
| 根据材料概括政策实施后的变化 | 当地农业生产逐渐恢复。 | 找实施后的变化，不重复措施 |
| 根据材料并结合所学，说明这些措施为什么有助于农业恢复 | 减轻赋税有助于减轻生产者负担；兴修水利有助于改善农业生产条件，从而促进农业恢复。 | 从措施出发，补充它们发挥作用的机制 |

第三问要求解释“为什么”，所以要补因果关系；第二问只要求概括变化，没有必要强行扩写这些机制。材料只涉及当地农业，也不足以推出“全国经济全面繁荣”。

再如，若题目要求“指出材料反映的是哪次工业革命”，且证据确实对应第二次工业革命，答“第二次工业革命”即可；若问“分析其影响”，只写名称就没有完成任务。

## 五、常见题型：先想什么，再怎样表达

下表是思考提示，不是看到关键词就照搬的句式。

| 题型 | 先想什么 | 表达提示与边界 |
| --- | --- | --- |
| 指出、列举 | 需要识别哪些对象或事实？ | 准确写名称或事实，按要求列举 |
| 概括、特点 | 哪些信息可以归并？其突出特征是什么？ | 可用“以……为主”“范围扩大”等准确表述，不强求“……性”“……化” |
| 原因、背景 | 什么因素促成这一事件？题目是否限定某种原因？ | 按证据解释；“根本/直接”和“主观/客观”是不同分类维度，不能叠加当作四个独立点 |
| 影响、意义 | 对谁、在哪个方面、产生了什么变化？ | 写清对象和作用；“促进了社会发展”这类空泛表述应具体化 |
| 局限性 | 有哪些不足、限制或负面后果？ | 放在当时的历史条件下评价，不给所有事件都套“保留残余” |
| 变化、趋势 | 前后相比，哪些方面发生了变化？ | 写清“由什么到什么”；有波动时不能直接概括为持续上升或下降 |
| 比较 | 比较对象和维度是否一致？要求共同点、不同点还是两者？ | 同一维度对照；若只说“比较”，先检查完整题干，不自动排除相同点 |
| 认识、启示 | 材料能支持什么理解、评价、规律或经验教训？ | 从具体证据出发；认识不只回答“是什么”，启示也不能只写空泛口号 |
| 措施、方式 | 谁采取了什么行动？ | 写清行动及必要对象，如“设立……”“推行……” |
| 说明、论证 | 要证明什么判断，证据怎样支持它？ | 不只列史实，还要解释史实与判断的联系 |

政治、经济、思想文化等角度可以帮助检查遗漏，但不是每题都要写全。选择相关且有依据的角度，不为凑点硬套框架，也不要把所有“根本原因”都机械归为经济或制度。

## 六、论述题：观点、证据和推理相互对应

论述题首先看完整要求：观点是给定的还是自拟的？要用哪些材料？是否限定时期、案例数量或材料之外的史实？

可以用下面的结构组织：

1. **提出观点：**回答题目关心的问题，表述明确，范围与证据相匹配，避免过大、过空。
2. **选取证据并分析：**按题目要求使用材料和准确史实，解释它们怎样支持观点，不只罗列事件名称。
3. **回扣观点：**概括论证结果，不新增未经证明的大判断；是否需要单独结尾，取决于题目和篇幅。

可用“史实说明了什么，因此支持什么观点”检查史论是否结合。论据数量遵循题目要求；未限定时，选择足以支持观点、又不重复的证据，不机械规定必须两个。

**结构服务于论证，不能替代内容。** 史实来源遵循题干限定，不一律要求只能来自课本，也不一律要求使用课外材料。观点、论据、结尾各得多少分，以具体评分标准为准，不设统一的固定分值公式。

## 七、平时学习：形成可验证的训练闭环

### 1. 先独立作答，再逆向拆答案

不要直接看答案后觉得“我也会”。先留下自己的答案，再把参考答案拆成下面三项：

| 答案点 | 依据 | 为什么回答了设问 |
| --- | --- | --- |
| 这一点表达了什么 | 来自哪条材料信息或哪项所学知识 | 怎样从依据得出答案，与题目哪个任务对应 |

参考答案是核对工具，不一定是唯一有效表述。判断重点是史实是否准确、信息是否相关、推理是否成立；具体给分还需看对应评分标准。

如果参考答案与材料、教材或老师讲解存在疑问，先核查，不要为了贴合答案而强行解释。

### 2. 按卡点做小练习

| 卡点 | 小练习 | 检查方式 |
| --- | --- | --- |
| 看不懂材料 | 用自己的话复述“谁做了什么、发生了什么变化”，解释关键句 | 复述是否遗漏对象、时间或转折关系 |
| 找不到依据 | 只圈与一个设问有关的信息，并说明选择理由 | 圈出的信息是否真正回答问题 |
| 不会概括 | 把相关信息合并成一句话，再指出支撑这句话的证据 | 是否保留关键含义，又去掉重复细节 |
| 不会分析原因或影响 | 补出“因素/措施 → 如何发挥作用 → 结果”的联系 | 中间关系能否用材料或所学解释，是否把先后关系当成因果 |
| 不会比较 | 先确定共同维度，再分别写两个对象的情况 | 是否在比较同一方面，而不是各说各话 |
| 写不完整 | 先列任务清单，再分点回答，最后逐项核对 | 是否漏答、重复或越界 |

一句话概括是练习之一，不能代替词义理解、关键细节阅读及背景知识学习。角度词库也只是提示，使用时必须找到相应依据。

### 3. 错题归因后，安排修正和复测

建议每道重点错题记录：

- 题目要求完成什么？
- 我的答案哪里不准确或不完整？
- 主要错因是什么，有什么证据支持这个判断？
- 需要补哪项知识或练哪种能力？
- 下次作答具体采取什么动作？
- 什么时候重答，怎样用新题检验？

例如，问“措施”却写了“农业恢复”，可暂时归因为混淆行动与结果。修正动作不是多背一句答案，而是圈出行动词与变化词，换一则材料再辨认。

**训练闭环：独立作答 → 核对依据 → 确认主要错因 → 针对性补练 → 隔一段时间不看答案重答 → 用新材料复测。**

可以尝试次日重答、几天后换题复测，再根据表现调整间隔。这是可调整的安排，不是固定的提分期限。

### 4. 逐步减少提示，检查能否迁移

刚开始可以一起拆任务、找证据；接着只给提示，让学生完成；最后撤掉提示，使用未见过的材料独立作答，再进行限时训练。

判断进步时，看：

- 能否准确复述设问并完成全部任务？
- 能否为答案点指出依据，并解释必要的关系？
- 同类错误是否减少？
- 换成新材料后，是否仍能独立完成？

不能只用看过多少答案、背过多少句子衡量学习效果。

## 八、知识怎么学：框架、史实和联系一起掌握

不必平均用力背每个细节，但不能只背性质、影响、意义。对重要事件，建议整理：

| 知识要素 | 要能回答的问题 |
| --- | --- |
| 时间与空间 | 发生在什么时候、哪里？与前后事件有什么顺序关系？ |
| 背景与原因 | 为什么发生？有哪些条件或矛盾？ |
| 人物与内容 | 谁参与？主要做了什么？ |
| 结果与影响 | 直接结果是什么？对哪些对象产生了什么影响？ |
| 性质与评价 | 怎样界定和评价？哪些事实支持这一判断？ |
| 联系与比较 | 与相关事件有哪些联系、共同点或差异？ |

学习时先理解，再合上书复述或画出框架，随后回到教材核对。课本结论可以作为准确表达的参照，但要能用自己的话解释，并说出支撑结论的关键史实。

遇到材料题，再从框架中选择与设问有关的知识，不把背熟的内容全部倾倒进答案。

## 九、深圳考试信息与时间安排

截至**2026年10月13日**核查，深圳市2026年高中阶段学校考试招生文件规定：历史实行**闭卷笔试，满分70分**；2026年历史考试安排为6月27日14:30至15:30，即**60分钟**。依据见文末来源。

这些是2026年的考试信息，不代表以后年份或校内考试安排不变。参加后续年份考试时，应重新核对当年的官方通知。

题型分值、论述题要求及各答案点给分，以对应试卷和评分标准为准，不把“34分选择题 + 36分主观题”或某种论述题分值拆分当作长期固定规则。

时间安排可通过完整限时练习调整：记录各部分用时，检查是否留出主观题作答和核对时间。遇到卡题先标记并继续，不预设每个学生都必须在20分钟内完成选择题。

## 十、作答前后的简短检查卡

- [ ] 我明确了对象、时期、范围和全部任务。
- [ ] 我按题目要求选择了材料与所学依据。
- [ ] 我完成了必要的概括、比较、解释或论证。
- [ ] 我的答案没有重复、漏答或无依据扩写。
- [ ] 我检查了关键史实和术语。

**记住：先看问题，再找证据；按任务加工，准确表达；错题修正后，还要换题验证。**
