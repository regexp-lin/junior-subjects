# 深圳中考历史考点大全

更新日期：2026年10月30日。适用用途：初中历史系统复习、查漏补缺，以及深圳中考材料题的知识准备。

## 一、使用范围与考试口径

这是一份按初中历史主要内容编写的**复习知识总表**，“大全”指覆盖主要学习板块，不是深圳市教育部门公布的逐条考纲，也不代表每条都会在某一年出现。知识按历史主题组织，不绑定课号，便于不同修订版教材对照使用。具体教学内容、表述和学习深度应与学生当届教材及学校要求核对。

- **已核实的深圳安排**：2026年起，历史为独立闭卷笔试，满分70分，时长60分钟；深圳试行自主命题。不能直接用广东省其他地区试卷的题数、范围安排代替深圳口径。[深圳中考改革实施意见](https://www.szlh.gov.cn/lhqjyj/gkmlpt/content/11/11468/post_11468563.html)
- **年度信息**：2026年招生通知确认历史满分70分。面向2027年及以后备考时，须再核对当年正式通知，不能把旧年题型比例当成固定规定。[2026年招生通知](https://szeb.sz.gov.cn/szzkw/zkgg/zkxx/content/post_12687196.html)
- **课程依据与版本边界**：教育部2022年版义务教育历史课标提供基本框架；2025年日常修订版已存在，权威高校的2026年教研通知明确援引该版。本表不是两个版本逐条对照后的“新增、删除”清单，也不把原2022版称作截至目前唯一最新版。[教育部2022年版课程文件](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)、[华东师范大学教研通知](https://history.ecnu.edu.cn/a1/65/c33433a762213/page.htm)

表中的“材料题连接”是学习建议，不是官方命题概率。先做到“认出史实”，再做到“解释关系”，最后用材料证据回答问题。配套阅读：[深圳中考历史材料题考法解析](../历史材料题/探索/深圳中考历史材料题考法解析.md)。

## 二、先建立六条历史主线

| 板块 | 主线 | 学完后应能回答 |

| 中国古代史上段 | 中华文明起源 → 早期国家 → 秦汉统一 → 魏晋南北朝分立与交融 | 中华文明如何形成？统一国家如何建立和巩固？ |
| 中国古代史下段 | 隋唐发展 → 辽宋夏金元并立与统一 → 明清国家发展和社会变化 | 制度、经济、民族交往和中外交流怎样变化？ |

## 三、中国古代史：史前至魏晋南北朝

### 1. 史前社会与中华文明起源

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |
| 古上01 | 研究史前历史的方法 | 化石、遗址、遗物等考古材料是研究史前社会的重要证据；史前时期缺少当时的文字记录 | 说明某遗物“能证明什么”，不能把想象当发现；传说须与考古等证据互证 |
| 古上02 | 中国境内早期人类 | 元谋人、北京人等体现中国境内早期人类活动；北京人遗址位于北京周口店，会使用火 | 不同遗址的人类年代、工具、用火证据要分别记，不能混写 |
| 古上03 | 山顶洞人等晚期古人类 | 注意打制石器、磨光钻孔技术及装饰品反映的生产生活变化 | 由工具推断技术，由装饰品讨论审美，结论不能超出证据 |
| 古上04 | 农业与定居生活 | 农作物栽培、家畜饲养、聚落和磨制石器的发展，推动社会生产生活变化 | 农业出现不等于采集狩猎立刻消失；生产工具变化与农业发展相联系 |
| 古上05 | 河姆渡与半坡 | 河姆渡：长江流域、稻作、干栏式建筑；半坡：黄河流域、粟作、半地穴式房屋和彩陶 | 比较地理环境、农作物、住房；不能写成两地只有这些作物或器物 |
| 古上06 | 多元一体的文明起源 | 良渚、陶寺、红山等遗址显示不同区域的发展与联系；大型建筑、墓葬差异等有助于认识社会分化 | 认识“多元”与相互联系，不用单一遗址概括全部中华文明 |
| 古上06a | 中华文明的突出特性 | 连续性、创新性、统一性、包容性、和平性；可联系文字传承、技术创新、统一国家、民族交往与文明交流理解 | 用具体史实解释特性，不能将其误解为历史上从无分裂、冲突或战争 |
| 古上07 | 传说时代 | 炎帝、黄帝传说与中华民族的人文初祖认同；尧舜禹和禅让传说；大禹治水 | 区分后世记述、传说与已证实史实，不把传说人物活动直接当精确纪年事件 |

### 2. 夏商周、春秋战国与早期国家

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |
| 古上08 | 夏商西周的更替 | 约公元前2070年夏建立；商、西周先后发展；公元前771年西周灭亡，前770年东周开始 | 建立王朝顺序和时间尺度；夏建立年代是约数 |
| 古上09 | 王位世袭与分封制 | 王位世袭代替禅让；西周通过分封建立地方统治和等级秩序，诸侯承担义务 | 分封具有巩固统治的作用，也有地方势力扩张的隐患 |
| 古上10 | 青铜器与甲骨文 | 青铜铸造反映技术与礼制；商代甲骨文是中国已发现的古代文字中年代较早、体系较完整的文字 | 甲骨文是文字史料也有实物载体；器物既反映技术，也可反映权力和礼仪 |
| 古上11 | 春秋争霸与战国兼并 | 周王室衰微；诸侯争霸、兼并推动政治格局变化，并促进人口流动和交往 | 既看战争破坏，也看社会整合；不把春秋争霸和战国兼并完全等同 |
| 古上12 | 经济与社会变革 | 铁制农具、牛耕推广推动生产发展；土地关系和社会结构变化，为改革提供条件 | 用“生产发展—利益关系变化—改革需求”解释变法背景 |
| 古上13 | 商鞅变法 | 公元前356年开始；确立县制，奖励耕织、军功，废井田制，允许土地自由买卖等；增强秦国实力 | 分类为政治、经济、军事措施；变法成效不能写成当时已统一全国 |
| 古上14 | 都江堰 | 战国秦国李冰主持修建，兼具防洪、灌溉等功能，促进成都平原农业发展 | 从工程功能解释社会影响，不只记人物、名称 |
| 古上15 | 孔子与老子 | 孔子：仁、以德治国、有教无类等；老子：顺应自然、无为而治等思想 | 分辨学派主张；不能把孔子民本思想写成现代民主政治 |
| 古上16 | 百家争鸣 | 孟子、荀子、墨子、庄子、韩非等；围绕治国、社会秩序提出不同主张，促进思想文化发展 | 结合社会大变革解释思想活跃；比较儒、道、墨、法，避免只背人物名单 |

### 3. 秦汉统一多民族国家的建立和巩固

| 古上23 | 张骞与丝绸之路 | 张骞出使西域，促进中原与西域联系；陆上丝绸之路连接东西方；海上交通发展 | 丝路传递商品、技术和文化；不是只有丝绸，也不是张骞一人“创造”全部路线 |
| 古上24 | 西域都护 | 公元前60年西汉设置西域都护，成为中央政府管辖西域的重要制度举措 | 用机构、政令和交往等证据说明边疆治理，不以单一地图替代论证 |

| 古上26 | 两汉科技文化 | 蔡伦改进造纸术；张仲景《伤寒杂病论》、华佗；司马迁《史记》；佛教传入、道教兴起 | 蔡伦是改进造纸术；《史记》是纪传体通史，不是编年体史书 |

## 四、中国古代史：隋唐至明清

### 1. 隋唐的统一、制度与开放

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |
| 古下01 | 隋统一与大运河 | 581年隋建立，589年统一；大运河加强南北交通与经济联系，也加重当时劳役负担 | 从不同时段和主体评价工程，不能只有“劳民伤财”或“功在千秋” |
| 古下02 | 科举制 | 隋唐逐渐形成、发展，通过考试选官；扩大选官范围、影响教育和社会流动；1905年废除 | 科举扩大参与但存在身份、性别等限制，不能等同现代教育公平 |
| 古下03 | 唐朝治国 | 618年唐建立；贞观之治、武则天时期、开元盛世；重视生产、人才和治理 | 用具体措施解释治世；“贞观”和“开元”对应不同君主 |
| 古下04 | 三省六部制 | 中央决策、审议、执行等机构分工，六部处理具体政务 | 分工和相互牵制服务于皇权，不是近代三权分立 |
| 古下05 | 经济与社会风气 | 曲辕犁、筒车、手工业、长安等城市；社会生活呈现开放活跃的特点 | 用器物与诗画观察生活，避免以少数上层女性活动推断所有女性地位 |
| 古下06 | 民族交往 | 唐与吐蕃等往来，文成公主入藏；唐朝在西域设置管理机构 | 和亲、贸易、制度管理等角度并用，不把所有交往都概括为战争 |
| 古下07 | 中外交流 | 遣唐使、鉴真东渡、玄奘西行；唐文化影响周边，也吸收外来文化 | 玄奘去天竺，鉴真去日本；交流包括“走出去”和“传进来” |
| 古下08 | 唐代文化与衰落 | 唐诗、书法、绘画；安史之乱是唐由盛转衰的转折，藩镇割据等削弱统治；907年唐亡 | 安史之乱结束不等于唐朝同时灭亡；文化成就与政治盛衰不机械同步 |
| 古下09 | 五代十国 | 唐亡后政权更替和南北差异；分裂中仍有经济发展和统一趋势 | 时间线连接唐、宋，不把五代十国当作一个统一王朝 |

### 2. 辽宋夏金元：并立、发展与统一

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |
| 古下10 | 北宋政治 | 960年北宋建立；加强中央集权、重文轻武，削弱地方军政财权 | 同时认识维护统一与军政效率、财政负担等问题 |
| 古下10a | 王安石变法 | 1069年起，为富国强兵推进募役、方田均税、农田水利、保甲等改革，增加财政收入、改善部分治理，也引发争议 | 分析目标、措施、执行和不同群体利益，不以单一成败标签代替解释 |
| 古下11 | 辽、西夏与宋 | 契丹、党项建立政权；澶渊之盟等体现战争与议和；榷场贸易等联系发展 | 少数民族政权同属中国历史；不能简单照搬近代国与国关系 |
| 古下12 | 金、南宋与岳飞 | 女真建立金；1127年北宋灭亡、南宋建立；岳飞抗金；宋金和议 | 评价人物结合维护民众利益和历史作用，避免把古代民族关系等同近代侵略关系 |
| 古下13 | 农业、手工业与商业 | 占城稻传播，纺织、制瓷、造船发展；商业突破时间空间限制，北宋四川出现交子 | 交子是纸币，不是纸张发明；农业和手工业发展支撑商业 |
| 古下14 | 经济重心南移 | 唐中期以来南方经济地位上升，至南宋经济重心南移完成 | 依据税收、人口、粮食、城市等证据判断，不只靠一个物产名称 |
| 古下15 | 城市与海外贸易 | 开封、临安等城市发展；市民生活和瓦子；市舶司管理海外贸易 | 市舶司和清代广州十三行不是同一制度；繁荣不等于没有政府管理 |
| 古下16 | 蒙古与元统一 | 铁木真统一蒙古；忽必烈1271年定国号元；1276年攻占临安，1279年完成统一 | 区分蒙古政权建立、元国号、南宋灭亡和全国统一的节点 |
| 古下17 | 元的制度与边疆 | 行省制度；宣政院管辖西藏事务；澎湖巡检司等；民族交往发展 | 郡县和行省不是同一层级；用制度证据说明统一国家的发展 |
| 古下18 | 宋元科技文化 | 活字印刷术、指南针和火药应用发展；宋词、元曲；司马光《资治通鉴》 | 说明科技传播的世界影响；《资治通鉴》是编年体通史，与《史记》区分 |

### 3. 明清：国家发展、经济文化与近代前夜

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |
| 古下19 | 明朝建立和皇权强化 | 1368年明建立；废丞相和中书省，权分六部；厂卫等特务机构；八股取士 | 废的是丞相制度，不能写成废除中央行政管理；注意制度的控制作用 |
| 古下20 | 郑和下西洋 | 1405年开始，船队远航亚非，促进交往；航海技术、国力和组织能力是条件 | 与新航路开辟比较目的、性质和影响，不能因为同是航海就视为相同 |
| 古下21 | 海疆防卫与交往 | 戚继光抗倭；葡萄牙攫取在澳门的居住权；晚明海上贸易与冲突并存 | 倭寇与普通日本商民不是同一概念；注意事件与澳门回归年代区别 |
| 古下22 | 明末危机与清建立 | 明末财政、灾荒、社会矛盾激化；李自成起义；1636年清改国号，1644年明亡、清军入关 | 1636年和1644年不能互相替代；解释多重原因而非只归因个人 |
| 古下23 | 清前期经济 | 农业恢复、外来高产作物推广、手工业和商业发展，人口增长 | 粮食与人口关系有促进也有压力；商品经济发展不等于进入资本主义社会 |
| 古下24 | 台湾与东南海疆 | 1662年郑成功收复台湾；1684年清设台湾府；台湾与大陆联系发展 | 分清收复、设置机构等不同举措；勿混成同一年 |
| 古下25 | 西藏、新疆及北部边疆 | 册封达赖、班禅，设驻藏大臣等；平定准噶尔及大小和卓叛乱、设伊犁将军；雅克萨之战与《尼布楚条约》 | 以因地制宜的机构、册封、军事、外交等说明治理，勿把所有措施都写在同一区域 |
| 古下26 | 军机处与思想控制 | 军机处设立进一步强化君主专制；文字狱和文化控制抑制思想活力 | 皇权强化与国家统一有关联但不是同一概念，评价应分层 |
| 古下27 | 对外政策 | 清代闭关锁国严格限制对外贸易和交往，妨碍学习先进科学技术；仍存在一定对外贸易 | 不能写成“完全没有贸易”；限制民间贸易与所有时段海禁完全相同也不准确 |
| 古下28 | 明清科技著作 | 李时珍《本草纲目》、宋应星《天工开物》、徐光启《农政全书》；技术总结与生产经验 | 根据领域说明贡献，不能笼统写“都发明了四大发明” |
| 古下29 | 建筑与文艺 | 明长城、北京城；《三国演义》《水浒传》《西游记》《红楼梦》；昆曲、京剧 | 文学可辅助认识社会观念，但小说情节不能直接当事实；京剧形成有长期融合过程 |

## 五、中国近代史：1840—1949年

### 1. 民族危机与早期救亡探索

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |
| 近01 | 鸦片走私与禁烟 | 鸦片走私危害社会、财政和军政；林则徐1839年虎门销烟 | 销烟是英国发动战争的借口，不能把维护主权说成战争的根本原因 |
| 近02 | 鸦片战争与《南京条约》 | 1840—1842年；割香港岛、赔款、开放五口、协定关税等，破坏主权，中国开始沦为半殖民地半封建社会 | 区分香港岛、九龙、台湾等不同条约地域；贸易开放的被迫性须说明 |
| 近03 | 第二次鸦片战争 | 1856—1860年；英法联军火烧圆明园；《天津条约》《北京条约》等扩大侵略权益；沙俄侵占中国北方大片领土 | 侵略者、事件与条约对应，不把八国联军与英法联军混淆 |
| 近04 | 太平天国运动 | 1851年金田起义，1853年定都天京；提出《天朝田亩制度》，后有《资政新篇》；1864年失败 | 区分农民平均主义土地设想与发展资本主义的主张；分析局限与中外势力镇压 |
| 近05 | 洋务运动 | 19世纪60—90年代；以自强、求富为口号，兴办军事和民用企业、近代教育、海军；维护清朝统治 | 是近代化早期探索，未改变封建制度；不能因最终失败否认客观作用 |
| 近06 | 边疆危机与左宗棠 | 左宗棠收复新疆主要地区；1884年新疆建省；边疆危机还涉及东南、西南等 | 对比古代西域都护与近代建省，认识治理措施随时势变化 |
| 近07 | 甲午战争 | 1894—1895年；黄海海战、威海卫战役，北洋舰队覆没；邓世昌等抗争 | 区分个人英勇与战争整体结果；结合制度、组织、国力解释失败 |
| 近08 | 《马关条约》 | 割辽东半岛、台湾全岛及附属各岛屿、澎湖列岛；赔款、增开商埠、允许日本开设工厂等；大大加深民族危机 | 认识资本输出与经济侵略；割辽东条款后来受到三国干涉，并非一直由日本据有 |
| 近09 | 列强瓜分与维新 | 甲午后民族危机加深，列强争夺权益；公车上书、维新宣传、戊戌变法 | 从危机、资本主义发展和思想传播解释改革，不把背景只写成甲午一个事件 |
| 近10 | 戊戌变法 | 1898年；康有为、梁启超等倡导变法，涉及政治、经济、教育、军事；戊戌政变后失败 | 资产阶级改良运动与思想启蒙；与洋务运动比较改革层次 |
| 近11 | 义和团与八国联军 | 义和团反帝斗争有鲜明局限；1900年八国联军侵华；1901年《辛丑条约》 | 不把扶清灭洋等同科学的救国方案；结合排外盲目性作具体评价 |
| 近12 | 《辛丑条约》的影响 | 巨额赔款、严禁反帝活动、驻兵等；清政府成为列强统治中国的工具，中国完全陷入半殖民地半封建社会深渊 | “完全陷入”不等于中国变成完全殖民地，也不等于封建因素消失 |

### 2. 民主革命、思想变化与中国共产党诞生

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |
| 近13 | 孙中山与革命组织 | 兴中会、中国同盟会；三民主义；革命派与维新派道路不同 | 用组织、纲领、方法比较，区分三民主义和新三民主义 |
| 近14 | 辛亥革命 | 1911年武昌起义；1912年中华民国成立；推翻清朝统治，结束君主专制，推动民主共和观念传播 | 没有结束中国半殖民地半封建社会，也没有消除所有封建因素 |
| 近15 | 《中华民国临时约法》 | 规定主权在民、公民权利、责任内阁等，具有资产阶级共和国宪法性质 | 法律规定与实际执行分开；不能因颁布约法就说民主制度已稳固 |
| 近16 | 北洋军阀统治 | 袁世凯独裁与复辟、护国战争、军阀割据等，体现民主革命的艰巨性 | 不把辛亥革命的失败简单归结为孙中山让位一个原因 |

| 近18 | 五四运动 | 1919年；巴黎和会中国外交失败成为导火索；学生先锋、工人主力，反帝反封建，推动马克思主义传播 | 区分运动开始和中心、主力变化；是新民主主义革命开端，不是中共成立 |
| 近19 | 马克思主义传播 | 十月革命、五四运动、新式刊物与社团、工人运动等促进传播 | 解释理论传播与社会需求、实践的关系，不能只列一个人物 |
| 近20 | 中国共产党成立 | 1921年中共一大在上海召开、后转移至浙江嘉兴南湖；中共二大提出民主革命纲领 | 党的成立使中国革命面貌焕然一新；区分一大与二大内容 |

| 近22 | 国民革命失败 | 四一二、七一五反革命政变；第一次国共合作破裂 | 从敌我力量、领导权和武装等方面认识教训，避免只写“没有合作好” |

### 3. 革命新道路、抗日战争与解放战争

| 近36 | 新民主主义革命胜利 | 中共领导、正确道路和政策、人民支持、人民军队斗争等共同作用 | “人民支持”要落到土地政策、支前、组织动员等证据；区分国内与世界意义 |

## 六、中国现代史：1949年以来

### 1. 国家建立、政权巩固与社会主义制度建立

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |
| 现01 | 新中国成立 | 1949年政协第一届全体会议、《共同纲领》；10月1日开国大典；中国人民成为国家主人 | 国家独立和人民解放为建设创造前提，社会主义基本制度此时尚未全面建立 |
| 现02 | 西藏和平解放 | 1951年西藏和平解放，祖国大陆获得统一，各族人民团结进一步加强 | “祖国大陆”不能随意替换为包含台湾等在内的“全国全部领土” |
| 现03 | 抗美援朝 | 1950年中国人民志愿军入朝，1953年停战；保家卫国，维护安全，提高国际地位 | 停战不等于战争双方签订和平条约；战争与国内建设的关系须结合背景 |
| 现04 | 土地改革 | 1950年《中华人民共和国土地改革法》；到1952年底，除部分少数民族地区外，全国大陆基本完成土地改革，实行农民土地所有制 | 由地主土地所有制转为农民土地所有制，土地仍为私有；不等于农业合作化 |
| 现05 | 第一个五年计划 | 1953—1957年，集中力量发展重工业等，开始改变工业落后面貌，向社会主义工业化迈进 | “开始改变”不是已实现工业化；工业分布、产量图表是重要材料 |
| 现06 | 人民代表大会制度 | 1954年第一届全国人大、第一部《中华人民共和国宪法》，确立人民代表大会制度 | 人大是国家权力机关，政协是政治协商机构，不能互相替代 |
| 现07 | 三大改造 | 1953—1956年，对农业、手工业、资本主义工商业进行社会主义改造；公有制占主体，社会主义基本制度建立 | 资本主义工商业主要采取公私合营、赎买政策；与土地改革的对象、性质不同 |

### 2. 建设探索与改革开放

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |
| 现08 | 社会主义建设探索 | 中共八大正确分析国内主要矛盾；全面建设社会主义时期取得成就，也发生严重曲折 | 分时期、分事件评价，不能以失误否认成就或以成就掩盖失误 |
| 现09 | “大跃进”与人民公社化 | 1958年开始；急于求成，忽视经济规律和发展阶段，造成严重问题；随后进行调整 | 从生产力水平、政策和客观规律解释，避免只背“左的错误” |
| 现10 | “文化大革命” | 1966—1976年，给党、国家和人民造成严重挫折与损失 | 期间个别科技成果不能证明运动推动发展；明确因果关系与同期发生不同 |
| 现11 | 建设者与科学成就 | 王进喜、焦裕禄、雷锋等；两弹一星、农业与医学等科技成果 | 将精神品质与具体行动联系；成就来自制度组织、人才、科研积累等多种条件 |
| 现11a | 三线建设 | 20世纪60年代中期开始，以加强国防和经济建设为目标，在中西部开展工业、交通和科研等建设 | 联系国际环境、工业布局与国家安全，兼顾建设成就、条件限制和后续调整 |
| 现12 | 伟大历史转折 | 1978年真理标准问题大讨论；十一届三中全会作出把工作中心转移到经济建设上来、实行改革开放的历史性决策 | 改革开放起点不是1992年；思想解放与政策转折之间建立联系 |
| 现13 | 农村改革 | 家庭联产承包责任制，分户经营、自负盈亏，调动农民积极性 | 集体土地所有制未改为土地私有；经营方式变化与所有权变化要分清 |
| 现14 | 城市经济体制改革 | 扩大企业自主权，调整所有制、分配和经营机制；国企改革逐步深入 | 改革是过程，不把所有措施和成果写成某一天一次完成 |
| 现15 | 对外开放 | 1980年深圳、珠海、汕头、厦门经济特区；沿海开放城市、沿海经济开放区等；浦东开发开放 | 经济特区是实行特殊经济政策和管理体制的地区，不能写成政治制度改变 |
| 现16 | 深圳的历史位置 | 深圳是改革开放窗口和试验田，体现政策支持、敢闯敢试、人才科技和对外联系的作用 | 看到深圳材料要先判断具体年代和设问，不能所有题都只答“改革开放” |
| 现17 | 社会主义市场经济 | 1992年邓小平南方谈话、中共十四大提出建立社会主义市场经济体制的目标 | 市场不等于资本主义专属；1992年提出目标不等于当年全部建成 |
| 现18 | 开放深化 | 2001年中国加入世界贸易组织，参与国际分工与规则合作；开放范围和水平不断提升 | 加入世贸组织不是改革开放的开端；机遇与竞争、风险并存 |

### 3. 制度、统一、外交与现代化成就

| 编号 | 考点 | 必须掌握的史实与理解 | 材料题连接、易错提醒 |
| --- | --- | --- | --- |

| 现30 | 新时代成就与目标 | 脱贫攻坚、全面建成小康社会，推进中国式现代化；创新、协调、绿色、开放、共享的新发展理念；2022年中共二十大擘画发展蓝图 | 社会主要矛盾变化不等于社会主义初级阶段基本国情改变；区分已实现成就、2035年基本实现社会主义现代化目标与本世纪中叶奋斗目标 |
| 现31 | 社会生活变化 | 收入、消费、住房、出行、通信、社会保障等变迁反映经济社会发展 | 数据要看时间、单位、人均或总量、城乡与区域差异，不能以局部改善推断所有问题解决 |

### 2. 一战、俄国革命与战间期

| 世下17 | 法西斯扩张 | 意、德、日法西斯发展，侵略扩张威胁世界和平；绥靖政策助长侵略 | 不把意德日上台方式完全视为相同；经济危机并非所有国家法西斯化的唯一原因 |

| --- | --- | --- | --- |
| 世下18 | 二战进程 | 1939年德国突袭波兰，二战全面爆发；1941年苏德战争、太平洋战争；中国抗战是东方主战场 | 1931年中国局部抗战、1937年全民族抗战与1939年二战全面爆发分清 |
| 世下19 | 反法西斯同盟 | 1942年《联合国家宣言》；各国协同作战是胜利的重要保障 | 反法西斯同盟形成与联合国正式成立不同，不能把1942年宣言写成联合国成立 |
| 世下20 | 转折与胜利 | 斯大林格勒保卫战；诺曼底登陆开辟欧洲第二战场；1945年德国、日本投降 | 斯大林格勒与诺曼底的作用不同；欧洲战争结束不等于二战全部结束 |
| 世下21 | 雅尔塔会议与联合国 | 大国协调战后安排；联合国1945年成立，维护和平安全、促进合作 | 二战胜利、战后秩序既有合作也有大国利益安排；不能说联合国消除所有战争 |
| 世下22 | 冷战 | 美苏矛盾；1947年杜鲁门主义；马歇尔计划；1949年北约成立；1955年华约成立，两极格局形成 | 冷战不是美苏直接全面热战，但伴随局部战争；不等于全世界只有两个国家有影响 |
| 世下23 | 战后资本主义变化 | 西欧恢复和联合，日本崛起；美国发展与新经济；社会保障制度发展 | 经济恢复、区域联合、国家调控和福利政策是不同层次，不能互相替代 |
| 世下24 | 欧洲联合 | 欧洲共同体、1993年欧洲联盟成立；区域一体化加强 | 欧盟不是欧洲所有国家的联盟，也不代表成员国主权完全消失 |
| 世下25 | 社会主义发展与挫折 | 苏联改革、东欧社会主义建设与改革；1989年前后东欧剧变，1991年苏联解体 | 分析体制、改革、外部等因素；苏联解体不等于世界社会主义消失 |
| 世下26 | 殖民体系瓦解 | 印度独立、非洲独立运动、1960年“非洲年”、纳米比亚独立等；亚非拉谋求发展 | 政治独立与经济发展任务不同；南非废除种族隔离与纳米比亚独立不能混为一事 |
| 世下27 | 万隆与不结盟 | 亚非会议、万隆精神；不结盟运动体现新独立国家争取自主、反对霸权 | 不结盟不是不参与国际事务，也不等于所有成员政策一致 |
| 世下28 | 多极化趋势 | 两极格局结束后，多种力量发展，美国、欧洲、中国、俄罗斯、日本和广大发展中国家等影响格局 | 多极化是趋势，不能写成已形成稳定的若干极均衡体系 |
| 世下29 | 经济全球化 | 国际贸易、资本、技术与生产分工跨国发展；跨国公司和世贸组织等；相互依存增强 | 全球化不等于利益均等；机遇、竞争、风险和逆全球化现象需结合材料 |
| 世下30 | 科技与社会 | 信息技术、互联网、生物技术、新能源等改变生产生活，带来隐私、就业、数字鸿沟等问题 | 区分不同技术领域，不把所有现代发明都当作第二次工业革命成果 |
| 世下31 | 人口、生态与和平发展 | 人口增长及结构变化、环境污染、资源问题；和平与发展是当今时代主题，国际合作仍有重大任务 | “时代主题”不等于现实中没有冲突；用全球合作解释跨国问题治理 |

## 九、深圳备考应能贯通的十二个专题

这些专题是组织知识的复习抓手，没有据此计算“必考”“高频”或押题概率。地方材料只提供情境，最后仍要回到史实与设问。

| 专题 | 可串联的史实 | 需要解释的核心关系 |
| --- | --- | --- |
| 统一多民族国家 | 秦统一、汉大一统、西域都护、唐代交往、元行省、明清边疆治理 | 统一、制度与民族交往如何互相促进；不把古今治理概念混用 |
| 国家治理与法治 | 分封、郡县、科举、三省六部、行省；《汉谟拉比法典》《权利法案》、近现代宪法 | 法律服务什么社会关系，如何约束权力，时代局限是什么 |
| 农业、土地与民生 | 原始农业、都江堰、江南开发、经济重心南移、近现代土地政策 | 土地所有权、经营方式、劳动积极性、国家建设之间的关系 |
| 海洋与中外交流 | 丝路、宋元海贸、郑和、新航路、殖民扩张、近代口岸、改革开放 | 主动交流与被迫开放、平等合作与殖民掠夺的区别 |
| 科技与科学家 | 四大发明、古代科技著作、两次工业革命、两弹一星、航天与信息技术 | 科技条件、社会需求、组织保障、科学家精神与社会影响 |
| 思想与社会变革 | 百家争鸣、文艺复兴、启蒙、马克思主义、新文化运动、思想解放 | 思想回应哪些问题，如何与组织和实践结合 |
| 近代化的不同道路 | 洋务、戊戌、辛亥；英美法革命；俄日改革；中国革命和改革 | 变革主体、目标、条件、方式、结果为何不同 |
| 人民群众与社会力量 | 工人运动、农民土地要求、抗战动员、支前、改革实践 | 人民不是抽象口号，要说明具体行动怎样影响历史 |
| 教育与人才流动 | 科举、新式学堂、近代留学、科学家归国、科教兴国 | 人才流动为什么发生，怎样反映国家需求与国际环境 |
| 城市与社会生活 | 长安、开封、佛罗伦萨、伦敦、上海、深圳 | 城市怎样承载政治、经济、文化与技术变化，以及发展代价 |
| 世界战争与秩序 | 两次世界大战、战后体系、联合国、冷战、多极化 | 战争、合作、大国实力与国际规则之间的关系 |
| 广东、深圳与国家发展 | 虎门销烟、广州近代革命活动、黄埔军校、深圳经济特区、港澳回归 | 把地方事件放入国家与世界进程，避免只背地方知识孤立答题 |

## 十、必须会画的时间轴与对照表

### 1. 中国历史骨架

夏 → 商 → 西周 → 东周（春秋、战国）→ 秦 → 西汉 → 东汉 → 三国 → 西晋 → 东晋及十六国 → 南北朝 → 隋 → 唐 → 五代十国 → 辽宋夏金等政权并立 → 元 → 明 → 清 → 中华民国 → 中华人民共和国。

这是便于记忆的骨架；并立政权存在交叠，不能把所有名称理解为简单前后接续。

| 时间 | 事件 | 必须连带理解 |
| --- | --- | --- |
| 前221、前202、前60年 | 秦统一、西汉建立、西域都护设置 | 统一建立与制度巩固是不同过程 |
| 589、618、960、1271、1279年 | 隋统一、唐建立、北宋建立、元定国号、元完成统一 | 建国、改国号、完成统一有不同时间 |
| 1368、1644年 | 明建立、明亡及清军入关 | 清改国号在1636年 |
| 1840、1895、1901年 | 鸦片战争爆发、《马关条约》《辛丑条约》 | 社会性质变化的阶段，不能把条约与战争开始年份混写 |
| 1911、1912、1915、1919、1921年 | 辛亥、民国、新文化、五四、中共成立 | 政治、思想与组织力量的变化 |
| 1927、1935、1936年 | 革命道路探索、遵义会议、长征胜利与西安事变 | 中国革命与民族危机两条线同时推进 |
| 1931、1937、1945、1949年 | 局部抗战、全民族抗战、抗战胜利、新中国成立 | 革命任务与阶段发生转换 |
| 1950—1952、1953—1957、1956年 | 土地改革、一五计划、三大改造基本完成 | 时间有交叠，任务和性质不同 |
| 1978、1980、1992、2001年 | 改革开放转折、经济特区、市场经济体制目标、加入世贸 | 开放和体制改革不断深化 |
| 1971、1972、1979、1997、1999年 | 恢复联合国合法席位、尼克松访华、中美建交、港澳回归 | 不同类型外交与统一成就 |

### 3. 容易混淆的六组对照

| 对照组 | 共同观察维度 | 区别关键 |
| --- | --- | --- |
| 洋务—戊戌—辛亥—新文化 | 主体、目标、学习重点、方式、结果 | 技术、制度、思想层面变化存在交叠，不能解释为绝对彼此排斥的四个阶段 |

| 二月革命—十月革命 | 革命对象、领导、结果、性质 | 推翻沙皇与推翻临时政府；资产阶级民主革命与社会主义革命 |
| 新政—新经济政策—中国改革 | 背景、制度前提、政策工具、作用 | 都可讨论政策调整，但国家制度、历史任务不同，不能说本质完全相同 |

## 十一、知识怎样转化为材料题能力

| 能力 | 自测任务 | 达标表现 |
| --- | --- | --- |
| 时空观念 | 给事件定位朝代、年代、地区，读懂路线图和政权地图 | 不发生人物穿越、制度提前或地点错置 |
| 史料实证 | 区分实物、文献、图像、口述等，说明材料的证明范围 | 能说出“凭什么这样判断”，不把一条证据无限放大 |
| 历史解释 | 用材料与所学解释原因、特点、变化和影响 | 不把列举事件当作分析，因果链条清楚 |
| 唯物史观 | 结合生产力、社会关系、群众实践和具体条件认识变迁 | 不把复杂变化只归因于一位英雄或一个偶然事件 |
| 家国情怀 | 在具体史实中认识国家、民族、人类社会的价值与责任 | 有史实支撑，尊重不同文明，不以空泛口号代替解释 |

以上五方面依据历史课程核心素养框架组织；它们会共同出现在同一道题中，不必机械地一题只归一类。[教育部历史课程标准（2022年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582345700037.pdf)

### 跨学科主题探究也要会做

跨学科主题学习把历史问题与语文、地理、数学、艺术、信息技术等方法联系起来，重点仍是有证据地研究历史。以下为自编学习任务示例，不是深圳官方指定活动：

| 任务 | 可结合的学科方法 | 应形成的历史学习成果 |
| --- | --- | --- |
| 为博物馆拟一个主题展览 | 语文说明文、艺术设计、信息检索 | 展览主题、展品年代与来源、展签，以及展品如何支持主题 |
| 调查一处遗址或历史建筑 | 地理定位、现场测绘、文化保护知识 | 时间与空间定位、资料互证、历史价值和保护建议，区分复原与原物 |
| 研究家庭生活变迁 | 口述访谈、档案整理、数据图表 | 对比不同时期的生活与社会背景，注明样本有限，不能以一家代表全国 |
| 绘制交通或贸易路线图 | 地理地图、数学统计、信息技术 | 准确图例、路线年代、交流内容及社会影响，不用今天路线替代古代路线 |

新修订教材重视通史主线、主题探究和学史方法，可参看[人民教育出版社的教材修订介绍](https://www.pep.com.cn/xw/zt/hd/12/zbtjc/202411/t20241118_1996860.html)。2024年教材修订与2025年课标日常修订是两件事，不能将上述每项直接标成“2025课标新增”。

## 十二、复习顺序与完成标准

1. **先通史**：用六条主线和时间轴定位每条考点；讲清“发生了什么、前后有什么变化”。
2. **再联系**：每学一个改革、革命或制度，补齐背景、内容、影响、局限；每学一个文化成就，补齐时代、领域、贡献和证据。
3. **做专题**：从十二个专题中选择已学内容，练习中外对照、古今联系；比较时使用同一维度。
4. **练材料**：对照配套解析，把问题拆成任务，以材料证据和所学共同作答；特别练概括、历史解释和论述。
5. **回查教材**：不熟悉的条目返回教材正文、地图、图注、史料和活动栏目；新旧教材变化以学生实际用书核对。

每一行可自查：①能否脱离提示说出基本史实；②能否放进时空背景；③能否解释一个关系；④能否指出一个常见误区。四项不能完成时，继续复习，不能只以“看过”标记掌握。
