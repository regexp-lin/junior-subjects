# 第8课 西欧的城市和大学｜思维导图

> **所属单元：** 第三单元：封建时代的欧洲  
> 建议先遮住分支自述，再核对本图；箭头“→”表示主要因果或演进关系，“＋”表示共同条件。

```text
西欧的城市和大学
├─ 城市复兴（10世纪起）
│  ├─ 农业进步、剩余增加、贸易发展、人口增长
│  ├─ 道路交会/港口/主教驻地聚集
│  └─ 手工业、商业中心
├─ 自治与市民
│  ├─ 金钱赎买或武力斗争
│  ├─ 人身自由、财产权、市政选举/法庭（程度有限）
│  └─ 市民阶层；富裕商人/作坊主是资产阶级前身
├─ 行会
│  └─ 管理资格、质量、价格；也限制竞争
└─ 大学（12世纪）
   ├─ 社会需要专业人才＋古典/阿拉伯文化传入
   ├─ 博洛尼亚、巴黎；七艺→法学、医学等
   └─ 培养官员、律师、医生
复习抓手：城市自治不等于城市完全独立。
```
