# 第16课 英国资产阶级革命｜详细知识点（背诵版）

> **所属单元：** 第六单元·资本主义制度的初步确立。  
> **整理依据：** [本目录教材PDF](./16_第16课_美国资产阶级革命.pdf)，依据其正文、史料和课后活动整理。

> **背诵范围：** 革命背景、过程、《权利法案》和意义为课内必背；“理解辨析”用于解释革命性质、制度和局限；传统法律和人物史事按标注选背。

## 一、先背这一条主线

**资本主义发展 → 君主专制损害新兴资产阶级利益 → 议会与王权斗争加剧 → 1640年革命开始 → 内战、1649年共和国 → 克伦威尔个人专权 → 1660年王朝复辟 → 1688年“光荣革命” → 1689年《权利法案》限制王权 → 君主立宪制逐渐形成。**

这场革命的目标与意义在于结束封建君主的专制统治，为资本主义发展开辟道路。它经历了反复、妥协和制度建设，不能压缩成“杀死国王就立即建立稳定民主”。

## 二、议会与王权的斗争

### 1. 经济背景：英国资本主义迅速发展

新航路开辟后，英国积极开展对外贸易和殖民活动，资本主义迅速发展。新兴资产阶级经济力量增强，希望维护经营、财产和政治活动的利益，反对专制王权任意征税、侵犯议会权利。

**根本原因可背为：** 英国封建君主专制统治阻碍资本主义发展。根本原因不能只写“查理一世与议员吵架”或“苏格兰人民起义”，这些是具体冲突或事件。

### 2. 英国已有“王权有限”和“王在法下”的传统

教材指出，英国自13世纪以来逐渐确立这类政治传统。它们意味着王权并非可以完全不受约束，国王也应遵守法律和一定的议事规则。

**教材相关史事：** 1215年，国王约翰一世签署《大宪章》，规定国王未经贵族会议决定不得额外征税，不能不经合法判决便逮捕、监禁、没收财产或放逐自由人。它限制王权，维护贵族、骑士和市民等利益。

**议会制度：** 13世纪末基本确立，后来逐步取得立法、审批征税、弹劾大臣等权利；14世纪中期形成上、下两院，贵族组成上院，没有贵族头衔的骑士和市民代表组成下院。它给新兴资产阶级反对专制提供了政治活动场所。

**辨析：** 中世纪议会不是现代普选议会，《大宪章》也不是为所有人建立平等民主；本课借这些史事说明限制王权的历史传统。

### 3. 詹姆士一世：君权神授与专制统治

17世纪初，英国女王去世且没有直系后代，苏格兰国王继任英国国王，称詹姆士一世。他信奉**君权神授**，实行专制统治，既损害新兴资产阶级利益，也违背“王权有限”“王在法下”的传统。

**君权神授：** 宣称君主权力来自神，用宗教权威为专制统治辩护。资产阶级利用议会审批征税等传统权利，与国王展开斗争。冲突的表现是议会与王权之争，深层是新经济力量与旧专制制度的矛盾。

### 4. 查理一世与《权利请愿书》

詹姆士一世的继任者查理一世继续推行君主专制，无视议会权利。1628年，议会提交《权利请愿书》，重申：

1. 未经议会同意，国王不得征税。
2. 未经法院判决，不能随意逮捕人。
3. 和平时期不能随意在居民家中驻军。

查理一世先是假意应允，得到拨款后又解散议会，使矛盾进一步激化。**税收之争不仅是钱的问题，也是国家权力由谁行使、国王能否违法专断的问题。**

## 三、英国内战和“光荣革命”

### 1. 1640年：重新召开议会，革命拉开序幕

为筹措军费镇压苏格兰人民起义，查理一世不得不重新召开议会。议员猛烈抨击国王专权，要求维护议会权利，揭开英国资产阶级革命的序幕。

**标志与诱因分开：** 苏格兰人民起义使国王需要军费，是重新召开议会的直接背景；1640年议会重新召开、反对国王专权，才是教材用于说明革命开始的事件。

### 2. 1642年：查理一世挑起内战

1642年，查理一世派兵抓捕议员未遂，之后宣布讨伐议会中的反对分子，挑起内战。议会军同王军展开较量。经过反复斗争，克伦威尔领导议会军打败王军。

**教材战役史事，理解选背：** 战争初期议会处于劣势；1643年议会与苏格兰结盟；1644年马斯顿荒原战役有利于扭转战局；1645年纳西比战役中议会军取得决定性胜利。主干重点是内战起因、双方、克伦威尔和议会军胜利，不必用战役细节代替主线。

### 3. 1649年：处死查理一世，建立共和国

1649年，查理一世经审判被处死，英国随后宣布成立共和国。它表明革命已发展到废除君主制的阶段，对君权神授观念构成冲击。

但共和国成立后，克伦威尔独揽大权，革命废除了君主制，却没有结束个人专权，国内矛盾仍然尖锐、局势不稳。**“没有国王”不等于“没有独裁”，政体名称与权力实际运行需要分别观察。**

教材人物扫描：克伦威尔在内战中贡献突出，后来成为实际上的军事独裁者；1653年自任“护国主”，镇压贫苦农民争取土地的斗争并远征爱尔兰。评价他应同时看到反专制作战的作用与个人专权、镇压民众的一面。

### 4. 1660年：封建王朝复辟

克伦威尔去世后，继任者不能稳定局势。1660年，查理一世之子查理二世接受议会有条件的邀请，成为国王，封建王朝复辟。詹姆士二世继位后加强王权，恢复天主教会，进行反攻倒算，引起新的反抗。

**理解：** 复辟是革命中的反复，但不代表革命此前一切变化都消失。国王能否按旧方式专断统治仍是斗争焦点，最终又引发王位与权力安排的改变。

### 5. 1688年：“光荣革命”

英国议会邀请詹姆士二世的女儿玛丽和女婿威廉入主英国。威廉率军登陆，詹姆士二世逃往法国；威廉与玛丽接受议会提出的条件，登上王位。教材把这次政权更替称为一次没有流血的革命，英国人称其为**“光荣革命”**。

**重点理解：** 王位仍然保留，但新君主接受议会条件，体现议会力量增强和以妥协方式安排政权。教材“不流血”的说法针对这次主要政权更替，不可据此把此前多年内战也说成没有流血。

**意义与限度：** 它有利于结束专制复辟的政治危机，为进一步以法律限制王权创造条件；但保留君主，普通民众没有因此立即取得普遍、平等的政治权利，仍有时代与阶级局限。

## 四、英国君主立宪制的初步确立

### 1. 1689年《权利法案》：主体和目的

- **通过机构：** 英国议会。
- **时间：** 1689年。
- **目的与作用：** 明确议会的权利以及国王应遵守的原则，限制王权，巩固革命后的政治安排。
- **性质：** 具有资产阶级性质的法律文献，而不是宣布废除君主制的文件。

### 2. 主要内容：逐条背清

| 内容 | 限制或保障的重点 |
| --- | --- |
| 议会定期召开 | 国王不能任意阻断议会运作 |
| 议员享有讨论国事和言论自由的权利 | 保障议会独立议政 |
| 征税权属于议会 | 限制国王任意征收金钱 |
| 国民可以自由请愿 | 保障一定的政治表达权利 |
| 国王未经议会许可不得随意废除法律、停止法律执行 | 限制国王凌驾法律之上的权力 |

材料题常引“未经议会同意停止法律非法”和“未经议会准许征税非法”，应分别概括为**限制国王擅自停止法律执行的权力，以及任意征税的权力**，总原则是王权必须受到法律和议会制约。

### 3. 制度逐渐形成，而非一日完成

此后，议会又通过法律规定王位继承，进一步限制国王。议会权力不断加强，**君主立宪制逐渐形成**。

**可背定义：** 君主立宪制是在保留君主的同时，以法律和议会限制君主权力的政治制度。本课强调，资产阶级掌握的议会实际上控制国家权力。

**学习边界：** 1689年是重要法律节点，英国君主立宪制是在此后逐步发展完善的。不要把后来成熟的内阁制度、今日王室职能等细节全部倒放到1689年。

## 五、性质、意义与历史特点

### 1. 为什么属于资产阶级革命

它反对阻碍资本主义发展的封建君主专制，资产阶级通过议会等政治力量发挥重要作用，革命后形成有利于资产阶级利益的政治制度，为资本主义发展开辟道路。

**理解补充：** 常见概括还包括资产阶级与新贵族共同领导。新贵族指经营方式和利益逐渐同资本主义发展联系起来的部分贵族；不能把他们同坚持旧封建特权的所有贵族混为一谈。

### 2. 历史意义（课内必背）

**英国资产阶级革命推翻封建君主的专制统治，为英国资本主义进一步发展开辟道路，并对世界近代历史产生重要影响。**

政治上，国王权力受到法律和议会约束，君主立宪制初步确立；经济上，减少专制王权对资本主义发展的阻碍；世界影响上，为近代资本主义政治制度的发展提供重要经验。

### 3. 特点和局限（理解辨析）

- **曲折性：** 内战、共和国、个人独裁、王朝复辟、政权再更替相继出现，制度建设不是直线推进。
- **妥协性：** 最后保留君主，以法律和议会限权，没有简单恢复1649年的共和形式。
- **阶级局限：** 新制度主要维护资产阶级和相关有产阶层利益，民众尚未得到充分平等的参政权；不能等同于现代普选民主。
- **评价原则：** 是否保留国王不是判断革命成功与否的唯一标准，关键看专制是否受限制、国家权力关系是否改变、是否有利于资本主义发展。

## 六、关键时间线与易混辨析

| 时间 | 事件 | 所处环节 |
| --- | --- | --- |
| 1215年 | 《大宪章》 | 限制王权的历史传统，教材相关史事 |
| 1628年 | 《权利请愿书》 | 革命前议会与王权的斗争 |
| 1640年 | 议会重新召开 | 革命拉开序幕 |
| 1642年 | 查理一世挑起内战 | 武装斗争开始 |
| 1649年 | 处死查理一世，成立共和国 | 暂时废除君主制 |
| 1660年 | 查理二世即位，王朝复辟 | 革命出现反复 |
| 1688年 | “光荣革命” | 更换君主，接受议会条件 |
| 1689年 | 通过《权利法案》 | 法律限制王权，推动君主立宪制形成 |

1. **《权利请愿书》与《权利法案》：** 前者1628年，属于革命前冲突；后者1689年，属于革命后的制度建设。
2. **查理一世与查理二世：** 前者被处死，后者在1660年复辟即位。
3. **1688年与1689年：** 前者是“光荣革命”，后者通过《权利法案》。
4. **推翻专制与废除王位：** 最终结束专制，并没有永久废除君主制度。
5. **议会获权与全民获权：** 资产阶级议会权力加强，并不等于人人拥有相同政治权利。

## 七、简答题：照着答案练背

### 1. 英国资产阶级革命为什么爆发？

新航路开辟后英国资本主义发展，新兴资产阶级力量增强；国王信奉君权神授、实行专制、侵犯议会传统权利，严重损害资产阶级利益。根本原因是封建君主专制阻碍资本主义发展，征税和议会权利之争不断激化矛盾。

### 2. 概述英国资产阶级革命的主要过程。

1640年议会重新召开，革命拉开序幕；1642年内战爆发；1649年处死查理一世、成立共和国，后出现克伦威尔个人专权；1660年王朝复辟；1688年“光荣革命”；1689年通过《权利法案》，君主立宪制逐渐形成。

### 3. 《权利法案》怎样限制王权？

它规定议会定期召开，议员拥有讨论国事和言论自由，征税权属于议会，国民可以自由请愿；国王未经议会许可不得随意废除法律或停止法律执行，使国王权力受法律与议会约束。

### 4. 什么是君主立宪制？

它保留君主，但以法律和议会限制君主权力。本课英国君主立宪制的形成，体现议会权力增强，资产阶级掌握的议会实际上控制国家权力。

### 5. 怎样评价“光荣革命”？

它通过更换君主和接受议会条件的方式，打击专制复辟，为法律限制王权创造条件，有利于稳定政局和资本主义发展；但保留君主，主要维护有产阶层利益，未实现普遍、平等的政治权利，具有妥协性和局限性。

### 6. 英国资产阶级革命有何历史意义？

它推翻封建君主的专制统治，推动君主立宪制初步确立，为英国资本主义进一步发展开辟道路，对世界近代历史产生重要影响。
