# 第6课 古代罗马｜详细知识点（背诵版）

> **所属单元：** 第二单元：古代欧洲文明。  
> **教材依据：** [本课教材 PDF](06_第6课_古代罗马.pdf)，包括正文、地图、相关史事、材料研读和课后活动。  
> **使用说明：** 以“共和国—帝国—文化”为骨架；“理解辨析”解释因果与评价，“教材拓展”另列。年代按本课教材口径整理，内容为自主概括。

## 一、先背主线

**约公元前509年共和国建立 → 平民与贵族斗争、形成政治机构 → 战争扩张并扩大奴隶制 → 斯巴达克起义 → 恺撒独裁与内战 → 屋大维建立元首制，共和国演变为帝国 → 2世纪全盛 → 3世纪危机 → 395年分裂 → 476年西罗马灭亡。**

本课抓四条线：**政体变化、对外扩张、奴隶制矛盾、文化遗产**。罗马并非从建城起就是帝国，也不是由恺撒直接完成帝国建立；395年的分裂和476年的西罗马灭亡是两个不同事件。

## 二、课内必背：罗马共和国

### 1. 地理基础与共和国建立

1. 罗马发源于意大利半岛的台伯河畔。意大利半岛三面临海、土地肥沃，有利于农业、畜牧业，也便于对外联系。
2. 很早就有众多民族在此生活。公元前8世纪，意大利半岛形成许多国家，罗马是其中之一。
3. **约公元前509年**，罗马废止王政，建立共和国。
4. 母狼哺育罗马祖先的故事属于建城传说，反映集体记忆与身份认同，不能直接当作经过考古证实的建国经过。
5. 教材补充：末代国王专横、侵害贵族和平民，罗马人在布鲁图斯等领导下推翻王政。核心记忆是“废止王政、建立共和国”，不必背诵传说全部人物。

### 2. 平民为什么斗争，获得什么权利

**原因：** 共和国初期贵族垄断权力，平民社会、政治权利受限制。平民是自由人，不等于奴隶，但与贵族并不天然平等。

**斗争与成果：** 在冲突中，罗马制定一系列涉及债务、土地、国家制度的法律，平民逐渐获得重要社会政治权利，取得与贵族大体平等的法律地位：

- 可以担任各级官职；
- 可以获得公有土地；
- 免受债务奴役；
- 受审时不受鞭打；
- 有权参加公民大会、选举官员、通过立法。

**理解：** 权利扩大是长期斗争结果，不是建立共和国当天就自动实现。“大体平等的法律地位”也不能等于财富、社会影响完全相同，更没有取消对奴隶的压迫。

### 3. 共和国的主要政治机构

| 机构 | 组成或职能 |
| --- | --- |
| 元老院 | 由300名元老组成，掌握国家实际权力 |
| 执政官及其他官员 | 两名执政官等主持日常政务 |
| 公民大会 | 拥有选举、立法等权力 |

要点：罗马共和国存在多个机构分担事务，但教材强调**元老院掌握实际权力**。不能照搬雅典，把罗马公民大会说成实际最高权力机关；也不能把“共和国”直接等同于现代民主共和国。

### 4. 罗马对外扩张的过程

1. 建国之初即不断扩张，**公元前3世纪前期征服意大利半岛**。
2. 随后同北非迦太基争夺地中海霸权，最终灭亡迦太基，又征服希腊等地。
3. **公元前1世纪后期**，征服整个地中海地区，地中海成为罗马控制区域的中心。
4. **读图顺序：** 先找台伯河畔罗马与意大利，再看北非、西班牙、巴尔干、小亚细亚，比较不同时期疆域逐渐扩大。

**教材补充：布匿战争。** 公元前264—前146年，罗马与迦太基先后进行三次战争。罗马称迦太基人为“布匿人”，故有此名。第一次获西西里等地；第二次汉尼拔进攻意大利、屡创罗马，但迦太基最终战败；第三次迦太基被毁，幸存者被卖为奴隶。战争既反映争霸，也显示扩张的残酷性。

### 5. 奴隶制扩大与斯巴达克起义

- **来源：** 罗马把大量被征服地区的人变成奴隶，战争扩张促进奴隶制进一步发展。
- **劳动与处境：** 奴隶在矿山、农庄等从事艰苦劳动，有的被迫当角斗士，在角斗场与人或猛兽搏斗，处境悲惨。
- **起义：** **公元前73年**，角斗士斯巴达克发动奴隶起义，队伍声势浩大，多次击败罗马军队。
- **结果与影响：** 最终被镇压，但冲击了罗马奴隶主统治，反映奴隶制社会矛盾尖锐。
- **不能夸大：** 起义没有推翻罗马政权、废除奴隶制，更不是共和国转为帝国的唯一原因。

**材料研读：** 《法理概要》把人分为自由人和奴隶，规定主人对奴隶有生杀权，奴隶所得归主人。可概括为：罗马是奴隶制社会，奴隶受主人支配，权利和人身地位极不平等；法律维护奴隶主利益。

## 三、课内必背：罗马帝国

### 1. 从恺撒独裁到屋大维元首制

**恺撒：** 公元前49年，时任行省总督的恺撒率军进攻罗马，打败对手、控制元老院，实行独裁。公元前44年被刺杀，罗马又经历多年内战。

**屋大维：** 他是恺撒养子，以继承人身份争取军队，最终成为内战胜利者。公元前31年成为唯一统治者，**公元前27年获“奥古斯都”称号**。

**元首制：** 表面尊重共和传统，以首席元老身份统治，不直接称帝；实际把所有权力集中手中、执政终身，依靠军队实行统治。共和国由此演变为帝国。

**判断制度的关键：** 看实际权力集中在谁手里，而非只看是否保留元老院或是否使用“皇帝”称号。通常以公元前27年作为罗马帝国建立的标志性年代；不能将恺撒等同为完成这一转变的屋大维。

### 2. 帝国前期的繁荣

1. 前期政治相对稳定，地中海世界各地区联系加强。
2. 农业、手工业、贸易获得一定发展，交通和商业往来扩大。
3. **2世纪，罗马帝国进入全盛时期**。版图跨欧、亚、非三洲，地中海居其中心。
4. 这一繁荣以奴隶劳动和帝国控制为背景，不能因经济繁荣就说所有人生活良好、社会没有矛盾。

### 3. 罗马与汉代中国的交往

- 罗马帝国时期，丝绸之路已经打通，东西方交流发展。
- 罗马与汉代中国不仅彼此有一定了解，还有直接人员往来。中国史籍将罗马称为“大秦”。
- 教材地图显示，既可经中亚等地的陆上通道联系，也可通过西亚、印度洋及南海等海上商路联系，体现陆海交通相互补充。
- 《后汉书》记载有罗马人到达洛阳、觐见东汉皇帝，献象牙、犀角、玳瑁等；这些自称“使者”的人可能是商人或民间艺人。
- **史料边界：** 人员来往有史料记载，但不能把所有“使者”都当作已确证的正式外交使团；商品来源也不必然等于人员出生地。

### 4. 基督教的产生与地位变化

- **时间地点：** 1世纪初，产生于罗马帝国统治下的巴勒斯坦地区，后来传播到帝国各地。
- **教材补充：** 最初产生于犹太人中，据传创始人为耶稣；早期受到罗马政府迫害。后来富人加入、教会影响扩大，教会与政府靠近，政府转而宽容、支持。
- **按本课教材：** **392年，罗马皇帝宣布基督教为罗马国教**。背诵以本课教材年代为准。
- **理解：** 从受迫害到受支持，反映宗教与政治关系变化。1世纪初是产生时间，392年是教材所列国教化时间，不得混写。

### 5. 帝国危机、分裂与西罗马灭亡

**3世纪的内部危机：** 统治者混战，人民起义不断，农业萎缩，工商业衰落，民生凋敝。政治、经济危机相互加剧。

**外部压力：** 日耳曼人的渗透和威胁日益严重。

**分裂：** **395年**，罗马帝国分裂为东、西两个帝国。

**灭亡：** **476年**，西罗马帝国在内部矛盾和日耳曼人的打击下灭亡。

**原因表达：** 内部政治经济危机削弱国家，外来打击加速灭亡，两者共同作用。不能只归因于“日耳曼人强大”，也不能说395年罗马文明全部终结。东罗马继续存在，其发展在拜占庭课学习。

## 四、课内必背：古代罗马文化

### 1. 文学与史学

- 罗马继承地中海各文明遗产，也形成自己的创造。
- **维吉尔《埃涅阿斯纪》：** 罗马著名史诗。
- **李维《罗马史》：** 系统叙述从罗马建城到公元前1世纪的历史。
- 区分“作品属于哪个文明”和“作品讲述哪个时代”，不能将罗马作品与希腊《荷马史诗》、两河《吉尔伽美什史诗》混淆。

### 2. 道路与建筑

- **道路：** 四通八达，是连接帝国各地区的重要纽带，便利管理、军事调动、贸易和人员往来。
- **建筑代表：** 大竞技场、万神殿，反映工程建筑能力及公共生活需要。
- 大竞技场也使人看到奴隶角斗的残酷，建筑技术成就与社会压迫可以同时存在。
- 神庙与竞技场功能不同，不能因为都是宏伟建筑就混写用途。

### 3. 罗马法与法学

1. 罗马人在国家管理和司法实践中颁布许多法律，发展出完整法学系统。
2. **《十二表法》**是后世罗马法典乃至欧洲法学的重要渊源。
3. **历史贡献：** 法律规则和法学思想对后世影响深远。
4. **时代局限：** 罗马法也维护奴隶制及奴隶主利益，不能因其影响大就说实现了人人平等。
5. **比较：** 《十二表法》属于罗马；《汉谟拉比法典》属于古巴比伦。二者都是古代法律遗产，不能互换名称、时代和地域。

## 五、教材拓展：公历的缘起

古罗马历法吸收古埃及太阳历。恺撒命人以太阳历为蓝本编制新历，称**儒略历**，一年365天，通过每4年在2月增加1天来调整误差；后来历法不断修订，成为今天公历的基础。

理解重点：**埃及太阳历 → 罗马儒略历 → 后世修订的公历**，体现文明继承和长期改进。不能说现代公历由恺撒一次制定后完全不变，也不要将屋大维建立元首制与恺撒改革历法混为一事。

## 七、重点易混辨析与活动题

1. **平民与奴隶不同。** 平民属于自由人，曾争取到重要公民权；奴隶受主人支配，不能把平民斗争和奴隶起义混成同一次运动。
2. **共和国不等于没有贵族特权。** 元老院掌握实际权力，平民权利是斗争所得。
3. **恺撒独裁先于屋大维元首制。** 前者被刺后仍有内战，后者完成向帝国的转变。
4. **帝国分裂不等于西罗马灭亡。** 分别为395年、476年，东罗马并未在476年同时灭亡。
5. **罗马扩张有多方面后果。** 财富、交通、贸易联系增长，也伴随奴役、破坏和矛盾加深。
6. **罗马法影响深远与其不平等性可以并存。** 评价应区分后世贡献与当时制度局限。

**课后活动：节庆娱乐日增加会产生什么影响？** 节日费用由国库承担，娱乐日不断增加会扩大财政开支；过度依赖国家供养和娱乐也可能影响生产、社会风气，加重财政经济负担。答题须用“可能”“加重”等表述，不能仅凭娱乐天数就证明这是帝国灭亡的唯一原因。

## 八、简答题：可直接背诵的答案

**1. 罗马平民为什么斗争，获得哪些权利？**  
答：贵族垄断权力，平民为争取社会政治权利展开斗争；后来可任官、获公有地、免受债务奴役，受审不被鞭打，参加公民大会、选官并立法，取得与贵族大体平等的法律地位。

**2. 罗马扩张怎样影响社会？**  
答：扩张使罗马控制意大利和地中海，获得土地财富，加强区域联系；同时把大量被征服者变为奴隶，扩大奴隶制，给当地人民带来灾难，加深矛盾并引起反抗。

**3. 斯巴达克起义的原因和影响是什么？**  
答：奴隶受残酷压迫，角斗士被迫搏斗。公元前73年斯巴达克发动起义，多次击败罗马军队，最终虽被镇压，仍冲击奴隶主统治，反映奴隶制社会矛盾尖锐。

**4. 罗马共和国怎样演变为帝国？**  
答：恺撒在公元前49年进攻罗马、实行独裁，前44年被刺后内战持续；屋大维最终获胜，表面保留共和传统，实际集权并执政终身，创立元首制。公元前27年获“奥古斯都”称号，标志向帝国的转变。

**5. 西罗马帝国为什么灭亡？**  
答：3世纪起内部混战、起义和经济衰落削弱国家，外部日耳曼人的渗透、打击加重危机；395年帝国分裂，476年西罗马在内外因素共同作用下灭亡。

**6. 怎样评价罗马文化遗产？**  
答：罗马继承并发展地中海文明，在史诗、史学、道路、建筑、法律和历法方面贡献重要；罗马法和法学、道路工程及历法影响后世。评价时也要认识奴隶制背景及文化遗产所反映的不平等。

**7. 罗马与汉代中国交往说明什么？**  
答：陆上丝绸之路和海上商路连接东西方，双方不仅有所了解，还有直接人员来往，体现古代文明交流。记载中的“使者”可能是商人或艺人，不能全部认定为正式外交使团。
