# 第5课 古代希腊｜详细知识点（背诵版）

> **所属单元：** 第二单元：古代欧洲文明。  
> **教材依据：** [本课教材 PDF](05_第5课_古代希腊.pdf)，包括正文、地图、材料、相关史事与活动。  
> **使用说明：** 按“城邦—雅典和斯巴达—亚历山大—文化”背诵；“理解辨析”“教材拓展”用于深化，避免与基本事实混淆。内容为自主概括。

## 一、先背主线

**爱琴海早期文明 → 公元前8—前6世纪众多城邦兴起 → 雅典发展奴隶制民主政治，斯巴达实行寡头政治 → 公元前334年亚历山大东侵，建立跨欧亚非帝国 → 希腊文化取得辉煌成就，东西方联系加强。**

本课核心：**城邦小国寡民；公民权利有边界；民主与寡头并存；战争具有征服性，也可能客观推动交流。**古代希腊是欧洲文明的重要发祥地，但古希腊不是当时已经统一的大民族国家。

## 二、课内必背：希腊城邦

### 1. 古代希腊的范围和自然环境

- 大致包括希腊半岛、爱琴海诸岛、小亚细亚半岛西岸、黑海沿岸、意大利南部、西西里岛等地区，范围大于今天希腊国家。
- **中心：** 希腊半岛。这里多山、耕地有限；海岸曲折、港湾众多、岛屿密布。
- **影响：** 山地和分散地域有利于形成分立的政治共同体；良好海洋条件适宜航海、海外贸易与对外联系。
- **理解：** 地理环境提供条件，并不直接、唯一决定政治制度。不能说“多山必然民主”，斯巴达的存在就是不同道路的例子。

### 2. 早期文明与城邦兴起

1. 希腊最早文明产生于**爱琴海地区**，包括克里特文明和迈锡尼文明。
2. **公元前8—前6世纪**，出现众多城邦；希腊人同时向外殖民，势力扩展到地中海、黑海周边。
3. **城邦概念：** 一般以一个城市或市镇为中心，把周围农村联合起来组成国家。
4. **突出特点：** **小国寡民**。最大的城邦公民不过数万人，小的只有数百人。
5. 城邦不只是城市，还是政治共同体，周围农村也是其组成部分；城邦公民人数也不能等同于所有居民人数。

### 3. 公民与其他居民的不同地位

| 身份 | 权利、义务或主要处境 |
| --- | --- |
| 公民 | 有权拥有土地和房屋，参与城邦管理；承担参军打仗义务，是宗教、节庆、文体活动主体 |
| 妇女 | 主要承担家务、生育后代，被排除在政治权利之外 |
| 外邦人 | 是自由人，但没有政治权利，也不能占有土地 |
| 奴隶 | 几乎没有权利和自由，受主人支配 |

**公民与城邦关系：** 城邦是公民组成的政治共同体，公民通过议事、审判等参与治理，并承担保卫城邦等义务；公民身份决定政治参与资格。这里的公民范围有限，不能理解为所有定居者。

亚里士多德材料把有权参加议事和审判的人视为公民。答题应抓**政治参与资格**，不能只凭“住在城里”“有财富”判断公民身份。

## 三、课内必背：雅典和斯巴达

### 1. 雅典奴隶制民主政治的机构

雅典位于希腊半岛中东部。经过发展，形成奴隶制民主政治。

| 机构 | 地位与职能 |
| --- | --- |
| 公民大会 | 最高权力机关，对所有重要问题作出决定 |
| 500人议事会 | 预先讨论提交公民大会的决议，主持公民大会 |
| 官员 | 处理有关事务，必须接受公民大会监督 |
| 民众法庭（教材补充） | 公民参与审判的重要机关 |

**关系：** 议事会准备、主持会议，不能取代公民大会的最高地位；官员接受监督，说明公民政治参与具有制度形式。

### 2. 伯里克利时期的发展

- **时间、人物：** 公元前5世纪中期，伯里克利主政。
- **抽签任职：** 大部分公职人员从全体公民中抽签产生，有助于扩大公民任职机会。注意“大部分”，不能说所有官职都靠抽签。
- **津贴制度：** 公民担任国家官职、出席公民大会可获津贴，减少贫穷公民参政的经济障碍。
- **结果：** 雅典民主政治进一步发展，进入极盛时期；经济繁荣，文化艺术发展，雅典卫城建筑群在这一时期建成。
- **理解：** 津贴有助于贫穷公民实际参政，但没有把妇女、外邦人和奴隶自动变成公民。

### 3. 如何评价雅典民主

**历史价值：** 在公民范围内实行直接参与，公民大会决定重大事务，通过议事、监督、抽签和津贴等保障参与，对后世政治思想产生影响。

**阶级与身份局限：** 公民只占总人口的一小部分，妇女、外邦人和奴隶无相应政治权利；它建立在奴隶制社会基础上，属于奴隶制民主政治。

**运行局限：** 公民大会可能被野心家操纵，造成政治不稳定和决策失误。课文导入中，处置盟邦的决定在两次大会间改变，提示情绪、辩论可能影响重大决策。

结论须完整：**有公民参与的历史价值，也有参与范围和决策机制的局限。**不能一方面说“全民民主”，也不能另一方面说“没有任何民主成分”。

### 4. 教材补充：民众法庭

雅典每年从年满30岁的公民中抽签选出6000名审判员，再按案件组成不同人数法庭。听取原告、被告演说后投票判决，终审且立即执行。它扩大公民司法参与，但身份与演说可能影响结果，也会产生冤错。**能够参审不等于判决必然公正，抽签也不能自动保证专业能力。**

### 5. 斯巴达的寡头政治与军事生活

1. **位置：** 伯罗奔尼撒半岛南部。
2. **政体：** 寡头政治，即少数人的统治；国王、长老议事会权力很大，公民大会只是名义上的最高权力机关。
3. **公民生活：** 从小接受军事训练，成年后大部分时间生活在军营。
4. **边民：** 多住在边缘地区，是自由人，从事农业、商业、手工业，无权参与斯巴达政治。
5. **希洛人：** 居民中人数最多，被固定在斯巴达人的土地上，承担艰苦农业劳动，地位如同奴隶。

### 6. 雅典与斯巴达比较

| 比较 | 雅典 | 斯巴达 |
| --- | --- | --- |
| 政治形式 | 奴隶制民主政治 | 寡头政治 |
| 公民大会 | 实际最高权力机关 | 名义最高权力机关 |
| 突出特点 | 公民直接参政，抽签、津贴 | 少数人掌权，重视军事训练 |
| 共同基础 | 都是希腊城邦，公民权利有边界，劳动者受奴役 | 都是希腊城邦，公民权利有边界，劳动者受奴役 |

比较时不要把“民主”理解为雅典没有压迫，也不要把斯巴达全部居民都写成职业军人。

## 四、课内必背：亚历山大东侵

### 1. 背景与过程

- 公元前4世纪，希腊北部马其顿成为军事强国。
- **公元前334年**，马其顿国王亚历山大率军进攻波斯帝国，连战连捷。
- **公元前330年**，灭亡波斯帝国；随后继续东侵。
- 建立庞大帝国，被称为亚历山大帝国，亚历山大被称为大帝。
- 亚历山大不久病死，帝国在将领争权中走向分裂。不可将其写成长期稳定、世代延续的统一国家。

### 2. 帝国疆域

**西起希腊，东到印度河流域，北抵中亚，南达埃及南部，地跨欧、亚、非三洲。**读地图还可辨认伊苏斯、高加米拉等重要战场及巴比伦、波斯波利斯、亚历山大城等地点；正文首先要背疆域四至与跨洲范围。

### 3. 东侵的影响与评价

- **征服性和破坏性：** 给被征服地区人民带来巨大灾难，伴随战争、掠夺和统治压迫。
- **客观交流作用：** 帝国扩大不同地区的联系，促进东西方文化大交汇，加强经济联系。
- **评价方法：** 区分战争性质、人民遭遇与客观后果；交流作用不能抵销侵略造成的灾难，也不能把文化交流说成只有战争才能实现。

可联系古印度犍陀罗艺术、埃及亚历山大城，理解不同文明在联系中交流，但不要把后世一切交流成果都直接归给亚历山大本人。

## 五、课内必背：古代希腊文化

### 1. 文学、神话与史学

| 领域 | 人物、作品或特点 | 价值 |
| --- | --- | --- |
| 神话 | 神人同形同性，神的外貌性情与人相似 | 反映古希腊人的观念与想象 |
| 史诗 | 《荷马史诗》 | 文学遗产，了解早期希腊社会的主要文献 |
| 史学 | 希罗多德《历史》 | 叙述希腊与波斯战争，作者被称西方“史学之父” |
| 史学 | 修昔底德《伯罗奔尼撒战争史》 | 军事政治史的开山之作 |

神话和史诗具有文学加工，运用其认识历史时应与考古等材料互证；“神人同形同性”不是说希腊人没有宗教信仰。

### 2. 雕塑与建筑

- 人物雕塑注重展现人的力量、美感与动作。
- **《掷铁饼者》**表现运动员铁饼摆回最高点、将要掷出的一瞬间，富有动感。
- 建筑成就主要体现在神庙等公共建筑，常以廊柱环绕、雕刻装饰。
- **雅典卫城建筑群**融合建筑和雕刻，是古典建筑瑰宝；看图可从柱式、空间布局、公共及宗教功能分析。

### 3. 哲学与科学

- **哲学：** 苏格拉底、柏拉图、亚里士多德提出和讨论西方哲学的许多重要问题，对后世产生长期影响。记住三人属于哲学领域，不能与史家混写。
- **欧几里得：** 《几何原本》从定义、公理出发，推演几何体系，长期是几何学基本教材，体现逻辑论证。
- **阿基米德：** 数学家、物理学家、发明家，重视严密准确，发现浮力定律，提出杠杆原理。
- 希腊文化成就产生于长期发展和跨地区联系，不都集中在伯里克利一人主政时期。

### 4. 体育与教材拓展：戏剧

**奥林匹亚赛会：** 因举办地得名，从公元前776年起逐渐发展为全希腊赛事；期间各城邦停止敌对冲突。项目由赛跑逐步增加，只有希腊人可参加，胜者获橄榄枝冠冕，被视为英雄。它反映共同文化认同，但不意味着各城邦已政治统一。

**教材拓展：戏剧。** 起源于祭祀酒神活动，分悲剧与喜剧。悲剧多借神话讨论城邦制度、伦理问题；喜剧多取材现实，长于讽刺。埃斯库罗斯、索福克勒斯、欧里庇德斯是悲剧代表；阿里斯托芬、米南德是喜剧代表。此项理解戏剧特点为主，人物可按学习要求选背。

## 六、时间线与重点易混

| 时间 | 事件 |
| --- | --- |
| 公元前8—前6世纪 | 众多希腊城邦兴起，向外殖民 |
| 公元前5世纪中期 | 伯里克利主政，雅典民主进一步发展 |
| 公元前4世纪 | 马其顿成为军事强国 |
| 公元前334年 | 亚历山大开始东侵 |
| 公元前330年 | 波斯帝国灭亡 |

1. **城邦不是一座孤立城市。** 它包括城市、市镇及周围农村，是国家与公民共同体。
2. **居民不等于公民，公民不等于全体人口。** 雅典民主有严格身份边界。
3. **抽签是大多数公职的产生方式，津贴是参政保障。** 两者作用不同，不能互相替代。
4. **雅典公民大会实有最高权力；斯巴达只是名义最高。** 同名机构不代表相同政体。
5. **希腊城邦时期与亚历山大帝国时期不同。** 前者分立小国，后者是征服形成的跨洲帝国。
6. **战争促进交流是客观后果，不是洗去侵略性的理由。** 评价应全面、分层。

## 七、简答题：可直接背诵的答案

**1. 什么是希腊城邦？有什么特点？**  
答：城邦是以城市或市镇为中心、联合周围农村组成的国家，突出特点是小国寡民。它也是公民共同体，公民有参与管理等权利，也承担兵役等义务。

**2. 伯里克利怎样推动雅典民主发展？**  
答：大部分公职人员从全体公民中抽签产生，公民担任官职和出席公民大会可获津贴，使贫穷公民更有条件参政；公元前5世纪中期雅典民主进一步发展，进入极盛时期。

**3. 怎样评价雅典民主政治？**  
答：它在公民范围内实行直接参政，通过公民大会、抽签、津贴与监督体现民主参与，有历史价值；但公民仅占少数，妇女、外邦人、奴隶无相应政治权利，且容易受操纵、出现决策失误，属于有限的奴隶制民主。

**4. 雅典与斯巴达政体有什么不同和共同点？**  
答：雅典实行奴隶制民主政治，公民大会拥有实际最高权力；斯巴达实行寡头政治，国王与长老议事会权力大，公民大会只是名义最高。二者都是城邦，政治权利有身份界限，均存在奴役劳动。

**5. 怎样评价亚历山大东侵？**  
答：东侵是征服战争，给被征服人民带来巨大灾难；帝国的建立客观上扩大地区联系，促进东西方文化大交汇和经济联系。应同时认识侵略破坏与客观交流后果。

**6. 列举希腊文化成就及其意义。**  
答：有《荷马史诗》、希罗多德与修昔底德的史著、《掷铁饼者》和卫城建筑、苏格拉底等人的哲学、《几何原本》及阿基米德的科学发现；这些成果在文学、史学、艺术、哲学和科学方面影响后世。
