# 第21课 第一国际和巴黎公社｜详细知识点（背诵版）

> **所属单元：** 第七单元：第一次工业革命和马克思主义的诞生。  
> **整理依据：** [本课教材 PDF](21_第21课_第一国际和巴黎公社.pdf)，教材第117—121页。“课内必背”按本版教材归纳；“理解辨析”解释因果和性质；“教材拓展”供完成主干背诵后复习。

## 一、先背本课主线

**工业发展、工人阶级壮大和经济危机 → 国际联合需求增强 → 1864年第一国际成立 → 马克思主义进一步传播 → 1870年普法战争及法国危机 → 1871年巴黎公社成立 → 建立新政权、推行改革 → 英勇斗争后失败，留下宝贵经验。**

本课两件大事分别是：**国际工人组织的建立**和**无产阶级建立政权的尝试**。联系上一课，可概括为“科学理论—国际组织—政权实践”。

## 二、课内必背：第一国际

### 1. 成立背景

1. **经济和阶级条件：** 19世纪五六十年代，欧洲工业快速发展，工人阶级逐渐壮大。
2. **危机推动：** 1857年资本主义经济危机从美国扩散到欧洲，工厂倒闭、工人失业，社会矛盾尖锐。
3. **斗争发展：** 英国、法国、德意志、意大利等国家和地区的工人联合开展斗争，争取权益。
4. **认识提高：** 工人逐渐认识到国际团结、合作的重要性，需要跨国组织协调斗争。
5. **思想条件：** 马克思主义已经诞生，为工人运动发展提供科学理论指导。

**背诵句：** 工业发展壮大了工人队伍，经济危机激化社会矛盾，各国工人的斗争和相互支援提出了加强国际联合的需要。

### 2. 教材史例：伦敦建筑工人罢工

1859年，伦敦建筑工人为反抗剥削、缩短工时举行罢工，得到其他行业与外国工人的支持。经过近一年斗争取得胜利，推动工会联合；其他国家和地区也出现工人互助会、联合会等组织。

**说明的问题：** 不同行业、不同国家工人的相互支援，能增强斗争力量；国际联合有现实基础，并非凭空提出的口号。

### 3. 成立概况

| 项目 | 必背内容 |
| --- | --- |
| 时间 | **1864年9月** |
| 地点 | **英国伦敦**，大会在圣马丁堂举行 |
| 参加者 | 英国、法国、德意志、意大利、波兰等国家和地区的工人代表 |
| 正式名称 | **国际工人协会** |
| 史称 | **第一国际** |
| 性质 | 国际工人组织 |
| 主要主张 | 加强无产阶级国际团结与联合斗争，反对资产阶级 |

### 4. 马克思的作用

- 受邀参加成立大会。
- 当选临时中央委员会委员，担任德国通讯书记。
- 为协会制定纲领、章程等重要文件。
- 是第一国际的创始人和领导人。

**辨析：** 第一国际是各国工人联合的产物，不能写成马克思一个人单独建立；也不能将恩格斯与马克思共同起草《共产党宣言》的事直接套用到第一国际的全部文件。

### 5. 主要活动和意义

**活动：** 在各国建立支部，指导、帮助工人运动，争取提高工资、缩短工时、改善劳动条件等合法权益。

**意义：** 第一国际成为欧洲工人阶级斗争的领导中心，增强各国工人的联系与团结，推动马克思主义进一步传播，使国际工人运动进入新阶段。

### 6. 与早期工人运动相比的新特点

| 比较角度 | 早期运动 | 19世纪五六十年代以来的新发展 |
| --- | --- | --- |
| 联系范围 | 多以本地、本国斗争为主 | 国际相互支援、联合增强 |
| 组织形式 | 单次起义、罢工等 | 工会等组织联合，建立国际性组织 |
| 理论条件 | 缺乏科学理论指导 | 马克思主义传播并产生影响 |
| 斗争内容 | 从反对机器发展到政治诉求 | 有组织地争取劳动权益，推动更广泛联合 |

**注意：** 新阶段仍有罢工、示威等形式，不能说以前的斗争形式全部消失。

## 三、课内必背：巴黎公社的建立

### 1. 历史背景：普法战争与法国危机

- **1870年夏天：** 法国与普鲁士爆发战争，即普法战争。
- **战争结果：** 法军战败，法兰西第二帝国崩溃，资产阶级临时政府建立。
- **临时政府态度：** 面对逼近巴黎的普鲁士军队屈膝投降。
- **巴黎人民行动：** 组织国民自卫军，保卫巴黎。

**人物辨析：** 普法战争时的法国皇帝是**拿破仑三世**，即路易·波拿巴；他是拿破仑的侄子。不能与第18课建立法兰西第一帝国的拿破仑混淆。

### 2. 起义的直接导火线

**1871年3月18日，临时政府军队袭击国民自卫军的大炮阵地。** 巴黎人民发现后立即发动起义，临时政府逃出巴黎。

**因果分层：** 战败、政府投降与阶级矛盾是背景；袭击大炮阵地是起义的直接导火线，答题时不要互换。

### 3. 公社成立

- **时间：** **1871年3月28日**。
- **地点：** 法国巴黎。
- **名称：** 巴黎公社。
- **性质、地位：** **世界上第一个无产阶级政权**。
- **国际联系：** 得到第一国际支持，很多领导人是第一国际成员。

**两个日期：** 3月18日是人民起义，3月28日是公社正式成立。

## 四、课内必背：公社的措施及其性质

以下按本版教材列举的措施分类记忆。答题应列举具体措施，再说明它反映的政权性质。

### 1. 政治、军事与政权建设

- 废除旧军队、旧警察。
- 取消资产阶级法庭和议会，建立新的治安、司法和立法机构。
- 规定公社公职人员通过民主选举产生。
- 限制公职人员薪资。

**理解：** 公社要改变旧政权机构及其运行方式，防止公职人员依靠职位取得高额利益，使公共权力更贴近劳动人民。

### 2. 生产管理与工人权益

- 没收逃亡资本家的工厂，交工人管理。
- 禁止工厂主随意克扣工人工资。
- 禁止工厂主随意开除工人。

**理解：** 措施直接触及资本家利益，维护工人的生产和生活权益，体现新政权的无产阶级性质。教材说的是“逃亡资本家的工厂”，不能扩大成“立即没收全部私人财产”。

### 3. 教育和社会权益

- 发展教育，实行小学免费义务教育。
- 本版教材还列举了宣布妇女拥有选举权、男女同工同酬等措施。

**理解：** 措施体现改善普通劳动者生活、扩大教育和社会权益的取向。历史措施的提出、实施范围及实际效果是不同问题，不能仅凭一项规定就断言所有社会问题已经解决。

### 4. 怎样用措施证明政权性质

**答题结构：** “具体措施＋维护谁的利益＋政权性质”。例如：公社将逃亡资本家的工厂交工人管理，保护工人工资和劳动权益，表明它维护劳动人民利益，是无产阶级政权。

## 五、课内必背：公社失败与历史意义

### 1. 失败过程

1. 逃出巴黎的临时政府勾结普鲁士军队镇压公社。
2. 公社领导巴黎人民进行英勇抵抗。
3. **1871年5月21日**，反动军队进入巴黎，公社战士继续战斗。
4. **5月28日**，巴黎全城失陷，巴黎公社失败。

教材以拉雪兹公墓的战斗和公社社员墙表现公社战士英勇不屈的精神。

### 2. 如何解释失败

- **教材直接结论：** 敌强我弱，公社寡不敌众。
- **具体条件：** 临时政府与普鲁士勾结，镇压力强；公社的力量和活动范围有限。
- **理解层次：** 这是无产阶级建立新政权的早期探索，实践经验和社会历史条件有限，评价时应放回当时背景。

**易错：** 不能因失败就说公社没有历史意义，也不能仅用“作战不勇敢”解释失败。教材记载恰恰体现其英勇抵抗。

### 3. 历史意义

1. **实践地位：** 是无产阶级推翻资产阶级统治、建立无产阶级专政的第一次伟大尝试。
2. **理论和经验：** 丰富了马克思主义理论，为未来无产阶级革命留下宝贵经验。
3. **精神遗产：** 公社社员敢于革命、彻底革命，面对强敌英勇不屈，激励后来的革命者。

**背诵句：** 巴黎公社虽失败，却以建立无产阶级政权的实践丰富了马克思主义，为以后革命提供经验，留下英勇不屈的精神遗产。

## 六、教材拓展：“五一”国际劳动节

- **1866年：** 第一国际代表大会通过争取八小时工作日的决议。
- **1886年5月1日：** 美国工人发动大规模罢工和示威，要求实行八小时工作日，涉及芝加哥、纽约、波士顿等地，并得到其他国家工人响应。
- **纪念意义：** 后来每年5月1日成为国际劳动节，纪念工人争取权益的斗争。

**理解辨析：** 第一国际成立于1864年，八小时工作日决议在1866年，美国工人大规模运动在1886年；三件事相互联系，时间不能合并。劳动权益的实现经历长期斗争，不能理解成某次罢工后所有国家立即普遍实行八小时制。

## 八、常见简答题：可直接背诵

### 1. 第一国际成立的背景是什么？

欧洲工业发展，工人阶级壮大；经济危机使工人失业、社会矛盾尖锐；各国工人斗争和相互支援不断发展，认识到国际团结的重要性，产生建立国际工人组织的需要。

### 2. 第一国际开展了哪些活动？有什么意义？

它在各国建立支部，指导、帮助工人争取提高工资、缩短工时、改善劳动条件。它加强工人国际联合，推动马克思主义传播，使国际工人运动进入新阶段。

### 3. 巴黎公社怎样建立？

普法战争中法国战败，临时政府投降，巴黎人民组织国民自卫军。1871年3月18日，临时政府袭击大炮阵地，引发人民起义；3月28日，巴黎公社成立，成为世界上第一个无产阶级政权。

### 4. 哪些措施体现巴黎公社的无产阶级性质？

废除旧政权机构，建立新的治安、司法和立法机构；公职人员民主选举产生并限制薪资；把逃亡资本家的工厂交工人管理，保护工人工资和就业权益；发展免费义务教育等，体现维护劳动人民利益。

### 5. 如何评价巴黎公社？

公社是无产阶级建立新政权的第一次伟大尝试。虽然由于敌强我弱等条件而失败，但丰富了马克思主义理论，为后来的革命提供宝贵经验，其英勇不屈的精神具有深远影响。

### 6. 怎样理解人民群众是历史的创造者？

工人通过罢工、组织联合和政治斗争争取权益，巴黎人民在危机中保卫城市、建立公社并推行改革。这些实践说明人民群众的劳动和斗争推动社会发展，个人作用也应放在群众实践中理解。
