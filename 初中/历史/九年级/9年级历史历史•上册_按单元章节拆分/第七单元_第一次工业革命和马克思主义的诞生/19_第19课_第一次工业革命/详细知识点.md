# 第19课 第一次工业革命｜详细知识点（背诵版）

> **所属单元：** 第七单元：第一次工业革命和马克思主义的诞生。  
> **整理依据：** [本课教材 PDF](19_第19课_第一次工业革命.pdf)，正文及课后活动见教材第106—110页。按教材概括，分为“课内必背”“理解辨析”和“教材拓展”；先背史实，再用问答检查。

## 一、先背本课主线

**英国资本主义发展、市场扩大 → 棉纺织技术革新 → 瓦特改进蒸汽机并推广 → 工厂制度确立 → 火车和铁路发展 → 机器生产代替手工生产，生产力和社会结构发生巨大变化。**

第一次工业革命是生产领域的深刻变革，18世纪60年代开始于英国。它使人类进入“蒸汽时代”。19世纪中期，英国率先完成工业革命，成为世界上第一个工业国家。

## 二、课内必背：纺织技术的革新

### 1. 为什么首先发生在英国

1. **政治条件：** 英国君主立宪制建立后，政局稳定，为资本主义经济发展提供了条件。
2. **经济基础：** 资本主义经济迅速发展，生产规模扩大，原有生产方式需要改进。
3. **直接推动：** 国内外市场不断扩大，棉纺织品需求增加，刺激生产方式改进和新技术发明。

**背诵句：** 英国资本主义制度的确立提供了政治条件，资本主义经济发展和国内外市场扩大推动了技术革新。

**理解辨析：** 海外贸易、殖民扩张、资金和劳动力等可帮助理解英国的工业化条件；回答本课教材题时，先答“制度、经济、市场”三点。不能只写“英国煤多”，也不能把市场扩大说成制度确立的原因。

### 2. 开始的时间、国家与部门

- **时间：** 18世纪60年代。
- **国家：** 英国。
- **最先发生的部门：** 棉纺织业。
- **基本变化：** 生产中逐渐采用机器，大幅提高效率，推动其他生产部门变革。
- **概念：** 人们把生产领域这种革命性的变化称为“工业革命”。

### 3. 棉纺织领域的主要机器

| 机器 | 发明者 | 教材所列时间 | 特点与作用 |
| --- | --- | --- | --- |
| 珍妮机 | 哈格里夫斯 | 约1765年 | 一次能纺多根纱线，提高纺纱效率；纱线粗细仍不够均匀 |
| 水力纺纱机 | 阿克莱特 | 1769年 | 利用水力驱动，纱线质量比珍妮机更高 |
| 骡机 | 克隆普顿 | 1779年 | 结合珍妮机与水力纺纱机的优点，可同时纺数百根纱线 |
| 动力织布机 | 卡特莱特 | 18世纪80年代 | 能使用多种动力，教材列其生产效率为手工织布的40倍 |

**背诵顺序：** 珍妮机 → 水力纺纱机 → 骡机 → 动力织布机。

### 4. 技术革新为什么会相互推动

纺纱机器出现后，棉纱产量大增，需要更多织布能力与之配合，推动织布技术改进。机器制造和使用又增加了对动力、煤炭、金属和运输的需求，带动其他生产部门发展。

**材料题提示：** 材料出现“手轮纺车被丢弃”“纱线由机器纺制”，可概括为机器逐渐代替手工生产；若同时出现收入增加，只能说明材料中的部分从业者受益，不能推出全体工人收入一直上升。

## 三、课内必背：蒸汽机和工厂制度

### 1. 为什么需要改进动力

早期机器主要依靠人力、畜力或水力。人力、畜力功效有限；水力受河流位置、水量等自然条件制约。生产规模扩大后，人们迫切需要更高效、便利、适用范围更广的动力。

### 2. 瓦特的贡献

- **人物：** 英国人瓦特。
- **贡献：** 在已有蒸汽机基础上长期研究、不断改进，使蒸汽机动力更强、使用更方便。
- **应用时间：** **1785年，瓦特改进后的蒸汽机在纺织领域投入使用。**
- **推广：** 很快用于其他生产部门；到19世纪30年代，蒸汽机成为工业生产的主要动力来源。

**人物理解：** 瓦特通过修理机器接触纽科门蒸汽机，针对耗费燃料、效率低等缺陷进行改进，还推动零部件规格标准化。这说明技术创新需要观察生产问题、长期试验和改进。

### 3. 蒸汽机广泛应用的意义

1. **动力方面：** 提供更强大、较少受自然条件束缚的动力。
2. **生产方面：** 推动更多机器和技术出现，极大提高生产力。
3. **工厂布局方面：** 工厂可以突破对河流水力的依赖，扩大设厂地点的选择。
4. **时代变化：** 人类社会进入“蒸汽时代”。

**必背辨析：** 瓦特的主要贡献是“改进蒸汽机”，不能写成他从无到有发明了最早的蒸汽机；工业革命先在棉纺织业开始，蒸汽机后来推动其深入发展。

### 4. 工厂制度如何确立

1. 工业革命推进，出现工厂这种新的生产组织方式。
2. 早期工厂多利用水力，常建在水流湍急的河边。
3. 蒸汽机应用后，工厂突破自然条件限制，迅速普及。
4. 工厂容纳大量机器同时运转，工人集中劳动、分工协作，提高效率。
5. 工厂用严格的规章制度管理工人和生产。
6. 进入19世纪，传统手工工场逐渐被工厂取代，工厂制度最终确立。

| 比较项目 | 传统手工工场 | 工厂 |
| --- | --- | --- |
| 主要生产手段 | 手工工具和手工劳动 | 机器生产 |
| 动力条件 | 主要依靠劳动者操作工具 | 可使用水力、蒸汽动力等 |
| 劳动组织 | 已有分工协作 | 大量机器和工人集中，分工更细 |
| 管理特点 | 围绕手工生产组织 | 生产节奏与机器运行相联系，规章更严格 |

**比较要点：** 二者都可能有雇佣关系和分工；最关键的区别是是否以机器生产为主要方式。

## 四、课内必背：火车、铁路与工业革命扩展

### 1. 交通变革的需要

传统陆路交通主要依靠人或牲畜拉动，速度慢、载重量小，难以满足大规模工业生产和商品运输需要。蒸汽动力的应用推动交通运输业变革。

### 2. 斯蒂芬森与铁路

- **人物与国家：** 英国人斯蒂芬森。
- **时间：** **1825年**。
- **成就：** 他主持修建的达灵顿—斯托克顿铁路竣工，同年其设计的蒸汽机车试车成功。
- **后续：** 英国兴起铁路建设热潮；到19世纪末形成四通八达的铁路网。
- **作用：** 交通更快捷、便利，运输成本降低，生产与市场联系更加紧密。

### 3. 汽船：教材“相关史事”

1807年，美国人富尔顿制造的“克莱蒙特号”汽船投入使用，以蒸汽机为主要动力，推动水路交通变化。汽船后来不断提高载重量与速度，船壳也由木材向钢铁发展。

**对应记忆：** 瓦特—蒸汽机；斯蒂芬森—蒸汽机车；富尔顿—汽船。蒸汽机是动力机，蒸汽机车与汽船是使用这种动力的交通工具。

### 4. 工业革命的完成和扩展

- **英国：** 19世纪中期率先完成工业革命，成为世界上第一个工业国家。
- **其他国家：** 从18世纪后期开始，法国、美国等国学习英国的技术和生产经验，开展工业革命。
- **理解：** 各国开始、推进和完成的时间并不相同，不能把英国的完成时间套用到全部国家。

## 五、影响：按“生产—生活—阶级”背诵

### 1. 生产方式与社会财富

机器生产逐渐代替手工生产，极大提高生产力，创造出巨大的社会财富。这是评价第一次工业革命时首先应答的内容。

### 2. 生产生活方式

工厂扩大，工业城市发展，越来越多人口从事工业；铁路、汽船提高运输效率，人员与商品流动加快，生产和市场联系更紧密。

### 3. 社会结构

工业革命使社会日益分化为**工业资产阶级和工业无产阶级两大对立阶级**。前者占有工厂、机器等生产资料，后者主要依靠受雇劳动取得收入。

### 4. 联系下一课的理解

财富增加并不意味着人人同步富裕。资本家与工人的利益矛盾、劳动条件恶劣和贫困问题，推动工人运动兴起。工业化还带来污染等问题；作综合评价时可说明这些社会代价，但不能只列弊端而遗漏生产力的巨大进步。

## 六、教材拓展：亚当·斯密与《国富论》

- 亚当·斯密是古典政治经济学的奠基人之一，生活在工业革命前期。
- 他主张经济活动需要自由环境，重视自由竞争与市场调节，提出“自由放任”理论；“看不见的手”指市场调节作用。
- 代表作是《国富论》，全名《国民财富的性质和原因的研究》；严复译本名为《原富》。
- 教材指出其局限：过分强调市场作用，忽视政府调节，没有充分预见无序竞争的问题。

**掌握层次：** 先完成工业革命主干背诵，再识记本节人物、著作和观点，不把“自由放任”误认作马克思主义主张。

## 七、时间线与易错点

| 时间 | 对应史实 |
| --- | --- |
| 18世纪60年代 | 第一次工业革命开始于英国 |
| 约1765年 | 哈格里夫斯发明珍妮机 |
| 1769年、1779年 | 水力纺纱机、骡机先后出现 |
| 1785年 | 瓦特改进的蒸汽机在纺织领域投入使用 |
| 1807年 | 富尔顿汽船推动水路运输变化 |
| 1825年 | 斯蒂芬森设计的蒸汽机车试车成功 |
| 19世纪30年代 | 蒸汽机成为工业生产的主要动力来源 |
| 19世纪中期 | 英国率先完成工业革命 |

1. **开始不等于完成：** 开始是18世纪60年代，英国完成是19世纪中期。
2. **棉纺织业不等于整个纺织业：** 回答最先发生的部门时写准确。
3. **工厂不等于手工工场：** 工厂以机器生产为主要特征。
4. **“蒸汽时代”不等于“电气时代”：** 电力广泛应用属于后来的第二次工业革命内容。
5. **生产力提高不等于消灭贫困：** 社会财富增长与分配状况应分别分析。

## 八、常见简答题：可直接背诵

### 1. 第一次工业革命为什么首先发生在英国？

英国君主立宪制建立后政局稳定，资本主义经济迅速发展；国内外市场扩大，棉纺织品需求增长，推动生产方式改进和技术发明。

### 2. 瓦特改进蒸汽机有什么意义？

它提供了强大、便利的动力，减少生产对自然条件的依赖，推动工厂普及和更多技术发明，极大提高生产力，使人类进入“蒸汽时代”。

### 3. 工厂与手工工场相比有什么特点？

工厂以机器生产为主要方式，大量机器同时运转，工人集中劳动、分工协作，并用严格规章管理生产，生产效率显著提高。

### 4. 铁路发展起了什么作用？

铁路使交通更快捷、便利，增加运输能力、降低运输成本，加强生产与市场的联系，促进人员和商品流动。

### 5. 第一次工业革命带来哪些主要影响？

机器生产代替手工生产，极大提高生产力、创造社会财富，改变人们的生产生活方式；工业城市发展，社会日益分化为工业资产阶级和工业无产阶级两大对立阶级。

### 6. 为什么说劳动人民的生产实践推动了科技发展？

许多发明者从生产、修理和操作机器的实际问题出发，通过观察、试验和改进创造新工具。生产需求推动发明，发明又提高生产效率，二者相互促进。
