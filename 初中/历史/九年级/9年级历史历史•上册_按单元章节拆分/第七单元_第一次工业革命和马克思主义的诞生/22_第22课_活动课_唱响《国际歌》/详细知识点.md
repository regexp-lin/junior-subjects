# 第22课 活动课：唱响《国际歌》｜详细知识点（背诵版）

> **所属单元：** 第七单元：第一次工业革命和马克思主义的诞生。  
> **整理依据：** [本课教材 PDF](22_第22课_活动课_唱响《国际歌》.pdf)，教材第122—123页，并联系第20、21课。“课内必背”对应教材活动目标与史实；词曲创作资料标为“活动补充”；实践部分帮助准备课堂展示。

## 一、先背本课主线

**巴黎公社及国际工人运动 → 《国际歌》诞生与传唱 → 传入中国、鼓舞革命斗争 → 理解无产者追求解放、团结奋斗的精神 → 通过史料、地图、歌词鉴赏与演唱展示历史认识。**

**一句话定位：** 《国际歌》是全世界无产阶级的战歌，把工人运动的历史记忆和追求解放的理想转化成歌曲，在中国革命中发挥了激励作用。

## 二、课内必背：歌曲的历史背景

### 1. 国际工人运动为什么兴起

第一次工业革命创造大量财富，同时使资本家与工人的矛盾日益尖锐。工人为了改善生活、反抗剥削和压迫，开展罢工、起义等斗争，逐渐认识到组织和国际联合的重要性。

### 2. 三个需要联系的历史节点

| 时间 | 事件 | 与本课的联系 |
| --- | --- | --- |
| 1848年 | 《共产党宣言》发表，马克思主义诞生 | 无产阶级斗争获得科学理论指导 |
| 1864年 | 第一国际在伦敦成立 | 加强各国工人联系，推动国际工人运动 |
| 1871年 | 巴黎公社建立并最终失败 | 公社的斗争与精神是理解《国际歌》创作背景的重要内容 |

### 3. 巴黎公社的基本史实

1. **背景：** 普法战争中法国战败，资产阶级临时政府投降，巴黎人民组织国民自卫军保卫城市。
2. **起义：** 1871年3月18日，临时政府袭击大炮阵地，巴黎人民发动起义。
3. **成立：** 1871年3月28日，巴黎公社成立，是世界上第一个无产阶级政权。
4. **探索：** 建立新的政权机构，推行维护工人和劳动人民利益的措施。
5. **失败：** 临时政府勾结普鲁士镇压，公社寡不敌众，1871年5月28日巴黎全城失陷。
6. **意义：** 是无产阶级建立新政权的第一次伟大尝试，留下宝贵经验和英勇不屈的精神。

**理解要点：** 公社失败没有消除工人阶级追求解放的愿望；歌曲传承的是这场斗争的历史记忆、理想和精神。

## 三、活动补充：词曲作者与创作过程

本课要求查找词曲作者及创作过程，教材两页活动正文没有逐项给出以下资料。可将这些基本事实作为资料卡使用，具体引用时保留出处。

### 1. 歌词

- **词作者：** 欧仁·鲍狄埃，法国工人诗人、巴黎公社参加者。
- **创作时间：** **1871年6月**，巴黎公社失败后。
- **主要内容：** 表达劳动者反抗剥削压迫、团结奋斗、争取自身解放的愿望。
- **历史联系：** 歌词产生于具体工人运动背景，不能脱离巴黎公社只解释为一般的励志作品。

### 2. 曲谱

- **曲作者：** 皮埃尔·狄盖特。
- **谱曲时间：** **1888年**。
- **地点：** 法国里尔。
- **作用：** 易于传唱而富有力量的旋律，使作品更广泛地进入工人集会和群众活动。

**地理辨析：** 里尔位于法国，不能写成“比利时里尔”。曲作者的出生地、活动地和谱曲地点是不同信息，制作地图时应按事件标注地点。

### 3. 必须分开的三个时间

**1871年3—5月：巴黎公社斗争；1871年6月：歌词创作；1888年：现行著名旋律谱成。**

歌词与曲谱并非同年完成，词作者和曲作者也不是同一人。不能把1888年说成巴黎公社成立或歌词写成的时间。

## 四、课内必背：在中国的传播和影响

### 1. 为什么要研究中国传播史

教材要求了解20世纪以来《国际歌》如何鼓舞中国人民争取民族独立、人民解放。研究重点包括翻译、传播载体、传唱场景和革命者事迹。

**活动补充资料卡：** 1923年，瞿秋白翻译的《国际歌》歌词发表于《新青年》。这一事例可用于说明歌曲通过翻译和报刊传播进入中国革命文化；它是中文译介史中的重要版本，不能由此说此前从未有过介绍或翻译。资料核对出处见文末《国际歌》条目的中国传播部分。

### 2. 必须记住的中国史事

**1923年6月20日，出席中国共产党第三次全国代表大会的代表来到广州黄花岗七十二烈士陵园，集体唱《国际歌》。** 教材以此说明中国共产党全国代表大会闭幕时奏唱《国际歌》的传统。

| 信息要素 | 背诵内容 |
| --- | --- |
| 时间 | 1923年6月20日 |
| 人物群体 | 中共三大代表 |
| 地点 | 广州黄花岗七十二烈士陵园 |
| 行动 | 集体唱《国际歌》 |
| 体现 | 对革命先烈的纪念、共同理想和团结奋斗精神 |

### 3. 歌曲在中国革命中的作用

1. **精神激励：** 鼓舞革命志士坚定信念，面对困难和牺牲。
2. **团结动员：** 集体演唱把共同理想转化为可感受、可表达的情感联系。
3. **历史传承：** 传播工人运动和革命斗争的历史记忆。
4. **认识联系：** 体现中国革命与国际工人运动之间的思想、文化联系。

**表达分寸：** 歌曲能够激励与凝聚群众，不能把革命胜利的原因只归结为一首歌。歌曲作用应放在群众斗争、组织领导和社会条件中理解。

### 4. 查找传播资料时怎样避免混淆

- 区分“最早介绍”“某次翻译”“中文全译或新译”“某个版本开始传唱”，这些不是同一件事。
- 同一歌曲可能有不同译本，不能未经核实就把某位译者说成全部中文歌词的唯一作者。
- 人物故事要查明姓名、时间、地点、来源；文学作品和影视情节不能直接当作史料原文。

## 五、理解辨析：《国际歌》的精神内涵

### 1. 反抗压迫、追求解放

歌曲表现受压迫劳动者要求改变不平等处境的愿望。理解时要联系工人劳动强度大、收入低、政治权利受限制等时代状况。

### 2. 依靠自身力量

表达劳动者通过自身组织、斗争和实践争取解放的思想。可联系早期空想社会主义者把希望寄托于统治阶级的局限，理解工人主体意识的变化。

### 3. 国际团结

强调不同国家劳动者的共同理想与联合，呼应《共产党宣言》的国际联合主张和第一国际的组织实践。“国际”有具体历史含义，不只是“传播国家很多”。

### 4. 坚定信念、英勇奋斗

巴黎公社虽然失败，追求解放的理想和不屈精神仍然传承。演唱时的庄重、坚定和激昂，应与这些历史内容相联系。

**背诵句：** 《国际歌》体现劳动者反抗剥削压迫、追求自身解放、依靠群众力量、加强国际团结和坚定奋斗的精神。

## 六、活动实践：各组要掌握和展示什么

| 小组 | 核心任务 | 可以展示的成果 | 内容自查 |
| --- | --- | --- | --- |
| 史料搜集组 | 查公社史事、词曲创作和在中国传唱的事例 | 手抄报、资料卡、事件时间轴 | 时间、人物、地点有依据，注明出处 |
| 史地综合组 | 查歌曲在世界各地传播的事例 | 世界地图上的传播示意图 | 巴黎、里尔、广州位置正确；每条传播路线有资料支撑 |
| 歌词鉴赏组 | 联系历史理解作品 | 朗诵、关键词分析、短讲 | 说明表达内容与历史背景的联系 |
| 艺术表演组 | 学唱、弹唱或表现特定历史场景 | 合唱、配乐、短舞蹈 | 表演前能说明所表现的时代和事件 |

### 1. 一张资料卡应包含什么

**主题—时间—地点—人物—事件—反映的精神—资料出处。** 若某项没有可靠依据，应继续查找，不用想象补全。

### 2. 怎样做歌词鉴赏

按“**歌词关键词或短句 → 表达了什么愿望 → 对应什么历史处境 → 有什么精神内涵**”展开。例如，团结的表达可联系跨国工人联合，坚定奋斗的表达可联系公社战士抵抗镇压。

### 3. 怎样准备一分钟讲解

先交代创作背景与作者，再举中国传唱的具体史事，最后说明歌曲精神与历史意义。不能只有“我很感动”的感想而缺少史实。

### 4. 教材建议的综合活动

在班级合唱和小组研究基础上，组织年级主题歌会并展示研究成果；还可结合共青团活动日、吸收新团员仪式开展演唱。活动评价应同时看史实、理解、合作和表达。

## 七、时间线与易错辨析

| 时间 | 对应事件 | 掌握层次 |

| 1871年6月 | 鲍狄埃创作歌词 | 活动补充 |

1. **词与曲：** 鲍狄埃作词，狄盖特谱曲。
2. **创作与传播：** 法国的创作史和在中国的翻译传唱史是相互联系的两个过程。
3. **纪念与发生：** 今天演唱某首歌，不代表歌中涉及的历史事件发生在今天或当地。
4. **作品与史料：** 歌曲可反映某群体的情感和理想，研究具体事件仍需与其他史料互证。
5. **活动与背诵：** 作者、年代、背景和精神内涵需要记忆，展示形式可由小组选择，无需把全部活动步骤逐字背下。

## 八、常见简答题：可直接背诵

### 1. 《国际歌》诞生于怎样的历史背景？

工业革命推动工人阶级壮大，剥削和压迫引发工人斗争。1871年巴黎公社建立后失败，参加者和劳动人民继续追求解放，《国际歌》歌词在这一背景下诞生，表达了坚定奋斗和团结解放的理想。

### 2. 《国际歌》的词曲作者分别是谁？

歌词由欧仁·鲍狄埃于1871年创作，皮埃尔·狄盖特于1888年谱曲；歌词与曲谱完成于不同年份。

### 3. 举出教材记载的《国际歌》在中国传唱的一件史事。

1923年6月20日，中共三大代表来到广州黄花岗七十二烈士陵园集体唱《国际歌》，体现对革命先烈的纪念和团结奋斗的共同理想。

### 4. 《国际歌》体现哪些精神？

体现劳动者反抗剥削压迫、追求解放、依靠自身力量、加强国际团结，以及坚定信念、英勇奋斗的精神。

### 5. 《国际歌》在中国革命中有什么作用？

它鼓舞革命者为民族独立和人民解放而斗争，凝聚共同理想，传承革命精神，也体现中国革命与国际工人运动的思想文化联系。

### 6. 怎样用可靠资料完成本课探究？

围绕创作与传播提出问题，查明时间、地点和人物，记录资料作者与出处，对关键史实进行互证；区分史料、文学叙述和个人感想，再用地图、资料卡、鉴赏或表演呈现结论。
