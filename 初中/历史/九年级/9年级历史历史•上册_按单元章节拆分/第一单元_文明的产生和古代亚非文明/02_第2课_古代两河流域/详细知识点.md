# 第2课 古代两河流域｜详细知识点（背诵版）

> **所属单元：** 第一单元：文明的产生和古代亚非文明。  
> **教材依据：** [本课教材 PDF](02_第2课_古代两河流域.pdf)，包括正文、地图、材料研读和课后活动。  
> **使用说明：** 先背“课内必背”，再用“理解辨析”解释材料；“教材拓展”单列，避免与正文混淆。内容为自主概括。

## 一、先背主线

**两河农业发展 → 乌鲁克、乌尔等城市兴盛，奴隶制国家形成 → 阿卡德初步统一 → 汉谟拉比统一两河中下游，古巴比伦达到鼎盛 → 以君主专制和《汉谟拉比法典》维护统治 → 楔形文字、历法、星期制、60进制影响后世。**

背本课抓住“四个词”：**两条河流、早期城市、奴隶制法典、多元文化**。政治统一与文化延续不是一回事：王朝可以更替，文字、制度和知识仍可能传播、发展。

## 二、课内必背：古代两河流域文明的兴起

### 1. 两河是哪两条河，位于哪里

1. 两河指**幼发拉底河、底格里斯河**，大体自北向南流入波斯湾。
2. 两河流域位于西亚，涉及今天土耳其、叙利亚、伊拉克、伊朗和科威特的一部分，不能简单等同于今天某一个国家。
3. 上游水量充沛、土地肥沃；中下游有广阔冲积平原，土壤有利于农业生产。人们运用灌溉技术发展农业。
4. **1万多年前**，这里已经出现农业和畜牧业。农业发展为人口增加、城市兴起与早期国家产生提供基础。

**理解：** 水土条件是文明发展的重要条件，灌溉、劳动和组织能力同样重要。不能说“只要有河就一定有文明”，也不能把干旱地区写成完全无法发展农业。

### 2. 城市兴起与奴隶制国家形成

- **时间、地区：** 约从公元前3500年起，两河中下游一些城市日益兴盛。
- **代表：** 乌鲁克、乌尔。以这些城市为中心，一些奴隶制国家先后形成。
- **城市功能：** 同时是国家的政治中心、经济中心、宗教中心，并非只有居民聚居或买卖商品的功能。
- **社会等级：** 以统治者为代表的贵族占有主要财富，平民需向统治者缴纳粮食和其他物品，说明财富和权力分配不平等。
- **对外联系：** 当地居民很早开展对外贸易，与西亚其他地区以及北非、南亚、中亚多地建立联系。

教材“乌尔的社会等级”图中，统治者与贵族宴饮，仆从、乐师侍奉，平民运送牛羊和物品。**读图结论：** 城市存在明显等级差别，劳动产品的一部分流向统治者。不要把宴饮图概括为“所有居民生活富足”。

### 3. 阿卡德王国的初步统一

- **背景：** 各国为争夺资源经常发生战争。
- **时间：** 约公元前24世纪，阿卡德王国初步统一两河流域中下游地区。
- **权力：** 国王掌握全国军政、经济、宗教大权，并向外扩张。
- **教材补充：** 建立中央与地方管理制度，以首都为全国政治、经济中心；统一语言文字、公文书写格式和度量衡。
- **理解：** 这些措施有助于加强管理、政令传达和经济联系，反映统一国家治理能力的发展。阿卡德统一早于汉谟拉比统一，两者不是同一王国、同一次统一。

## 三、课内必背：古巴比伦王国与《汉谟拉比法典》

### 1. 古巴比伦王国达到鼎盛

1. 古巴比伦最初是幼发拉底河中游的一个城市国家。
2. **公元前18世纪前期**，汉谟拉比在位，发动对外征服战争，采取各个击破的策略，统一两河流域中下游。
3. 他建立起强大的奴隶制国家，古巴比伦王国达到鼎盛。
4. 汉谟拉比实行**君主专制，加强中央集权**，把司法、行政、军事大权掌握在自己手中。

**概念理解：** 君主专制强调最高权力集中在君主手中；中央集权强调中央加强对地方的控制。两者相互联系，但观察角度不同。

### 2. 法典的地位、形式与目的

- **地位：** 《汉谟拉比法典》是**迄今已知世界上第一部较为完备的成文法典**。
- **措辞：** “迄今已知”限定现有发现；“较为完备”说明保存和体系较完整，不能简写成“世界第一部法律”。
- **形式：** 法典刻在石柱上。上部表现汉谟拉比接受神授王权的场景，下部用楔形文字刻写前言、正文和后记，正文有**282条**。
- **目的：** 以法律形式维护奴隶主阶级统治和等级秩序，巩固王权。神授王权图像还反映统治者借宗教为权力提供依据。
- **史料价值：** 内容广泛，可用于了解古巴比伦的社会等级、家庭关系、经济活动和法律观念。

### 3. 从法典看古巴比伦社会

| 方面 | 教材事实 | 反映的问题 |
| --- | --- | --- |
| 社会等级 | 自由民、半自由民、奴隶三个严格等级 | 法律承认并维护身份差别 |
| 奴隶处境 | 奴隶主对奴隶有生杀予夺权 | 奴隶受支配，缺乏人身自由 |
| 奴隶来源 | 战俘为主，也有买来的、家生的奴隶 | 战争、买卖等维系奴隶制 |
| 家庭关系 | 男性家长对妻子儿女有绝对权威，欠债可送妻儿抵债 | 父权强大，家庭成员权利不平等 |
| 经济活动 | 租赁、雇佣、交换、借贷等规定很多 | 商品经济比较活跃 |

**注意：** 自由民不等于享有现代公民的平等权利；商品经济活跃不等于资本主义经济。古巴比伦仍是奴隶制国家。

### 4. 如何读懂法典条文

教材课后材料涉及：未经主人允许剃去奴隶标识会受罚；买来的奴隶短期内患重病，可以退还；奴隶否认主人身份，证实后会被割耳。

可按三步分析：

1. **看对象：** 条文中主人、奴隶、买者、卖者的身份不同。
2. **看权利与处罚：** 奴隶可被买卖、退还，受到身体惩罚；法律重点保护主人的占有权。
3. **下结论：** 奴隶地位低下，被当作财产支配；法典维护奴隶主阶级利益，体现奴隶制社会性质。

不能只写“惩罚严厉”，因为题目常要求指出惩罚背后的阶级利益和社会制度。

### 5. 法典评价与此后政权更替

**历史作用：** 法典在古代西亚影响重要，表明人类社会法制传统源远流长，也为研究古代社会保存了丰富资料。**历史局限：** 它维护等级特权和奴隶制压迫，并非现代法治意义上的人人平等。

古巴比伦灭亡后，两河流域多次更换统治者，但汉谟拉比时期形成的专制统治传统有所延续。教材补充：公元前9世纪亚述逐渐扩张为帝国，公元前7世纪末新巴比伦战胜亚述，公元前539年波斯帝国占领巴比伦。**正文重点是古巴比伦及法典，补充政权顺序用于建立时间背景。**

## 四、课内必背：古代两河流域文化

### 1. 楔形文字

- **书写方法：** 用一头削尖的芦苇秆，在半湿泥板上压刻符号。
- **名称来源：** 符号笔画由粗到细，形似木楔，故称楔形文字。
- **使用范围：** 用于书写古代西亚地区的多种语言；不能把一种文字形式误认成只有一种民族语言。
- **内容价值：** 文献类型多样，涵盖社会生活各方面，是研究两河流域文明的重要材料，也是当地文明的重要标志。

### 2. 建筑艺术与文化融合

王宫和神庙是城市的标志性建筑。建筑使用来自各地的珍稀材料，一些装饰具有异域风格，反映贸易往来、跨地区联系和文化的多元融合。神庙的突出地位也反映宗教在城市社会生活中的重要作用。

### 3. 天文、历法、星期制和数学

- 人们在长期生产生活中观察、记录自然现象，发展天文、数学知识。
- **历法：** 按月亮运行周期，将一年分为12个月，每月约30天；通过设置闰月，调整太阳与月亮运行周期之间的差距。
- **星期制：** 将一周划分为7天，是星期制的源头。
- **60进制：** 当地人的重要发明，至今仍影响时间和角度计量。例如1小时60分钟、1分钟60秒，1度60角分。
- **辨析：** 古代两河流域的上述历法不能与埃及太阳历混背；“每月约30天”也不是说月亮运行周期恰好固定为30天。

### 4. 材料研读与教材拓展

两河流域谚语强调善意言语和相互回应，反映对尊重他人、友善交往的重视。解读时要立足材料，不因少量谚语就说古代社会没有压迫。

**教材拓展：《吉尔伽美什史诗》。** 作品讲述乌鲁克英雄国王吉尔伽美什与恩基都的友谊、探险，以及失去朋友后寻求长生而未果的故事，体现对友情、生死和生命意义的思考，部分故事在后世继续流传。记住作品所属文明及主题即可，不必背全部情节。

## 五、关键时间线

| 时间 | 事件 |
| --- | --- |
| 1万多年前 | 两河地区出现农业和畜牧业 |
| 约公元前3500年起 | 中下游城市兴盛，早期奴隶制国家形成 |
| 约公元前24世纪 | 阿卡德初步统一两河中下游 |
| 公元前18世纪前期 | 汉谟拉比统治、古巴比伦鼎盛，颁布法典 |
| 公元前539年 | 波斯帝国占领巴比伦（教材补充） |

记忆顺序：**农业早于城市，城市国家早于区域统一，阿卡德早于古巴比伦。**公元前年份数字越大，通常年代越早。

## 六、重点易混辨析

1. 两河流域在西亚；尼罗河流域在非洲东北部，二者不能混写。
2. 乌鲁克、乌尔是早期城市；古巴比伦是后来的城市国家及王国，不能把不同阶段合成一次事件。
3. 汉谟拉比统一的是两河中下游，不是征服整个世界，也不是这里第一次出现统一政权。
4. 《汉谟拉比法典》维护奴隶主利益；“有成文法”并不自动意味着平等或现代民主。
5. 评价法典应同时说法制传统、史料价值与阶级局限，避免只有赞美或只有“残酷”。
6. 楔形文字、星期制、60进制属于两河文明；象形文字、太阳历、金字塔是古埃及代表成就。

## 七、简答题：可直接背诵的答案

**1. 两河流域文明兴起有哪些有利条件？**  
答：两河提供水源，冲积平原土壤有利于农业，人们掌握灌溉技术，农业和畜牧业较早发展，为人口增长、分工、城市和国家形成提供基础；对外贸易又加强了区域联系。

**2. 汉谟拉比怎样使古巴比伦达到鼎盛？**  
答：他通过征服战争、各个击破，统一两河中下游，建立强大的奴隶制国家；实行君主专制、加强中央集权，掌握司法、行政、军事权，并颁布法典巩固统治。

**3. 怎样评价《汉谟拉比法典》？**  
答：它是迄今已知世界上第一部较为完备的成文法典，在古代西亚影响重要，体现法制传统源远流长，也保存社会史料；但它维护奴隶主统治、等级特权和父权秩序，有明显时代局限。

**4. 法典怎样反映古巴比伦的社会状况？**  
答：居民分成严格等级，奴隶主对奴隶有生杀予夺权；男性家长权力很大，家庭地位不平等；租赁、雇佣、交换、借贷规定较多，说明商品经济比较活跃。

**5. 楔形文字有什么特点和价值？**  
答：用芦苇秆在半湿泥板上压刻，笔画像木楔，可书写西亚多种语言；文献内容丰富，记录社会生活各方面，是两河文明标志和研究古代西亚的重要材料。

**6. 两河流域哪些成果至今仍有影响？**  
答：一周7天的划分是星期制源头；60进制仍用于时间和角度计量；当地的成文法传统、文字文献及文化成果也对后世产生重要影响。
