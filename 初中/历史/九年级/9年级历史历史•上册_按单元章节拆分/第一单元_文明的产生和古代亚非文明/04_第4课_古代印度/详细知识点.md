# 第4课 古代印度｜详细知识点（背诵版）

> **所属单元：** 第一单元：文明的产生和古代亚非文明。  
> **教材依据：** [本课教材 PDF](04_第4课_古代印度.pdf)，包括正文、地图、种姓表、材料研读及活动。  
> **使用说明：** 以“课内必背”掌握史实，以“理解辨析”解释制度和材料；“教材拓展”单独标明。内容为自主归纳。

## 一、先背主线

**约公元前25世纪，印度河流域出现城市文明 → 公元前18世纪走向衰亡 → 公元前1500年左右雅利安人迁入，逐渐建立种姓制度 → 公元前6世纪前后佛教产生 → 佛教向亚洲多地传播 → 史诗、宗教艺术与含“0”的数字符号系统等贡献突出。**

本课要分别背好**文明遗址、社会制度、宗教、文化**四条线。印度河城市文明与后来雅利安人建立的种姓制度不是同一阶段；“古代印度”也是历史地理概念，范围不完全等于今天的印度共和国。

## 二、课内必背：印度河流域文明

### 1. 古代印度的地理范围

1. 古代印度在地理上主要指今天的**南亚次大陆**。
2. 主要地形区有**印度河平原、恒河平原、德干高原**。
3. 北部有喜马拉雅山脉、兴都库什山脉，西临阿拉伯海，东临孟加拉湾，三面临海。
4. 印度河发源于青藏高原，水量丰沛，有利于农业生产。
5. **读图提示：** 文明遗址主要分布在印度河流域及周边适合生产、生活的地区；不能认为古代印度所有地区同时出现同样的城市文明。

教材《大唐西域记》材料中，“三垂大海，北背雪山”对应三面临海、北靠高山；“北广南狭”概括南亚次大陆北部较宽、南部渐窄的轮廓。材料中的历史地名及范围应与现代国家区分。

### 2. 兴起时间与代表城市

- **兴起：** 约公元前25世纪，古代印度文明最早出现在印度河流域。
- **发现：** 20世纪20年代，考古学家在哈拉帕发现城市文明遗存，后来又发现摩亨佐·达罗等遗址。
- **代表：** **哈拉帕、摩亨佐·达罗**。
- **生产证据：** 出土大量农业、畜牧业、手工业遗存，说明生产领域较多、社会分工发展。
- **衰亡：** 公元前18世纪，印度河流域文明走向衰亡。教材没有在正文中确定单一原因，答题不要自行把某一种推测写成定论。

### 3. 城市文明的特点

| 遗址现象 | 可以概括的特点 |
| --- | --- |
| 有公共建筑、行政中心、住宅区、工商业区 | 城市具有公共管理和功能分区 |
| 建设多用规格统一的砖石 | 建筑标准较统一，组织和制作水平较高 |
| 街道布局规整 | 有较成熟的城市规划 |
| 房屋内有完整的给排水设施 | 注重城市供水、排水和生活设施 |
| 多地发现刻符号的印章 | 存在符号记录与交流，但释读仍有困难 |

**材料题表达：** “统一砖石＋规整街道＋给排水”可共同证明城市建设水平较高。不能仅凭规划规整，就直接判断国王姓名、具体政体或居民都享有平等权利。

### 4. 印章符号与史料边界

印章上有人物、动物及几何图形等，也有数量不等的符号。这些符号**可能是印度河文明的文字，至今尚未被成功释读**。

理解：实物材料可以证明某些建筑、工艺和生产活动；尚未释读的符号不能当作已经读懂的政治文书。因此，对其制度和社会结构的判断必须注意证据限度，不能随意引用所谓印章“译文”。

## 三、课内必背：种姓制度与佛教

### 1. 种姓制度的形成

**公元前1500年左右**，雅利安人迁入南亚次大陆，陆续定居于印度河、恒河流域。印度北部逐渐出现许多小国家，在国家形成过程中建立严格的社会等级制度，称**种姓制度**。

种姓制度不只是职业分类，而是把身份、权利、职业与婚姻限制固定在等级中，体现严重的社会不平等。

### 2. 四个等级及其分工

| 等级 | 名称 | 教材所列主要职能、处境 |
| --- | --- | --- |
| 第一等级 | 婆罗门 | 掌管祭祀，拥有宗教特权 |
| 第二等级 | 刹帝利 | 掌管军事和行政权力 |
| 第三等级 | 吠舍 | 从事农业、畜牧业和商业 |
| 第四等级 | 首陀罗 | 主要由被征服居民构成，为前三等级服务 |
| 四种姓之外 | “贱民”，被称为“不可接触者” | 从事被当时社会视为“不洁”的职业，遭受严重歧视 |

记忆顺序：**婆、刹、吠、首；祭祀、军政、农牧商、服役。**“贱民”是历史歧视性称谓，使用引号是为了认识旧制度，并非认同这种价值判断。

### 3. 种姓制度的主要特点

1. **身份世袭：** 种姓身份世代相承，个人很难自由改变。
2. **等级森严：** 高低贵贱分明，不同等级地位不平等。
3. **职业限制：** 低等级者不得从事高等级职业。
4. **婚姻限制：** 不同等级不得通婚。
5. **排斥现象：** 四种姓外的“不可接触者”受到格外严重的社会隔离和歧视。

**材料研读：** 《法显传》记载“旃荼罗”与人分居，进城时击木提示，别人避开。可据此说明他们被排斥于正常社会交往之外、社会地位极低。不能只答“他们生活在城市外面”，还要揭示等级歧视。

### 4. 佛教产生的社会背景

- **经济变化：** 公元前6世纪前后，恒河流域经济发展，以吠舍等级为主的商人崛起，冲击婆罗门特权。
- **政治与生活：** 国家之间冲突不断，给民众带来苦难。
- **思想变化：** 各种思潮兴起，反映人们对现实秩序及人生问题的思考，佛教是其中重要一种。
- **因果理解：** 佛教并非凭空产生，而与社会经济发展、等级矛盾和战争苦难有关。不要把全部原因缩成“创始人想建立宗教”。

### 5. 佛教的创立、主张与影响

1. **时间：** 公元前6世纪前后。
2. **创始人：** 乔达摩·悉达多，后来被尊称为**释迦牟尼、佛陀**，这些名称指向同一个人。
3. **早期主张：** 反对婆罗门特权，提出“众生平等”，同时宣扬“忍耐顺从”。
4. **发展：** 信仰者日益增多，佛教一度成为印度的重要宗教，孔雀王朝时期影响继续扩大。
5. **理解评价：** 反对婆罗门特权对种姓等级观念形成冲击；但宣扬忍耐顺从也可能缓和人们对现实苦难的反抗。宗教意义的平等主张不等于现实社会已实现政治、经济平等。

### 6. 佛教的传播路线

- **向南、东南传播：** 经今斯里兰卡传到缅甸、泰国、柬埔寨等地。
- **向东传播：** 公元前后传入中国，后来又传到朝鲜半岛、日本和越南等地。
- **概括影响：** 佛教逐渐成为跨地区宗教，影响亚洲多地的思想、艺术和文化交流。
- **易错点：** “公元前后”指公元纪年转折前后的一段时间，不是明确的“公元前某年”；不能把它写成公元前6世纪佛教创立时就已传入中国。

### 7. 教材补充：孔雀王朝等政权

孔雀王朝约存在于公元前324—前187年，最著名统治者是**阿育王**。他通过征战，基本统一南亚次大陆，首都华氏城人口众多、十分繁华。此后贵霜帝国、笈多王朝等先后统治南亚次大陆部分地区，推动政治、经济、文化发展，并参与东西方文化交流。

背诵时保留“**基本统一**”这一限定，不改成“始终统一全部南亚”。这些王朝与更早的印度河文明处于不同历史阶段。

## 四、课内必背：古代印度文化

### 1. 两大史诗

- **《摩诃婆罗多》：** 描绘古代印度列国之间的争斗，歌颂正义、反对邪恶。
- **《罗摩衍那》：** 汇集大量民间故事和神话故事，是后世印度文学、艺术创作的重要源泉。
- 两者是印度文学瑰宝，也提供认识古代社会和观念的线索。史诗具有神话、文学加工，不能把其中情节全部当作准确历史纪实。

### 2. 建筑、雕刻与绘画

佛塔和石窟建筑中的雕刻、绘画，用丰富形式讲述宗教故事，充满想象力与创造力。它们说明宗教不仅影响思想信仰，也推动建筑、美术等发展。桑奇佛塔是教材展示的实例。

### 3. 天文、数学、医学

| 领域 | 主要成就 |
| --- | --- |
| 天文历法 | 依据日月运行规律制定历法 |
| 数学 | 发明一套包括“0”在内的数字符号系统，后来广泛应用 |
| 医学 | 掌握以金、石、草木入药的知识，并通过手术治疗疾病 |

**数字系统理解：** “0”及相关符号系统方便表示数值和进行计算，是古印度的重要贡献。后来这些数字经阿拉伯人传播而广泛应用；不能因为常称“阿拉伯数字”，就把最初创造者全部写成阿拉伯人。传播者与创造者的贡献都应尊重。

## 五、三种古代文明对照与时间线

| 文明 | 地理基础 | 制度或政治代表 | 文化代表 |
| --- | --- | --- | --- |
| 古代两河流域 | 幼发拉底河、底格里斯河 | 古巴比伦、君主专制、法典 | 楔形文字、星期制、60进制 |
| 古代埃及 | 尼罗河 | 法老权力、金字塔 | 象形文字、太阳历、数学医学 |
| 古代印度 | 印度河、恒河及南亚地形区 | 种姓制度 | 佛教、史诗、含“0”的数字系统 |

共同点：大河农业为发展提供条件，形成早期国家，创造多样文化。差异：自然环境、制度、信仰和具体成就各有特色，体现文明多元性。不能只比“谁更先进”，而应比较各自特点与贡献。

| 时间 | 事件 |
| --- | --- |
| 约公元前25世纪 | 印度河流域文明兴起 |
| 公元前18世纪 | 印度河流域文明走向衰亡 |
| 公元前1500年左右 | 雅利安人迁入南亚 |
| 公元前6世纪前后 | 佛教产生 |
| 孔雀王朝时期 | 阿育王基本统一南亚，佛教影响扩大 |
| 公元前后 | 佛教传入中国 |

## 六、重点易混辨析与教材拓展

1. **古代印度不只包括今天印度领土。** 印度河文明的部分核心遗址位于今天巴基斯坦，历史地理范围应结合地图判断。
2. **种姓是世袭等级，不是自由选择的职业。** 一般分工不必然带有身份贵贱和禁婚，种姓制度有这些强制限制。
3. **四种姓不包括“不可接触者”。** 后者在四种姓之外，不能列为“第五个正常等级”。
4. **佛教反对婆罗门特权，不等于种姓制立即被废除。** 思想批判与现实制度变化应区分。
5. **佛教在印度创立，后来传入中国。** 发源地、传播地及艺术发展地不能混同。
6. **原有符号尚未成功释读。** 不要把史诗、佛教文献误当作印度河印章的译文。

**教材拓展：犍陀罗艺术。** 南亚次大陆西北部的犍陀罗地区受到希腊文化影响，希腊雕塑风格、神话观念与佛教题材结合，形成独特艺术；它沿丝绸之路东传，对中国云冈、龙门等石窟造像有影响。这是文明交流与融合的例子，不能说中国石窟艺术全部来自单一外来文明。

## 七、简答题：可直接背诵的答案

**1. 印度河城市文明有哪些特点？**  
答：农业、畜牧业、手工业发展；哈拉帕、摩亨佐·达罗等城市有公共建筑和功能分区，砖石规格统一，街道规整，给排水设施较完整，反映较高城市规划建设水平；印章符号尚未成功释读。

**2. 种姓制度有哪些主要特点？**  
答：种姓身份世袭，等级森严，低等级不能从事高等级职业，不同等级不得通婚；四种姓外的“不可接触者”受到严重排斥和歧视，是不平等的社会等级制度。

**3. 佛教为何在公元前6世纪前后产生？**  
答：恒河流域经济发展，商人崛起冲击婆罗门特权；国家冲突使民众苦难加重，各种思想兴起。乔达摩·悉达多在这一背景下创立佛教，反映对现实秩序和人生问题的思考。

**4. 早期佛教有哪些主张，应怎样理解？**  
答：反对婆罗门特权，提出众生平等，同时宣扬忍耐顺从。前者冲击等级观念，后者可能缓和对现实苦难的反抗；其平等主要是宗教主张，不能等同于现实已全面平等。

**5. 佛教主要怎样向外传播？**  
答：经斯里兰卡传到缅甸、泰国、柬埔寨等地；公元前后传入中国，后来传播到朝鲜半岛、日本、越南等地，对亚洲思想和艺术交流产生重要影响。

**6. 古代印度对世界文化有哪些重要贡献？**  
答：创立佛教，创造两大史诗及佛塔、石窟艺术；依据日月制定历法，发明包括“0”在内的数字符号系统，发展药物知识与外科治疗；这些成果在交流中影响其他地区。
