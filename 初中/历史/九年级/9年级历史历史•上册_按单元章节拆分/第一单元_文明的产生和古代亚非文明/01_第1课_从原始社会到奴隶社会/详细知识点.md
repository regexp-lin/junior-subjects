# 第1课 从原始社会到奴隶社会｜详细知识点（背诵版）

> **所属单元：** 第一单元：文明的产生和古代亚非文明。  
> **教材依据：** [本课教材 PDF](01_第1课_从原始社会到奴隶社会.pdf)，包括课文、插图、材料及课后活动。  
> **使用说明：** “课内必背”用于掌握教材事实；“理解辨析”用于解释因果；“教材拓展”帮助理解，不与基本史实混背。以下内容为自主归纳。

## 一、先背主线

**约300万年前人类开始形成 → 旧石器时代以渔猎、采集为生 → 1万多年前进入新石器时代，农业、畜牧业兴起 → 生产力提高、社会分工发展 → 剩余产品增加、私有财产出现 → 社会分化、阶级出现 → 奴隶制国家产生。**

本课贯穿两条线：一是工具、生产和生活方式变化，二是生产发展引起社会关系变化。**劳动对人类的形成和发展具有重要作用；生产力的发展是社会变化的根本推动力量。**各地区发展的时间和具体道路并不完全一致。

## 二、课内必背：人类的形成与原始社会生活

### 1. 人类开始形成与“露西”化石

1. **时间：** 约300万年前，人类开始形成。
2. **发现：** 1974年，古人类学家在今埃塞俄比亚发现一位距今约300万年的年轻女性遗骨化石，取名“露西”。
3. **证据：** 研究表明，“露西”已经能够直立行走。这是认识早期人类演化的重要实物证据。
4. **理解补充：** 人类由古猿逐步演化而来。直立行走有助于解放双手、开阔视野，便于使用和制造工具、搬运食物；劳动又促进手、脑及社会协作的发展。人类的形成是漫长演化过程，不能把某一块化石当作所有人类的唯一祖先。

### 2. 原始社会怎样分期

- 原始社会的人主要使用石器，也利用黏土、骨、牙、蚌、木、竹等制作生产生活用具。
- **分期依据：** 考古学家依据石器制作方法的变化，将原始社会分为旧石器时代和新石器时代。
- **旧石器时代：** 从人类形成到农业起源，是人类历史上非常漫长的时期，主要使用打制石器。
- **新石器时代：** 1万多年前，人类社会进入新石器时代，磨制石器普遍使用，农业和畜牧业在世界多地起源。
- 这是一种考古学分期，不能只按器物“看起来新旧”判断。磨制石器普遍使用也不意味着打制石器立即消失。

### 3. 旧石器时代的生产与生活

1. **居住：** 主要生活在洞穴等天然场所。
2. **工具：** 将石块敲击成具有锋刃的打制石器，用来切割、砍砸、处理猎物等。
3. **食物来源：** 掌握渔猎、采集等基本生活技能，主要获取自然界已有的食物，生产生活受自然条件限制较大。
4. **火的作用：** 烧制食物、御寒、照明、防御野兽，改善了人类的生存条件。
5. **认识：** 使用工具和火反映人类能动地改造自然。会用火不等于已经产生农业，不能把两者混为一谈。

### 4. 新石器时代的农业、畜牧业与定居

**工具变化：** 劳动工具更加复杂多样，磨制石器普遍使用。磨制使石器形状更规整，适应不同生产需要。

**农业起源的主要地区及作物：**

| 地区 | 教材列举的早期粮食作物 |
| --- | --- |
| 西亚 | 大麦、小麦 |
| 中国 | 水稻、粟、黍 |
| 南亚次大陆 | 稻 |
| 非洲 | 高粱 |
| 美洲 | 玉米、马铃薯 |

**畜牧业：** 人类逐渐驯养动物。西亚有山羊、绵羊、牛、猪、狗；东亚有猪、鸡、狗；美洲有羊驼等。注意：上述是教材举例，并不是各地全部作物、家畜的清单。

**生活转变：**

- 人类从主要获取现成食物，逐步转为种植作物、饲养动物，成为**食物生产者**。
- 生产食物需要持续照料土地、作物和家畜，食物来源相对稳定，定居生活开始。
- 陶器得到广泛使用，能够适应储藏、烹煮等生活需要。定居、农业和陶器相互联系，但不是每个地区同时一步完成。
- 新石器时代，人们共同生活，共同获取和分配食物。不能因为存在定居和陶器，就断定已经形成私有制和国家。

### 5. 原始艺术与技术

- 人类在岩洞、房屋和墓葬中描绘动物、人物形象，并用土、石、木、动物骨角牙等制作装饰品。
- 西班牙阿尔塔米拉岩洞、土耳其恰塔尔·休于的绘画，是观察原始艺术的材料。
- 中国山西陶寺古城遗址出土的绿松石管、绿松石甲饰，反映先民掌握了较先进的钻孔等加工技术。
- **读图方法：** 先描述人物、动物和活动，再概括生产生活；图像能够反映经验、想象和审美，不能仅凭一幅画确定具体政治制度。

## 三、课内必背：阶级出现与奴隶制国家产生

### 1. 生产发展怎样改变社会关系

1. 农业和畜牧业发展，提高生产力水平，人口增加。
2. 社会分工更加细致，一部分人脱离农业，专门从事手工业和产品交换。
3. 社会经济发展，剩余产品日益增加，为私有财产产生创造条件。
4. 原始社会组织中，出现专门从事管理的人；他们将一部分公共产品据为私有，逐渐发展为统治阶级。
5. 从事生产劳动的人处于被统治地位，社会出现阶级分化。

**概念解释：** 剩余产品，是维持直接生产者基本生活之外可以剩下的产品。阶级分化不仅是收入多少不同，更涉及对财富和权力的占有及统治、被统治关系。公共管理最初是社会需要，管理职能被少数人用来占有财富后，才逐渐转化为统治权力。

### 2. 墓葬材料怎样说明社会分化

原始社会末期，不同墓葬的随葬品数量和种类差别扩大：有的没有随葬品，有的随葬生产生活用具，有的随葬武器和精美装饰品。**这些差别反映社会成员在财富、身份和地位上的差异，是研究社会分化的重要证据。**不能把一件贵重器物孤立地视为国家已经产生的充分证明。

### 3. 战争、奴隶与国家机构

- **战争原因：** 原始社会组织之间争夺土地和其他资源。
- **奴隶来源：** 战败者往往被战胜者俘获，成为奴隶，被迫从事繁重生产劳动。这里的“往往”不能改成所有奴隶都来自战争。
- **社会变化：** 奴役加重社会压迫，社会矛盾和冲突加剧。
- **国家形成：** 统治者设置军队、监狱等机构，调节矛盾和冲突，维护统治，国家逐渐形成。
- **性质：** 最早的国家大多是奴隶制国家，国王是最大的奴隶主。国家产生意味着人类进入阶级社会，但这一过程是长期、复杂的。

### 4. 最早国家的地区分布与文明多元性

最早的国家出现于**西亚两河流域、北非尼罗河流域、东亚黄河和长江流域、南亚印度河流域**等地。共同特点是多位于适合农业耕作的大河流域。

理解这一分布，要联系水源、土壤和农业条件：河流提供生活、灌溉用水，冲积平原利于耕作；农业发展为人口集中、社会分工和国家形成提供基础。自然环境只是重要条件，还必须看到劳动、技术和社会组织的作用，不能说“大河自然产生国家”。

各地区文明各有创造：两河流域有楔形文字和《汉谟拉比法典》，埃及有象形文字和金字塔，中国有甲骨文和青铜器，印度有数字符号和史诗。**人类文明起源具有多元性，各种文明共同作出贡献。**

## 五、重点易混辨析

1. **原始社会不等于“没有技术”。** 石器加工、用火、农业、陶器、钻孔和艺术都体现创造力，只是生产力水平相对低。
2. **农业起源不等于国家立即诞生。** 农业发展经过剩余产品增加、分化加剧等环节，才推动早期国家产生。
3. **社会分工不等于阶级分化。** 前者是劳动任务不同，后者涉及财富占有、统治与被统治关系。
4. **氏族、部落等原始组织不等于国家。** 国家具有军队、监狱等统治机构，是社会分化发展到一定阶段的产物。
5. **国家产生不能只归结于战争。** 生产发展和社会分化提供基础，战争和奴役加剧矛盾，推动形成统治机构。
6. **“最早国家大多是奴隶制国家”不能改成“所有国家完全相同”。** 文明起源有共同规律，也有地区差异。

## 六、教材拓展：碳十四年代测定法

生物生存时与环境交换碳，死亡后停止补充碳十四；已有碳十四按一定速度衰减，其半衰期约为5730年。测定遗存中的碳十四含量，可估算生物死亡的大致年代。这一方法适用于相应的含碳生物遗存，存在适用条件和误差，不能把任何石器都直接拿来测碳十四年代。**本项帮助理解考古证据，不必背诵技术细节。**

## 七、简答题：可直接背诵的答案

**1. 农业和畜牧业起源为什么是重大变化？**  
答：农业和畜牧业使人类成为食物生产者，食物来源相对稳定，促进定居生活、人口增长和社会分工；生产力提高、剩余产品增加，又为私有财产、阶级和国家产生提供经济基础。

**2. 旧石器时代与新石器时代有什么主要区别？**  
答：旧石器时代主要使用打制石器，以渔猎、采集为生，多利用天然场所居住；新石器时代磨制石器普遍使用，农业和畜牧业在多地起源，人类成为食物生产者，开始定居，陶器广泛使用。

**3. 阶级是怎样逐渐出现的？**  
答：农业和畜牧业发展使生产力提高，社会分工细化，剩余产品增加，私有财产出现。一部分管理者占有公共产品，逐渐成为统治阶级，直接生产劳动者成为被统治阶级，阶级由此出现。

**4. 奴隶制国家怎样产生？**  
答：原始社会末期，社会分化日益明显，组织间为争夺资源进行战争，战败者往往成为奴隶，矛盾加剧。统治者设置军队、监狱等机构，维护统治，早期国家形成；最早的国家大多是奴隶制国家。

**5. 如何从墓葬研究社会变化？**  
答：比较墓葬规模及随葬品的数量、种类和精美程度。原始社会末期这些差别明显扩大，反映财富、身份和社会地位差异，说明社会分化加剧。

**6. 最早国家多分布在哪里？有何共同条件？**  
答：主要分布在两河、尼罗河、黄河和长江、印度河等大河流域。这些地区水源和土壤条件较适合农业；农业发展为人口增加、分工、社会分化和国家形成提供基础。
