# 第1课 从原始社会到奴隶社会｜思维导图

> **所属单元：** 第一单元：文明的产生和古代亚非文明  
> 建议先遮住分支自述，再核对本图；箭头“→”表示主要因果或演进关系，“＋”表示共同条件。

```text
文明产生与社会形态演进
├─ 人类形成（约300万年前）
│  └─ 直立行走 → 上肢解放 → 工具使用与活动扩大
├─ 原始社会
│  ├─ 旧石器：打制石器、渔猎采集、洞穴、用火
│  └─ 新石器（约1万多年前）：磨制石器、农业畜牧、定居、陶器、原始艺术
├─ 社会分化
│  └─ 生产力提高 → 分工/交换 → 剩余产品 → 私有财产 → 阶级
├─ 国家与奴隶制
│  └─ 统治阶级形成 → 为维护统治而产生早期国家
└─ 多元文明起源
   ├─ 两河：楔形文字、法典
   ├─ 埃及：象形文字、金字塔
   ├─ 中国：甲骨文、青铜器
   └─ 印度：数字、史诗
复习抓手：石器制作方式是旧/新石器的分界；“剩余产品”是私有制的经济条件。
```
