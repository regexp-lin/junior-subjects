# 第15课 早期殖民掠夺｜详细知识点（背诵版）

> **所属单元：** 第五单元·走向近代。  
> **整理依据：** [本课教材PDF](./15_第15课_早期殖民掠夺.pdf)，以正文、殖民地地图、“三角贸易”图及材料研读为主。  
> **背诵范围：** 葡西殖民活动、英荷法争夺、“三角贸易”及其影响为课内重点；“理解辨析”帮助解释；教材统计估计和印加帝国史事作为拓展理解。

## 一、先背这一条主线

**新航路开辟 → 葡萄牙、西班牙率先殖民掠夺 → 英、荷、法加入殖民争霸 → 英国在18世纪中后期开始建立殖民霸权 → 美洲矿山和种植园需要劳动力 → 跨大西洋奴隶贸易兴起 → 欧洲积累资本，非洲、美洲人民遭受深重灾难。**

“早期殖民掠夺”包括抢夺金银、控制商路、建立据点与殖民地、奴役当地居民、贩卖非洲人口和殖民战争。它不只是几次海外贸易，而是伴随武力和政治控制的侵略过程。

## 二、葡萄牙与西班牙的殖民掠夺

### 1. 共同背景与先后地位

新航路开辟，使欧洲殖民者能够到达更多地区。葡萄牙和西班牙最先支持航海探索，也最先开始殖民掠夺。殖民者的目的主要是夺取财富、控制贸易和扩展势力，不能把这些侵略解释为向当地单方面“传播文明”。

### 2. 葡萄牙：据点、商站和掠夺式贸易

- **主要分布：** 在沿非洲海岸通往亚洲的航路上建立许多殖民据点或商站，控制从印度洋到太平洋的海上通道。
- **经营手段：** 用欧洲手工业品换取当地黄金、象牙、珍珠、宝石、香料等，有时直接抢劫；还捕获非洲黑人，卖为奴隶。
- **美洲据点：** 在巴西建立面积广大的殖民地并实行殖民统治。
- **特点概括：** 沿海据点和海上贸易通道控制十分突出；同时也有巴西这样的大面积殖民地，不能绝对说“葡萄牙只建商站、不占土地”。

**图片理解：** 教材里斯本港口图中，大量船只往来于殖民据点和商站。港口繁荣背后，包含殖民掠夺所得财富的集中，不能仅根据港口繁忙就判定有关贸易都是平等交换。

### 3. 西班牙：美洲殖民帝国与强制劳动

- **海上力量：** 16世纪建立号称“无敌舰队”的强大海军，活动于地中海和大西洋。
- **美洲殖民：** 在美洲建立庞大的殖民帝国，强迫印第安人开采金银矿，一度攫取世界上最多的金银财富。
- **种植园：** 在当地兴办种植园，强迫印第安人和黑人奴隶劳动。
- **亚洲活动：** 占领菲律宾，以此为据点与中国、日本等进行贸易。
- **特点概括：** 大面积占领、开矿和种植园生产、强制劳动密切结合。

教材“矿井中的印第安人”图，反映美洲原住民被迫劳动、殖民者掠夺矿产资源。若设问“银矿产量增长说明什么”，不能只答生产发展，还要根据材料指出强制劳动和殖民剥削。

### 4. 地名中的殖民掠夺（教材相关史事）

西非部分沿海地区曾被称为“黄金海岸”“象牙海岸”“奴隶海岸”，分别与殖民者掠取黄金、象牙和贩卖人口有关。今天加纳沿海曾称“黄金海岸”，科特迪瓦与“象牙海岸”相关，贝宁曾与“奴隶海岸”相关。**重点是理解地名反映资源和人口被掠夺，不必把现今国名都作为主干背诵负担。**

## 三、英、荷、法殖民争霸

### 1. 英国扩张的经济与地理条件

16世纪，英国手工业尤其毛纺织业迅速发展，需要开拓海外市场。新航路开辟后，欧洲贸易中心逐渐由地中海沿岸转向大西洋沿岸，英国利用面向大西洋的有利位置，积极发展海外贸易和殖民活动。

英国与原来的海上强国西班牙发生冲突。**1588年，英国击败西班牙“无敌舰队”，此后西班牙逐渐衰落。** 这一胜利有利于英国海外扩张，但不能说英国在1588年便立即建立世界殖民霸权。

### 2. 海盗活动与国家支持

教材以德雷克为例：他既是航海家，也是海盗，率船队在加勒比海和南美洲沿海抢掠，拦截西班牙运输金银的船只，袭击西班牙殖民据点。英国女王伊丽莎白一世给予资助并分享抢来的财富。

**理解要点：** 当时英国海外扩张中，海盗暴力、商人逐利和王室支持相互结合。不能因参与者获得王室支持，就把抢劫性质改写成正常贸易。

### 3. 贸易公司：商业组织也是殖民工具

17世纪初，英国、荷兰、法国等国的殖民竞争加剧，纷纷建立带有殖民侵略性质的贸易公司。

1. 由私人集资成立，却得到政府大力支持。
2. 获得在一定区域内的贸易垄断特权。
3. 有些公司拥有军队，可以代表国家行事。
4. 以贸易为名拓展殖民活动，典型代表是**英国东印度公司**。

**答题提示：** 遇到“贸易公司”不能只从企业经营角度理解；若材料出现垄断特权、武装力量、控制地区等信息，应指出其殖民侵略性质。英国东印度公司也出现在美国独立一课的茶叶贸易问题中，两课可以联系记忆。

### 4. 荷兰：“海上马车夫”

- **兴盛时期：** 17世纪。
- **称号原因：** 拥有当时世界上最庞大的商船队，海上商业运输发达，在殖民贸易中占据上风，几乎垄断欧洲与世界各地的海上贸易活动，被称为“海上马车夫”。
- **非洲、亚洲活动：** 从葡萄牙手中夺取好望角、马六甲、锡兰，侵入印度尼西亚爪哇岛和中国台湾。
- **北美活动：** 建立新尼德兰殖民地。

“海上马车夫”主要形容海上运输和贸易地位，并不是指农业、人口或领土均居世界第一，也不意味着荷兰的殖民贸易没有暴力。

### 5. 法国加入，英国取得优势

法国在17世纪下半期开始于北美洲、非洲、亚洲陆续建立殖民地，加入殖民争夺。英国相继打败荷兰和法国，在世界各地夺取大片殖民地。**18世纪中后期，英国开始建立殖民霸权。**

把三个时间层次分清：**16世纪葡西率先扩张 → 17世纪荷兰海上贸易兴盛、英荷法竞争 → 18世纪中后期英国开始建立殖民霸权。**

## 四、“三角贸易”：罪恶的跨大西洋奴隶贸易

### 1. 为什么产生

欧洲殖民者在美洲开采金银矿、建立种植园，需要大量劳动力。殖民者的屠杀、虐待以及他们带来的天花等传染病，使印第安人人口锐减。16世纪以后，殖民者为补充劳动力，把非洲黑人掳为奴隶，贩到美洲劳动，横跨大西洋的奴隶贸易由此发展。

**因果链：** 殖民生产需要劳动力 + 原住民人口锐减 → 强行从非洲贩运人口 → 奴隶贸易扩大。人口锐减有暴力、强制劳动、疾病等多重因素，不能只归于某一种原因；贩运人口是殖民者的罪恶选择，不能当作合理的“用工办法”。

### 2. 三段路线和运送内容

| 航程 | 路线 | 主要运送内容 | 罪恶行为或经济目的 |
| --- | --- | --- | --- |
| 出程 | 欧洲 → 非洲 | 手工业品等 | 到非洲以货物“交换”或直接掳掠黑人 |
| 中程 | 非洲 → 美洲 | 被掳卖的黑人奴隶 | 横渡大西洋，把人运到美洲出售 |
| 归程 | 美洲 → 欧洲 | 金银或殖民地特产 | 把财富运回欧洲，获取巨额利润 |

三个地区的大致航线在地图上呈三角形，故称“三角贸易”。**核心是贩卖人口的罪恶交易，不能只把它背成三个洲之间的一般货物贸易。** 图示是对主要贸易网络的概括，也不是说每一艘船都完全按三段路线航行。

### 3. 参与者与利润

葡萄牙、西班牙、荷兰、英国、法国等国的奴隶贩子先后加入。贩运一个非洲黑人到美洲出售，往往能获得6—8倍利润，巨额利益驱动交易扩大。殖民者把人当作可以出售的商品，剥夺其人身自由与尊严。

教材描述运奴船上空间狭窄、空气不通，黑人被迫忍饥挨饿；病人和体弱者可能被扔进海里。有关史料说明，所谓商业利润建立在对生命的残酷摧残之上。

### 4. 对不同地区的影响

**对非洲：** 持续300多年的奴隶贸易造成大量人口损失，许多被掳者是青壮年劳动力，家庭破裂，社会生产和发展进程受到严重破坏。

**对美洲：** 原住民遭屠杀、奴役和疾病打击；非洲黑人被强迫在种植园、矿山等处劳动，遭受残酷剥削，奴隶制度扩展。

**对欧洲：** 殖民者通过贩奴、掠夺和殖民生产大发横财，加速资本原始积累，推动欧洲资本主义发展。

**教材统计的用法：** 教材估计约1500万黑人被卖到美洲，并指出掳掠和运输中的死亡更多、非洲人口损失可能近亿。这些属于特定统计口径下的估计，答题重点是人口损失巨大与社会破坏，不把估计数说成精确、没有争议的统计。

## 五、怎样理解资本原始积累

**课内核心：** 殖民掠夺和“三角贸易”使财富集中到欧洲殖民者手中，增加了资本原始积累，促进资本主义发展。

**理解补充：** “资本原始积累”是资本主义生产关系形成过程中，生产者与生产资料分离、财富集中并转化为资本的历史过程。殖民掠夺和奴隶贸易是其重要来源，不是全部内容；“原始”也不等于普通人靠勤俭节约积攒第一笔钱。

教材引用马克思，把美洲金银掠夺、对亚洲的征服、在非洲猎获人口并列，揭示资本主义早期财富积累的野蛮性与残酷性。评价时应说明财富从何而来、由谁付出代价，不能只背“推动资本主义发展”而略去罪行。

## 六、时间线与重点易混辨析

| 时间 | 事件或变化 | 记忆重点 |
| --- | --- | --- |
| 15世纪末起 | 葡西伴随新航路进行殖民掠夺 | 最先开始的两个国家 |
| 16世纪以后 | 跨大西洋奴隶贸易发展 | 美洲劳动力需求与暴力贩奴 |
| 1588年 | 英国击败西班牙“无敌舰队” | 西班牙逐渐衰落，英国扩张条件改善 |
| 17世纪 | 荷兰海上贸易兴盛 | “海上马车夫” |
| 17世纪初起 | 英荷法建立殖民贸易公司 | 私人资本、政府支持、垄断特权 |
| 18世纪中后期 | 英国开始建立殖民霸权 | 经过长期殖民争霸形成 |

1. **新航路与殖民掠夺：** 新航路提供跨洋联系条件，殖民掠夺则是欧洲国家利用海路扩张和夺财的行为。
2. **殖民地与据点：** 殖民地通常指受外来国家统治的地区；据点或商站是控制航路、贸易和军事活动的支点，二者不能一概等同。
3. **财富增加与社会进步：** 殖民者财富增加不等于被殖民地区生活改善，更不能抵消屠杀、奴役等罪行。
4. **争霸胜利的时间：** 1588年击败西班牙，不等于同年已战胜荷兰、法国并建立全球霸权。
5. **奴隶贸易与移民：** 被绑架、贩卖、强制运输的人口不能称为普通自愿移民。

**教材拓展，选读：** 1532年，西班牙殖民者皮萨罗袭击印加国王，以赎人为名索要大量金银后仍将其处死；次年攻入库斯科，灭亡印加帝国。这一史事体现殖民者的欺骗、暴力与财富掠夺。

## 七、简答题：照着答案练背

### 1. 葡萄牙和西班牙分别进行了哪些殖民活动？

葡萄牙沿非洲至亚洲航路建立据点和商站，控制海上通道，掠夺资源、贩卖人口，并在巴西建立殖民地。西班牙在美洲建立殖民帝国，强迫印第安人和黑人奴隶开矿、经营种植园，并占领菲律宾开展亚洲贸易。

### 2. 英国建立殖民霸权经历了哪些主要竞争？

英国1588年击败西班牙“无敌舰队”，随后同荷兰、法国进行长期殖民争夺，相继打败这些竞争对手，夺取大片殖民地，在18世纪中后期开始建立殖民霸权。

### 3. 为什么贸易公司具有殖民侵略性质？

这些公司得到政府支持，享有特定区域的贸易垄断权，有的拥有军队并能代表国家行事，通过控制贸易、武装侵略和占领地区扩大殖民活动，因此是殖民扩张的重要工具。

### 4. “三角贸易”怎样运行？

出程从欧洲运手工业品到非洲，掳掠或以货物“交换”黑人；中程把黑人奴隶横渡大西洋运到美洲出售；归程把美洲的金银或特产运回欧洲。欧洲、非洲、美洲之间的航线大致形成三角形。

### 5. “三角贸易”有什么影响？

它使大量非洲人口被掳走或死亡，家庭破碎，严重破坏非洲的发展；使美洲的黑人奴隶遭受强制劳动与残酷剥削；使欧洲殖民者获得巨额财富，加速资本原始积累，推动资本主义发展。

### 6. 怎样认识早期殖民掠夺？

它是欧洲国家以暴力、强制和不平等交换夺取财富的过程，给被侵略地区带来屠杀、奴役、资源掠夺和社会破坏；同时，掠夺财富成为欧洲资本原始积累的重要来源。欧洲资本主义的发展包含以殖民地人民苦难为代价的一面。
