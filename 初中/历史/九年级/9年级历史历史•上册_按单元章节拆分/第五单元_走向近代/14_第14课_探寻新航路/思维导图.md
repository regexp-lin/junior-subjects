# 第14课 探寻新航路｜思维导图

> **所属单元：** 第五单元：走向近代  
> 建议先遮住分支自述，再核对本图；箭头“→”表示主要因果或演进关系，“＋”表示共同条件。

```text
探寻新航路
├─ 动因
│  ├─ 商品经济/市场扩大、金银需求、新兴资产阶级逐利
│  └─ 传统商路受阿拉伯/意大利垄断，奥斯曼征重税
├─ 条件：罗盘、造船、地圆说、葡西王室支持
├─ 航线
│  ├─ 迪亚士：1488好望角
│  ├─ 达·伽马：1497—1498绕非洲到印度
│  ├─ 哥伦布：1492西航到美洲（误认为印度）
│  └─ 麦哲伦船队：1519—1522首次环球
└─ 影响
   ├─ 海上联系、整体世界、物种交流
   ├─ 欧洲市场扩大和资本积累
   └─ 殖民掠夺、原住民灾难、社会进程受打断
复习抓手：原因≠条件；全球联系的形成具有进步与暴力双重后果。
```
