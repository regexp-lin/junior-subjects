# 第17课 二战后资本主义国家的变化｜详细知识点（背诵版）

> **所属单元：** 第五单元·第二次世界大战后的世界变化。  
> **教材依据：** [本课教材PDF](./17_第17课_二战后资本主义国家的变化.pdf)，教材书面第93—96页。  
> **使用说明：** 依据本课正文、图表、材料和课后活动整理；“理解辨析”用于建立联系，“教材拓展”按教材拓展栏目识记，二者不代替正文结论。

## 一、先背全课结构

**西欧从战后废墟中恢复并联合 → 美国继续发展、日本迅速崛起 → 资本主义国家调整社会政策 → 社会保障扩大、妇女社会地位变化 → 现代科技深刻影响经济与生活。**

本课的“变化”包括经济恢复、区域合作、产业结构和社会政策等方面。评价时既承认发展与改善，也说明制度矛盾和时代局限，不能只用“资本主义完全不变”或“资本主义已没有矛盾”概括。

## 二、欧洲的联合

### 1. 西欧战后经济恢复的条件

战后西欧战争废墟遍地，住房短缺、经济萧条。教材以杜塞尔多夫城市废墟和英国妇女渴望住房的叙述，说明重建任务的紧迫。

西欧能够恢复发展，主要凭借：**原有工业基础、马歇尔计划援助、采用先进科技成果、制定恰当政策。** 工业基础意味着技术、产业和人才积累仍提供条件，并不意味着战时破坏轻微；美国援助是重要外部条件，也不能替代西欧自身重建与政策作用。

**答题组织：** 可按“基础—外援—科技—政策”四点背诵。若问整个战后资本主义世界的发展，还应依据具体国家补充市场、产业和国际环境，避免机械套用。

### 2. 为什么走向联合

两次世界大战使西欧认识到，持续对抗和分裂会削弱自身；要重振经济、提高国际地位，必须联合自强。法德由长期对立转向合作，是欧洲联合的重要条件。

**理解辨析：** 联合既有防止战争、改善关系的一面，也有共同发展、增强国际影响的一面。它不是“各国经济已经完全相同”，也不是一开始就形成一个统一国家。

### 3. 联合过程：从行业合作到欧洲联盟

| 时间 | 组织或变化 | 记忆重点 |
| --- | --- | --- |
| 20世纪50年代初 | 法国、联邦德国等六国组建欧洲煤钢联营 | 以具体工业领域合作起步 |
| 1958年 | 六国建立欧洲经济共同体、欧洲原子能共同体 | 合作范围扩大 |
| 1967年 | 三个组织合并为欧洲共同体 | 简称欧共体 |
| 1993年 | 在欧共体基础上成立欧洲联盟 | 简称欧盟，一体化加快 |

**地图补充：** 1967年六国为法国、联邦德国、意大利、比利时、荷兰、卢森堡；1973年英国、爱尔兰、丹麦加入；1981年希腊加入；1986年西班牙、葡萄牙加入。先读图例，再按颜色和国家位置识别，不要把瑞典、挪威、瑞士等地图上出现的国家都当成当时成员。

英国在1973年加入的是欧共体，不是1993年才成立的欧盟。这个名称和年份的辨析，也能用于第22课“英国脱欧”的历史溯源活动。

### 4. 欧洲联合的作用

欧共体成员加强合作，西欧经济持续繁荣，国际地位逐渐提高，努力在国际舞台用一个声音说话；欧盟成立加快欧洲一体化进程。

**理解：“一个声音”** 表示协调立场、争取更大共同影响，不代表每个议题都没有内部差异。欧洲联合对多极化有推动作用，可与第20课联系，但不能因此说美欧在所有领域都不存在合作或分歧。

### 5. 莫内材料研读

莫内希望在新基础上建立法德关系，把为战争服务的工业转化为造福人民的事业，认为欧洲分裂使欧洲丧失发挥作用的可能。

**参考解释：** 法德应摒弃长期对抗，通过煤钢等领域合作把战争资源转为和平建设力量；欧洲国家加强联合，能促进共同发展、减少冲突、提高国际地位。作答应从材料中的“法德关系—工业转向—欧洲作用”三层展开。

## 三、美国与日本的经济发展

### 1. 美国战后经济发展的阶段

第二次世界大战后，美国积极拓展世界市场，应用最新科技、革新生产技术，促进经济快速发展。20世纪七八十年代，美国经济发展速度放缓；20世纪90年代，大力发展信息产业。

到90年代末，以信息为主导的服务业已占美国国内生产总值四分之三，加之从经济全球化中受益，美国经济持续发展。

**理解辨析：** “增速放缓”不等于经济总量必然下降；“服务业占比高”不等于美国所有工业完全消失。教材数据限定在90年代末，不能改写成今日实时产业数据。

**因果链：** 科技成果应用和技术革新提高生产能力；世界市场扩展提供需求与收益；信息产业发展带动经济结构变化；全球化加强跨国联系。材料题可根据题目所给阶段选择原因，不能把90年代信息产业直接放到所有战后年份。

### 2. 美国占领日本与战后改革

战后美国单独占领日本，在日本推行非军事化和民主化改革，推动颁布“和平宪法”。《日本国宪法》宣示放弃战争和战争力量，因而被称为“和平宪法”。

**公布与施行辨析：** 本课脚注将1947年写作“颁布”；[日本众议院官方说明](https://www.shugiin.go.jp/internet/itdb_english.nsf/html/statics/guide/dietfun.htm)记载，宪法于**1946年11月3日公布、1947年5月3日施行**。本笔记区分这两个法律节点，避免与第4课混淆。

中华人民共和国成立后，美国出于冷战战略需要，积极扶持日本，试图遏制、封锁中国。**政策转向要放在冷战背景下理解**，不能把扶持仅解释为美国无条件希望帮助日本人民。

### 3. 日本经济迅速发展的因素

- **改革条件：** 战后非军事化、民主化改革改变部分旧制度。
- **外部条件：** 美国出于冷战需要扶持日本；朝鲜战争爆发后，大量军需订单使日本较快摆脱战后困境。
- **国内政策：** 日本政府制定适当经济政策。
- **技术条件：** 大力引进先进技术，推动生产和经济发展。

**1968年，日本成为资本主义世界仅次于美国的第二经济大国。** 答题时保留“资本主义世界”限定，不能擅自改为不带范围的世界排名，也不能写成日本在政治或军事上都达到第二。

### 4. 经济发展与政治大国追求

20世纪七八十年代以来，随着经济发展，日本谋求政治大国地位的欲望增强，军费不断增加，引起亚洲邻国关注和不安。经济实力提高与政治影响诉求有关，但两者不是简单自动等号。

**教材相关史事：** 1951年日美签订安全保障条约，美国继续驻军日本；1956年日本与苏联恢复正常邦交并加入联合国；1960年日美签订新的安全保障条约，日本仍未改变对美国的军事依赖。

**图片理解：** 日本新干线1964年开始运营，教材介绍当时最高时速210千米。它可以作为技术应用和交通发展的例子，但不能用一张列车图直接证明全民生活水平或全部经济指标。

### 5. 西欧、美国、日本比较

| 地区或国家 | 共同点 | 本课突出特点 |
| --- | --- | --- |
| 西欧 | 运用科技、政策调整、拓展合作 | 战后重建、美国援助、走向联合 |
| 美国 | 科技和技术革新发挥作用 | 扩展世界市场，90年代发展信息产业 |
| 日本 | 科技引进、政策和外部条件重要 | 战后改革，美国扶持与军需订单 |

**概括方法：** 找共同点不能抹平差异；解释日本时可写军需订单，解释西欧时应强调马歇尔援助与区域联合，解释美国时不能说“依靠马歇尔计划受援”。

## 四、资本主义国家的社会生活

### 1. 社会保障制度的建立

战后西方主要资本主义国家为缓和社会矛盾，纷纷调整政策，逐步建立医疗保健、养老、住房、失业保险和教育等社会保障。

**典型节点：** 1948年英国宣布建成“福利国家”；法国、联邦德国等随后宣布成为“福利国家”；20世纪50年代美国多次修订《社会保障法》，扩大受益群体，提高最低工资，资助贫困学生。

**制度来源：** 教材强调社会保障制度的建立是人民群众斗争的结果。不能只写成政府领导人个人恩赐，也不能把所有国家的制度内容和建立年份一概相同化。

### 2. 积极作用与局限

**作用：** 调节收入分配不平等，提供基本生活保障，维持社会稳定，在缓和社会矛盾方面起一定作用。

**局限：** 增加政府开支，不可能解决资本主义制度的基本矛盾。既不能否定改善民生的实际作用，也不能把福利政策解释为社会制度性质已经改变。

**跨课理解补充：** 可联系第13课资本主义基本矛盾，理解政策调整为何不能从根本上消除制度矛盾。本课首先要求记住“改善保障与缓和矛盾，同时有财政负担和制度局限”。

### 3. “梯子”和“安全网”材料

“梯子”比喻通过个人努力改善生活、实现发展的机会与途径；“安全网”比喻社会保障，防止失业、疾病、年老等风险使人陷入生存困境。

**完整答法：** 社会应既鼓励个人劳动和进取，又提供基本保障；两者相互配合，有助于改善生活和维护稳定。不能把“安全网”说成让所有人不工作，也不能把“梯子”解释成政府取消保障。

### 4. 妇女地位的变化

19世纪末20世纪初，西方资本主义国家妇女开始获得选举权。战后随着受教育程度提高，妇女获得更多知识技能，独立意识增强，在现代社会几乎所有行业中发挥作用。

**教材相关史事：** 联合国1975年、1980年、1985年、1995年召开四次世界妇女大会，肯定妇女在经济社会发展中的作用，倡导提高教育和健康水平、消除性别歧视和妇女贫困、保护妇女人权。

**理解辨析：** 妇女地位提高是长期过程，不是所有国家同一年获得选举权；活动范围扩大也不意味着性别歧视和不平等已全部消除。

## 五、教材拓展：科学技术的新发展

20世纪四五十年代以来，人类在原子能、电子计算机、生物技术、航天技术等领域取得重大突破。

| 时间 | 教材列举的进展 |
| --- | --- |
| 1945年 | 第一颗原子弹在美国试爆成功 |
| 1946年 | 电子计算机“埃尼阿克”诞生 |
| 1953年 | 美英科学家建立DNA双螺旋结构模型 |
| 1957年 | 苏联发射第一颗人造地球卫星 |
| 1961年 | 苏联发射第一艘载人飞船 |

科技提高社会生产力，加速战后世界经济恢复发展，深刻改变生产和生活。**技术应用需要具体说明：** 计算技术可用于信息处理，航天技术改变人类探索空间能力；这些解释属于理解辅助，不要把所有发明都归属美国或日本。

“埃尼阿克”的技术先驱地位按教材识记即可，若进一步比较不同种类早期计算机，需要先限定电子、数字、通用、可编程等标准，避免脱离定义争论“第一”。

## 六、时间线与易错辨析

**1947年日本“和平宪法”施行 → 1948年英国“福利国家” → 50年代初煤钢联营 → 1958年两个共同体 → 1967年欧共体 → 1968年日本资本主义世界第二经济大国 → 1993年欧盟。**

- 欧共体不是欧盟，三个组织合并为欧共体在1967年。
- 欧洲联合是区域合作，不等于北约军事联盟。
- 西欧与日本受美国支持的形式和背景不能完全互换。
- 社会保障发展与资本主义基本矛盾仍存在，可以同时成立。
- 妇女社会参与扩大与仍需争取平等，也可以同时成立。

## 七、常见简答题

**1. 战后西欧经济迅速发展的原因是什么？** 原有工业基础、马歇尔计划援助、采用先进科技、制定恰当政策；后来成员国加强合作也促进持续发展。

**2. 欧洲为什么联合，有何影响？** 吸取战争教训、重振经济与提高国际地位，需要联合自强。联合改善法德等国关系，促进经济繁荣和国际影响，欧盟成立加快一体化。

**3. 战后日本经济迅速发展为什么不能只归结为美国帮助？** 美国扶持、军需订单是重要外部因素，战后改革、适当政策与引进先进技术等国内条件同样重要，应综合分析。

**4. 如何评价“福利国家”？** 它扩大社会保障，调节收入分配、维持稳定，是人民斗争的重要成果；但增加财政负担，不能从根本上解决资本主义基本矛盾。
