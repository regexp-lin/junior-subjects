# 第19课 亚非拉国家的成长｜主要知识点

> **所属单元：** 第五单元·第二次世界大战后的世界变化。  
> **教材依据：** [本课教材PDF](./19_第19课_亚非拉国家的成长.pdf)，教材书面第102—107页。  
> **使用说明：** 依据本课正文、图表、材料和课后活动整理；“理解辨析”用于建立联系，“教材拓展”按教材拓展栏目识记，二者不代替正文结论。

## 一、课时主线

**战后民族解放高涨 → 万隆会议与区域合作增强 → 非洲国家大批独立 → 拉美争取真正自主、收回主权 → 殖民体系崩溃，发展中国家成为重要国际力量。** 独立之后仍有巩固主权、发展经济与社会平等的任务。

## 二、万隆会议与东盟

- 背景：新独立国家面临巩固政权、发展经济的共同问题，反对冷战，不愿卷入大国军事冲突。
- **1955年4月，印尼万隆，29个亚非国家和地区代表参加亚非会议。** 通过和平相处、友好合作十项原则，体现和引申和平共处五项原则。
- **万隆精神：** 团结合作、友好相处，共同反帝反殖，争取和巩固独立，维护世界和平。
- 周恩来提出**“求同存异”**，促进会议顺利进行；“同”在共同经历与反殖、独立、和平发展愿望，“异”在制度、意识形态等差别。
- 意义：首次没有西方殖民国家参加、由亚非国家自己处理事务的会议；标志发展中国家作为新兴独立政治力量登上国际舞台。
- **1967年东盟成立：** 印尼、泰国、菲律宾、新加坡、马来西亚在曼谷创建，促进地区经济、社会、文化发展及和平稳定。

## 三、非洲民族独立运动

| 时间 | 事件 |
| --- | --- |
| 1951年 | 利比亚宣布独立 |
| 1952年、1953年 | 埃及革命，次年共和国成立 |
| 1956年 | 纳赛尔宣布苏伊士运河国有化 |
| 1960年 | 17国独立，称“非洲年” |
| 1962年 | 阿尔及利亚摆脱法国殖民统治 |
| 1990年 | 纳米比亚独立，非洲殖民体系崩溃的重要标志 |

苏伊士运河连接**地中海与红海**。国家获得独立不等于立刻解决经济发展和社会不平等问题。

## 四、拉美维护国家主权

- 拉美许多国家早已独立，但仍受外国经济渗透、政治控制，美国将其视作“后院”。
- **1959年古巴革命胜利：** 卡斯特罗领导推翻美国支持的独裁政权，进行土地改革、没收美国垄断资本企业；后来走上社会主义道路。
- 巴拿马运河连接**大西洋与太平洋**。1977年巴美签约，取消美国永久占领特权；巴拿马逐步收回各项主权，**1999年底收回运河区全部主权**。
- 总体意义：大批新兴民族独立国家出现，延续数世纪的殖民体系崩溃，改变世界格局，发展中国家成为不可忽视的力量。

## 五、材料图表与拓展

- 两幅非洲地图：从大部分被殖民列强控制，变为独立国家广泛出现；看图例、年代，不把独立与经济发达混为一谈。
- 1960年联合国独立宣言强调人民自决，反对外国征服统治；殖民体系崩溃主要源于人民斗争，不能说是殖民国家主动恩赐。
- **教材拓展：** 南非反种族隔离斗争中，曼德拉及非国大作用重要；1990年获释，1991年废除种族隔离制度，1994年当选南非首位黑人总统。南非1961年成立共和国，不等于当时已实现种族平等。

## 六、简答与遮挡自测

**问：战后民族解放为什么迅速发展？** 答：殖民主义长期压迫激起人民反抗；二战削弱殖民帝国，民族觉醒和组织力量增强；新独立国家互相支持，国际反殖、自决原则和联合国相关行动提供有利环境。
