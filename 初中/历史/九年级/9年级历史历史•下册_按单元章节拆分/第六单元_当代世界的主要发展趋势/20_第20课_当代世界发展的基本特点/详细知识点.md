# 第20课 当代世界发展的基本特点｜详细知识点（背诵版）

> **所属单元：** 第六单元·当代世界的主要发展趋势。  
> **教材依据：** [本课教材PDF](./20_第20课_当代世界发展的基本特点.pdf)，教材书面第110—114页。  
> **使用说明：** 按本课正文、材料和活动整理；“理解辨析”“方法示例”是学习辅助，不冒充教材原文。组织成员数、经济数据均保留教材标明的统计年份。

## 一、先把四条线连起来

**世界多极化反映国际力量和政治格局的变化；经济全球化反映跨国生产、投资与贸易联系；社会信息化反映科技与社会生活的变化；文化多样性反映人类文明丰富而不同的历史创造。** 联合国与世贸组织是本课理解国际合作的两大重要组织。

四个特点不是彼此孤立的标签。经济与科技发展影响国家实力，国际力量变化影响合作规则，互联网促进经济和文化交流；这些变化又可能伴随安全、发展与文化保护方面的新问题。复习时既背概念，也能把事例放进相应的框架。

## 二、世界多极化与联合国

### 1. 冷战结束后的国际力量变化

两极格局消失后，美国成为唯一超级大国，企图建立以美国为主导的“单极世界”。教材以2003年伊拉克战争说明这一企图及其影响：美国以伊拉克拥有大规模杀伤性武器为借口发动战争，使中东局势进一步动荡，也给自身带来沉重包袱。

**教材相关史事：** 2001年9月11日，恐怖主义分子劫持美国客机，袭击纽约世界贸易中心双塔和五角大楼，另有一架坠毁，近3000人罹难。“9·11”说明恐怖主义的危害；不能将恐怖袭击与后来战争简单等同，也不能忽略教材对战争后果的评价。

与此同时，两极格局中已孕育的世界多极化趋势继续发展。所谓多极化，是多个重要力量在国际事务中的影响增强，国际力量关系趋于多元。它不是“所有国家实力完全相同”，也不是“世界已建立稳定、固定的多极格局”。

### 2. 多极化趋势继续发展的主要力量

| 力量 | 教材所列变化 | 理解重点 |
| --- | --- | --- |
| 欧盟 | 推进经济政治一体化，追求战略自主 | 联合增强成员在国际事务中的作用 |
| 俄罗斯 | 凭借军事力量与自然资源，致力于国家复兴 | 苏联解体后取代苏联在联合国的地位 |
| 日本 | 保持经济大国地位，谋求政治大国地位 | 经济实力与政治诉求相联系 |
| 中国 | 改革开放深化，综合实力增强，坚持和平发展 | 倡导建立新型国际关系 |
| 广大发展中国家 | 总体实力不断增强 | 成为推动多极化和多边外交的重要力量 |

教材统计有明确时点：欧盟到2022年有27个成员国；2010年中国经济总量跃居世界第二位；2023年中国经济总量超过126万亿元、稳居世界第二位。**这些是特定年份资料，答题时保留年份，不能改成无时间限制的“最新数据”。**

**“想一想”答题：** 冷战后多极化为何继续发展？可从欧盟联合增强、俄罗斯复兴、日本谋求更大作用、中国和发展中国家实力提升等方面回答，概括为国际力量对比变化、多个重要力量发展，对单一力量主导世界形成制约。

### 3. 联合国的成立、性质与机构

- **成立：** 1945年10月。
- **性质：** 世界上最大的主权国家政府间国际组织。
- **地位：** 人类构建世界和平与安全的成果，多边主义的旗帜；以联合国为中心的国际多边架构是国际合作的重要平台。
- **主要机构：** 联合国大会、安全理事会、秘书处等。
- **安理会组成：** 5个常任理事国、10个非常任理事国。常任理事国为中国、法国、英国、美国、俄罗斯，拥有否决权。

到2023年联合国有193个会员国。教材脚注指出，非常任理事国最初为6个，1965年增至10个。机构数量、成员数量、会员国数量对应不同概念，不能混记。

### 4. 首要宗旨与维和作用

《联合国宪章》材料的第一项宗旨是**维护国际和平与安全**。为此，可采取集体办法防止和消除对和平的威胁，制止侵略，并以和平方法、依正义和国际法原则处理争端。

答“首要宗旨”写核心短句即可；答“如何实现”再结合集体行动、和平解决争端等内容展开。不要只摘录材料中的一个手段来代替总目标。

1956年，联合国创建维持和平部队，简称维和部队，因佩戴蓝色头盔或贝雷帽而称“蓝盔部队”。根据安理会或联大的决议，联合国可以向冲突地区派遣维和部队，阻止局部冲突扩大，防止冲突再起，帮助受害平民。

**教材相关史事：** 从1948年开始，联合国已开展70多项维和行动；中国1989年首次参加维和行动，1992年首次派出成建制“蓝盔部队”。到2022年，中国累计派出维和人员5万余人次，参加近30项维和行动，是派遣维和人员最多的安理会常任理事国。这里“维和行动开始”和“维和部队创建”是两种表述，不能强行合并为同一个年份。

**图像理解：** 联合国旗帜以浅蓝色为背景，世界地图由橄榄枝相托，象征和平；中国维和官兵获“和平荣誉勋章”的图片，可以用来说明中国参与联合国维和、承担维护和平的责任。

## 三、经济全球化与世界贸易组织

### 1. 经济全球化增强的背景与表现

20世纪八九十年代以来，世界局势趋于缓和，各国把发展经济作为首要任务；生产力和科技水平提高，国家间经济联系日益紧密，经济全球化趋势加强。

主要表现是跨国公司影响日益增大，国际投资与国际贸易迅速增长。进入21世纪，以互联网和人工智能等为代表的新一轮科技发展继续推动全球化，使其成为强劲的历史潮流。

**理解辨析：** 全球化并非一个国家同几个国家做生意的简单加总，而是生产、投资、贸易等跨国联系更加广泛和深入。可用跨国企业采购、跨境投资、商品全球流通等例子帮助理解，但这些生活示例属于解释概念，不是教材逐项列举的必背结论。

### 2. 世贸组织的成立、宗旨与职能

| 项目 | 课内知识 |
| --- | --- |
| 成立 | 1995年 |
| 原则 | 非歧视性、开放、公平等 |
| 宗旨 | 促进全球贸易和经济发展，提高人类生活水平 |
| 主要职能 | 制定和规范多边贸易协定、组织贸易谈判、解决贸易争端 |
| 中国加入 | 2001年 |
| 中国立场 | 坚定维护以世贸组织为核心的多边贸易体制 |

到2021年世贸组织缔约方达到164个。教材脚注补充，其总部在日内瓦，前身是关税与贸易总协定。背主干先掌握成立时间、职能与中国加入，前身与总部作为教材补充识记。

### 3. 全球化进程中的波折

在经济全球化不断发展的同时，世界经济风险和不确定性增加；逆全球化思潮抬头，单边主义、保护主义明显上升；经济失控风险加剧，地区经济危机可能引起世界性波动。

**分析时要兼顾两面：** 全球化扩大经济联系和发展机会，也加强风险传导。出现波折不等于全球化已经终止；强调历史潮流也不意味着各国所得利益完全相同、没有矛盾和风险。

### 4. 教材相关史事：区域经济一体化

欧盟是经济一体化程度较高的区域组织；东盟以经济合作为基础，推进东南亚地区政治、经济、安全一体化合作；北美自由贸易区由美国、加拿大、墨西哥组成；亚太经合组织是亚太地区的重要经济合作论坛和合作机制。

教材以2010年建成中国—东盟自由贸易区为案例。**理解辨析：** 区域一体化发生在一定区域，经济全球化面向跨区域、全球联系；两者可以同时发展，不能把区域组织成员数当作全球组织成员数。上述名称与数据应按教材的历史语境使用。

## 四、社会信息化和文化多样性

### 1. 社会信息化：动力、变化与问题

20世纪60年代以来，信息技术快速发展，互联网应用加速普及，对人类社会产生深刻影响。网络信息技术日益成为创新驱动发展的先导力量，推动劳动力、资本、能源、信息等要素流动和共享，推动生产力新的质的飞跃。

互联网提高了人类认识和改造世界的能力，把世界变成“地球村”，国家间相互依存、相互影响的程度加深；人们享受更加丰富的现代生活，同时信息安全问题日益凸显。

**课后活动示例：** 学习中可在线检索文献、共享课程和远程交流；生活中可网上购物、线上办事、远程沟通。解释影响时应形成“技术应用—具体变化—相应问题”的链条，例如信息获取更快，但还需要判断信息真伪和保护个人信息。这是生活化理解，不是要求照搬的固定答案。

### 2. 文化多样性：意义与态度

当今世界有200多个国家和地区、2500多个民族、6000多种语言；不同历史文化背景的人们共同创造了多样的世界文化。

文化多样性是世界文化创新与交流的源泉，是民族平等和保障人权的基础，也是人类文化不断进步的重要动力。经济全球化和社会信息化使文化交流更广泛，也给文化多样性带来前所未有的挑战。

中国在传承中华优秀文化的同时，尊重世界文化多样性，促进不同文化之间的交流互鉴。教材以2019年亚洲文明对话大会及亚洲文化嘉年华说明文明交流。

**理解辨析：** 维护本民族文化与学习其他文明可以相互促进；文化交流不等于以一种文化代替其他文化。评价文化时避免把自身习惯简单当作衡量所有文明的唯一标准。

## 五、教材拓展：不结盟运动与七十七国集团

**不结盟运动：** 冷战发生后，一些国家为维护国家独立、摆脱美苏控制，实行和平、不结盟的对外政策。1961年正式成立，一定程度上影响了两极格局。到2024年有121个成员，绝大多数是发展中国家。中国是不结盟运动观察员国。

**七十七国集团：** 1964年第一届联合国贸易和发展会议上，77个发展中国家和地区的代表发表共同宣言，要求建立新的、公正的国际经济秩序。到2022年有134个成员，名称保持不变。中国与该集团保持良好合作关系。

两者可联系“发展中国家在国际事务中作用增强”，但一个强调维护独立和不结盟，一个更突出国际经济秩序与发展利益，不要相互替换。

## 六、时间线与易错辨析

| 时间 | 事件 |
| --- | --- |
| 1945年10月 | 联合国成立 |
| 1956年 | 联合国创建维和部队 |
| 1961年 | 不结盟运动正式成立 |
| 1964年 | 七十七国集团形成 |
| 1995年 | 世贸组织成立 |
| 2001年 | 中国加入世贸组织；发生“9·11”事件 |
| 2003年 | 美国发动伊拉克战争 |

课后判断题依次为：**正确、错误、正确、正确。** 第二项应改为“安理会常任理事国拥有否决权”。此外，要区分政治多极化、经济全球化与文化多样性；既不能用经济总量直接等同全部国家实力，也不能把国际组织理解成取代主权国家的世界政府。

## 七、常见简答题

**1. 为什么冷战后多极化趋势继续发展？** 欧盟、俄罗斯、日本、中国和广大发展中国家等力量发展，国际力量对比不断变化；多个重要力量在国际事务中的作用增强，推动国际关系向多极化发展。

**2. 联合国在维护和平方面有什么作用？** 以维护国际和平与安全为首要宗旨，提供国际合作平台，推动以和平方法解决国际争端，并根据决议开展维和行动，阻止冲突扩大、防止冲突再起、帮助受害平民。

**3. 概括世贸组织的作用。** 依据非歧视性、开放、公平等原则，制定和规范多边贸易协定、组织谈判、解决贸易争端，促进全球贸易和经济发展、提高人类生活水平。

**4. 怎样看待全球化中的逆流？** 全球化由生产力、科技进步和跨国经济联系推动，是历史潮流；但单边主义、保护主义与危机风险使其出现波折，需要通过国际合作应对。

**5. 应如何对待文化多样性？** 认识其是文明进步的重要动力，传承本国优秀文化，尊重文化差异，促进不同文化平等交流、相互借鉴。
