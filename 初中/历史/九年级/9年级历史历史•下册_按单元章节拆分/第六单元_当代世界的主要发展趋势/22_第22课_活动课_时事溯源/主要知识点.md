# 第22课 活动课 时事溯源｜主要知识点

> **所属单元：** 第六单元·当代世界的主要发展趋势。  
> **教材依据：** [本课教材PDF](./22_第22课_活动课_时事溯源.pdf)，教材书面第121—122页。  
> **使用说明：** 按本课正文、材料和活动整理；“理解辨析”“方法示例”是学习辅助，不冒充教材原文。组织成员数、经济数据均保留教材标明的统计年份。

## 一、活动主线

**选择时事 → 提出问题与确定历史视角 → 搜集、核验资料 → 建立时序和知识图谱 → 分析历史与现实的联系 → 形成报告、交流答辩 → 持续跟踪。** 本课重点是研究方法，不是背诵一场事件的固定结论。

## 二、活动目标与任务

- 了解时事与相关史事的关联，分析历史渊源，提高分析能力。
- 运用历史知识，客观、理性解释时事及其影响，初步掌握从历史发展视角看现实问题的方法。
- 查阅、分析资料，得出结论并清楚表达；分组合作完成任务。
- 选择自己感兴趣、最近发生的时事，在教师指导下确定主题和视角，搜集报道与评论，制作知识图谱，联系相关史事并分享认识。

## 三、按教材开展分工

| 小组 | 主要工作 |
| --- | --- |
| 历史组 | 搜集报道，梳理时事时序，查找史料，分析时事与历史事件联系 |
| 道德与法治组 | 运用政治、经济、法律知识解释时事发生和发展趋势 |
| 地理组 | 绘制时事及相关史事的地理示意图，解释地理因素 |

各组先制定计划、明确分工，再讨论辨驳、形成报告，准备班级报告会和答辩；随后跟踪新闻，制作系列手抄报。

## 四、资料甄别与因果分析（方法补充）

1. 为每条资料记录作者或机构、标题、发布日、链接或页码；区分事件发生日与报道日。
2. 优先查原始文件、权威机构资料和可靠报道，多源核验；报道事实、评论观点和小组推论分别标记。
3. 时间先后不自动等于因果；从历史、政治、经济、地理等方面分析，避免只找一个原因。
4. 不确定之处写“待核实”，不要补造人物言论、统计数字或采访。

## 五、教材案例：英国脱欧

教材以英国脱欧说明“当时的时事会成为历史”：**2016年公投决定脱欧，2020年1月底正式脱欧**。由此可追问：英国何时加入欧盟前身欧共体？为什么退出？为什么法案由女王批准？

**方法示例：** 第一个问题联系欧洲一体化，第二个需查政治、经济、社会等多方面资料，第三个联系英国君主立宪制度。不同问题所需证据不同；教材提出问题并不代表已给出全部答案。

**使用边界：** 脱欧是教材的历史案例，不是把它冒充今天新发生的新闻。正式活动应另选真实近期事件并核实日期；暂未选定时，可以用教材案例演练研究步骤。

## 六、展示与评价（方法补充）

报告应有题目、核心问题、事实摘要、历史时间线、资料证据、解释、结论和来源。评价看问题是否明确、史实是否准确、证据是否可靠、解释是否多角度、表达是否清楚、合作是否落实；同学质疑时回到证据回答。

**简答：时事溯源有什么意义？** 能理解历史与现实的联系，对现实热点进行冷静思考，更客观理性地认识现实，领悟历史学习的意义。

## 七、遮挡自测

1. 时事溯源应先定结论还是先提问题？
2. 三个学科小组分别负责什么？
3. 为什么不能把先后关系直接当成因果？
4. 报告中怎样处理未核实信息？

1. 先选择时事、提出问题，再搜集分析证据得出结论。
2. 历史组梳理时序与渊源；道法组分析政治经济法律；地理组绘图并解释地理联系。
3. 两件事前后发生不一定有因果，还要证明相互作用的具体机制。
4. 标记待核实，不作为确定结论依据，不编造补齐。
