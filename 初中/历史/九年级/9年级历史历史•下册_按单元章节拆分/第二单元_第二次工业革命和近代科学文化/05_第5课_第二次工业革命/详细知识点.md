# 第5课 第二次工业革命｜详细知识点（背诵版）

> **所属单元：** 第二单元：第二次工业革命和近代科学文化。  
> **教材依据：** [本课教材 PDF](05_第5课_第二次工业革命.pdf)，教材第24—28页，含正文、人物扫描、恩格斯材料、内燃机表、交通工具图像、课后比较表与德国发展拓展。  
> **使用说明：** “课内必背”记成就与影响，“理解辨析”解释联系；不将未核实的具体专利日期、企业数据作为课内史实。

## 一、先背主线

**主要资本主义国家经济快速发展，科学研究取得重大进步 → 19世纪六七十年代第二次工业革命开始 → 科学研究与技术革新结合更紧密 → 电力广泛应用、内燃机与新交通工具出现、化工与新材料发展 → 生产力和生活发生巨大变化 → 工业强国成长、垄断形成、帝国主义扩张加速。**

用三条技术线和一条社会线记忆：**电—电气时代；内燃机—交通和石油；化工—材料和产品；生产力—垄断—对外扩张。**不能仅把本课当作发明家名单，要从技术、产业、生产组织和社会影响串联理解。

## 二、课内必背：开始背景与特点

### 1. 时间和背景

随着第一次工业革命展开，主要资本主义国家经济快速发展，科学研究也取得重大进步。**19世纪六七十年代，第二次工业革命开始。**

经济发展为技术应用提供条件与需求，科学进步提供知识基础。1831年法拉第发现电磁感应早于第二次工业革命开始，说明科学发现到大规模工业应用之间有发展过程，不能将某项先导发现的年份当作整个工业革命起点。

### 2. 核心特点

**科学研究与技术革新更紧密地结合。**人们根据科学原理研发设备，再通过工程改进、生产与推广使其走进工厂和家庭。

“更紧密”是相对第一次工业革命而言，并非第一次没有科学、第二次不需要实践。爱迪生把新科学发现用于发明，法拉第的电磁感应成为发电技术依据，都是教材中的例证。

## 三、课内必背：电的应用

### 1. 电磁感应与发电机

导入介绍：**1831年英国科学家法拉第**通过实验发现电磁感应现象，并制作简易发电机。人们据此发明、改进早期发电机；到**19世纪70年代**，不断完善的发电机进入生产领域，电力成为新的动力来源。

**最显著成就：电力成为新的能源进入生产生活领域。**复习要将“发现原理—发明设备—改进应用—社会普及”四步分清，不能说法拉第一次实验后全世界立即电气化。

### 2. 爱迪生的贡献

美国人**爱迪生发明耐用白炽灯泡**，并在纽约建立美国第一座火力发电站。发电站供能促进电灯广泛使用，说明技术普及不仅需要单件产品，还需要能源供应等配套。

人物扫描突出他善于思考、不断追问、把科学发现用于发明，拥有1000多项发明专利权，尤其注重商业推广。教材强调的是“耐用白炽灯泡”和实践推广，不宜把它改写为他最先发现电、独自发明所有电器。

### 3. 电力应用的领域与时代

在各国发明家共同努力下，电焊机、电钻、电报、电话、电车等纷纷问世。可按功能记忆：**生产工具、通信手段、交通工具、生活照明**。

人类社会进入“**电气时代**”。这表示电力在生产生活中作用显著增强，不等于蒸汽机、煤炭或其他动力立即淘汰，也不是“电子计算机时代”。注意“电气”与后来电子信息技术发展阶段不同。

### 4. 恩格斯材料如何理解

材料将蒸汽机把热转化为机械运动，与电使多种能量形式转化并用于工业相联系，预言生产力将大发展。

答案应分层：**电拓宽能量转化和应用方式 → 提供新动力并改造生产技术 → 带动照明、通信、交通等领域 → 推动生产力发展。**材料讨论的是技术能力和工业利用，不是说能量可以无中生有，也不是仅赞美某一个电器。

## 四、课内必背：内燃机和新的交通工具

### 1. 内燃机的发展表

内燃机是应用技术领域的另一项重大成就。短短20多年，驱动能源由煤气转向汽油、柴油。

| 年份 | 发明者 | 国籍 | 内燃机种类 |
| --- | --- | --- | --- |
| 1876年 | 奥托 | 德国 | 煤气内燃机 |
| 1883年 | 戴姆勒 | 德国 | 汽油内燃机 |
| 1897年 | 狄塞尔 | 德国 | 柴油内燃机 |

记忆时将**时间—人物—燃料**配对，不能把戴姆勒写成柴油机发明者。内燃机与蒸汽机属于不同技术路线，本课重点在其成为新型交通工具发动机，不必背未经教材核实的内部结构细节。

### 2. 汽车发明与福特流水线

**19世纪80年代，内燃机驱动的汽车出现。**教材图片是德国人**卡尔·本茨**发明的世界第一辆内燃机汽车复制品。

**1913年，美国福特汽车公司使用流水线生产汽车**，带来汽车制造业革命，汽车价格大幅下降，越来越多家庭拥有汽车。

区分两类创新：**本茨对应产品发明，福特对应生产方式革新。**流水线通过分工与连续作业提高生产效率，有利于降低成本，推动产品普及。这是对教材“价格下降”的理解，不能写成福特发明了第一辆汽车。

### 3. 飞机及中国航空探索

**1903年12月17日，莱特兄弟**在美国北卡罗来纳州试验飞机，发动机驱动螺旋桨，使飞机滑行并升空。教材把它列为内燃机应用与交通变革的重要实例。

此后中国人**冯如**刻苦钻研，制造飞机并获得国际比赛大奖，被誉为“中国始创飞行大家”。复习中应看到多国探索者的共同努力，不能把新技术发展只理解成单一国家的独立创造。

### 4. 交通与产业的连锁变化

内燃机驱动的汽车、轮船、拖拉机、飞机等，为生产生活带来极大便利。可理解为：扩大活动范围、提高运输效率，有利于人员物资交流和生产组织。

**内燃机需求增大 → 汽油、柴油等燃料需求增长 → 石油开采业发展 → 石油化学工业产生加速。**这条链说明某项发明会带动相关产业，并非交通工具改变只影响出行。

**联系上册（辨析）：** 第一次工业革命已有蒸汽轮船，第二次出现或发展以内燃机为发动机的轮船；不能笼统说人类在第二次工业革命才第一次拥有轮船。

## 五、课内必背：化学工业和新材料

### 1. 现代化学工业发展

现代化学工业的产生是应用技术领域的重要突破。19世纪60—80年代，已能用新方法生产**碱、硫酸、人造染料**等，产品成本更低、性能更好。

这既扩大产品种类，也改进生产成本与性能，说明技术革新并非只有大型机器和交通工具，还包括原料、材料与生产工艺变化。

### 2. 现代炸药、塑料、人造纤维

- **1867年，瑞典人诺贝尔发明现代炸药。**
- **1869年，现代塑料工业诞生。**
- **1884年，人造纤维问世，开辟新的纺织品生产领域。**

注意时间和成果对应，不能把人造纤维混同于人造染料。塑料与纤维提示人类通过化学技术获得新材料，不只依赖传统天然材料。

### 3. 诺贝尔与诺贝尔奖

诺贝尔既是化学家、工程师，也是实业家。他为避免实验危及他人，曾到湖中船上做炸药试验；其发明在军事、工程等方面应用。

依据遗嘱，他的大部分财产用于奖励基金，奖励在**物理学、化学、生理学或医学、文学及和平**等方面对人类作出杰出贡献者，形成诺贝尔奖。可由此理解科学创新、应用后果与社会责任的联系；不能把奖项名称反过来当作他本人的全部研究领域。

## 六、课内必背：第二次工业革命的影响

### 1. 生产力和生活

促进生产力发展，极大改善生活。新动力推动生产，新交通通信缩短距离，照明和新产品改变生活，流水线改进生产效率。举例时每类提供一项即可，避免只写“科技先进”而无具体证据。

### 2. 主要资本主义国家与垄断

主要资本主义国家迅速发展，成为工业强国。在经济发展基础上出现**垄断组织**，自由资本主义向**垄断资本主义，即帝国主义**过渡。

**理解概念：** 垄断组织可理解为少数大企业或企业联合加强对某些生产、市场领域的控制。教材重点是资本主义发展阶段变化，不能把“帝国主义”只按字面理解为建立君主帝国，也不能写成资本主义制度被另一种社会制度取代。

### 3. 对世界的影响

帝国主义国家加速对外扩张，对世界产生深远影响。工业技术和国力增强，一方面推动经济联系，另一方面也被用于扩大侵略和争夺，不能把“生产力进步”直接等同于所有地区、所有群体都同样受益。

**与第6课衔接：** 本课重在发明与产业、资本主义发展，第6课进一步讨论人口、教育、城市和环境、贫富分化。评价工业革命时应兼顾创造财富和社会问题，不能只列积极成就。

## 七、两次工业革命比较表

| 比较项目 | 第一次工业革命 | 第二次工业革命 |
| --- | --- | --- |
| 标志或最显著成就 | 蒸汽机的改进及应用 | 电力广泛进入生产生活 |
| 代表产业 | 纺织业、采煤业等 | 电气、汽车制造、化学工业等 |
| 技术基础特点 | 生产经验积累发挥重要作用 | 科学研究与技术革新更紧密结合 |
| 主要时代特征 | 蒸汽时代 | 电气时代 |
| 交通实例 | 蒸汽机车、蒸汽轮船 | 内燃机汽车、飞机等 |

**共同点：** 都推动生产技术革新、生产力提高和社会生活变化。**区别：** 新动力、重点产业和科技结合程度不同。回答比较题尽量使用同一角度对照，不能一边写年份、另一边写人物。

“第一次只凭经验、第二次完全不需经验”是绝对化表述；“第二次以电为显著标志”也不能抹去内燃机和化工成就。

## 八、教材拓展：工业革命和德国发展

第一次工业革命时，德意志尚分裂割据，经济落后于英法。**1864—1871年**，俾斯麦推动普鲁士通过三次战争完成统一，建立首都柏林的德意志帝国。

统一后德国抓住第二次工业革命机遇，电气、汽车制造和化学工业蓬勃发展，到19世纪末成为仅次于美国的世界第二大工业国。理解为：**统一提供国家条件，抓住技术产业变革机会促进跨越发展。**不能仅用单一发明解释德国崛起，也不能把三次战争当作工业革命本身。

## 九、时间线与易错辨析

| 时间 | 成就或事件 |
| --- | --- |
| 1831年 | 法拉第发现电磁感应 |
| 19世纪六七十年代 | 第二次工业革命开始 |
| 1867年 | 诺贝尔发明现代炸药 |
| 1869年 | 现代塑料工业诞生 |
| 1876年 | 奥托煤气内燃机 |
| 1883年 | 戴姆勒汽油内燃机 |
| 1884年 | 人造纤维问世 |
| 1897年 | 狄塞尔柴油内燃机 |
| 1903年 | 莱特兄弟试验飞机 |
| 1913年 | 福特汽车公司使用流水线 |

易错点：①法拉第发现电磁感应，不是爱迪生；②本茨发明汽车，福特革新生产；③第二次工业革命在19世纪开始，不是1903年才开始；④电力与内燃机是两类主要成就；⑤经济组织变化是垄断形成，而非所有竞争消失。

## 十、常见简答题

**1. 第二次工业革命有哪些主要成就？**  
答：电力广泛用于生产生活；内燃机出现并带动汽车、飞机等交通工具；现代化学工业和炸药、塑料、人造纤维等新产品、新材料发展；生产方式也有流水线等创新。

**2. 为什么说科技与生产联系更紧密？**  
答：电磁感应原理推动发电机研制和电力应用，爱迪生把科学发现用于发明与推广，科学知识通过技术革新转化为生产能力，体现研究、发明与产业应用的结合。

**3. 怎样概述其影响？**  
答：促进生产力和生活改善，推动主要资本主义国家成为工业强国；出现垄断组织，资本主义向帝国主义阶段过渡，帝国主义国家加速对外扩张，对世界产生深远影响。
