# 第13课 资本主义经济大危机｜主要知识点

> **所属单元：** 第四单元·资本主义经济大危机和第二次世界大战。  
> **整理依据：** [本课教材PDF](./13_第13课_资本主义经济大危机.pdf)，教材书面第68—72页；课内重点与理解辨析、教材拓展分开掌握。

## 一、课时主线

**20世纪20年代繁荣掩盖基本矛盾 → 购买力不足、生产过剩与股票投机 → 1929年美国股市崩溃，危机扩散 → 胡佛自由放任使危机加剧 → 1933年罗斯福新政加强国家干预 → 经济缓慢复苏，但资本主义根本矛盾未解决。**

## 二、从繁荣到危机

- **根本矛盾：** 生产社会化与生产资料资本主义私人占有之间的矛盾。
- **具体原因：** 生产力和企业利润增长，工人工资增长缓慢，购买力严重不足，导致生产过剩；分期付款刺激消费；股票投机使股价狂涨，金融市场失控。
- **开端：** 1929年10月24日，美国股票价格急剧下跌，“黑色星期四”成为经济大危机开端。
- **表现：** 企业破产、银行倒闭、生产贸易萎缩、大量失业。美国1929—1933年工业产量下降超过40%，贸易额减少70%，1500万—1700万人失业。
- **特点：** 波及范围广，持续时间长，破坏性大；到1933年资本主义世界工业产量下降超过1/3，贸易总额减少2/3，失业超过3000万。
- **影响：** 人民生活困苦、社会矛盾激化，动摇资产阶级统治；各国争夺市场、提高关税，国际矛盾加剧。

## 三、罗斯福新政

**1933年罗斯福就任总统，采用国家干预手段扭转经济形势。**

| 方面 | 主要措施 |
| --- | --- |
| 金融 | 《紧急银行法案》，整顿银行、恢复信用 |
| 工业 | 《全国工业复兴法》，公平竞争法规、协调企业、最低工资、限制工时；《全国劳工关系法》维护部分工人权益 |
| 农业 | 《农业调整法》，调节生产销售、限制产量、稳定价格 |
| 就业 | “以工代赈”，兴建公共设施，提供工作机会 |
| 保障 | 《社会保障法》，建立保障制度、应急救济机构，救济失业家庭 |

**典型项目：** 田纳西水利工程属于政府投资公共工程，是“以工代赈”的例子。

## 四、新政评价

- **积极作用：** 经济缓慢复苏，工业生产有所恢复，生活改善，人民信心一定程度恢复；改革某些弊病，增强政府宏观调控能力，对资本主义世界影响深远。
- **性质与局限：** 在维护资本主义制度前提下的政策调整，没有改变资本主义本质，无法解决美国社会根本矛盾。
- **“新”的关键：** 政府由放任转向加强干预和调控，而非建立社会主义制度。

## 五、图表、材料与易错点

- 美国国民生产总值图显示1929年1039亿美元、1933年560亿美元，之后恢复但有波动，说明危机严重且复苏并非立即完成。
- 罗斯福“使人民有工作”材料体现政府直接组织公共工程，以就业救济并促进恢复。
- “生产过剩”是相对有支付能力需求的过剩，并非人人已得到足够商品；销毁商品与穷人挨饿并存正说明这一点。
- **教材拓展：** 华尔街位于纽约，集聚金融机构，成为金融中心象征。

## 六、常见简答与遮挡自测

**问：如何理解新政的3R？** 恢复针对经济生产和金融信用，救济针对失业与贫困，改革针对金融、劳资关系和社会保障等制度，三者相互联系。

2. 新政开始于何时？
3. “以工代赈”是什么意思？
4. 新政为何不能根除经济危机？
