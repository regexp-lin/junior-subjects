# 第3课 美国内战｜详细知识点（背诵版）

> **所属单元：** 第一单元：殖民地人民的反抗与资本主义制度的扩展。  
> **教材依据：** [本课教材 PDF](03_第3课_美国内战.pdf)，教材第15—18页，含正文、人物扫描、战争地图、葛底斯堡相关史事、黑人备忘录、课后日记材料与领土扩张拓展。  
> **使用说明：** 史实与理解辨析分开；课外未核实的具体统计、战役不列入必背。

## 一、先背主线

**美国独立后发展并扩张 → 北方资本主义工商业与南方奴隶制种植园经济发生矛盾 → 奴隶制存废成为焦点 → 林肯当选后南方分裂联邦、挑起战争 → 北方初期失利 → 1862年两项法令调动民众 → 北方获胜，维护统一、废除奴隶制 → 资本主义发展障碍进一步清除，但种族歧视继续存在。**

可用五组词复述：**经济矛盾、分裂与统一、法令与群众、战争与制度、自由与平等。**教材要求从制度和经济理解战争，不应只按战役顺序记忆。

## 二、课内必背：南北矛盾与内战爆发

### 1. 美国独立后的发展

独立后，美国经济迅速发展、领土不断扩张。到19世纪中期，已成为东临大西洋、西濒太平洋的工业大国。随着西部领土增加，南北在新州采取什么制度上的争论日益激烈。

导入说明：19世纪50年代末南方约有400万黑奴，其中约60%在种植园劳动，种植园主可任意惩罚、买卖甚至杀害奴隶。北方反奴隶制民众组织废奴社，借“地下铁道”网络帮助奴隶逃亡。**“地下铁道”在此指秘密援助网络，不能按字面理解成地下铁路工程。**

### 2. 南北两种经济类型与不同主张

| 比较角度 | 北方 | 南方 |
| --- | --- | --- |
| 主要经济类型 | 资本主义工商业 | 使用黑奴劳动的种植园经济 |
| 劳动力与奴隶制 | 要求废除奴隶制，增加自由劳动力 | 维护并扩大奴隶制，控制黑人劳动 |
| 对外贸易与关税 | 要求提高关税，抵制外国商品输入 | 要求降低关税，换取英国廉价工业品 |
| 棉花等原料 | 工商业发展有相应需求 | 主张扩大原料出口 |
| 西部新增土地 | 主张建立自由州 | 力图建立新的蓄奴州 |

**根本原因（理解归纳）：** 南北经济类型不同，奴隶制成为资本主义进一步发展的障碍，双方利益矛盾越来越尖锐。

**矛盾焦点：奴隶制的存废，尤其是否向西部新增地区扩展。**关税和新州问题不是相互无关的争吵，都体现经济利益及奴隶制问题。答根本原因时要讲制度、经济矛盾，答导火线则写林肯当选，二者不能互相替代。

### 3. 林肯当选与南方分裂

**1860年，林肯当选美国第16任总统。**他主张限制奴隶制发展，南方奴隶主以此为借口发动战争。南方7州宣布退出联邦，成立“南部同盟”，后来又有4州加入。

人物扫描介绍，林肯出身贫困，靠勤奋自学成为律师和议员；同情奴隶、痛恨奴隶制，起初希望通过和平方法逐步限制、最终废除奴隶制。战争爆发后废奴立场逐渐坚定。

**辨析：** 林肯当选是矛盾激化的触发事件，不是南北矛盾的根源；他并非上台时就宣布立即武力解放全国所有奴隶。应把个人政策放在南北长期矛盾与战争变化中理解。

### 4. 战争爆发及双方目标

**1861年4月，南方军队挑起战争。**林肯为维护国家统一，命令北方军队迎战，美国内战爆发，史称“南北战争”。

南方试图脱离联邦以维护奴隶主利益，北方维护统一，并在战争中把废除奴隶制与战争目标结合。不能将其说成两个独立国家之间的普通对外战争，也不能写成林肯主动挑起分裂。

## 三、课内必背：北方的胜利

### 1. 战争初期北方为何被动

南方蓄谋已久、准备充分，北方在战场上屡屡失利，首都华盛顿险些被攻占。北方民众强烈不满，要求联邦政府采取措施扭转局面。

**理解：** 国家经济较发达并不意味着每场战争必然从一开始就获胜，战争准备、政策动员和民众参与都会影响战局。教材特别强调政府及时回应群众要求，不能只以“北方工业强所以自动获胜”代替全过程。

### 2. 1862年《宅地法》

**内容：** 允许**没有参加过叛乱的公民**在西部通过**购买和劳动**获得土地。

**作用：** 回应农民对土地的需求，提高其支持联邦、参加战争的积极性。作答时按教材措辞，不必补入未经本课核实的具体年龄、面积或年限，也不能简写成“所有人无条件免费获得土地”。

### 3. 1862年《解放黑人奴隶宣言》

**发表时间：1862年。**宣布自**1863年元旦起**，**南方叛乱地区**的奴隶永远获得自由，并允许其以自由人的身份加入北方军队。

- **时间要分清：** 发表与规定起始日期不同；1862年与1863年不能任选一个不作说明。
- **适用范围要准确：** 直接针对南方叛乱地区的奴隶，不是当时全国所有奴隶立刻同步自由。
- **政治和军事联系：** 解放奴隶把黑人争取自由与北方战争胜利联系起来，扩大北方的群众基础，也打击南方奴隶制。

### 4. 两项法令为什么重要

**《宅地法》—土地诉求—农民支持；《解放黑人奴隶宣言》—自由诉求—黑人支持。**两项法令调动农民和黑人奴隶积极性，他们踊跃参军作战，扭转北方在战场上的被动局面。

**理解辨析：** 法令是政策动员的重要转折，葛底斯堡是教材明确的战役转折点，不要将两种“转折”混成同一事件。解释胜利时既要看到林肯政府的政策和领导，也要看到农民、黑人等广大民众的贡献。

### 5. 葛底斯堡战役与战争结束

**相关史事：1863年7月1—3日**，双方在宾夕法尼亚州葛底斯堡激战。此前南方希望继续挫伤北方士气并促使欧洲国家承认“南部同盟”。北方军队严阵以待、围攻南方，南军随后撤退。教材明确指出：**葛底斯堡战役是南北战争的转折点。**

**1864年**，北方军队围攻“南部同盟”的“首都”里士满；**1865年**南方投降，美国内战以北方获胜结束。林肯1864年再次当选总统，1865年被拥护奴隶制的狂热分子刺杀。

要区分**华盛顿（联邦首都）与里士满（“南部同盟”的“首都”）**，也要区分1863年战争转折与1865年战争结束。

## 四、课内必背：性质、意义与局限

### 1. 为什么是第二次资产阶级革命

教材结论：**美国内战实质上是美国第二次资产阶级革命。**判断依据在于它维护国家统一、废除奴隶制，进一步清除资本主义发展障碍，而不只看它表现为内战。

**联系上册（理解辨析）：** 美国独立战争摆脱英国殖民统治，是第一次资产阶级革命；内战解决国内奴隶制和分裂危机，是第二次。一个国家可以因不同发展障碍而发生不同阶段的革命，不能因独立战争已获胜就认为之后无需制度变革。

### 2. 积极意义

1. **国家层面：** 维护国家统一，挫败南方分裂行动。
2. **制度层面：** 废除奴隶制，黑人摆脱奴隶身份。
3. **经济层面：** 进一步清除资本主义发展的障碍，为以后经济迅速发展创造条件。

解释第三点要将前两点转为因果：统一避免国家分裂，有利于经济联系；废除奴隶制有利于增加自由劳动力及其流动。这里是对教材结论的理解，不意味着战争结束后所有经济问题立即解决。

### 3. 局限：自由并不等于充分平等

教材指出，**黑人依然长期遭到歧视**。废除奴隶身份是重大进步，但社会偏见、暴力和权利侵害仍可能存在。

1874年阿拉巴马州黑人备忘录反映：政治和民事权利得不到保障；投票权遭剥夺、缩小，行使困难危险；暗杀、私刑、恐吓、迫害和逮捕危及安全；解雇、退租土地等手段损害生计。

可按三类归纳：**政治权利受侵害、人身安全无保障、经济生活受压迫。**不能根据“合法公民”“获得选举权”等字眼就断言黑人已有充分、平等的实际权利。

## 五、地图与史料研读

### 1. 美国内战形势图

先读图例，区分自由州、自由地区、忠于联邦的蓄奴州、南部叛乱蓄奴州，以及军队进攻路线和投降地点。找华盛顿、里士满、葛底斯堡、密西西比河相关地区，结合路线理解战局变化。

地图中特别值得注意的是**忠于联邦的蓄奴州**：战争中的政治阵营与奴隶制分布不能机械一一对应。这也有助于理解解放宣言为什么注明“南方叛乱地区”。不能仅凭一个州位于地图北侧或南侧，就忽略图例规定的具体性质。

### 2. 1874年黑人备忘录

先看时间：1874年在1865年战争结束之后，说明它用于认识战后问题。再看作者：遭受侵害的黑人群体。最后看内容：政治、暴力和经济三个层面的权利受损。材料可以支持“种族歧视继续存在”，但不能因此否定奴隶制废除的进步。

### 3. 农场主卢阿克的日记

课后日记形成于1861年新年前后。作者既担忧联邦解体与战争，又指责废奴主义者的“煽动”，表现出**珍视联邦统一、忧惧战争，同时反对激进废奴的保守立场**。

其价值在于提供战争前普通农场主对危机的感受、态度和预期，说明社会立场复杂，并非所有北方或中部居民都立即支持激进废奴。其局限在于这是个人观点，含有情绪和偏见，不能代表全体美国人，也不能将其对战争的预言当成后来已经发生事实的客观记录。

史料分析可用：**形成时间—作者身份—立场态度—可证明的问题—代表性限度。**不能因为史料有立场就说毫无价值，也不能因为是亲历者日记就全盘照信。

## 六、教材拓展：美国领土扩张与西进运动

独立后美国以购买、威胁、颠覆、战争等方式不断扩张。教材举例：1803年购买路易斯安那；1845年吞并得克萨斯；1846年侵略墨西哥，1848年迫使其“出售”大片领土；1867年向俄国购买阿拉斯加和阿留申群岛；1898年吞并夏威夷等地。

同时鼓动人口由东向西迁移，史称“西进运动”。其间大批印第安人被屠杀或赶往偏远地区。**评价要兼顾国家和经济扩展与被侵略、被驱逐者付出的代价。**本段是教材拓展，不能把后于内战的1867年、1898年事件写成内战爆发前的原因。

## 七、时间线与易错辨析

| 时间 | 事件 |
| --- | --- |
| 1860年 | 林肯当选总统 |
| 1861年4月 | 南方挑起战争，内战爆发 |
| 1862年 | 颁布《宅地法》，发表解放宣言 |
| 1863年元旦 | 宣言规定南方叛乱地区奴隶获得自由的起始日 |
| 1863年7月 | 葛底斯堡战役，战争转折点 |
| 1864年 | 北方围攻里士满；林肯再次当选 |
| 1865年 | 南方投降，内战结束；林肯被刺 |

易错点：①根本原因不是林肯当选；②北方迎战为维护统一，南方首先挑起战争；③宣言发表与实施时间不同；④维护统一与废除奴隶制都是战争成果；⑤奴隶制废除不等于种族歧视消失；⑥内战不是美国取得民族独立的战争。

## 八、常见简答题

**1. 美国南北矛盾有哪些表现，焦点是什么？**  
答：双方在奴隶劳动与自由劳动力、关税高低、原料出口和西部新州制度等方面利益冲突，焦点是奴隶制存废及其扩展。其背后是南北不同经济类型的矛盾。

**2. 林肯为维护统一采取了什么重要措施？**  
答：南方挑起战争后命令北方迎战；1862年政府颁布《宅地法》，林肯发表《解放黑人奴隶宣言》，调动农民和黑人参战，扭转战局，最终取得胜利。

**3. 如何评价林肯？**  
答：林肯领导北方进行内战、维护国家统一，通过解放宣言推进废奴，为清除资本主义发展障碍作出重要贡献。他的作用应与广大农民、黑人和民众的斗争相联系。

**4. 怎样理解内战的进步与局限？**  
答：战争维护统一、废除奴隶制，为资本主义迅速发展创造条件，是第二次资产阶级革命；但黑人仍长期受歧视，政治、经济和人身权利未获得充分保障。
