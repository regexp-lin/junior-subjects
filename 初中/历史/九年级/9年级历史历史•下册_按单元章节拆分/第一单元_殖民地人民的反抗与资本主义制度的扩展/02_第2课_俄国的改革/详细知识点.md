# 第2课 俄国的改革｜详细知识点（背诵版）

> **所属单元：** 第一单元：殖民地人民的反抗与资本主义制度的扩展。  
> **教材依据：** [本课教材 PDF](02_第2课_俄国的改革.pdf)，教材第10—14页，含正文、人物扫描、扩张形势图、相关史事、材料研读、课后活动和知识拓展。  
> **使用说明：** “课内必背”记史实，“理解辨析”组织因果评价；课末十二月党人列为“教材拓展”。

## 一、先背主线

**俄国形成统一国家 → 地主把农民束缚在土地上，1649年农奴制确立 → 彼得一世改革增强经济和军事实力，但保留农奴制 → 资本主义发展需要自由劳动力，旧制度日益成为障碍 → 克里木战争失败加剧危机 → 1861年亚历山大二世改革废除农奴制 → 俄国走上资本主义发展道路，同时保留专制制度与旧制残余。**

本课关键在于看清**“增强国力”与“改变社会制度”不是同一件事**。彼得一世学习西方、兴办工场，仍依赖农奴；亚历山大二世废除农奴制，却仍维护沙皇和地主利益。不能因都称“改革”就认为两者结果完全相同。

## 二、课内必背：俄国的形成与农奴制确立

### 1. 俄罗斯国家的发展线索

- 俄罗斯人的祖先是**东斯拉夫人的一支**，9世纪晚期建立基辅罗斯等早期国家。
- 13世纪上半叶，这一地区被蒙古征服。
- 在反抗蒙古统治过程中，**莫斯科公国**崛起，逐步兼并其他公国。
- 到16世纪初，建立统一的俄罗斯国家。
- **伊凡四世**执政时采用“沙皇”称号，强化专制统治。“沙皇”来自拉丁语“恺撒”，意为皇帝。

注意：早期国家出现、蒙古征服、统一国家建立和农奴制法典化是不同阶段，不能都写在16世纪或1649年。

### 2. 农奴制为什么会确立

俄国**地广人稀、劳动力缺乏**，地主竭力把农民束缚在土地上，确保土地上有稳定劳动力供其役使。地主利益要求与法律强制相结合，使农民越来越难离开地主控制。

**1649年，俄国颁布法典，确立农奴制。**法典规定，地主可以无限期追回逃亡农民，还可追回逃亡农民的妻子儿女。农民因而世世代代失去人身自由，成为农奴。

### 3. 如何理解农奴制的束缚

1. **人身方面：** 不能自由离开地主控制，逃亡可被追回，限制延及家属后代。
2. **劳动方面：** 农业和手工业主要使用农奴劳动，劳动者缺乏自由选择职业和去向的条件。
3. **经济方面：** 工商业发展极其缓慢；到资本主义有所发展后，自由劳动力缺乏又成为进一步发展的严重障碍。

**理解辨析：** 农奴制不只是农业生产技术落后，而是束缚劳动者的社会制度。购买机器、开办工场可以增加生产能力，但若不改变人身束缚，工场发展仍受旧制度限制。课文明确指出工场也使用农奴，不能将“工场出现”理解成农奴制已经消失。

## 三、课内必背：彼得一世及其改革

### 1. 改革起点与目标

**1689年彼得一世亲政**后，决心改变俄国落后面貌，采取一系列改革措施，并积极对外扩张。他曾假扮水手随使节团考察西欧，了解西方国家发展情况。

改革从国家上层推行，重点是加强行政、军事和经济实力。评价其学习精神要有措施作依据，同时不能遗漏其加强专制和保留农奴制的性质。

### 2. 主要措施及相互联系

| 方面 | 教材措施 | 理解其作用 |
| --- | --- | --- |
| 国家治理 | 建立中央集权行政体制 | 进一步加强沙皇专制权力，增强组织和动员能力 |
| 军事人才 | 创建新式常备军，按功劳和才能提拔人才 | 改进军队和人才使用，有利于增强军力 |
| 经济 | 鼓励兴办手工工场，允许工场主购买整个村庄的农奴 | 增加生产供给，同时显示工场仍依赖农奴劳动 |
| 文化教育 | 派遣留学生，创办报纸、新式学校和科学院 | 学习、传播知识和技术，为国家发展培养人才 |
| 对外战争 | 1700—1721年与瑞典作战并获胜 | 夺取波罗的海出海口，扩大对外联系和战略空间 |

### 3. 圣彼得堡与波罗的海

彼得一世在对瑞典战争期间营建新首都**圣彼得堡**。导入指出，新城位于涅瓦河的波罗的海出海口，兼有对瑞典攻防的地理考虑和实现改革意图的作用。修建城市征召大量农奴，说明国家建设仍以农奴制为基础之一。

地图标明：**1712年前首都是莫斯科，1712年起为圣彼得堡。**将城市、出海口、战争和改革联系起来记，比孤立记一个地名更能理解其历史作用。

### 4. 作用与局限

**作用：** 使俄国经济和军事实力大大增强。

**局限：** 没有触动农奴制，沙皇专制权力进一步加强。18世纪下半叶，**叶卡捷琳娜二世**继续对外扩张领土，对内维护农奴制。

**理解辨析：** 学习西欧不必然等于建立资本主义制度；国家实力增强也不等于农民获得自由。不能把“彼得一世改革增强国力”与“1861年改革废除农奴制、走上资本主义道路”合并为同一次改革的结论。

## 四、课内必背：亚历山大二世废除农奴制

### 1. 改革的经济与社会背景

19世纪上半叶，在西欧资本主义影响下，俄国粮食出口激增、手工工场大量出现，资本主义经济有一定发展。然而农奴制使自由劳动力缺乏，**严重阻碍资本主义进一步发展**。

分析因果时要写完整：农民被束缚于土地和地主 → 难以自由流动、转换职业 → 工商业所需自由劳动力不足 → 旧制度与资本主义发展的矛盾加深。教材强调的是“进一步发展受到严重阻碍”，不能写成改革前俄国完全没有资本主义经济。

### 2. 克里木战争失败的刺激

**1853—1856年克里木战争**中，俄国对抗支持奥斯曼帝国的英法联军，最终失败，暴露农奴制下俄国军事和经济落后，引发国内政治危机。“克里木”也称“克里米亚”。

教材用具体事例说明落后：武器装备、军事训练和作战方针落后；铁路缺乏，军队调动、后勤补给效率低；木帆船对阵英法蒸汽战舰。由此可见，战场失败背后有工业、交通、组织和制度问题，不能只归因于某一场战斗指挥失误。

### 3. 改革的发动者、目的与方式

**发动者：沙皇亚历山大二世。**内外交困中，他认为与其等待农民自下而上起来解放自己，不如由国家自上而下解放农民。

- **方式：** 自上而下颁布法令改革。
- **主要目的：** 化解危机、防止农民反抗危及统治，维护沙皇统治与地主利益。
- **理解辨析：** 改革确实使农奴获得人身自由，但统治者的主要动机不能简化成仁慈。评价历史要同时分析行动目的和客观效果，两者并非完全一致。

### 4. 1861年改革的两项核心内容

**1861年，亚历山大二世颁布废除农奴制法令。**

1. **人身自由：** 农奴可以改变身份，自由转换职业。由此缓解资本主义发展所需自由劳动力不足的问题。
2. **土地赎买：** 农奴获得解放同时，可出钱赎买一份土地。但实际赎价往往高于当时地价，成为对农奴的无情掠夺。

背诵抓住：**自由不是免费得地，赎地不是彻底摆脱负担。**一方面要肯定人身自由的制度变化，另一方面要说明土地安排保护了地主利益、让农民承担沉重代价。

### 5. 为什么是俄国历史的重要转折点

改革**废除农奴制，推动俄国走上发展资本主义的道路**。农民可以转换身份和职业，为工商业提供自由劳动力；社会出现新气象，资本主义发展加快。课后列宁材料列举城市发展、工厂增加、铁路修建加快，为这一判断提供表现。

作答“转折点”要指出社会发展方向变化，不能只写“国家变强了”。1861年改革以解除旧制度束缚推动资本主义发展，是本课与单元“资本主义制度扩展”主题的联系。

### 6. 改革的局限与完整评价

改革**没有触动沙皇专制制度，农奴制残余依然存在**，继续影响俄国经济社会发展；高价赎地使农民受到掠夺，地主利益获得保护。

完整评价可分三步：**性质和方式（理解归纳）：沙皇主持、自上而下，具有推动资本主义的性质；积极影响：废除农奴制、推动资本主义；局限：维护地主利益，保留专制及旧制残余。**“具有资产阶级性质”是根据其废除旧制度、促进资本主义作用作出的理解归纳，并不意味着由资产阶级掌权主持。

## 五、地图、图像和材料解读

### 1. 15—18世纪俄国扩张形势图

按图例区分1462年莫斯科公国、至1598年、1599—1689年和1690—1795年扩占地区，观察俄国从莫斯科周边向外扩张，逐步形成横跨欧亚的广大疆域。找乌拉尔山、波罗的海、莫斯科和圣彼得堡，联系俄国夺取出海口的行动。

地图显示疆域变化，不能直接证明所有新占地区经济同样发达，也不能把领土扩大等同于农民生活改善。

### 2. 宣读“解放”法令的图像

图像表现由贵族宣读法令、农民接受法令的场景，可与“自上而下改革”相联系。引号提示对解放内容和代价作分析，但不能因有赎买负担便说农民完全没有获得人身自由。图像要与法令条文、材料结合，不能仅凭人物姿态推断其全部真实心态。

### 3. 亚历山大二世1861年讲话

材料说拖延会造成“灾难性后果”，并强调已尽力保障地主利益。前者说明统治危机和防止反抗的紧迫感，后者说明改革维护地主利益。回答主要目的：**维护统治秩序和地主阶级利益，防止农民革命。**

### 4. 列宁的双重评价

“城市的发展、工厂的增加、铁路的修建愈来愈迅速”肯定改革推动资本主义；“被剥夺得一无所有才获得‘自由’”揭示高价赎买等造成的掠夺。两句并不矛盾：**社会制度有进步，农民解放有沉重代价，改革并不彻底。**

## 六、教材拓展：十二月党人

19世纪初，一些俄国青年军官在反拿破仑战争中到过西欧，感受经济发展和社会进步，回国后不满农奴制与沙皇专制，组织秘密团体、宣传民主思想，准备依靠军队推翻沙皇政府。**1825年12月26日**他们发动武装起义，迅速失败，遭镇压、流放，被称为“十二月党人”。

列宁指出他们圈子狭小、远离人民，但事业没有落空。可理解为：斗争存在脱离群众的局限，也传播反专制思想，具有影响。它是教材拓展，不能写成1861年改革的直接实施者，也不能把其起义与沙皇的改革混为一谈。

## 七、时间线与易错辨析

| 时间 | 事件 |
| --- | --- |
| 9世纪晚期 | 基辅罗斯等早期国家建立 |
| 16世纪初 | 统一俄罗斯国家建立 |
| 1649年 | 法典确立农奴制 |
| 1689年 | 彼得一世亲政 |
| 1700—1721年 | 对瑞典战争，俄国夺取波罗的海出海口 |
| 1825年 | 十二月党人起义 |
| 1853—1856年 | 克里木战争 |
| 1861年 | 亚历山大二世废除农奴制 |

易错点：①彼得一世不等于亚历山大二世；②农奴制废除不等于沙皇专制废除；③农奴获得自由不等于免费获得土地；④改革前已有一定资本主义发展，改革是清除重要障碍；⑤改革仍有局限，不应写成彻底消除封建残余。

## 八、常见简答题

**1. 农奴制怎样阻碍俄国发展？**  
答：农奴被束缚在土地和地主控制下，不能自由转换身份、职业，农业手工业依赖农奴劳动，工商业发展缓慢；资本主义有所发展后，自由劳动力缺乏更加突出，严重阻碍进一步发展。

**2. 彼得一世改革与1861年改革有何不同？**  
答：彼得一世通过行政、军队、经济、文化改革增强国力，但未触动农奴制；1861年亚历山大二世废除农奴制，使农奴获得人身自由并可赎地，推动俄国走上资本主义发展道路。两者均由沙皇推动，都未取消沙皇专制。

**3. 为什么1861年改革成为转折点，又有何局限？**  
答：改革废除农奴制、释放自由劳动力，推动资本主义发展；但农民高价赎地，地主利益受保护，沙皇专制与旧制残余仍在，继续影响经济社会发展。
