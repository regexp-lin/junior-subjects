# 第1课 殖民地人民的反抗斗争｜详细知识点（背诵版）

> **所属单元：** 第一单元：殖民地人民的反抗与资本主义制度的扩展。  
> **教材依据：** [本课教材 PDF](01_第1课_殖民地人民的反抗斗争.pdf)，教材第4—9页，含正文、相关史事、人物扫描、地图、材料研读、课后活动与知识拓展。  
> **使用说明：** “课内必背”对应教材事实；“理解辨析”帮助解释因果；“教材拓展”对应课末栏目，不将未核实的补充当作课内结论。

## 一、先背课时主线

**欧洲殖民统治造成经济掠夺、政治压迫和社会不平等 → 拉丁美洲人民争取民族独立 → 玻利瓦尔、圣马丁领导运动并取得重要胜利 → 印度各阶层掀起反英大起义 → 殖民地人民的反抗打击殖民统治，推动民族意识觉醒。**

复述抓两条线：**拉美：压迫—独立—局限；印度：掠夺—联合起义—失败与意义。**本课讲殖民地人民争取民族解放，不能只背英雄人物而忽视广大民众及其生活处境。

## 二、课内必背：拉丁美洲独立运动

### 1. 拉丁美洲的范围和名称

拉丁美洲泛指今天**美国以南的美洲地区**。这一地区大约从16世纪初开始成为西班牙和葡萄牙的殖民地，居民主要使用西班牙语、葡萄牙语，两种语言都属于拉丁语族，因而得名“拉丁美洲”。

- “拉丁美洲”是带有历史文化含义的区域称呼，不能简单等同于南美洲；地图还包括墨西哥、中美洲和加勒比海地区。
- 教材用“大部分地区”概括西、葡殖民范围，并非所有拉美地区均属于这两个国家。**海地曾是法国殖民地**，因此不能把海地独立写成反西班牙统治。

### 2. 殖民统治为什么激起反抗

**经济方面：** 欧洲殖民者疯狂掠夺印第安人的金银工艺品，驱使当地居民在矿山、种植园劳动，垄断商业贸易。财富向殖民宗主国流动，广大劳动者遭受剥削。

**政治方面：** 殖民政府实施高压统治，欧洲白人殖民者把持政权，限制、排斥其他群体，甚至排挤土生白人。

**社会方面：** 形成按血统划分的金字塔式等级社会：印第安人和黑人处于最底层；白人与印第安人或黑人后代中的混血种人多为工匠、小贩和牧民；移民后代土生白人中有地主、商人及中下级官吏；欧洲白人殖民者处于上层。社会矛盾日益尖锐。

**理解辨析：** 各阶层受压迫的具体处境不同，却可能形成反殖民共同诉求。一些土生白人成为运动领导人，不等于只有土生白人参加，也不等于参加者没有利益差异。

### 3. 外部影响与运动兴起

18世纪末19世纪初，拉美绝大部分地区仍处于西班牙和葡萄牙殖民统治之下。在**美国独立战争和法国大革命**影响下，拉美掀起反抗殖民统治、争取民族独立的运动。

答题可从两个层次组织：**内因是殖民统治激化矛盾；外因是外部革命、独立运动的鼓舞。**启蒙思想对玻利瓦尔也有影响，但不能用外部思想替代当地社会矛盾这一现实基础。

### 4. 海地独立与运动蔓延

**1804年，法国殖民地海地独立，建立世界上第一个黑人共和国。**不久，拉美广大地区起义相继爆发。其意义在于出现具有示范性的独立胜利，显示殖民统治可以被打破。

“世界上第一个黑人共和国”是教材强调的地位；不能改成世界第一个共和国，也不能把1804年当作整个拉美同时独立的年份。

### 5. 玻利瓦尔领导的北部独立斗争

1. **动员措施：** 玻利瓦尔宣布解放黑人奴隶，承诺胜利后分给起义士兵土地。
2. **群众基础：** 大批印第安人、黑人和混血种人参加起义部队。
3. **关键行动：** **1819年**率军克服困难，越过常年积雪的安第斯山脉，打败西班牙军队。
4. **解放地区：** 哥伦比亚、委内瑞拉、厄瓜多尔等地。
5. **政治结果：** 成立“大哥伦比亚共和国”，玻利瓦尔当选总统。

**理解动员政策：** 解放奴隶和土地承诺回应了被压迫者的利益诉求，有利于扩大参军和支持的范围。答“取胜因素”时，可结合反殖民共同目标、群众参加和领导者的组织斗争，而不能只归结为个人勇敢。

人物扫描中，玻利瓦尔是土生白人后代，青年在欧洲求学，受启蒙思想影响，立志解放祖国。**玻利维亚以其名字命名**，体现拉美人民对其贡献的纪念。

### 6. 圣马丁领导的南部独立斗争

圣马丁领导了**阿根廷、智利和秘鲁**的独立运动。人物扫描介绍，他出身于西班牙殖民军官家庭，曾在欧洲参加抵抗拿破仑军队的战斗，1812年返回拉美参加独立战争，后来被阿根廷、智利和秘鲁称为“祖国之父”。

**玻利瓦尔和圣马丁被誉为拉丁美洲人民的“解放者”。**辨认人物时，要同时记“姓名—主要地区—共同地位”，避免把两条战线完全互换。

### 7. 阿亚库乔战役、运动结果与历史局限

**教材相关史事：** 阿亚库乔位于秘鲁高原。**1824年12月**，哥伦比亚—秘鲁联军在这里以少胜多，战后西班牙军队撤出秘鲁，西班牙在拉美的殖民统治受到严重打击。重要结论是战役对殖民统治的打击，不必用伤亡数字代替历史意义。

**运动结果：** **1826年，西属拉丁美洲殖民地基本实现独立。**葡萄牙殖民地巴西则在**1822年**由留在当地的葡萄牙王子宣布脱离宗主国，获得独立。巴西并非由玻利瓦尔或圣马丁解放。

**积极意义：** 推翻欧洲列强的殖民统治，产生一批独立国家。

**局限：** 独立国家的社会依旧等级分明，存在种族歧视；经济上继续受到列强控制。

**理解辨析：** 应区分政治独立、经济自主和社会平等。拉美获得政治独立是重大进步，但不能说从此摆脱一切外部控制、消除一切社会矛盾，也不能因仍有局限便否定独立运动的成就。

## 三、课内必背：印度民族大起义

### 1. 历史背景

19世纪中期，印度已沦为英国殖民地。当时英国完成了第一次工业革命，进一步加紧对印度的**经济掠夺和政治压迫**，印度各阶层对殖民统治强烈不满，反抗情绪日益高涨。

工业革命与殖民掠夺的联系：英国机器生产扩大，需要原料和销售市场，印度被纳入其殖民经济体系。这一解释帮助理解课文，不应理解为工业革命的所有影响都是殖民侵略。

### 2. 各阶层为什么不满

| 群体或领域 | 教材所述处境 | 引发的反应 |
| --- | --- | --- |
| 手工业者 | 英国进口印度原棉，倾销机器生产的棉纺织品，印度手工棉纺织业遭毁灭性打击 | 大量手工业者破产，生活困苦 |
| 农民 | 向王公、地主缴纳地租，部分还向殖民当局缴纳高额田赋 | 负担沉重，对殖民统治不满 |
| 部分王公 | 英国吞并部分王公领地 | 利益受损，一部分加入起义 |
| 印度士兵 | 为殖民者服务，却遭英国军官虐待，宗教信仰不受尊重 | 士兵成为起义首先发动者 |

注意：教材说**部分**印度王公参加，不能扩大成所有王公；“印度士兵”指当时英国殖民军队中的印度原住民雇佣兵，教材旧称“土兵”。

### 3. 起义爆发、发展和代表人物

- **1857年，驻守密拉特城的印度士兵首先起来反抗英国殖民者。**
- 农民、手工业者和一些利益受损的印度王公也参加起义，各阶层民众一致对外，民族意识高涨。
- 起义浪潮席卷印度北部、中部；起义者与英军进行了殊死搏斗。
- **章西女王**是英雄人物代表：1857年6月，章西士兵发动斗争，她响应起义、率军坚决抗击英军。章西陷落后，率军转战，在战斗中身先士卒，最终牺牲。

**人物评价方法：** 先说明其具体行动，再归纳抗击殖民侵略、英勇无畏的精神。不能只有“伟大”“英雄”等评价词而没有史实依据。

### 4. 起义结果与英国统治方式变化

**1859年底，起义被英军镇压下去。**起义期间，英国调整殖民统治方式，取消英国东印度公司的统治特权，由英国派总督直接统治。

须分清：围绕这次起义，英国殖民统治继续存在，改变的是统治管理方式；不能写成印度获得独立，也不能将英国东印度公司的特权取消理解为殖民主义终结。

### 5. 历史意义与运动性质

1. **对殖民者：** 沉重打击英国殖民者。
2. **对印度人民：** 反映印度民族意识的觉醒。
3. **放入亚洲：** 是19世纪中期亚洲民族解放运动的重要组成部分。

**为什么叫民族大起义？** 它虽由士兵首先发动，但农民、手工业者、部分王公等不同群体联合参加，形成反对英国殖民统治的共同联盟。教材课后引马克思的观点，目的在于从参与范围和共同斗争目标理解其民族性，不能仅称为局限在军营中的兵变。

## 四、地图与材料怎样读

### 1. 拉丁美洲独立运动形势图

先辨认太平洋、大西洋、墨西哥和南美洲，再看图例中的独立国家、重要战役和两位领导人的路线。**玻利瓦尔主要活动于南美北部，圣马丁从南部向智利、秘鲁推进。**地图上的红字年份对应不同地区独立，不能凭地图颜色推断这些国家独立后政治制度完全相同。

图文互证：海地图示1804年独立；巴西是葡萄牙殖民地，走向独立的过程与西属拉美不同；阿亚库乔战役位于秘鲁，反映南美反殖民斗争的重要胜利。

### 2. 印度民族大起义示意图

结合图例找**密拉特、德里、章西**，观察起义集中于印度北部、中部。地图可以说明空间范围和主要地点，不能据图断言印度全部地区均参加。

### 3. 关于织布工人和民歌的材料

“织布工人的尸骨把印度的平原漂白了”形象揭示英国殖民经济掠夺对印度手工业和劳动者生计的破坏；对“殖民者的心黑”的民歌表达民众的愤怒与仇恨。回答原因时应由文字落到**手工业破产、农民重负、政治压迫和民族歧视**，避免只写“英国人坏”。

材料中的悲惨景象与阶层处境互相印证，但不能把修辞表达直接当作精确人口统计。

## 五、时间线与对比

| 时间 | 事件 |
| --- | --- |
| 16世纪初起 | 拉美大部分地区逐步沦为西、葡殖民地 |
| 18世纪末19世纪初 | 拉美独立运动兴起 |
| 1804年 | 海地独立，建立第一个黑人共和国 |
| 1819年 | 玻利瓦尔率军越过安第斯山脉并取得胜利 |
| 1822年 | 巴西独立 |
| 1824年12月 | 阿亚库乔战役 |
| 1826年 | 西属拉美殖民地基本实现独立 |
| 1857年—1859年底 | 印度民族大起义 |

比较：两场运动都源于殖民统治激化矛盾，有广泛民众参与，打击殖民势力；拉美主要反西班牙、葡萄牙统治并取得独立，印度主要反英国殖民统治，起义失败。**共同性质不等于结果一致，结果不同也不否定共同反殖民目标。**

## 六、教材拓展：19世纪中期亚洲民族解放运动

课末指出，西方列强在亚洲侵略扩张，激起当地人民反抗。除印度外，中国、伊朗、阿富汗、爪哇（今属印度尼西亚）等地也出现斗争：中国太平天国运动在抗击清朝统治的同时与外国侵略势力激战；伊朗民众反抗外国商品倾销与封建王朝盘剥；阿富汗人民攻击英国殖民军据点；爪哇当地王公领导民众进攻荷兰殖民军总部。

教材概括这些运动虽然最终失败，但对欧洲殖民者造成巨大冲击。**这是认识地区关联的拓展，不要求把各地运动的全部时间、领袖和经过混入印度大起义的答案。**

## 七、常见简答题与参考答案

**1. 18世纪末19世纪初拉美为什么出现大规模独立运动？**  
答：西班牙、葡萄牙殖民统治实行经济掠夺、贸易垄断和政治高压，等级与种族矛盾尖锐，各阶层不满；美国独立战争和法国大革命鼓舞了拉美人民，推动争取民族独立的运动兴起。

**2. 怎样评价玻利瓦尔和圣马丁？**  
答：玻利瓦尔领导南美北部独立斗争，圣马丁领导阿根廷、智利、秘鲁等地独立运动。他们为推翻殖民统治、争取民族独立作出重要贡献，被誉为拉美人民的“解放者”；其成就也离不开广大民众参加和支持。

**3. 拉美独立运动有哪些成果与不足？**  
答：推翻欧洲列强的殖民统治，产生一批独立国家；但社会依旧等级分明、存在种族歧视，经济上继续受到列强控制，政治独立尚未自动带来经济自主与社会平等。

**4. 为什么印度各阶层会共同参加反英起义？**  
答：殖民掠夺使手工业者破产、农民负担沉重；吞并领地损害部分王公利益；士兵遭虐待与宗教歧视。不同群体共同受到殖民统治损害，形成反英联盟。

**5. 印度民族大起义有何历史意义？**  
答：虽然最终失败，但沉重打击英国殖民者，反映印度民族意识觉醒，是19世纪中期亚洲民族解放运动的重要组成部分，表现了殖民地人民反抗压迫的意志。
