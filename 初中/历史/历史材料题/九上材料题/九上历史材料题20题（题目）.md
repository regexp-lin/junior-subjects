## 使用说明

- **范围**：依据本地九上资料的七个单元、22课编写。20道大题通过合并相关课时覆盖全册，包括中古非洲与美洲、第一国际、巴黎公社和《国际歌》活动课，不要求使用九下知识作答。
- **性质**：全部为原创训练题，参考深圳中考材料题的主题探究、证据提取、历史解释和开放表达方式，不是历年真题或押题。
- **材料来源**：各题文字、时间线、表格均据所标课时知识作教学整理，不是历史人物原话或某部著作的逐字引文。假设情境另作说明，不虚配史料出处；表内真实年代采用历史纪年。
- **分值**：每题建议18分，20题共360分，是分次使用的题库，不是一套中考整卷。分值和评分建议均为本题库自拟，不代表深圳官方要求。
- **作答**：留意对象、时空、依据和任务数量；开放题有多种合理答案，必须用准确史实解释观点。
- **课名说明**：本地第16课文件夹误写“美国资产阶级革命”，原教材PDF正文第88页题名为“英国资产阶级革命”，本题库采用正文题名。

## 第01题　从食物生产到早期国家（18分）

**关联课时：第1课。从考古证据出发，研究生产与社会的变化。**

**材料一**　以下为依据教材概括的考古观察类型，不对应某一真实遗址，也不表示所有地区都按同样速度变化。

| 观察类型 | 可以看到的遗存 |
| --- | --- |
| 甲类 | 打制石器，较多猎获的野生动物骨骼 |
| 乙类 | 磨制石器、栽培谷物遗存、储藏设施及较稳定的房址 |
| 丙类 | 大型公共建筑，墓葬规模和随葬品差异明显 |

**材料二**　农业和畜牧业的发展增加了食物来源。社会分工逐渐细化，部分人可以专门从事手工业、交换或公共事务管理。随着剩余产品和私人财富增加，社会成员之间的贫富差距扩大，早期国家逐渐出现。

1. 根据材料一，指出甲、乙两类遗存分别反映的主要食物获取方式，并概括乙类遗存反映的居住特点。（6分）
2. 根据材料二并结合所学，说明生产发展怎样为社会分化和国家产生创造条件。（6分）
3. 有同学认为：“只要发现一座随葬品丰富的墓葬，就能证明当地已经建立国家。”你是否赞同？说明理由，并提出一种可以继续寻找的证据及其用途。（6分）

4. 从表中任选一项成果，为其写一则展签，包含所属文明、成果名称及一项历史价值。不得只抄名称。（4分）

## 第03题　古代印度的等级与思想（18分）

**关联课时：第4课。比较社会制度与思想主张。**

**材料一**　古代印度种姓制度把社会成员分为不同等级：有的掌握祭祀，有的负责军事行政，有的从事生产和商业，有的为较高等级服务。身份通常世袭，婚姻和职业受到等级限制；四种姓之外的人群还遭受更严重的歧视。

**材料二**　公元前6世纪前后，印度社会出现新的思想。佛教反对婆罗门特权，提出众生平等，吸引不同社会群体。后来佛教从南亚传向其他地区，但种姓制度并未因此立即消失。古代印度还发展出包含“0”在内的数字符号系统，经阿拉伯人等传播到更多地区。

1. 根据材料一，概括种姓制度的两项主要特征，并说明它为什么不只是一般的职业分工。（6分）
2. 根据材料二并结合所学，指出佛教创立者，分析其平等主张能够吸引部分社会成员的原因。（4分）
3. 有人说：“佛教提出众生平等，证明当时印度社会已经人人平等。”指出这一推论的问题。（4分）
4. 从佛教或数字符号系统中任选一个例子，说明古代印度对世界文明的一项贡献及其传播特点。（4分）

## 第04题　雅典民主的参与和限制（18分）

**关联课时：第5课。研究政治制度时，先辨认谁能够参与。**

**材料一**　公元前5世纪的雅典，成年男性公民可以参加公民大会，讨论并决定城邦重大事务。许多官职通过抽签产生，部分公共事务的参与者可以领取津贴。妇女、奴隶和外邦人不享有同等政治权利。

**材料二**　学习小组提出两种判断：甲认为，只要有公民大会，所有居民就都是国家主人；乙认为，既然多数居民被排除，雅典民主便没有任何历史价值。

1. 根据材料一，概括雅典政治参与的两项制度安排，并说明其中一项怎样有利于公民参与。（6分）
2. 解释雅典“公民”与“全体居民”为什么不能互换。（4分）
3. 分别指出材料二两种判断的不足，并结合材料说明。（4分）
4. 为“认识雅典民主”拟一个明确观点，并用一项具体制度安排及一项参与限制支持它。（4分）

## 第05题　罗马的扩张与历史遗产（18分）

**关联课时：第6课。学习小组整理罗马历史时间卡。**

**材料一**　四张时间卡尚未排序：

- 甲：公元前27年，屋大维建立元首制，罗马由共和国走向帝国。
- 乙：476年，西罗马帝国灭亡。
- 丙：公元前509年左右，罗马共和国建立。
- 丁：2世纪，罗马帝国进入强盛时期，疆域横跨欧、亚、非三洲。

**材料二**　罗马扩张带来土地、财富和大量奴隶。道路、港口等使帝国内部的商品与人员往来更便利，但征服也伴随杀戮、掠夺和奴役。罗马人在长期社会和司法实践中发展法律，形成影响后世的法律传统。

1. 将四张时间卡按先后排序，并指出甲卡体现的政体变化。（4分）
2. 根据材料二，从统治者或商人、被征服者两个角度说明罗马扩张的不同影响。（6分）
3. 结合所学，列举一项罗马法律成果和一项工程建筑或历法成果，分别说明其历史价值。（4分）
4. 若要判断“帝国某条道路有利于商业交流”，仅有道路遗址是否足够？说明理由，并补充一类相关史料。（4分）

## 第06题　土地、效忠与庄园生活（18分）

**关联课时：第7课。以下为西欧封建社会关系的教学示意。**

**材料一**　封君把土地封给封臣，封臣承担效忠、服兵役等义务；封君也负有保护封臣的责任。有的封臣又把部分土地封给其他人，形成多层权利义务关系。这种关系并不等同于国王直接任免全国各级官员。

**材料二**　庄园中既有领主自营地，也有佃户份地。农奴耕种分得的份地，还必须承担劳役和其他负担，不能自由离开庄园。庄园主要供应自身生活需要，庄园法庭处理纠纷、维护秩序，也维护领主利益。

1. 根据材料一，指出封君封臣关系的纽带，并概括双方各自承担的一项义务。（4分）
2. 根据材料一并结合所学，解释这种多层关系为什么容易形成地方权力分散。（4分）
3. 根据材料二，从经济组织和人身关系两个方面概括庄园生活的特点。（6分）
4. 说明庄园法庭的一项作用，并指出为什么不能据此把庄园称为现代法治社会。（4分）

## 第07题　西欧城市和大学的兴起（18分）

**关联课时：第8课。研究中世纪社会内部的新变化。**

**材料一**　10世纪以后，农业发展、人口增加，手工业与商品交换逐渐活跃。一些交通要道和集市周围形成新的城市。商人、手工业者不愿长期受制于领主的征税和管辖，通过金钱赎买、武力斗争等争取特许状，有些城市获得一定自治权。

**材料二**　12世纪，西欧一些城市出现大学。大学组织教学、辩论，培养神职人员以及法学、医学等方面的人才，并争取一定自治。大学仍受到教会和既有社会秩序的影响，与现代大学并不完全相同。

1. 根据材料一，概括城市兴起的两项条件，并解释其中一项怎样支持城市发展。（6分）
2. 指出城市争取自治的两种方式，并说明“自治”不等于“完全独立”。（4分）
3. 根据材料二并结合所学，分析城市发展为什么会增加对大学和专门人才的需要。（4分）
4. 有人认为：“城市和大学兴起，证明西欧已经彻底摆脱封建社会。”你如何评价？（4分）

## 第08题　拜占庭：法律与文化的桥梁（18分）

**关联课时：第9课。学习小组讨论拜占庭的历史遗产。**

**材料一**　6世纪，查士丁尼组织整理、编纂罗马法，相关法律文献合称《罗马民法大全》。它维护帝国统治和既有社会秩序，仍承认奴隶制；同时系统规定财产、契约等关系，保存并发展了罗马法律传统。

**材料二**　拜占庭位于多区域交通交汇之处，保存大量希腊、罗马典籍，并在商业和文化往来中吸收不同地区的知识。后来这些知识通过人员流动、翻译等渠道影响其他地区。1453年帝国灭亡，但其法律、建筑和文化遗产仍继续发挥作用。

1. 根据材料一，指出《罗马民法大全》在法律传承方面的贡献及其时代局限。（4分）
2. 根据材料二，概括拜占庭成为文化桥梁的两个条件或途径。（4分）
3. 从“国家灭亡”与“文化传承”的关系出发，解释为什么不能把1453年视为拜占庭文化影响的终点。（4分）
4. 以“研究历史遗产需要多角度评价”为观点，结合两则材料写一段说明，至少使用两项具体事实并解释其与观点的联系。（6分）

## 第09题　日本改革与权力变化（18分）

**关联课时：第10课。沿时间观察制度与社会关系的变化。**

**材料一**　646年开始，日本改革者参考唐朝制度，建立以天皇为中心的中央集权，地方设置行政机构，中央派官治理；同时将土地和部民收归国家，编订户籍、统一赋税，以加强国家对人口和土地的控制。

**材料二**　后来，土地私有和兼并发展，豪门、寺院建立庄园，中央控制受到削弱。地方武装逐渐形成武士集团。12世纪末，日本进入幕府统治时期，幕府与天皇朝廷并存，将军掌握实际政治、军事权力。

1. 结合所学，指出材料一改革的名称，并将其举措分别归入政治、经济两个方面。（4分）
2. 根据材料一并结合所学，说明借鉴唐制为何有利于改革者加强统治。（4分）
3. 根据两则材料，概括日本政治权力关系的变化，并分析推动这种变化的社会因素。（6分）
4. 同学说：“日本学习唐朝制度，说明其历史变化完全由外来文化决定。”结合材料评价这一说法。（4分）

| B | 学者在数学、天文学、医学等领域进行研究并形成著作 |
| C | 商人和学者把印度数字系统及其他地区的知识传播到更远地区 |

**材料二**　阿拉伯帝国联系多个地区，商业网络连接东西方城市。一些统治者重视知识与翻译，城市汇集学者、书籍和不同文化传统。今天所谓“阿拉伯数字”的起源和传播过程，就是多地区共同参与文明发展的一个例子。

1. 将A、B、C三项活动分别归为“吸收继承”“创新发展”“传播交流”，并从中选择一项说明你的分类依据。（4分）

4. 综合材料，提出一个关于文明交流的认识，并用两项材料事实支持。（4分）

## 第11题　中古非洲和美洲的多样创造（18分）

**关联课时：第12课。比较不同区域适应环境和组织社会的方式。**

**材料一**

| 区域 | 主要线索 |
| --- | --- |
| 西非部分地区 | 外地商旅需要黄金，西非部分地区需要盐等商品；黄金资源、农业生产与跨撒哈拉贸易相联系，加纳、马里、桑海等国家先后兴起 |
| 玛雅地区 | 培育、种植玉米等作物，发展城市、文字、数学和历法 |
| 印加地区 | 山地梯田与灌溉农业，道路、驿站和信使系统支持区域联系 |

**材料二**　有同学发现各区域的技术、文字与交通方式不同，便认为：“只有使用同一种文字、修建同一种城市的社会，才算有文明；没有照走欧洲道路的地区就没有自己的历史创造。”

1. 根据材料一，说明西非资源和不同地区的需求怎样推动贸易与国家发展。（4分）
2. 以印加为例，解释当地居民怎样利用或适应自然条件，并说明一项社会成就。（4分）
3. 运用材料一中的两项不同区域事实，反驳材料二的看法。（6分）
4. 如要进一步比较两个区域的发展，提出一个可比较的共同维度，并列出相应需要收集的两类史料。（4分）

<a id="q12"></a>
## 第12题　新的经营方式与人文主义（18分）

**关联课时：第13课。把经济、社会力量与思想变化联系起来。**

**材料一**　中世纪晚期，一些富裕农民承租土地、雇佣劳动者并向市场销售产品；一些商人组织手工工场，提供原料和工具，雇工分工生产。经营者逐渐积累财富，并希望获得更大的经营空间和社会地位。

**材料二**　意大利一些工商业城市成为文艺复兴的重要中心。艺术家和作家借用古代文化形式，关注现实生活、人的情感与价值，表达对封建神学束缚的不满。但这些变化并没有立即使所有人获得平等权利。

1. 根据材料一，概括租地农场和手工工场的两个共同特点。（4分）
2. 根据材料二并结合所学，指出相关思潮名称，解释“借用古代形式”为什么不等于“简单恢复古代社会”。（4分）
3. 从经济、社会力量、思想之间的联系出发，自拟一个观点，用两则材料加以论述，并至少补充一项相关人物及其作品或事迹。要求观点明确、史实准确、解释连贯。（8分）
4. 指出上述思想变化的一项历史局限。（2分）

## 第13题　航海计划怎样成为现实（18分）

**关联课时：第14课。区分“为什么想去”和“为什么能够去”。**

**材料一**　以下是一份根据时代背景自编的“远航计划说明”，不是任何航海家留下的原始文件：欧洲市场需要东方香料等商品，商人希望减少中转费用、扩大财富来源；王室愿意提供支持。罗盘使用、船舶改进和地理知识发展，使跨洋航行的可行性提高。

**材料二**

| 航行线索 | 路线或结果 |
| --- | --- |
| 甲 | 沿非洲西岸南下，抵达好望角 |
| 乙 | 绕非洲南端抵达印度 |
| 丙 | 横渡大西洋，1492年到达美洲部分地区 |
| 丁 | 1519—1522年，船队完成环球航行 |

1. 根据材料一，分别概括一项经济动因和一项实现条件，并解释二者的区别。（4分）
2. 结合所学，写出甲、乙、丙对应的航海家，并说明丁项为什么应写“船队完成”，而不是“麦哲伦本人完成”。（4分）
3. 结合材料与所学，说明新航路开辟怎样加强世界联系，并指出它伴随的一项严重后果。（6分）
4. 有人认为：“1492年航行到达的是无人大陆，航行加强联系后，双方都平等受益。”指出其中两项需要纠正的认识。（4分）

## 第14题　三角贸易中的利益与苦难（18分）

**关联课时：第15课。研究贸易网络时，要辨认不同主体及其处境。**

**材料一**　早期殖民贸易的一条典型链条：欧洲商人把枪支、杂物等运到甲地；把在甲地掳掠、购买的人口经大西洋运到乙地强迫劳动；再把乙地种植园生产的蔗糖、烟草、棉花等运回欧洲。这一概括呈现典型联系，不表示每艘船都依次航行全部三段。

**材料二**　欧洲殖民者从殖民掠夺和奴隶贸易中积累财富。大量非洲人被强行离开家园，原有社会受到破坏；在美洲，被奴役者遭受暴力控制和劳动剥削。不同群体参与同一贸易网络，并不意味着他们自愿或平等获益。

1. 写出甲、乙分别对应的大洲，概括这一贸易链条的名称及其核心罪恶。（4分）
2. 根据材料二，从欧洲殖民者、非洲社会、在美洲被奴役者三个角度说明其影响。（6分）
3. 结合所学，解释这种财富积累与欧洲资本主义发展的联系。能否据此证明殖民掠夺是资本主义发展的唯一原因？（4分）
4. 若只有殖民公司的利润账簿，能否完整评价三角贸易？说明理由，并提出一类可补充的史料及其用途。（4分）

## 第15题　英国王权与议会的变化（18分）

**关联课时：第16课，按教材正文题名“英国资产阶级革命”使用。**

**材料一**

| 时间 | 事件 |
| --- | --- |
| 1640年 | 议会重新召开，国王与议会的冲突加剧 |
| 1649年 | 查理一世被处死，英国宣布为共和国 |
| 1660年 | 斯图亚特王朝复辟 |
| 1688年 | 光荣革命 |

**材料二**　1689年《权利法案》以法律约束国王：未经议会同意，国王不得擅自停止法律实施、征税等；议会的相关权利得到确认。英国保留君主，君主立宪制逐渐确立。

1. 根据材料一，用两项事实说明英国革命过程的一个特点。（4分）
2. 根据材料二，说明国王与议会的权力关系发生了怎样的变化，并指出形成的政体。（4分）
3. 结合所学，指出新兴资产阶级和新贵族反对君主专制的一项社会经济原因。（2分）
4. 围绕“政治变革的过程与制度成果”，自拟一个观点，用材料中的至少两项具体事实进行论述。不得把保留君主直接等同于君主专制。（8分）

## 第16题　北美从争取独立到组织国家（18分）

**关联课时：第17课。不同文件回应不同历史任务。**

**材料一**　英国通过税收、贸易限制等加强对北美殖民地的控制，引起反抗。1776年《独立宣言》宣布13个殖民地脱离英国，并提出自由、平等和人民有权改变损害其权利的政府等原则。1783年英国承认美国独立。

**材料二**　1787年宪法确立联邦制，按照分权制衡原则组织国家：立法、行政、司法分别由相应机构行使。它巩固独立成果，但并未废除奴隶制，也没有使妇女等群体立即获得平等的政治参与权。

1. 根据材料一并结合所学，从两个方面说明美国独立战争的性质及各自依据。（6分）
2. 比较《独立宣言》和1787年宪法主要回应的历史任务。（4分）
3. 结合所学，写出美国行使立法、行政、司法权的主要机构，并说明分权制衡意在防止什么问题。（4分）
4. 结合两则材料，说明评价近代民主文件时为什么要区分“原则宣示”和“实际权利范围”。（4分）

## 第17题　法国革命、法典与帝国（18分）

**关联课时：第18课。评价革命人物时，应区分不同行为与影响。**

**材料一**　法国旧制度使不同等级的权利、税负明显不平等。启蒙思想批判专制和特权，传播自由、平等等观念。1789年革命爆发，《人权宣言》强调自由、法律面前平等和财产权利。

**材料二**

| 时间 | 相关史实 |
| --- | --- |
| 1799年 | 拿破仑发动政变，掌握政权 |
| 1804年 | 《拿破仑法典》颁布；同年法兰西第一帝国建立 |
| 帝国时期 | 对外战争打击部分欧洲封建势力、传播革命原则，也造成侵略、掠夺与民族压迫 |

1. 根据材料一，从社会制度和思想两个方面解释革命发生的背景。（4分）
2. 从《人权宣言》的原则中任选两项，说明它们与旧制度的冲突。（4分）
3. 指出1799年和1804年不能合并成同一事件的理由。（2分）
4. 以“评价拿破仑需要区分制度建设与战争影响”为观点，结合材料和所学写一段论述。至少使用两项具体事实，兼顾积极作用与局限或危害。（8分）

## 第18题　蒸汽、工厂与城市生活（18分）

**材料一**

| 观察对象 | 典型情况 |
| --- | --- |
| 手工工场 | 雇工分工协作，主要依靠手工生产 |
| 机器工厂 | 机器与工人集中，统一安排劳动，蒸汽动力逐渐得到广泛应用 |
| 交通运输 | 铁路、蒸汽机车等扩大商品和人员流动范围 |

**材料二**　工业革命使英国生产能力大幅提高，工业城市吸引人口。与此同时，工厂劳动时间长、童工处境恶劣，一些城市出现污染、拥挤和卫生问题。生产增长与生活改善之间存在需要解决的社会问题。

1. 根据材料一，概括工业革命在生产技术和组织形式上的两项变化。（4分）

4. 从“技术进步与社会发展”出发，自拟一个观点，用材料中的至少两项事实论证。须同时回应生产进步与社会问题。（8分）

## 第19题　工人运动为什么需要理论和组织（18分）

**关联课时：第20—21课。把社会矛盾、思想探索与组织实践相联系。**

**材料一**　工业资本主义发展创造大量财富，但许多工人收入低、劳动时间长，并承受失业风险。早期一些反抗把机器看作困苦根源；后来工人逐渐提出工资、工时和政治权利等要求，运动范围不断扩大。

**材料二**　马克思、恩格斯研究资本主义社会并参加工人运动。1848年《共产党宣言》发表，为工人阶级认识社会和开展斗争提供科学理论。1864年，国际工人协会在伦敦成立，后称第一国际，推动各国工人联系和共同斗争。

1. 根据材料一，概括工人开展斗争的两项现实原因，并说明捣毁机器这一方式的认识局限。（6分）
2. 根据材料二并结合所学，指出马克思主义诞生的标志，说明理论研究与工人运动实践之间的联系。（4分）
3. 指出第一国际的组织性质，并分析工人为什么需要加强跨国联系。（4分）
4. 有人说：“1848年已经建立了世界上第一个无产阶级国家。”辨析这一说法，要求区分理论文献、国际组织与政权。（4分）

## 第20题　为巴黎公社与《国际歌》办展（18分）

**关联课时：第21—22课。完成一次历史与音乐相结合的主题探究。**

**材料一**　拟用于展览的史实卡：

- A：1888年，狄盖特为歌词谱曲，歌曲逐渐广泛传播。
- B：1871年3月，巴黎公社成立，探索建立新的政权，实行公职人员选举等措施。
- C：1871年5月，巴黎公社失败；其后鲍狄埃创作《国际歌》歌词。

**材料二**　策展小组希望表达：公社虽失败，工人争取解放和团结奋斗的历史记忆并未中断。组内一位同学提出：“既然歌曲后来传播很广，就能证明1871年所有巴黎居民都支持公社，而且了解后来这首曲调。”

1. 按时间为A、B、C排序，指出巴黎公社的政权性质，并区分歌词创作与谱曲的时间。（4分）
2. 说明材料二中该同学的推论有哪些问题，至少指出两处。（4分）
3. 如要核查公社的具体措施，提出一类合适史料，并说明它比后来宣传海报更适合核实什么问题。（2分）
4. 为展览自拟一个包含明确历史判断的主题，用至少两项材料中的事实写一段展览导言，说明历史事件、艺术创作与记忆传播之间的联系。不要抄写歌词。（8分）
