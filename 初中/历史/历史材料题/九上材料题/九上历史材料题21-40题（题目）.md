## 使用说明

本组20题继续依据本地九上七个单元、22课编写。与前组相比，保留必要主干知识，重点更换研究问题、材料组织和作答产物，增加配组、纠错、比较、流程解释和论证提纲。

- 全部为原创训练题。文字、表格、流程和活动情境为据教材知识编写的教学整理，不是历史人物原话或史料逐字摘录。假设情境、示意数据单独标明，不虚配真实遗址、企业、文献或统计出处。
- 每题建议18分，本组共360分，供分次练习；分值、量规均为自拟，不代表深圳官方题型比例或评分标准。
- 设问限九上范围。题面给出的补充信息可以直接使用，不要求事先背诵九下内容。
- 参考深圳材料题的主题贯通、证据处理和史论结合方式，不是历年真题，也不作下一年命题预测。
- 第16课仍按原教材正文使用“英国资产阶级革命”，不沿用本地文件夹中的国别笔误。

## 第21题　食物生产的多地探索（18分）

**关联课时：第1、12课。为“人类怎样学会生产食物”制作学习展板。**

**材料一**　以下是依据教材整理的早期农业若干起源区域及当地早期培育的代表性作物，不表示每种作物都在同一年起源，也不表示其他地区没有农业。

| 区域 | 代表性栽培作物 |
| --- | --- |
| 西亚 | 小麦、大麦 |
| 东亚 | 水稻、粟、黍 |
| 美洲 | 玉米、马铃薯等 |

**材料二**　展板准备使用两组证据：A组为野生动物骨骼和猎具；B组为栽培谷物遗存、收割工具及储藏设施。研究人员需要从获取现成食物、主动生产食物等角度解释人类生活的改变。

1. 根据材料一，概括早期农业起源的一项空间特点，并用两个区域的作物例子支持。（4分）
2. 从材料二选择更直接支持“人类开始主动生产食物”的一组证据，解释组内两项证据各自的作用。（4分）
3. 结合所学，从生活方式和社会分工两个方面解释农业发展可能带来的变化。（4分）
4. 为展板写一段说明，解释“不同区域的农业创造共同丰富了人类文明”。须使用两个不同区域的例子，并区分作物的早期培育与后来跨地区传播。（6分）

**关联课时：第2课。尝试让材料回答具体研究问题。**

**材料一**

| 编号 | 据教材整理的材料线索 |
| --- | --- |
| A | 两河流域泥板文献记录粮食、交易、借贷等事务，使用楔形文字 |
| B | 《汉谟拉比法典》对租赁、雇佣和债务等作出规定，不同身份者的法律地位有差异 |
| C | 两河流域发展60进制等数学知识，天文历法与计时经验对后世产生影响 |

**材料二**　同一批文献既可能用于研究生产交换，也可能用于研究管理方式。法典中的规定能说明统治者期望建立的秩序，但研究实际案件怎样处理，还需查阅其他记录。

1. 为“社会经济活动”“社会等级关系”“数学知识传承”三个研究问题分别选择最合适的材料编号，并解释其中一项配组依据。（4分）
2. 根据A、B，说明书写与规则制定怎样回应经济社会活动的需要。（4分）
3. 根据C并结合日常生活，举一个今天仍可观察到的60进制运用例子，说明它为何属于历史传承的线索。（4分）
4. 若研究“法典规定是否在实际生活中得到执行”，设计一个小型研究方案，写出应比较的两类材料、要核查的具体内容及一项研究限制。（6分）

## 第24题　用不同材料认识古代印度（18分）

**关联课时：第4课。同一区域的历史需要不同材料共同照亮。**

**材料一**　哈拉帕、摩亨佐—达罗等遗址保留规划较整齐的街道和给排水设施；一些印章刻有尚未成功释读的符号。这些遗存能够帮助研究城市技术与生活，但符号内容不能随意翻译。

**材料二**　古代印度佛教艺术在传播中与其他地区文化相联系。犍陀罗艺术将佛教题材与希腊雕塑风格结合；数字符号系统也经阿拉伯人等传播到更多地区。这些现象与更早的印度河城市文明不属于同一历史阶段。

**待校摘要**　“哈拉帕印章已经被完全译出，因此我们知道当地居民普遍信奉后来创立的佛教。犍陀罗艺术说明不同文化接触只能保持原样，不能产生新形式。”

1. 从材料一中选出能够研究城市公共生活的两项线索，并分别说明其价值。（4分）
2. 根据材料二，概括文明传播中两种不同的联系形式。（4分）
3. 指出待校摘要中的三处问题，并分别写出修正意见。（6分）
4. 为“城市技术”与“宗教艺术交流”各拟一个研究问题，说明为什么不能只凭同一件未释读印章同时解答这两个问题。（4分）

## 第25题　从希腊城邦到跨区域帝国（18分）

**关联课时：第5课。比较制度，也比较人群在扩张中的处境。**

**材料一**　希腊世界存在不同城邦。雅典以成年男性公民参与的民主政治著称；斯巴达政治权力较集中于少数统治者，重视军事训练。两者都形成城邦共同体，并依赖奴隶等被统治群体的劳动。

**材料二**　亚历山大东征建立跨欧、亚、非的庞大帝国。战争破坏一些地区的社会生活，征服也使人员、商品和文化在更大范围流动。对统治者、商人和遭受战争的人而言，这一过程的意义并不相同。

1. 比较雅典、斯巴达在“政治参与方式”上的不同点和在“社会基础”上的共同点。（4分）
2. 根据材料二，指出亚历山大帝国与希腊城邦在空间规模上的区别，并说明这种变化如何影响区域联系。（4分）
3. 为“战争与文化交流”拟一个可以论证的判断句，不得以交流作用掩盖战争破坏。（2分）
4. 围绕你拟定的观点，用材料中的至少两项事实写一段论述，须分别解释交流作用与战争代价。（8分）

## 第26题　罗马平民与公开的法律（18分）

**关联课时：第6课。研究权利变化如何发生。**

**材料一**　罗马共和国初期，贵族占据重要政治地位。平民经过长期斗争，逐步争得一定政治与社会权利。《十二铜表法》把一些法律规则以文字形式公布，减少了贵族任意解释法律的空间，但仍保留奴隶制及其他不平等关系。

**材料二**　罗马在扩张和司法实践中继续发展法律。后人研究罗马政治时，既能看到共和国的制度名称，也会注意实际由谁掌握权力、哪些群体可以参与及规则怎样运作。

1. 根据材料一，概括“社会斗争—规则变化—权利变化”之间的联系。（4分）
2. 分别说明法律公开的一项作用与一项不能由此直接推定的结果。（4分）
3. 根据材料二，为判断“共和国的政治参与范围”提出两个具体检查问题。（4分）
4. 为《十二铜表法》撰写一则学习说明，须交代背景、成文化的作用、时代局限及一项后世影响。（6分）

4. 为表格写一段比较结论，须说明一种经济关系变化、一个延续因素，以及为什么不能把三个类型视为全欧洲同时完成的统一替代过程。（6分）

## 第29题　追问拜占庭的兴衰（18分）

**关联课时：第9课。将“发生了什么”进一步加工成“如何影响发展”。**

**材料一**　君士坦丁堡处在交通要地，贸易使帝国获得收入和文化资源。6世纪查士丁尼时期，对外征战一度扩大统治范围，但长期战争消耗国力，重税等加重社会负担。后来多次外来冲击，包括十字军的侵入，进一步削弱帝国。1453年，奥斯曼帝国攻陷君士坦丁堡。

**材料二**　帝国衰亡之后，法律文本、建筑和希腊罗马典籍并未同时消失。研究国家衰亡的原因，与研究文化遗产怎样流传，需要使用有联系但不完全相同的证据。

1. 根据材料一，将影响帝国的因素分为“发展条件”“内部压力”“外部冲击”，每类各举一项。（4分）
2. 从材料一任选两项相关因素，写出一条包含作用机制的因果链。（4分）
3. 说明“1453年城破”作为最终事件，与帝国长期衰弱的原因有什么区别。（4分）
4. 为“拜占庭兴衰与遗产”拟一个两部分的研究提纲：每部分有一个具体问题、一类适合史料及其用途，两个部分分别研究政治兴衰和文化传承。（6分）

## 第30题　日本借鉴外来制度的途径（18分）

**关联课时：第10课。把交流渠道、借鉴内容与社会变化分开。**

**材料一**　日本与中国、朝鲜半岛长期往来，遣隋使、遣唐使等有助于知识和制度经验传播。646年开始的大化改新参考唐制，涉及中央与地方管理、土地人口和赋税安排。日本还借用汉字并逐渐形成自己的文字体系。

**材料二**　学习卡需要校订：

- A：“遣唐使是传播制度文化的渠道，所以大化改新所有措施都由唐朝直接管理实施。”
- B：“日本借用汉字，因此从未形成自己的文字创造。”
- C：“学习外来经验与回应本国社会需要可以同时发生。”

1. 从材料一分别列举一项“交流渠道”“制度借鉴”“文化创造”，说明三者为何不是同一概念。（4分）
2. 修正A、B两张学习卡，分别指出推论跨越了哪一步。（4分）
3. 围绕C卡，解释改革者为什么既要学习经验，又要处理本国人口、土地等问题。（4分）
4. 若要核查一项借鉴措施是否在日本实际实施，设计两步核查办法，说明每步所需史料和作用；不要只写“证明双方曾有交流”。（6分）

| 7世纪 | 伊斯兰教产生，穆罕默德的活动推动阿拉伯半岛政治整合 |
| 此后扩张时期 | 帝国联系多个区域，城市、商路与不同文化发生联系 |
| 9世纪 | 巴格达的知识活动汇聚典籍、译者与学者，翻译研究发展 |

**材料二**　商路方便人员和书籍流动，城市提供相会与学习的空间，统治者的支持有助于组织翻译。学者并非只把外来文字换成另一种语言，还会讨论、校订和研究，形成新的知识成果。

1. 根据材料一，说明宗教发展、政治整合与知识活动之间可以建立怎样的阶段联系。（4分）
2. 从材料二选取两种力量，分别解释其在知识网络中的作用。（4分）
3. 为“知识如何跨区域发展”拟一个明确观点，不能只写一个主题词。（2分）
4. 用材料中的至少两项具体活动论证该观点，并在论述中交代它们分处不同阶段，避免把长期过程压缩成同一年发生的事件。（8分）

## 第32题　西非商路上的资源与国家（18分）

**关联课时：第12课。不要只把一条商路看成几种货物的移动。**

**材料一**　西非一些地区拥有黄金等资源，北非拥有食盐并需要黄金，双方通过跨撒哈拉商路交换。加纳、马里、桑海等国家在不同阶段发展，农业、贸易与城市共同提供基础。控制商路、组织秩序和发展文化等，也是国家发展的重要活动。

**材料二**　曼萨·穆萨的远行使马里的财富引起外部关注。不过，旅行者在某次行程中观察到的宫廷、商人和财富，不等于该地区所有人的日常生活，也不能独自解释数百年的国家兴衰。

1. 用“需求互补—商路—城市或国家”的结构，解释西非贸易网络的一个发展机制。（4分）
2. 在“矿区”“交换城市”“政治统治者”三个节点中任选两个，分别说明它们在网络中的作用。（4分）
3. 若以旅行记研究当地社会，说明应首先核查的两项来源信息，并指出为什么需要核查。（4分）
4. 拟出两个不同层面的研究问题，分别考察国家财富和普通居民生活；为每问配一类适合史料，并说明这两问怎样互相补充。（6分）

## 第34题　文艺复兴作品怎样表现人（18分）

**关联课时：第13课。以下为作品学习提示，不代替原作图像或逐字引文。**

**材料一**　《蒙娜丽莎》刻画人物形象与表情；《最后的晚餐》虽然取材宗教故事，却细致表现人物的动作和不同情感；莎士比亚戏剧描绘人的性格、选择与冲突。这些作品体现了对人的生活与价值的关注。

**材料二**　文艺复兴的重要中心出现于意大利工商业城市。经营与财富积累、市民和新兴资产阶级的文化需求、人才交流等，为创作和传播提供条件。作品仍可能使用古典或宗教题材，不能只凭题材名称判断其思想表达。

1. 根据材料一，概括三项作品提示之间的共同思想取向，并写出对应思潮名称。（4分）
2. 选择《最后的晚餐》，解释“宗教题材”与“关注人的情感”为什么可以同时存在于一部作品中。（4分）
3. 从材料二中选择一个条件，说明它怎样支持文艺创作。（2分）
4. 为“从作品读懂文艺复兴”写一段展览导言，自拟一个明确观点，至少使用两项作品事实，说明观察题材与观察表达方式有什么不同。（8分）

## 第35题　手工工场与机器工厂（18分）

**关联课时：第13、19课。先确认比较条件，再使用数字解释生产变化。**

**材料一**　手工工场中，雇工可以集中分工，但主要依靠手工；机器工厂中，机器成为重要生产手段，统一管理生产和劳动。雇佣劳动、市场销售等关系在两种组织中都可能存在。

**材料二（完全虚构的教学示意数据）**　假设两组工人都为10人，各劳动一天，生产的是同类产品：甲组以手工为主，生产100件；乙组使用某种机器，生产300件。此表不对应任何真实企业或历史统计，也未提供设备成本、工资、质量和劳动强度等数据。

1. 根据材料一，指出两种生产组织的一项共同点与一项关键区别。（4分）
2. 根据材料二，计算两组的人均日产量，并说明乙组是甲组的多少倍。（4分）
3. 该比较能够说明什么，又不能直接证明“乙组工人收入更高、生活一定更好”的原因是什么？（4分）
4. 如果要把示意比较变成对真实历史工厂的研究，提出两项需要核查的比较条件和两类需要补充的资料，说明核查目的。（6分）

## 第36题　新航路之后的贸易与权力（18分）

**关联课时：第14—15课。考察商业联系中权力怎样发挥作用。**

**材料一**　绕非洲到亚洲的航线和横跨大西洋的航线形成后，欧洲国家在海外建立据点，争夺市场和资源。某些贸易公司得到政府特许，拥有垄断权益，甚至使用武装。贸易、国家支持与殖民扩张发生紧密联系。

**材料二**　假设一个学习小组有三类资料：A为公司的利润和货运记录；B为政府授予公司的特许文件；C为被占领地区的地方记录或居民叙述。它们可能从不同角度记载同一段扩张过程，不能互相简单替代。

1. 根据材料一，说明新航路怎样为海外据点和贸易扩展提供条件。（4分）
2. 分别解释“政府特许”与“公司武装”如何改变普通商业交换的条件。（4分）
3. 在A、B、C中，为研究“公司利润”“权力来源”“当地社会处境”分别选择较直接的一类，并解释其中一个选择。（4分）
4. 为“贸易扩展是否意味着参与者处境相同”设计一个比较研究：明确两类主体、一个共同维度和需要配合使用的两类资料，并说明比较目的。（6分）

## 第37题　英国与北美的政治变革（18分）

**关联课时：第16—17课。比较共同诉求，也辨认具体任务。**

**材料一**　17世纪英国议会与国王围绕征税、法律和权力发生斗争；北美殖民地反对英国的税收与贸易限制，要求摆脱殖民控制。两地都有经济利益和政治权利的诉求，但需要解决的统治关系不同。

**材料二**　北美战争中，华盛顿领导大陆军作战，殖民地民众提供支持。1777年萨拉托加大捷改变战局并推动法国等扩大援助，1781年约克镇战役英军投降，1783年英国承认美国独立。内部动员、战场胜利与外部援助相互影响。

1. 根据材料一，指出两地的一项共同诉求，并分别说明其主要反对的统治关系。（4分）
2. 根据材料二，解释萨拉托加大捷与外部援助之间的联系，区分“转折性战役”与“独立获承认”两个节点。（4分）
3. 提出一个关于“政治变革道路与具体条件”的观点。（2分）
4. 为该观点写一份论证提纲，须有英国、北美各一项具体史实和各自的解释，并形成简短结论；不要只列时间表。（8分）

## 第39题　一次发明怎样带动连续改进（18分）

**关联课时：第19课。下列为据教材整理的技术关系，不是严格按单线发展的发明年表。**

**材料一**　棉纺织业中，珍妮纺纱机、水力纺纱机、骡机等提高了纺纱能力，织布、动力和运输环节也不断改进。瓦特改进蒸汽机，使蒸汽动力能够更广泛地使用。技术来自不同人的劳动，应用还需要资金、原料、工人和市场等条件。

**材料二**　某份待修改的人物简介写道：“瓦特独自创造了英国工业革命。他发明了最早的蒸汽机，因此所有行业立刻同时改用机器；只要知道他的生平，就能解释全部工厂的发展。”这是一段供辨析的自编文字，不是历史引文。

1. 根据材料一，举两个不同环节，说明技术进步为什么需要相互配合。（4分）
2. 解释发明、改进与广泛应用三个概念的区别。（4分）
3. 指出材料二中的两处关键问题，并分别纠正。（4分）
4. 将这段简介改写成一则准确的人物与时代说明，须保留瓦特的具体贡献，补充两项应用条件，并体现其他劳动者与连续改进的作用。（6分）
