# 03-数据、网络、信息检索与安全

计算机处理的是数据，网络传输的也是数据。学习编程前，需要先理解数据如何表示、网络如何工作，以及怎样安全、负责地使用网络资料和 AI 工具。

---

## 一、学习目标

学完本节，你应该能做到：

1. 知道计算机内部用 0 和 1 表示数据。
2. 理解 bit、Byte、KB、MB、GB 的大致含义。
3. 知道文字、图片、声音、视频都可以数字化。
4. 能解释浏览器、网址、域名、IP、服务器、上传、下载。
5. 会用关键词搜索资料，并初步判断资料是否可靠。
6. 知道保护隐私、设置密码、尊重版权和合理使用 AI 的基本规则。

---

## 二、数据是什么

数据是计算机可以保存、处理和传输的信息。

常见数据包括：

- 文字：作文、聊天记录、代码。
- 图片：照片、图标、网页插图。
- 声音：音乐、录音、提示音。
- 视频：课堂录像、短片。
- 数字：成绩、价格、年龄、温度。
- 程序：Python 代码、网页代码、应用软件。

计算机并不是直接“理解”文字和图片，而是把它们转换成数字进行处理。

---

## 三、二进制、位和字节

### 1. 二进制

计算机内部最基本的表示方式是二进制。

二进制只使用两个数字：

```text
0 和 1
```

可以把 0 和 1 想象成开关：

| 状态 | 二进制表示 |
|---|---|
| 关 | 0 |
| 开 | 1 |

一个灯只有开和关两个状态，用 0 和 1 就能表示。

### 2. bit

bit 是最小的数据单位，一个 bit 只能表示 0 或 1。

```text
1 bit = 一个 0 或 1
```

### 3. Byte

8 个 bit 通常组成 1 个 Byte，也叫 1 字节。

```text
8 bit = 1 Byte
```

文件大小常用字节及其更大的单位表示。

### 4. 常见容量单位

| 单位 | 大致含义 | 常见例子 |
|---|---|---|
| B | 字节，很小 | 一小段文字 |
| KB | 约一千字节 | 小文本、简单图标 |
| MB | 约一百万字节 | 图片、音乐、文档 |
| GB | 约十亿字节 | 视频、软件、游戏 |
| TB | 约一万亿字节 | 大容量硬盘 |

你不需要背精确换算，但要能判断：视频通常比图片大，图片通常比纯文本大。

## 四、文字、图片和声音如何数字化

### 1. 文字

计算机用编码规则把文字变成数字。

常见编码规则：

- ASCII：较早的英文字符编码。
- Unicode：可以表示多种语言文字。

例如，字母、数字、汉字、标点符号，在计算机中都会用对应数字保存。

### 2. 图片

图片由很多像素组成。

像素可以理解为图片中的小点。

| 概念 | 说明 |
|---|---|
| 像素 | 图片中的小点 |
| 分辨率 | 横向像素数 × 纵向像素数 |
| 颜色 | 每个像素可以有不同颜色 |
| 文件大小 | 像素越多、颜色越复杂，通常越大 |

活动：

1. 打开一张图片。
2. 放大很多倍。
3. 观察图片是否变成一个个小方块。
4. 这些小方块就是像素的直观表现。

### 3. 声音

声音也可以变成数字保存。

可以简单理解为：计算机在很短的时间间隔里不断记录声音的变化，再把这些变化保存为数字。

声音文件大小通常与这些因素有关：

- 时长。
- 音质。
- 压缩方式。

### 4. 视频

视频可以看成很多张连续变化的图片，再加上声音。

所以视频文件通常比较大。

## 五、认识网络

网络让不同设备之间可以传输数据。

当你打开一个网页时，大致发生了这些事：

```text
你在浏览器输入网址
→ 浏览器向服务器请求网页
→ 服务器返回网页数据
→ 浏览器把数据显示成页面
```

### 常见网络概念

| 概念 | 通俗解释 |
|---|---|
| 浏览器 | 用来访问网页的应用程序 |
| 网址 URL | 网络资源的地址 |
| 域名 | 方便人记忆的网站名称 |
| IP 地址 | 网络中设备或服务器的位置标识 |
| 服务器 | 为其他设备提供服务的计算机 |
| 客户端 | 请求服务的设备或程序，例如你的浏览器 |
| HTTP/HTTPS | 浏览器和服务器传输网页数据的规则 |
| 局域网 | 学校机房、家庭路由器下的小范围网络 |
| Wi-Fi | 无线接入网络的方式之一，不等于互联网本身 |

### 上传和下载

| 操作 | 含义 | 例子 |
|---|---|---|
| 上传 | 从本机发送到网络或服务器 | 提交作业、上传照片 |
| 下载 | 从网络保存到本机 | 下载资料、保存图片 |

注意：下载到电脑后，文件会保存在某个文件夹里。你需要知道它在哪里。

## 六、信息检索：如何更好地搜索

学习编程时，不可能只靠记忆。会查资料是一项重要能力。

### 1. 用准确关键词

不要只输入很模糊的问题。

| 模糊搜索 | 更好的搜索 |
|---|---|
| `电脑坏了怎么办` | `Windows docx 文件打不开 解决方法` |
| `python 不行` | `Python SyntaxError invalid syntax 原因` |
| `网页怎么做` | `HTML 标题 段落 图片 基础教程` |
| `图片不出来` | `HTML img 图片路径 不显示 原因` |
| `循环错了` | `Python while 循环 停不下来 原因` |

### 2. 搜索前先提取关键词

以“Python 输入成绩后判断是否及格”为例。

关键词可以是：

```text
Python input if else 成绩 判断
```

比整句搜索更清楚。

### 3. 看资料类型

搜索结果可能是：

- 官方文档。
- 教程文章。
- 问答网站。
- 视频教程。
- 广告内容。
- 复制转载内容。

初学者优先选择：

1. 老师指定资料。
2. 教材资料。
3. 官方文档或权威机构资料。
4. 结构清楚、示例简单的入门教程。

### 4. 交叉验证

如果两个资料说法不一样，不要马上相信第一个结果。

可以：

1. 再查一个来源。
2. 看发布时间。
3. 看是否适合初学阶段。
4. 自己动手试一试。
5. 问老师或同学确认。

## 七、网络安全与隐私保护

### 1. 不能随便泄露的信息

不要在陌生网站、聊天群或 AI 工具中随便输入：

- 真实姓名。
- 家庭住址。
- 电话号码。
- 身份证号。
- 学校班级。
- 账号密码。
- 验证码。
- 家庭成员信息。

### 2. 密码安全

好的密码应该：

1. 不太短。
2. 不直接使用生日、姓名、手机号。
3. 不多个重要账号共用同一个密码。
4. 不告诉别人。
5. 不写在容易被看到的地方。

不推荐：

```text
123456
password
生日+姓名
```

更推荐使用较长、包含不同字符的密码，并由家长或老师指导安全管理。

### 3. 不随便点击和下载

遇到下面内容要小心：

- “免费皮肤”“免费会员”。
- “中奖领奖”。
- “账号异常，请立即登录”。
- 陌生人发来的压缩包和程序。
- 来历不明的软件安装包。

不确定时，不要自己处理，先问老师或家长。

## 八、版权和引用规范

网上的图片、音乐、文字、代码，不是都可以随便使用。

学习作品中使用资料时，应做到：

1. 尽量使用自己拍摄、自己绘制或老师提供的素材。
2. 使用网上资料时记录来源。
3. 不把别人的作品说成自己的。
4. 不传播破解软件、盗版资源或恶意程序。
5. 公开展示作品前，检查是否包含他人隐私或受版权保护的内容。

简单引用记录示例：

```text
图片来源：学校官网资料页
文字资料来源：信息科技教材第 2 单元
代码参考：老师课堂示例，已自行修改和测试
```

## 九、负责任使用 AI 工具

AI 可以帮助你解释概念、检查思路、生成练习题，但不能代替你学习。

### 可以问 AI 的问题

```text
请用初中生能懂的话解释 Python 变量。
```

```text
我写了一个成绩判断程序，应该准备哪些测试数据？
```

```text
请帮我把下面流程改写成更清楚的步骤。
```

### 不适合直接问 AI 的方式

```text
帮我写完整作业，我直接交。
```

```text
这是我的账号和密码，帮我登录。
```

```text
帮我绕过学校系统限制。
```

### 使用 AI 后必须自己检查

AI 可能会出错，所以你要：

1. 自己运行代码。
2. 自己测试结果。
3. 能解释每一部分作用。
4. 不懂的地方继续追问或请教老师。
5. 不把 AI 生成内容直接当成事实。

## 十一、常见问题与对策

| 问题 | 对策 |
|---|---|
| 分不清 KB、MB、GB | 多比较真实文件大小，先形成大小感觉 |
| 以为 Wi-Fi 就是互联网 | Wi-Fi 是接入方式，互联网是更大的网络 |
| 搜索结果太多不知道看哪个 | 优先老师指定资料、官方资料和清楚的入门教程 |
| 直接复制网上代码 | 先写 IPO 和流程，再逐行理解代码 |
| 忘记记录图片来源 | 做作品时同步建立“素材来源.txt” |
| AI 生成答案看起来很对 | 必须运行、测试、核查来源 |
