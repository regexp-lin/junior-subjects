# 12-学习清单、评价标准与常见问题

本文件用于学习后的自查、复习和评价。你可以在每个阶段结束时用它检查自己是否真正掌握，而不是只觉得“看过了”。

---

## 一、总学习路线回顾

建议路线：

```text
计算机基础
→ 文件管理、路径、键盘输入
→ 数据、网络、信息检索与安全
→ 计算思维、流程图、IPO 模型
→ 图形化编程
→ Python 基础
→ Python 小项目
→ 网页或硬件拓展
→ 综合项目
→ 展示、反思、改进
```

如果时间较少，最小路线：

```text
文件管理
→ 英文符号和快捷键
→ IPO 与流程图
→ 图形化编程基础
→ Python 输入输出、变量、条件、循环
→ 一个综合小项目
```

## 二、计算机基础达标清单

### 1. 计算机系统

- [ ] 我能解释计算机会接收输入、处理数据、保存数据和输出结果。
- [ ] 我能说出硬件、软件、数据、网络的关系。
- [ ] 我能举出电脑、手机、服务器等计算设备的共同点。
- [ ] 我知道程序是让计算机执行的一组明确指令。

### 2. 硬件和软件

- [ ] 我知道 CPU 负责计算和执行指令。
- [ ] 我知道内存主要用于程序运行时临时存放数据。
- [ ] 我知道硬盘用于长期保存文件。
- [ ] 我知道键盘、鼠标、摄像头等是输入设备。
- [ ] 我知道显示器、音箱、打印机等是输出设备。
- [ ] 我知道操作系统和应用程序不是一回事。

### 3. 基本操作

- [ ] 我能打开、切换和关闭应用程序。
- [ ] 我能调整窗口大小和位置。
- [ ] 我能处理简单的程序无响应问题。
- [ ] 我会保存文件并重新打开。

## 四、数据、网络与安全达标清单

### 1. 数据基础

- [ ] 我知道计算机内部用 0 和 1 表示数据。
- [ ] 我知道 bit 是最小数据单位。
- [ ] 我知道 8 bit 通常组成 1 Byte。
- [ ] 我能大致理解 B、KB、MB、GB 的大小关系。
- [ ] 我知道文字、图片、声音、视频都可以数字化。
- [ ] 我知道图片由像素组成。

### 2. 网络基础

- [ ] 我知道网络让设备之间可以传输数据。
- [ ] 我知道浏览器用于访问网页。
- [ ] 我知道网址用于定位网络资源。
- [ ] 我知道域名方便人记忆，IP 地址用于网络定位。
- [ ] 我知道服务器为客户端提供服务。
- [ ] 我能区分上传和下载。
- [ ] 我知道 Wi-Fi 不等于整个互联网。

### 3. 信息检索和判断

- [ ] 我能把模糊问题改成关键词搜索。
- [ ] 我能区分教程、广告、问答、官方资料等不同来源。
- [ ] 我会优先参考老师指定资料、教材和权威资料。
- [ ] 我遇到矛盾信息时会交叉验证。
- [ ] 我使用资料时会记录来源。

### 4. 安全和规范

- [ ] 我不会随便泄露真实姓名、电话、住址、账号密码、验证码等信息。
- [ ] 我不会点击来历不明的链接。
- [ ] 我不会下载不明软件。
- [ ] 我知道密码不能太简单，也不能随便告诉别人。
- [ ] 我知道使用图片、文字、音乐、代码要尊重版权。
- [ ] 我能合理使用 AI，不直接复制、不泄露隐私、不盲信结果。

## 十、常见困难与对策

| 困难 | 可能原因 | 对策 |
|---|---|---|
| 找不到文件 | 文件管理不清楚 | 每节课固定项目目录，提交前检查路径 |
| 扩展名不对 | 系统隐藏扩展名 | 显示扩展名，确认 `.py`、`.html` 等后缀 |
| 经常输入中文标点 | 输入法状态没注意 | 运行前检查括号、引号、冒号 |
| 看不懂报错 | 害怕英文提示 | 先找行号和关键词，不要求全部读懂 |
| 条件判断混乱 | 没写清规则 | 先画表格，再写 `if` 顺序 |
| 循环停不下来 | 没有变化量或结束条件 | 写出起点、条件、重复内容、变化量 |
| 变量总是报错 | 变量名拼写不一致 | 使用有意义变量名，复制变量名避免拼错 |
| 程序能运行但结果错 | 没有测试边界数据 | 用 0、60、90、100 等数据测试 |
| 只会复制代码 | 没有先分析 | 每个程序先写 IPO 和自然语言步骤 |
| 项目太大做不完 | 选题范围过大 | 先做最小版本，再做拓展 |
| 网页图片不显示 | 图片路径错误或漏交 | 图片放入项目文件夹，使用相对路径 |
| AI 代码看不懂 | 直接复制 | 要求自己能解释输入、处理、输出和每个变量 |

## 十三、继续学习方向

完成入门后，可以选择一个方向继续深入。

| 方向 | 适合学生 | 可以学习什么 |
|---|---|---|
| Python 深入 | 喜欢解决问题和自动化 | 文件读写、数据统计、绘图、小游戏 |
| 网页制作 | 喜欢设计和展示 | HTML、CSS、JavaScript、网页布局 |
| 硬件机器人 | 喜欢动手和设备 | micro:bit、Arduino、传感器、机器人控制 |
| 数据处理 | 喜欢表格和分析 | 数据收集、清洗、统计、可视化 |
| 信息学竞赛 | 喜欢算法挑战 | 枚举、模拟、排序、搜索 |
| 数字创作 | 喜欢综合作品 | 动画、交互故事、宣传网页、创客项目 |

选择方向时，不要频繁换。先沿一个方向做出 2 到 3 个完整作品，再考虑拓展。

## 十四、最终目标

学习信息科技，不只是为了会用某个软件或背某种语法，而是为了形成解决问题的能力。

你最终要逐步做到：

```text
遇到问题
→ 能拆解
→ 能找资料
→ 能设计步骤
→ 能动手实现
→ 能测试修改
→ 能安全负责地展示作品
```

如果你能做到这些，就已经真正迈入了信息科技学习的大门。
