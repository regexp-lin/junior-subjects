# 02-文件管理、路径与键盘输入

很多初学者写程序遇到的第一个困难，不是代码太难，而是文件找不到、扩展名不对、路径写错、中文标点输错。本节专门打牢这些基础。

---

学完本节，你应该能做到：

1. 建立清楚的学习文件夹结构。
2. 正确新建、重命名、移动、复制、删除和查找文件。
3. 理解文件名、扩展名、文件类型的关系。
4. 初步理解绝对路径和相对路径。
5. 会压缩、解压和备份项目文件。
6. 能输入常见编程英文符号。
7. 熟练使用复制、粘贴、撤销、保存、查找等快捷键。

## 三、认识文件和文件夹

### 1. 文件

文件用于保存数据。常见文件包括：

| 文件 | 例子 | 用途 |
|---|---|---|
| 文本文档 | `学习记录.txt` | 保存文字 |
| 图片 | `校园照片.jpg` | 保存图像 |
| Python 程序 | `main.py` | 保存 Python 代码 |
| 网页 | `index.html` | 保存网页结构 |
| 样式文件 | `style.css` | 保存网页样式 |
| 压缩包 | `作业.zip` | 打包多个文件 |

### 2. 文件夹

文件夹用于分类管理文件。一个好的文件夹结构能让你很快找到资料。

不推荐：

```text
桌面
├── 代码.py
├── 新建文档.txt
├── 图片1.png
├── 最终版.html
├── 最终版2.html
└── 作业.zip
```

推荐：

```text
信息科技学习
├── 程序代码
│   ├── Python练习
│   │   └── 成绩等级判断.py
│   └── 网页作品
│       └── 校园安全网页
│           ├── index.html
│           ├── style.css
│           └── images
│               └── campus.jpg
└── 作业提交
    └── 2026-信息科技-网页作品.zip
```

## 四、文件名和扩展名

文件名通常由两部分组成：

```text
名称.扩展名
```

例如：

```text
成绩等级判断.py
校园安全网页.html
校园照片.jpg
学习记录.txt
```

### 常见扩展名

| 扩展名 | 常见类型 | 说明 |
|---|---|---|
| `.txt` | 文本文档 | 保存纯文字 |
| `.docx` | Word 文档 | 保存排版文档 |
| `.pptx` | 演示文稿 | 做展示汇报 |
| `.jpg` `.png` | 图片 | 网页和项目素材常用 |
| `.mp3` `.wav` | 音频 | 声音文件 |
| `.mp4` | 视频 | 视频文件 |
| `.py` | Python 程序 | Python 代码文件 |
| `.html` | 网页文件 | 网页结构 |
| `.css` | 样式文件 | 网页样式 |
| `.js` | JavaScript 文件 | 网页交互脚本 |
| `.zip` | 压缩包 | 打包多个文件 |

### 重要提醒

`hello.py.txt` 和 `hello.py` 不是一回事。

如果你想写 Python 程序，文件应是：

```text
hello.py
```

而不是：

```text
hello.py.txt
```

如果系统隐藏扩展名，你可能看不到真正的后缀。学习编程时，建议让系统显示文件扩展名。

## 五、路径是什么

路径表示文件或文件夹的位置。

可以把路径想象成地址。

```text
省/市/学校/教室/座位
```

文件路径也类似：

```text
信息科技学习/程序代码/Python练习/成绩等级判断.py
```

### 1. 绝对路径

绝对路径从磁盘或根目录开始，表示一个完整位置。

示例：

```text
C:/Users/Student/Documents/信息科技学习/程序代码/Python练习/main.py
```

或：

```text
/Users/student/Documents/信息科技学习/程序代码/Python练习/main.py
```

特点：

1. 位置完整。
2. 换一台电脑后可能不一样。
3. 路径很长，容易输错。

### 2. 相对路径

相对路径从当前文件夹出发。

例如网页文件夹：

```text
校园网页
├── index.html
└── images
    └── campus.jpg
```

在 `index.html` 中引用图片时，可以写：

```text
images/campus.jpg
```

这表示：从当前网页所在文件夹出发，进入 `images` 文件夹，找到 `campus.jpg`。

### 3. 路径常见错误

| 错误 | 结果 | 对策 |
|---|---|---|
| 图片放错文件夹 | 网页不显示图片 | 检查图片是否在指定文件夹 |
| 文件名大小写不同 | 某些系统找不到文件 | 文件名保持完全一致 |
| 扩展名写错 | 程序无法识别 | 显示扩展名并检查 |
| 中文/英文符号混用 | 代码报错或路径无效 | 编程中尽量使用英文符号 |
| 复制项目时漏文件 | 作品在别人电脑打不开 | 提交前压缩整个项目文件夹 |

## 六、压缩、解压和备份

### 1. 为什么要压缩

压缩包可以把多个文件和文件夹打包成一个文件，方便提交和传输。

常见压缩格式：

- `.zip`
- `.rar`
- `.7z`

学校作业建议优先使用 `.zip`，因为大多数电脑都能打开。

### 2. 如何压缩项目

假设你的项目文件夹是：

```text
成绩等级判断项目
├── main.py
├── 说明.txt
└── 测试记录.txt
```

提交时不要只交 `main.py`，应压缩整个项目文件夹。

步骤：

1. 找到 `成绩等级判断项目` 文件夹。
2. 右键选择压缩或发送到压缩文件。
3. 得到 `成绩等级判断项目.zip`。
4. 打开压缩包检查里面是否包含所有文件。
5. 再提交压缩包。

### 3. 如何解压

下载别人的示例项目后，不要直接在压缩包里运行。

正确步骤：

1. 下载压缩包。
2. 右键解压到一个文件夹。
3. 打开解压后的文件夹。
4. 找到真正的项目文件。
5. 再运行或查看。

### 4. 备份

重要文件至少保留两个位置：

- 电脑本地一份。
- U 盘、移动硬盘或云盘一份。

不要只把重要作业放在一个容易丢失的位置。

## 七、键盘输入与英文符号

编程对符号非常严格。中文括号、中文引号、中文冒号，常常会导致程序报错。

### 常见编程符号

| 符号 | 名称 | 常见用途 |
|---|---|---|
| `()` | 小括号 | 函数调用、表达式分组 |
| `[]` | 中括号 | 列表、下标 |
| `{}` | 大括号 | 字典、集合、代码块 |
| `"` `'` | 引号 | 表示文本 |
| `:` | 冒号 | Python 条件和循环后常用 |
| `,` | 逗号 | 分隔多个数据 |
| `.` | 点 | 小数点、属性、文件名 |
| `/` | 斜杠 | 路径、除法 |
| `\` | 反斜杠 | 某些路径或转义 |
| `=` | 等号 | 赋值 |
| `==` | 双等号 | 判断是否相等 |
| `+` `-` `*` `/` | 运算符 | 加减乘除 |
| `<` `>` | 尖括号 | 比较、HTML 标签 |
| `_` | 下划线 | 变量命名 |
| `#` | 井号 | Python 注释或编号 |

### 中文符号和英文符号的区别

| 中文符号 | 英文符号 |
|---|---|
| `（ ）` | `( )` |
| `“ ”` | `" "` |
| `‘ ’` | `' '` |
| `：` | `:` |
| `，` | `,` |

Python 里要用英文符号。例如：

正确：

```python
print("hello")
```

错误：

```python
print（“hello”）
```

## 八、常用快捷键

| 快捷键 | Windows 常用 | macOS 常用 |
|---|---|---|
| 复制 | `Ctrl + C` | `Command + C` |
| 粘贴 | `Ctrl + V` | `Command + V` |
| 剪切 | `Ctrl + X` | `Command + X` |
| 撤销 | `Ctrl + Z` | `Command + Z` |
| 保存 | `Ctrl + S` | `Command + S` |
| 全选 | `Ctrl + A` | `Command + A` |
| 查找 | `Ctrl + F` | `Command + F` |
| 切换应用 | `Alt + Tab` | `Command + Tab` |

学习时要养成：

1. 每完成一小步就保存。
2. 出错后先撤销最近一次修改。
3. 文件太长时用查找定位变量或关键字。
4. 复制代码后必须读懂再运行。

## 十、常见问题与解决

| 问题 | 可能原因 | 解决方法 |
|---|---|---|
| 文件找不到 | 保存位置不清楚 | 从总文件夹开始逐层查找 |
| 程序打不开 | 扩展名不对 | 显示扩展名，确认是 `.py`、`.html` 等 |
| 图片不显示 | 路径写错或图片漏交 | 检查图片文件夹和文件名 |
| 作业在老师电脑打不开 | 只交了一个文件，漏了素材 | 压缩整个项目文件夹 |
| Python 报语法错误 | 中文标点、漏冒号、括号不配对 | 逐个检查符号 |
| 文件名很乱 | 没有命名规则 | 使用“日期-主题-版本”命名 |
