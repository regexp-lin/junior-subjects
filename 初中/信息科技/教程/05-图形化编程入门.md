# 05-图形化编程入门

图形化编程适合初学者。它用积木块表示程序结构，可以减少英文符号和语法错误，让你先理解事件、顺序、条件、循环、变量等核心概念。

本节可以使用 Scratch、Blockly、Kitten、Code.org 或其他类似平台。不同平台界面可能不同，但学习思想相同。

---

## 一、学习目标

学完本节，你应该能做到：

1. 知道图形化编程中的舞台、角色、积木、脚本是什么。
2. 理解程序可以由事件触发运行。
3. 能按顺序拼接积木，让角色完成动作。
4. 能使用条件判断让程序根据情况变化。
5. 能使用循环减少重复积木。
6. 能使用变量记录分数、时间、生命值等数据。
7. 能完成一个动画、互动故事或小游戏。

---

## 三、第一个动画：事件和顺序

### 学习概念

| 概念 | 含义 |
|---|---|
| 事件 | 程序开始的触发条件，例如点击绿旗 |
| 顺序执行 | 积木从上到下一步一步执行 |
| 角色 | 执行动作和说话的对象 |
| 舞台 | 角色活动的区域 |

### 任务：角色自我介绍

目标：点击开始后，角色说话、移动、再说一句话。

### 操作步骤

1. 新建一个作品。
2. 保留默认角色，或选择一个喜欢的角色。
3. 添加事件积木：点击绿旗时。
4. 添加外观积木：说“大家好！”2 秒。
5. 添加运动积木：移动 10 步。
6. 再添加外观积木：说“我正在学习信息科技！”2 秒。
7. 点击运行，观察效果。
8. 保存作品，命名为 `第一个动画`。

### 思考问题

1. 程序从哪里开始执行？
2. 如果把“移动 10 步”和“说话”换顺序，效果会怎样？
3. 如果删除事件积木，程序还能自动开始吗？

### 拓展任务

让角色完成：

```text
说话 → 移动 → 转向 → 再说话 → 换造型
```

## 四、角色、坐标与运动

### 学习概念

角色在舞台上有位置。位置通常用坐标表示。

可以简单理解：

- 横向位置叫 x。
- 纵向位置叫 y。
- x 变大，角色向右。
- x 变小，角色向左。
- y 变大，角色向上。
- y 变小，角色向下。

### 任务：键盘控制角色移动

目标：按方向键控制角色上下左右移动。

### 操作步骤

1. 新建或打开作品。
2. 添加“当按下右方向键”事件。
3. 让角色 x 增加 10。
4. 添加“当按下左方向键”事件。
5. 让角色 x 减少 10。
6. 添加“当按下上方向键”事件。
7. 让角色 y 增加 10。
8. 添加“当按下下方向键”事件。
9. 让角色 y 减少 10。
10. 运行并测试四个方向。

### 测试表

| 按键 | 预期效果 | 实际效果 | 是否正确 |
|---|---|---|---|
| 右方向键 | 向右移动 |  |  |
| 左方向键 | 向左移动 |  |  |
| 上方向键 | 向上移动 |  |  |
| 下方向键 | 向下移动 |  |  |

### 常见错误

| 问题 | 可能原因 | 修改方法 |
|---|---|---|
| 按右键反而向左 | x 增减写反 | 右键用 x 增加，左键用 x 减少 |
| 按键没反应 | 事件积木选错 | 检查是否是对应方向键事件 |
| 角色跑出舞台 | 移动步数太大 | 调小数值，或增加边界判断 |

## 五、条件判断

条件判断让程序根据情况做不同事情。

生活例子：

```text
如果碰到墙，就退回去。
如果答对问题，就加分。
如果时间用完，就结束游戏。
```

### 任务：碰到边缘就反弹

目标：角色自动移动，碰到舞台边缘时反弹。

### 操作步骤

1. 添加事件：点击绿旗时。
2. 添加循环：重复执行。
3. 在循环中添加移动积木：移动 10 步。
4. 添加判断或运动积木：碰到边缘就反弹。
5. 点击运行。
6. 观察角色是否会来回移动。

### 思考问题

1. 哪个积木负责重复？
2. 哪个积木负责判断边缘？
3. 如果没有循环，只移动一次还是一直移动？

### 任务：答题判断

目标：角色提出问题，用户回答后判断对错。

步骤：

1. 点击开始。
2. 角色提问：“2 + 3 等于几？”
3. 用户输入答案。
4. 如果答案等于 5，角色说“答对了”。
5. 否则，角色说“再想想”。

IPO 表：

| 项目 | 内容 |
|---|---|
| 输入 | 用户输入的答案 |
| 处理 | 判断答案是否等于 5 |
| 输出 | 答对或错误提示 |

## 六、循环重复

循环用于重复执行一组操作。

如果不用循环，角色走 10 次可能要放 10 个移动积木。使用循环后，只需要一个移动积木加一个重复积木。

### 常见循环

| 循环类型 | 含义 | 例子 |
|---|---|---|
| 重复指定次数 | 做固定次数 | 重复 10 次移动 |
| 一直重复 | 不停执行 | 游戏角色一直移动 |
| 重复直到 | 到某条件为止 | 重复直到碰到终点 |

### 任务：重复画图或移动

目标：让角色重复移动并转向，形成一个简单图案或动画。

步骤：

1. 点击开始。
2. 清空或重置舞台。
3. 重复 4 次：
   - 移动 100 步。
   - 右转 90 度。
4. 观察是否形成正方形路径。

思考：

1. 如果重复 3 次，会怎样？
2. 如果右转 120 度，会怎样？
3. 如果移动步数变小，图形会怎样？

## 七、变量与计分

变量可以保存会变化的数据。

在游戏中常见变量：

- 分数。
- 时间。
- 生命值。
- 等级。
- 用户姓名。

### 任务：简单计分游戏

目标：点击角色一次，分数加 1。

步骤：

1. 新建变量 `score` 或 `分数`。
2. 点击绿旗时，把分数设为 0。
3. 当角色被点击时，把分数增加 1。
4. 让角色说“得分了！”。
5. 测试多次点击，观察分数变化。

### 测试表

| 操作 | 预期分数 | 实际分数 |
|---|---:|---:|
| 点击绿旗 | 0 |  |
| 点击角色 1 次 | 1 |  |
| 点击角色 5 次 | 5 |  |

### 拓展

增加倒计时：

1. 新建变量 `time` 或 `时间`。
2. 开始时设为 30。
3. 每隔 1 秒减 1。
4. 时间到 0 时停止游戏。

## 八、综合作品：互动故事或小游戏

完成图形化阶段时，建议做一个综合作品。

### 可选主题

| 作品 | 练习内容 |
|---|---|
| 自我介绍动画 | 事件、顺序、角色外观、文字输出 |
| 校园文明宣传动画 | 背景切换、角色对话、事件控制 |
| 迷宫小游戏 | 坐标、键盘控制、条件判断 |
| 问答计分系统 | 输入、判断、变量计分 |
| 接苹果游戏 | 循环、随机位置、碰撞检测、分数 |

### 项目要求

一个合格作品至少包含：

1. 1 个开始事件。
2. 2 个以上角色或 2 个以上场景。
3. 至少 1 个条件判断。
4. 至少 1 个循环。
5. 至少 1 个变量。
6. 能说明作品规则。
7. 能正常运行并保存。

### 制作步骤

```text
1. 选题
2. 写出作品规则
3. 画出主要流程
4. 制作最小版本
5. 增加角色、背景或分数
6. 测试问题
7. 保存和提交
8. 展示和反思
```

### 示例：问答计分系统

规则：

```text
1. 点击开始，分数设为 0。
2. 角色提出第 1 个问题。
3. 用户输入答案。
4. 如果正确，分数加 1。
5. 否则提示正确答案。
6. 继续第 2 个问题。
7. 最后显示总分。
```

IPO 表：

| 项目 | 内容 |
|---|---|
| 输入 | 用户答案 |
| 处理 | 判断答案是否正确，更新分数 |
| 输出 | 对错提示和最终分数 |

## 九、图形化编程调试方法

| 现象 | 可能原因 | 检查方法 |
|---|---|---|
| 点击开始没有反应 | 没有事件积木 | 检查是否有“点击绿旗时” |
| 角色不动 | 移动积木没接上或数值为 0 | 检查积木是否连接、数值是否正确 |
| 分数不变 | 变量没有增加 | 检查点击事件和变量积木 |
| 游戏一开始分数不是 0 | 开始时没有重置变量 | 点击绿旗时把分数设为 0 |
| 程序停不下来 | 使用了一直循环但没有结束条件 | 增加停止条件或停止按钮 |
| 判断错误 | 条件写反 | 用具体数据测试条件 |

调试时要一次只改一个地方，改完立刻测试。
