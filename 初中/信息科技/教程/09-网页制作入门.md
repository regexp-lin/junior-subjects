# 09-网页制作入门

网页制作适合喜欢可视化作品的学生。一个简单网页通常由 HTML、CSS 和 JavaScript 组成：HTML 负责结构，CSS 负责样式，JavaScript 负责交互。

本节是可选拓展。如果已经完成 Python 基础，可以选择学习网页制作，做一个个人介绍页、校园文明宣传页、信息安全宣传页或班级活动展示页。

---

## 一、学习目标

学完本节，你应该能做到：

1. 建立网页项目文件夹。
2. 编写基本 HTML 页面。
3. 使用标题、段落、列表、图片和链接。
4. 使用 CSS 设置颜色、字体、间距和布局。
5. 使用 JavaScript 完成简单按钮交互。
6. 理解网页图片路径和文件组织的重要性。
7. 完成一个主题展示网页。

---

## 二、网页项目文件夹

建立文件夹：

```text
信息科技学习/程序代码/网页作品/校园安全宣传页
```

建议结构：

```text
校园安全宣传页
├── index.html
├── style.css
├── script.js
└── images
    └── campus.jpg
```

| 文件 | 作用 |
|---|---|
| `index.html` | 网页入口文件，写结构和内容 |
| `style.css` | 样式文件，控制颜色、字体、布局 |
| `script.js` | 脚本文件，控制按钮等交互 |
| `images` | 保存图片素材 |

注意：网页文件和图片的位置很重要。图片路径写错，网页就显示不出来。

## 三、第一个网页

### 1. 创建 `index.html`

输入：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>你好，网页！</h1>
    <p>这是我制作的第一个 HTML 网页。</p>
</body>
</html>
```

### 2. 打开网页

步骤：

1. 保存文件为 `index.html`。
2. 找到文件所在文件夹。
3. 双击 `index.html`。
4. 使用浏览器打开。
5. 修改文字后保存，再刷新浏览器查看变化。

### 3. 你需要理解

| 标签 | 含义 |
|---|---|
| `<!DOCTYPE html>` | 声明这是 HTML 页面 |
| `<html>` | 网页的根标签 |
| `<head>` | 放网页信息，如标题、编码 |
| `<title>` | 浏览器标签页标题 |
| `<body>` | 网页中真正显示的内容 |
| `<h1>` | 一级标题 |
| `<p>` | 段落 |

## 四、标题、段落、列表、图片和链接

### 1. 标题

```html
<h1>校园安全宣传</h1>
<h2>一、课间安全</h2>
<h3>1. 上下楼梯</h3>
```

标题从 `<h1>` 到 `<h6>`，数字越大，级别越低。

### 2. 段落

```html
<p>课间活动时，不追逐打闹，不在楼梯上奔跑。</p>
```

### 3. 列表

无序列表：

```html
<ul>
    <li>不追逐打闹</li>
    <li>不攀爬栏杆</li>
    <li>上下楼梯靠右行</li>
</ul>
```

有序列表：

```html
<ol>
    <li>发现问题先报告老师</li>
    <li>保护现场</li>
    <li>等待处理</li>
</ol>
```

### 4. 图片

如果图片在 `images` 文件夹中：

```html
<img src="images/campus.jpg" alt="校园照片">
```

| 属性 | 作用 |
|---|---|
| `src` | 图片路径 |
| `alt` | 图片无法显示时的说明文字 |

### 5. 链接

```html
<a href="https://example.com">访问学习资料</a>
```

使用链接时要注意来源是否可靠，不要链接到不安全或无关网站。

## 六、CSS：让网页更美观

HTML 负责内容结构，CSS 负责样式。

### 1. 创建 `style.css`

在项目文件夹中创建：

```text
style.css
```

输入：

```css
body {
    font-family: Arial, sans-serif;
    background-color: #f4f8ff;
    color: #222222;
    line-height: 1.6;
    margin: 40px;
}

h1 {
    color: #1f5fbf;
}

.card {
    background-color: white;
    border: 1px solid #dddddd;
    border-radius: 8px;
    padding: 20px;
    margin-bottom: 20px;
}
```

### 2. 在 HTML 中连接 CSS

在 `index.html` 的 `<head>` 中加入：

```html
<link rel="stylesheet" href="style.css">
```

完整示例：

```html
<head>
    <meta charset="UTF-8">
    <title>我的个人介绍</title>
    <link rel="stylesheet" href="style.css">
</head>
```

### 3. 使用 class

HTML 中：

```html
<div class="card">
    <h2>我的兴趣</h2>
    <p>我喜欢阅读、篮球和编程。</p>
</div>
```

CSS 中：

```css
.card {
    background-color: white;
    padding: 20px;
    border-radius: 8px;
}
```

### 4. 常见 CSS 属性

| 属性 | 作用 |
|---|---|
| `color` | 文字颜色 |
| `background-color` | 背景颜色 |
| `font-size` | 字号 |
| `font-family` | 字体 |
| `margin` | 外边距 |
| `padding` | 内边距 |
| `border` | 边框 |
| `border-radius` | 圆角 |

## 七、页面布局入门

可以用容器把内容分成不同区域。

### 示例

HTML：

```html
<div class="container">
    <div class="card">
        <h2>安全提示</h2>
        <p>上下楼梯靠右行。</p>
    </div>

    <div class="card">
        <h2>文明倡议</h2>
        <p>不追逐打闹，爱护公共设施。</p>
    </div>
</div>
```

CSS：

```css
.container {
    max-width: 800px;
    margin: 0 auto;
}

.card {
    background-color: white;
    padding: 20px;
    margin-bottom: 16px;
    border: 1px solid #dddddd;
}
```

这样页面会更整齐。

## 八、JavaScript：简单按钮交互

JavaScript 可以让网页响应用户操作。

### 1. 在 HTML 中添加按钮

```html
<button onclick="changeText()">点击查看倡议</button>
<p id="message">请点击按钮。</p>
<script src="script.js"></script>
```

注意：`script.js` 通常放在 `body` 结束前。

### 2. 创建 `script.js`

输入：

```javascript
function changeText() {
    document.getElementById("message").textContent = "让我们一起做文明、安全、负责的数字公民。";
}
```

### 3. 理解

| 代码 | 含义 |
|---|---|
| `button` | 按钮 |
| `onclick` | 点击时执行 |
| `changeText()` | 自己定义的函数 |
| `id="message"` | 给段落起名字，方便找到 |
| `textContent` | 修改文字内容 |

## 九、综合作品：主题展示网页

### 可选主题

- 我的兴趣介绍页。
- 校园文明宣传页。
- 信息安全知识宣传页。
- 班级活动展示页。
- 科学小知识互动页。

### 项目要求

一个合格网页作品至少包含：

1. `index.html`。
2. `style.css`。
3. 至少 3 个内容板块。
4. 至少 1 张图片。
5. 至少 1 个列表。
6. 至少 1 个链接或按钮。
7. 如果使用图片，要记录来源。
8. 不包含真实隐私信息。

### 制作步骤

```text
1. 选主题
2. 建文件夹
3. 写 HTML 内容
4. 添加图片和链接
5. 写 CSS 美化
6. 添加一个按钮交互
7. 测试图片路径和按钮
8. 写说明和素材来源
9. 压缩提交
```

### 素材来源记录

建立 `素材来源.txt`：

```text
图片 1：自己拍摄的校园照片
图片 2：老师提供的班级活动图片
文字资料：根据课堂笔记整理
```

## 十、常见问题与解决

| 问题 | 可能原因 | 解决方法 |
|---|---|---|
| 网页打开是空白 | 文件内容未保存或标签错误 | 保存文件，检查 `<body>` 内容 |
| 中文乱码 | 没写 UTF-8 编码 | 在 `<head>` 加 `<meta charset="UTF-8">` |
| 图片不显示 | 路径错误或图片不在文件夹 | 检查 `images/文件名` 是否一致 |
| CSS 没效果 | 没连接 CSS 或文件名写错 | 检查 `<link rel="stylesheet" href="style.css">` |
| 按钮没反应 | JS 文件没连接或函数名不一致 | 检查 `<script src="script.js"></script>` 和函数名 |
| 页面太乱 | 没有分区和统一样式 | 使用 `.container` 和 `.card` 整理 |
