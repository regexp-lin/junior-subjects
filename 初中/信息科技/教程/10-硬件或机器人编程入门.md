# 10-硬件或机器人编程入门

硬件或机器人编程可以让程序控制现实中的设备，例如灯、按钮、蜂鸣器、显示屏、马达和传感器。常见平台包括 micro:bit、MakeCode、Arduino、机器人套件等。

本节是可选拓展。如果学校有硬件设备，可以跟着做；如果没有，也可以先在模拟器中理解输入、处理、输出。

---

## 一、学习目标

学完本节，你应该能做到：

1. 理解硬件编程中的输入、处理、输出。
2. 知道灯、屏幕、声音、马达属于输出设备。
3. 知道按钮、光线传感器、温度传感器等属于输入设备。
4. 能用事件、条件和循环控制硬件。
5. 能完成闪烁灯、按钮控制、传感器判断等简单任务。
6. 知道基本硬件安全规则。
7. 能完成一个小型硬件交互作品。

---

## 二、硬件编程中的 IPO

硬件编程也可以用 IPO 模型理解。

```text
Input 输入 → Process 处理 → Output 输出
```

| 类型 | 硬件例子 | 说明 |
|---|---|---|
| 输入 | 按钮 | 用户按下按钮 |
| 输入 | 光线传感器 | 检测环境亮度 |
| 输入 | 温度传感器 | 检测温度 |
| 输入 | 超声波传感器 | 检测距离 |
| 处理 | 主控板 | 执行程序和判断 |
| 输出 | LED 灯 | 显示亮灭或颜色 |
| 输出 | 蜂鸣器 | 发出声音 |
| 输出 | 显示屏 | 显示文字或图案 |
| 输出 | 马达 | 让机器人移动 |

例子：光线暗时自动亮灯。

| 项目 | 内容 |
|---|---|
| 输入 | 光线传感器读到亮度 |
| 处理 | 判断亮度是否低于阈值 |
| 输出 | 如果暗，就点亮灯 |

## 三、安全规则

使用硬件前必须注意安全。

1. 不随意连接不认识的电源。
2. 不用湿手触碰电路板和电线。
3. 不短接电源正负极。
4. 不强行拔插接口。
5. 接线前先确认设备是否断电。
6. 使用马达、风扇、机器人时注意手指和头发。
7. 发现发热、异味、冒烟，立即断电并告诉老师。
8. 不拆开电池或充电设备。
9. 不把硬件作品用于伤害别人或破坏设备。

如果不确定，先问老师，不要自己乱试。

## 四、任务 1：闪烁灯

### 1. 任务说明

让 LED 灯反复亮起和熄灭，形成闪烁效果。

### 2. IPO 分析

| 项目 | 内容 |
|---|---|
| 输入 | 无，程序自动运行 |
| 处理 | 反复执行亮灯、等待、灭灯、等待 |
| 输出 | LED 闪烁 |

### 3. 自然语言步骤

```text
1. 开始程序
2. 打开 LED 灯
3. 等待 1 秒
4. 关闭 LED 灯
5. 等待 1 秒
6. 回到第 2 步
```

### 4. 用到的编程概念

- 顺序结构：亮灯 → 等待 → 灭灯 → 等待。
- 循环结构：不断重复。
- 输出：控制 LED 灯。

### 5. 修改实验

尝试修改：

1. 等待时间变短，闪烁会怎样？
2. 等待时间变长，闪烁会怎样？
3. 如果使用不同颜色的灯，效果会怎样？

## 六、任务 3：按按钮显示不同图案

### 1. 任务说明

按不同按钮时，在屏幕或点阵上显示不同图案或文字。

例如：

- 按 A：显示笑脸。
- 按 B：显示爱心。
- 同时按 A 和 B：显示“OK”。

### 2. IPO 分析

| 项目 | 内容 |
|---|---|
| 输入 | 按钮 A、按钮 B 的状态 |
| 处理 | 判断按下的是哪个按钮 |
| 输出 | 显示对应图案或文字 |

### 3. 步骤

```text
1. 检测按钮 A 和按钮 B
2. 如果按下 A，显示笑脸
3. 如果按下 B，显示爱心
4. 如果同时按下 A 和 B，显示 OK
5. 重复检测
```

### 4. 思考

1. 如果两个按钮同时按下，应该优先显示什么？
2. 如果没有按钮按下，屏幕要不要清空？
3. 如果按钮反应太快或太慢，可以怎样调整？

## 七、任务 4：传感器与条件判断

### 1. 任务说明

光线暗时自动亮灯，光线亮时关闭灯。

### 2. IPO 分析

| 项目 | 内容 |
|---|---|
| 输入 | 光线传感器数值 |
| 处理 | 判断光线是否低于阈值 |
| 输出 | 亮灯或灭灯 |

### 3. 关键概念：阈值

阈值就是判断的分界线。

例如：

```text
如果亮度 < 50，就认为环境比较暗。
否则，认为环境比较亮。
```

### 4. 自然语言步骤

```text
1. 读取光线数值
2. 如果光线数值小于 50
3. 打开灯
4. 否则关闭灯
5. 重复检测
```

### 5. 调试方法

如果灯一直亮或一直灭，检查：

1. 传感器是否连接正确。
2. 读取到的光线数值大概是多少。
3. 阈值是否设置太高或太低。
4. 条件是否写反。

### 6. 测试表

| 用光照传感器 |  | 灯灭 |  |
| 普通室内光 |  | 根据阈值判断 |  |

## 八、任务 5：倒计时提醒器

### 1. 任务说明

按下按钮后开始倒计时，倒计时结束后发出声音或显示提示。

### 2. IPO 分析

| 项目 | 内容 |
|---|---|
| 输入 | 用户按下按钮 |
| 处理 | 从指定数字开始倒计时 |
| 输出 | 显示数字，结束后发声或显示完成 |

### 3. 自然语言步骤

```text
1. 等待按钮按下
2. 设置时间为 10
3. 显示当前时间
4. 等待 1 秒
5. 时间减 1
6. 如果时间大于 0，回到第 3 步
7. 否则显示完成并发出提示音
```

### 4. 用到概念

- 事件：按钮按下。
- 变量：保存剩余时间。
- 循环：重复倒计时。
- 条件：判断是否结束。
- 输出：屏幕和声音。

## 十、硬件项目调试

| 问题 | 可能原因 | 解决方法 |
|---|---|---|
| 程序下载失败 | 数据线、端口或设备未连接 | 检查连接，重新选择设备 |
| 灯不亮 | 接线错误或程序没有控制灯 | 检查接口和输出语句 |
| 按钮没反应 | 输入接口选错或事件没设置 | 检查按钮连接和事件积木 |
| 传感器数值奇怪 | 接线松动或阈值不合适 | 先显示传感器数值，再调整阈值 |
| 马达不动 | 电源不足或接口错误 | 检查电池和接线 |
| 程序一直重复异常 | 循环或条件写错 | 用最小程序逐步测试 |

调试建议：

1. 先测试一个硬件，再组合多个硬件。
2. 先让程序显示传感器读数。
3. 不确定阈值时，多观察几组数据。
4. 记录每次修改了什么。
