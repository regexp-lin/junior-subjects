# 01-认识计算机系统

本节帮助你理解计算机到底是什么。学习编程之前，先要知道程序运行在哪里，计算机如何接收信息、处理信息、保存信息和输出结果。

---

## 一、学习目标

学完本节，你应该能做到：

1. 用自己的话解释“计算机是什么”。
2. 说出硬件、软件、数据、网络之间的关系。
3. 说出 CPU、内存、硬盘、输入设备、输出设备的基本作用。
4. 会进行基本窗口操作：打开、切换、关闭应用。
5. 知道操作系统和应用程序的区别。
6. 能用“输入、处理、存储、输出”分析电脑、手机、服务器等设备。

---

## 二、计算机是什么

计算机是一种能够按照程序处理数据的电子设备。

可以用一句话理解：

```text
计算机接收输入，按照程序处理，保存需要的数据，再输出结果。
```

例如你用手机点外卖：

| 过程 | 例子 |
|---|---|
| 输入 | 你选择店铺、商品、地址 |
| 处理 | 平台计算价格、配送费、预计时间 |
| 存储 | 保存订单信息和支付记录 |
| 输出 | 显示订单状态、骑手位置、送达通知 |

台式电脑、笔记本、手机、平板、服务器、智能手表、机器人控制器，本质上都可以用这个框架理解。

---

## 三、计算机系统由什么组成

一个计算机系统通常包括：

```text
硬件 + 软件 + 数据 + 网络 + 用户
```

| 组成 | 通俗理解 | 例子 |
|---|---|---|
| 硬件 | 看得见、摸得着的设备 | CPU、内存、硬盘、键盘、屏幕 |
| 软件 | 指挥硬件工作的程序 | 操作系统、浏览器、Python、游戏 |
| 数据 | 被处理的信息 | 文字、图片、声音、视频、代码 |
| 网络 | 让设备互相传递数据的连接 | Wi-Fi、互联网、校园网 |
| 用户 | 使用计算机的人 | 学生、老师、程序员 |

如果只有硬件，没有软件，计算机不知道该做什么。

如果只有软件，没有数据，程序也没有可以处理的内容。

如果有网络，计算机就可以与其他设备交换数据，例如打开网页、下载文件、提交作业。

---

## 四、硬件基础

### 1. CPU

CPU 可以理解为计算机的“大脑”或“执行指令的人”。程序中的每一步最终都要被 CPU 执行。

你需要知道：

1. CPU 负责计算和执行指令。
2. 程序运行越复杂，CPU 工作越多。
3. CPU 速度会影响程序运行速度，但不是唯一因素。

生活类比：

```text
CPU 像做题的人，负责一步一步计算。
```

### 2. 内存

内存是程序运行时临时放数据的地方。

你需要知道：

1. 打开的程序会占用内存。
2. 同时打开很多程序，内存压力会变大。
3. 关机后，内存里的临时数据通常会消失。

生活类比：

```text
内存像书桌。你正在做的作业、打开的书、草稿纸都放在书桌上。
```

### 3. 硬盘或固态硬盘

硬盘用于长期保存文件。

你需要知道：

1. 文档、图片、视频、代码文件都保存在硬盘里。
2. 关机后，硬盘里的文件仍然存在。
3. 硬盘空间不足时，可能无法保存新文件或安装软件。

生活类比：

```text
硬盘像书柜。暂时不用但要长期保存的资料放在书柜里。
```

### 4. 输入设备

输入设备用于把人的操作或外界信息送进计算机。

常见输入设备：

- 键盘
- 鼠标
- 触摸屏
- 摄像头
- 麦克风
- 扫描仪
- 传感器

编程时，程序也可以接收输入，例如：

- 用户输入姓名。
- 用户点击按钮。
- 用户按下键盘。
- 传感器读到温度或光线。

### 5. 输出设备

输出设备用于把计算机处理结果展示给人或环境。

常见输出设备：

- 显示器
- 音箱
- 打印机
- 指示灯
- 震动马达
- 机器人电机

编程中的输出可以是：

- 屏幕显示文字。
- 网页显示图片。
- 游戏角色移动。
- 机器人亮灯。
- 程序生成一个文件。

### 6. 主板、显卡和网卡

| 硬件 | 通俗理解 | 你需要知道 |
|---|---|---|
| 主板 | 连接各种硬件的平台 | 各硬件要通过主板协同工作 |
| 显卡 | 处理图像显示的硬件 | 游戏、动画、图像处理会用到 |
| 网卡 | 连接网络的硬件 | 电脑能上网离不开网络设备 |

初学阶段不需要背复杂参数，只要理解每个部件解决什么问题。

## 五、软件基础

软件是让硬件工作的程序。

软件可以分成两大类：

```text
系统软件 + 应用软件
```

### 1. 操作系统

操作系统是最基础的软件，负责管理硬件、文件、应用程序、用户账户和权限。

常见操作系统：

- Windows
- macOS
- Linux
- Android
- iOS

操作系统提供这些功能：

1. 打开和关闭应用程序。
2. 管理文件和文件夹。
3. 管理键盘、鼠标、屏幕、网络等硬件。
4. 管理用户账户和权限。
5. 让应用程序可以运行。

### 2. 应用程序

应用程序是在操作系统上运行的软件，用来完成具体任务。

| 应用程序 | 用途 |
|---|---|
| 浏览器 | 访问网页、搜索资料、在线学习 |
| 文档软件 | 写文章、做表格、制作演示文稿 |
| 代码编辑器 | 编写程序代码 |
| Python | 运行 Python 程序 |
| 图形化编程平台 | 制作动画、小游戏、互动作品 |
| 压缩软件 | 打包和解压文件 |

## 六、必须会做的基本操作

### 任务 1：打开应用程序

请完成：

1. 打开浏览器。
2. 打开文件管理器。
3. 打开一个文档或记事本应用。
4. 观察任务栏、程序坞或窗口列表中出现了哪些应用。

检查自己是否会：

- 从桌面图标打开应用。
- 从开始菜单、启动台或搜索打开应用。
- 关闭应用窗口。

### 任务 2：切换窗口

请完成：

1. 同时打开浏览器和文件管理器。
2. 在两个窗口之间切换。
3. 尝试使用快捷键切换：Windows 常用 `Alt + Tab`，macOS 常用 `Command + Tab`。
4. 调整窗口大小。
5. 把两个窗口并排放在屏幕上。

学习编程时，你经常需要同时看教程、写代码、运行程序、查看文件夹，所以切换窗口很重要。

### 任务 3：处理程序无响应

如果程序卡住，不要立刻乱点。

按这个顺序处理：

1. 等待几秒，看看是否恢复。
2. 尝试保存正在编辑的内容。
3. 关闭卡住的窗口。
4. 如果无法关闭，再使用系统提供的强制退出或任务管理功能。
5. 重新打开文件，检查是否丢失内容。

注意：不要因为程序卡住就随便删除文件或重启电脑。先想办法保存和确认。

## 七、用输入、处理、存储、输出分析设备

请看下面的例子。

### 例子 1：电脑写作文

| 环节 | 内容 |
|---|---|
| 输入 | 键盘输入文字 |
| 处理 | 文档软件处理文字、格式和排版 |
| 存储 | 保存成 `.docx` 或 `.txt` 文件 |
| 输出 | 屏幕显示作文，打印机打印作文 |

### 例子 2：手机拍照

| 环节 | 内容 |
|---|---|
| 输入 | 摄像头接收光线 |
| 处理 | 手机处理颜色、清晰度、压缩图片 |
| 存储 | 保存成照片文件 |
| 输出 | 屏幕显示照片，也可以分享给别人 |

### 例子 3：网页搜索

| 环节 | 内容 |
|---|---|
| 输入 | 你输入关键词 |
| 处理 | 浏览器和搜索服务器查找相关网页 |
| 存储 | 搜索记录、网页缓存可能被保存 |
| 输出 | 显示搜索结果列表 |

## 九、常见误区

| 误区 | 正确认识 |
|---|---|
| 会玩游戏就是会用电脑 | 学习还需要会管理文件、保存作业、查资料、处理问题 |
| 内存就是硬盘 | 内存主要用于运行时临时存放，硬盘用于长期保存 |
| 软件坏了就是电脑坏了 | 可能是软件、设置、文件、权限或网络问题 |
| 服务器离我很远，所以和我无关 | 你打开网页、登录账号、提交作业都可能在使用服务器 |
| 电脑能自己理解我的意思 | 计算机只按明确指令和规则处理数据 |
