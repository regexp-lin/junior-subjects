# 初中数学《锐角三角函数》教案（精简版）

## 一、总体设计

### 1. 适用对象

适用于九年级《锐角的三角函数》新授课，也可用于中考复习中“直角三角形与实际应用”专题。学生学习前应掌握直角三角形的基本性质、勾股定理、相似三角形、比例线段、平方根和简单方程。

教学中要突出：锐角三角函数是直角三角形中“角”与“边的比”的对应关系；同一个锐角的三角函数值与三角形大小无关；解直角三角形的本质是利用已知边角关系求未知边角；实际问题要先把生活情境转化为直角三角形模型。

### 2. 教学目标

学生通过本专题学习，应能：

1. 理解锐角三角函数的意义，能在直角三角形中准确指出锐角的对边、邻边、斜边。
2. 掌握正弦、余弦、正切的定义：

   $$\sin A=\frac{\text{对边}}{\text{斜边}},\quad \cos A=\frac{\text{邻边}}{\text{斜边}},\quad \tan A=\frac{\text{对边}}{\text{邻边}}$$

3. 会求常见直角三角形中锐角的三角函数值。
4. 记忆并熟练使用 $30^\circ$、$45^\circ$、$60^\circ$ 的三角函数值。
5. 会用三角函数表或计算器求锐角三角函数值及已知函数值求锐角。
6. 会解直角三角形，能根据已知条件选择正弦、余弦、正切或勾股定理。
7. 能用锐角三角函数解决测高、测距、坡度、仰角俯角、方位角等实际问题。
8. 在应用题中能画出示意图，写清单位，并检验结果是否符合实际意义。

### 3. 课时安排

| 课时 | 主题 | 核心任务 |
|---|---|---|
| 第 1 课时 | 正弦的概念 | 从相似三角形理解“对边与斜边的比” |
| 第 2 课时 | 余弦与正切 | 掌握三种三角函数定义并会辨认边 |
| 第 3 课时 | 特殊角三角函数值 | 记忆并推导 $30^\circ$、$45^\circ$、$60^\circ$ 的值 |
| 第 4 课时 | 三角函数值的求取 | 使用三角函数表或计算器求值与反求角 |
| 第 5 课时 | 解直角三角形 | 已知边角求未知边角 |
| 第 6 课时 | 测高与测距应用 | 仰角、俯角、水平距离、物体高度 |
| 第 7 课时 | 坡度、方位角与综合应用 | 处理坡度、坡角、方位角、路径问题 |
| 第 8 课时 | 单元复习与分层训练 | 建立知识框架，纠错与综合提升 |

### 4. 学情与对策

| 常见困难 | 教学对策 |
|---|---|
| 分不清对边、邻边、斜边 | 每题先标角，再沿角找边；斜边永远对直角 |
| 把三角函数理解成边长 | 强调三角函数值是两个边长的比 |
| 换一个相似三角形就以为函数值改变 | 用相似三角形说明同角对应边的比不变 |
| 特殊角函数值混淆 | 用 $30^\circ$-$60^\circ$-$90^\circ$ 和等腰直角三角形推导记忆 |
| 应用题不会建模 | 固定步骤：画图、标角、标边、选函数、列式求解 |
| 仰角、俯角、方位角读题困难 | 画水平线和铅垂线，把文字转成角 |
| 坡度与坡角混淆 | 明确坡度 $i=\frac{\text{铅直高度}}{\text{水平距离}}=\tan\alpha$ |

### 5. 核心知识框架

| 内容 | 要点 |
|---|---|
| 基本对象 | 锐角三角函数只在直角三角形中围绕某个锐角定义 |
| 正弦 | $\sin A=\frac{A\text{ 的对边}}{\text{斜边}}$ |
| 余弦 | $\cos A=\frac{A\text{ 的邻边}}{\text{斜边}}$ |
| 正切 | $\tan A=\frac{A\text{ 的对边}}{A\text{ 的邻边}}$ |
| 特殊角 | $30^\circ$、$45^\circ$、$60^\circ$ 的函数值要熟记 |
| 基本关系 | 同一锐角中，角越大，$\sin A$ 和 $\tan A$ 越大，$\cos A$ 越小 |
| 解直角三角形 | 已知两个元素且至少有一条边，求其余边角 |
| 应用模型 | 测高、测距、仰角、俯角、坡度、方位角 |

## 第 1 课时：正弦的概念

### 1. 课时目标

理解在直角三角形中，一个锐角的对边与斜边的比是一个固定值；知道这个比叫做这个锐角的正弦；能在简单图形中求锐角的正弦值。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 导入 | 同一倾斜角的两架梯子，长度不同但倾斜程度相同 | 倾斜程度与边长的比有关 |
| 探究 | 构造几个含同一个锐角的直角三角形 | 利用相似三角形说明比值不变 |
| 定义 | 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$ | 对 $\angle A$，$a=BC$ 为对边，$c=AB$ 为斜边 |
| 表达 | $\sin A=\frac{BC}{AB}$ | 正弦值是比值，不是边长 |
| 练习 | 已知边长求 $\sin A$ | 先找角，再找对边和斜边 |

### 3. 概念板书

在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$。对于锐角 $A$：

$$\sin A=\frac{\angle A\text{ 的对边}}{\text{斜边}}=\frac{BC}{AB}$$

如果两个直角三角形有一个锐角相等，那么它们相似，对应边成比例，所以

$$\frac{\text{对边}}{\text{斜边}}$$

只由这个锐角决定，与三角形的大小无关。

### 4. 例题板书

1. 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$AB=13$，$BC=5$，求 $\sin A$。

   $$\sin A=\frac{BC}{AB}=\frac5{13}$$

2. 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$AC=8$，$BC=6$，求 $\sin A$。

   先求斜边：

   $$AB=\sqrt{8^2+6^2}=10$$

   所以

   $$\sin A=\frac{BC}{AB}=\frac6{10}=\frac35$$

3. 已知 $\sin A=\frac{3}{5}$，且 $A$ 为锐角。若斜边为 $20$，求 $A$ 的对边。

   $$\frac{\text{对边}}{20}=\frac35,\quad \text{对边}=12$$

### 5. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 在直角三角形中，斜边为 $17$，某锐角的对边为 $8$，求该角的正弦 |
| 当堂检测 | 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$AC=12$，$BC=5$，求 $\sin A$ 与 $\sin B$ |
| 参考答案 | $\frac8{17}$；$\sin A=\frac5{13}$，$\sin B=\frac{12}{13}$ |
| 课后作业 | 完成 5 道“给边求正弦”的基础题，要求每题先写清对边和斜边 |

## 第 2 课时：余弦与正切

### 1. 课时目标

掌握余弦、正切的定义；能在直角三角形中准确求 $\sin A$、$\cos A$、$\tan A$；理解同一个直角三角形中，换一个锐角后对边和邻边会改变。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 复习 | 对 $\angle A$ 找对边、斜边 | 先确定研究的角 |
| 新授 | 引入邻边与余弦 | 邻边是夹着该锐角但不是斜边的直角边 |
| 新授 | 引入正切 | 正切不涉及斜边，是对边与邻边的比 |
| 辨析 | 同图中求 $\sin A,\cos A,\tan A$ 与 $\sin B,\cos B,\tan B$ | 对边和邻边随角改变 |
| 训练 | 已知两边求三角函数值 | 缺边先用勾股定理 |

### 3. 概念板书

在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$。对于锐角 $A$：

$$\sin A=\frac{BC}{AB},\quad \cos A=\frac{AC}{AB},\quad \tan A=\frac{BC}{AC}$$

可以简记为：

| 函数 | 比值 |
|---|---|
| 正弦 | 对边比斜边 |
| 余弦 | 邻边比斜边 |
| 正切 | 对边比邻边 |

### 4. 例题板书

1. 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$AC=12$，$BC=5$，求 $\angle A$ 的三个三角函数值。

   $$AB=\sqrt{12^2+5^2}=13$$

   $$\sin A=\frac5{13},\quad \cos A=\frac{12}{13},\quad \tan A=\frac5{12}$$

2. 同上题，求 $\angle B$ 的三个三角函数值。

   $$\sin B=\frac{12}{13},\quad \cos B=\frac5{13},\quad \tan B=\frac{12}{5}$$

3. 在直角三角形中，某锐角 $A$ 的邻边为 $9$，斜边为 $15$，求 $\sin A,\cos A,\tan A$。

   对边为

   $$\sqrt{15^2-9^2}=12$$

   所以

   $$\sin A=\frac45,\quad \cos A=\frac35,\quad \tan A=\frac43$$

### 5. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 直角三角形两直角边为 $7,24$，斜边为 $25$，求较小锐角的三角函数值 |
| 当堂检测 | 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$AB=10$，$AC=6$，求 $\sin A,\cos A,\tan A$ |
| 参考答案 | $\sin=\frac7{25}$，$\cos=\frac{24}{25}$，$\tan=\frac7{24}$；$\sin A=\frac45$，$\cos A=\frac35$，$\tan A=\frac43$ |
| 课后作业 | 完成 6 道“已知两边求三角函数值”的练习，其中至少 2 道需要先用勾股定理求第三边 |

## 第 3 课时：特殊角三角函数值

### 1. 课时目标

会推导并记忆 $30^\circ$、$45^\circ$、$60^\circ$ 的正弦、余弦、正切值；能利用特殊角函数值进行简单计算和反求角。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 导入 | 等边三角形作高 | 得到 $30^\circ$-$60^\circ$-$90^\circ$ 三角形 |
| 推导 | 设等边三角形边长为 $2$ | 三边比为 $1:\sqrt3:2$ |
| 推导 | 等腰直角三角形 | 三边比为 $1:1:\sqrt2$ |
| 整理 | 完成特殊角函数值表 | 先理解，再记忆 |
| 应用 | 根据函数值判断角 | $\sin 30^\circ=\cos60^\circ=\frac12$ |

### 3. 特殊角函数值表

| 角 | $\sin$ | $\cos$ | $\tan$ |
|---|---|---|---|
| $30^\circ$ | $\frac12$ | $\frac{\sqrt3}{2}$ | $\frac{\sqrt3}{3}$ |
| $45^\circ$ | $\frac{\sqrt2}{2}$ | $\frac{\sqrt2}{2}$ | $1$ |
| $60^\circ$ | $\frac{\sqrt3}{2}$ | $\frac12$ | $\sqrt3$ |

记忆提示：

$$\sin 30^\circ=\cos 60^\circ,\quad \sin 60^\circ=\cos30^\circ$$

互余两个锐角的正弦、余弦互换：

$$\sin A=\cos(90^\circ-A)$$

### 4. 例题板书

1. 计算：

   $$2\sin30^\circ+3\cos60^\circ-\tan45^\circ$$

   $$=2\cdot\frac12+3\cdot\frac12-1=\frac32$$

2. 已知 $A$ 为锐角，$\tan A=\sqrt3$，求 $A$。

   $$A=60^\circ$$

3. 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$\angle A=30^\circ$，$AB=10$，求 $BC$ 和 $AC$。

   $$BC=AB\cdot\sin30^\circ=5$$

   $$AC=AB\cdot\cos30^\circ=5\sqrt3$$

4. 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$\angle A=45^\circ$，$AC=6$，求 $BC$ 和 $AB$。

   $$BC=AC=6,\quad AB=6\sqrt2$$

### 5. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 计算 $\sin60^\circ-\cos30^\circ+\tan45^\circ$ |
| 当堂检测 | 已知 $A$ 为锐角，$\cos A=\frac{\sqrt2}{2}$，求 $A$ |
| 当堂检测 | 直角三角形中，一个锐角为 $60^\circ$，斜边为 $8$，求两直角边 |
| 参考答案 | $1$；$45^\circ$；$4$ 和 $4\sqrt3$ |
| 课后作业 | 默写特殊角函数值表，并完成 8 道特殊角计算题 |

## 第 4 课时：三角函数值的求取

### 1. 课时目标

会使用三角函数表或计算器求锐角的三角函数值；会根据三角函数值求对应锐角的近似值；知道结果需要按题目要求取近似数。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 复习 | 特殊角函数值 | 特殊角精确值优先使用 |
| 查值 | 求 $\sin37^\circ$、$\cos52^\circ$、$\tan18^\circ$ | 注意角度单位是“度” |
| 反求角 | 已知 $\sin A=0.6018$，求 $A$ | 查表或用计算器反三角函数 |
| 近似 | 保留整数、十分位、百分位 | 统一按题目要求舍入 |
| 辨析 | $\sin A$ 与 $A$ 的区别 | 函数值是比值，角是角度 |

### 3. 方法板书

使用计算器时：

1. 确认角度制为 DEG。
2. 求函数值：先按函数键，再输入角度，或按计算器规定顺序输入。
3. 已知函数值求角：使用 $\sin^{-1}$、$\cos^{-1}$、$\tan^{-1}$。
4. 应用题中最后结果按要求取近似值，并保留单位。

常用近似值示例：

| 角 | $\sin$ | $\cos$ | $\tan$ |
|---|---|---|---|
| $20^\circ$ | $0.3420$ | $0.9397$ | $0.3640$ |
| $35^\circ$ | $0.5736$ | $0.8192$ | $0.7002$ |
| $50^\circ$ | $0.7660$ | $0.6428$ | $1.1918$ |

### 4. 例题板书

1. 求 $\sin38^\circ$，结果保留四位小数。

   $$\sin38^\circ\approx0.6157$$

2. 已知 $A$ 为锐角，$\cos A=0.7660$，求 $A$。

   $$A\approx40^\circ$$

3. 已知直角三角形中，某锐角 $A=36^\circ$，斜边为 $15$，求 $A$ 的对边，结果保留一位小数。

   $$\text{对边}=15\sin36^\circ\approx15\times0.5878=8.817$$

   所以对边约为 $8.8$。

4. 直角三角形中，某锐角的对边为 $7$，邻边为 $10$，求这个锐角，结果精确到 $1^\circ$。

   $$\tan A=\frac7{10}=0.7$$

   $$A\approx35^\circ$$

### 5. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 求 $\sin25^\circ$、$\cos68^\circ$、$\tan42^\circ$，保留四位小数 |
| 当堂检测 | 已知 $\sin A=0.5$，$\tan B=1.4281$，求锐角 $A,B$ |
| 当堂检测 | 斜边 $20$，锐角 $28^\circ$ 的对边约是多少 |
| 参考答案 | 约 $0.4226$、$0.3746$、$0.9004$；$A=30^\circ$，$B\approx55^\circ$；约 $9.4$ |
| 课后作业 | 完成 6 道查值题、4 道反求角题、2 道简单边长计算题 |

## 第 5 课时：解直角三角形

### 1. 课时目标

理解“解直角三角形”的含义；会根据已知条件选择合适的三角函数或勾股定理求未知边角；能够规范写出计算过程。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 概念 | 已知直角三角形中的若干元素，求其余边角 | 至少要知道一条边 |
| 类型一 | 已知一边一锐角 | 用三角函数求边，用互余求角 |
| 类型二 | 已知两边 | 用勾股定理求边，用三角函数求角 |
| 方法选择 | 对边、邻边、斜边对应函数 | “有什么边、求什么边”决定函数 |
| 规范 | 画图、标已知、列式、计算、答 | 避免只写结果 |

### 3. 方法板书

在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$：

| 已知与所求 | 常用关系 |
|---|---|
| 已知斜边和角，求对边 | $\text{对边}=\text{斜边}\cdot\sin A$ |
| 已知斜边和角，求邻边 | $\text{邻边}=\text{斜边}\cdot\cos A$ |
| 已知邻边和角，求对边 | $\text{对边}=\text{邻边}\cdot\tan A$ |
| 已知对边和角，求邻边 | $\text{邻边}=\frac{\text{对边}}{\tan A}$ |
| 已知两边求第三边 | 勾股定理 |
| 已知两直角边求角 | $\tan A=\frac{\text{对边}}{\text{邻边}}$ |

### 4. 例题板书

1. 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$\angle A=35^\circ$，$AB=12$，求 $BC$ 和 $AC$。

   $$BC=AB\sin35^\circ\approx12\times0.5736=6.8832$$

   $$AC=AB\cos35^\circ\approx12\times0.8192=9.8304$$

   所以 $BC\approx6.9$，$AC\approx9.8$。

2. 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$\angle A=40^\circ$，$AC=15$，求 $BC$。

   $$\tan40^\circ=\frac{BC}{AC}$$

   $$BC=15\tan40^\circ\approx15\times0.8391=12.5865$$

   所以 $BC\approx12.6$。

3. 在直角三角形中，两直角边分别为 $9$ 和 $12$，求斜边及较小锐角。

   $$c=\sqrt{9^2+12^2}=15$$

   设较小锐角为 $A$，则

   $$\tan A=\frac9{12}=0.75$$

   $$A\approx37^\circ$$

4. 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，$BC=8$，$AB=17$，求 $\angle A$。

   $$\sin A=\frac8{17}\approx0.4706$$

   $$A\approx28^\circ$$

### 5. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 直角三角形中，斜边 $10$，一个锐角 $52^\circ$，求两直角边 |
| 当堂检测 | 直角三角形中，一直角边 $18$，它所邻的锐角为 $34^\circ$，求另一条直角边 |
| 当堂检测 | 两直角边为 $5$ 和 $11$，求较小锐角 |
| 参考答案 | 约 $7.9$ 和 $6.2$；约 $12.1$；约 $24^\circ$ |
| 课后作业 | 完成 8 道解直角三角形题，要求每题写出使用的三角函数关系式 |

## 第 6 课时：测高与测距应用

### 1. 课时目标

会把仰角、俯角、水平距离、高度等实际信息转化为直角三角形；能用正切、正弦、余弦解决简单测高和测距问题；注意观测点高度和单位。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 情境 | 测旗杆、楼高、河宽 | 不能直接测量时用角和距离间接求解 |
| 概念 | 仰角与俯角 | 都是视线与水平线所成的角 |
| 建模 | 画水平线、铅垂线和视线 | 形成直角三角形 |
| 列式 | 高度与水平距离常用正切 | $\tan\alpha=\frac{\text{高度差}}{\text{水平距离}}$ |
| 修正 | 观测者眼睛离地高度 | 最后加上或减去观测点高度 |

### 3. 方法板书

实际问题一般步骤：

$$\text{审题}\rightarrow\text{画图}\rightarrow\text{标量}\rightarrow\text{选函数}\rightarrow\text{列式}\rightarrow\text{计算}\rightarrow\text{答}$$

仰角、俯角问题中常用：

$$\tan\alpha=\frac{\text{铅直高度差}}{\text{水平距离}}$$

如果观测点离地高度为 $h$，求物体总高度时要把 $h$ 加回去。

### 4. 例题板书

1. 在离旗杆底部 $20\text{ m}$ 的点测得旗杆顶端的仰角为 $35^\circ$，求旗杆高度。

   设旗杆高为 $x\text{ m}$：

   $$\tan35^\circ=\frac{x}{20}$$

   $$x=20\tan35^\circ\approx20\times0.7002=14.004$$

   旗杆高约为 $14.0\text{ m}$。

2. 某人眼睛离地 $1.6\text{ m}$，在离楼底 $30\text{ m}$ 处测得楼顶仰角为 $50^\circ$，求楼高。

   设楼高为 $H\text{ m}$：

   $$\tan50^\circ=\frac{H-1.6}{30}$$

   $$H=30\tan50^\circ+1.6\approx30\times1.1918+1.6=37.354$$

   楼高约为 $37.4\text{ m}$。

3. 在河岸一点 $A$ 处测得对岸树顶 $T$ 的仰角为 $28^\circ$，树高 $12\text{ m}$，求河宽。

   设河宽为 $x\text{ m}$：

   $$\tan28^\circ=\frac{12}{x}$$

   $$x=\frac{12}{\tan28^\circ}\approx\frac{12}{0.5317}\approx22.6$$

   河宽约为 $22.6\text{ m}$。

4. 在楼顶 $A$ 处看地面一点 $B$ 的俯角为 $42^\circ$，楼高 $25\text{ m}$，求 $B$ 到楼底的水平距离。

   俯角等于地面点看楼顶的仰角，设水平距离为 $x\text{ m}$：

   $$\tan42^\circ=\frac{25}{x}$$

   $$x=\frac{25}{\tan42^\circ}\approx27.8$$

### 5. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 离树底 $15\text{ m}$ 处测得树顶仰角 $40^\circ$，求树高 |
| 当堂检测 | 眼睛离地 $1.5\text{ m}$，离楼 $24\text{ m}$，测得楼顶仰角 $36^\circ$，求楼高 |
| 当堂检测 | 高 $18\text{ m}$ 的灯塔顶部看船的俯角为 $30^\circ$，求船到塔底的水平距离 |
| 参考答案 | 约 $12.6\text{ m}$；约 $18.9\text{ m}$；约 $31.2\text{ m}$ |
| 课后作业 | 完成测高、测距应用题各 3 道，每题必须画示意图 |

## 第 7 课时：坡度、方位角与综合应用

### 1. 课时目标

理解坡度、坡角的含义；会用三角函数处理坡道长度、水平距离和铅直高度；会在方位角问题中画出方向线并构造直角三角形。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 坡度 | 引入道路上升高度与水平距离 | 坡度是比，不是角 |
| 坡角 | 坡面与水平面的夹角 | 坡度等于坡角的正切 |
| 方位角 | 北偏东、南偏西等方向 | 先画正北方向，再按偏转角画射线 |
| 综合 | 多个直角三角形共边或相减 | 图形清楚，边角对应准确 |
| 反思 | 结果是否符合实际 | 长度为正，角度在合理范围内 |

### 3. 方法板书

坡度：

$$i=\frac{\text{铅直高度}}{\text{水平距离}}$$

坡角为 $\alpha$ 时：

$$i=\tan\alpha$$

坡面长度 $l$、铅直高度 $h$、水平距离 $d$ 满足：

$$l^2=h^2+d^2,\quad \sin\alpha=\frac{h}{l},\quad \cos\alpha=\frac{d}{l},\quad \tan\alpha=\frac{h}{d}$$

方位角问题中，常用互余角、平行线内错角、等腰或直角三角形关系辅助建模。

### 4. 例题板书

1. 一段坡路的坡度为 $1:4$，水平距离为 $80\text{ m}$，求上升高度。

   $$\frac{h}{80}=\frac14,\quad h=20$$

   上升高度为 $20\text{ m}$。

2. 坡角为 $12^\circ$ 的坡道，水平距离为 $50\text{ m}$，求坡道上升高度。

   $$h=50\tan12^\circ\approx50\times0.2126=10.63$$

   上升高度约为 $10.6\text{ m}$。

3. 坡道长 $30\text{ m}$，坡角为 $8^\circ$，求铅直高度和水平距离。

   $$h=30\sin8^\circ\approx4.2$$

   $$d=30\cos8^\circ\approx29.7$$

4. 轮船从港口 $A$ 出发向正东航行 $20\text{ km}$ 到 $B$，此时灯塔 $C$ 在 $B$ 的北偏东 $35^\circ$ 方向，且在 $A$ 的北偏东 $55^\circ$ 方向，求 $BC$ 的近似长度。

   画图后可得 $\angle A=35^\circ$，$\angle B=125^\circ$，过 $C$ 作 $AB$ 的垂线，设垂足为 $D$。设 $BD=x$，则 $AD=20+x$，且

   $$CD=x\tan55^\circ=(20+x)\tan35^\circ$$

   或根据实际图形方向列等价关系求解。教学时重点放在画图和角的确定，可作为提高题处理。

### 5. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 坡度为 $1:3$，水平距离 $45\text{ m}$，求上升高度 |
| 当堂检测 | 坡角为 $15^\circ$，水平距离 $60\text{ m}$，求上升高度 |
| 当堂检测 | 坡道长 $40\text{ m}$，坡角 $10^\circ$，求水平距离 |
| 参考答案 | $15\text{ m}$；约 $16.1\text{ m}$；约 $39.4\text{ m}$ |
| 课后作业 | 完成坡度题 4 道、方位角基础题 2 道、综合建模题 1 道 |

## 第 8 课时：单元复习与分层训练

### 1. 课时目标

系统梳理锐角三角函数的定义、特殊角函数值、解直角三角形方法和实际应用模型；能识别常见错误；通过分层训练完成基础巩固与综合提升。

### 2. 复习提纲

| 模块 | 复习问题 |
|---|---|
| 定义 | 研究的是哪个锐角？对边、邻边、斜边分别是哪条边？ |
| 三角函数 | $\sin$、$\cos$、$\tan$ 分别是哪两个边的比？ |
| 特殊角 | $30^\circ$、$45^\circ$、$60^\circ$ 的函数值是否熟记？ |
| 查值反求角 | 是否确认角度制？是否按要求取近似值？ |
| 解直角三角形 | 已知哪些边角？要选哪个函数关系？ |
| 应用题 | 是否画图？是否把仰角、俯角、坡度、方位角转成图形语言？ |

### 3. 易错题辨析

1. 在直角三角形中，已知 $AB$ 是斜边，求 $\tan A$ 时写成 $\frac{\text{对边}}{AB}$。

   错误点：正切是对边比邻边，不涉及斜边。

2. 在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C=90^\circ$，把 $\angle A$ 的邻边误认为 $BC$。

   对 $\angle A$ 来说，$BC$ 是对边，$AC$ 是邻边。

3. 看到 $\sin A=\frac12$ 就直接写 $A=60^\circ$。

   对锐角而言：

   $$\sin30^\circ=\frac12$$

   所以 $A=30^\circ$。

4. 测楼高时只算出视线形成的高度差，忘记加上眼睛离地高度。

   若观测点高 $1.6\text{ m}$，应有：

   $$\text{楼高}=\text{高度差}+1.6$$

5. 把坡度 $1:5$ 当成坡角 $15^\circ$。

   坡度是 $\frac{\text{铅直高度}}{\text{水平距离}}$，坡角才是角。

### 5. 单元小结

本章的主线是“角与边的比”。先通过相似三角形认识同一锐角的边长比不变，再定义正弦、余弦、正切；之后利用特殊角、三角函数表或计算器求函数值；最后把三角函数用于解直角三角形和实际测量问题。

解题时要坚持三个步骤：先找直角三角形，再找研究的锐角，最后根据已知边和所求边选择函数关系。应用题中最关键的是画图建模，尤其要处理好仰角、俯角、坡度、方位角以及观测点高度。

## 附：教学建议

1. 第 1、2 课时要放慢，重点训练“对边、邻边、斜边”的辨认。学生只要边找错，后续公式都会错。
2. 特殊角函数值不要只要求死记硬背，应让学生至少会用两类基本三角形推导：等边三角形的一半和等腰直角三角形。
3. 解直角三角形时建议每题都让学生写一句“选用的关系式”，例如 $\tan A=\frac{\text{对边}}{\text{邻边}}$，帮助他们形成稳定步骤。
4. 应用题的训练要从单一模型开始，再进入综合模型。测高、测距、坡度题适合全班掌握，复杂方位角题可作为提高内容。
5. 评价时既看计算结果，也看图形、角的标注、函数关系式和单位。对于近似计算题，应统一保留位数要求。
