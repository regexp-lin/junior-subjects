## 题 1

在同一坐标系中，一次函数 $y_1 = 2x - 1$ 与 $y_2 = -x + 5$ 的图像相交于点 $P$。

(1) 求交点 $P$ 的坐标；

(2) 根据图像，直接写出 $2x - 1 > -x + 5$ 的解集；

(3) 求这两条直线与 $x$ 轴围成的三角形面积。

**答案：**

**(1)** 联立方程：

$$2x - 1 = -x + 5 \implies 3x = 6 \implies x = 2$$

$$y = 2 \times 2 - 1 = 3$$

$$\boxed{P(2,\,3)}$$

**(2)** $y_1 > y_2$ 即 $2x - 1 > -x + 5$。由图像可知，在交点 $P$ 的右侧，$y_1$ 的图像在 $y_2$ 上方。

$$\boxed{x > 2}$$

**(3)** $y_1 = 2x - 1$ 与 $x$ 轴交于 $A\!\left(\dfrac{1}{2},\,0\right)$；$y_2 = -x + 5$ 与 $x$ 轴交于 $B(5,\,0)$。

$$AB = 5 - \dfrac{1}{2} = \dfrac{9}{2}$$

交点 $P$ 到 $x$ 轴距离为 $3$。

$$S = \dfrac{1}{2} \times \dfrac{9}{2} \times 3 = \dfrac{27}{4}$$

$$\boxed{S = \dfrac{27}{4}}$$

## 题 2

已知一次函数 $y = kx + b$ 的图像经过点 $A(3,\,1)$，且与一次函数 $y = 2x - 5$ 的图像交于 $x$ 轴上一点。

(1) 求 $k$ 和 $b$；

(2) 根据图像，写出 $kx + b \geq 2x - 5$ 的解集。

**答案：**

**(1)** $y = 2x - 5$ 与 $x$ 轴交点：令 $y = 0$，得 $x = \dfrac{5}{2}$，即交点为 $\left(\dfrac{5}{2},\,0\right)$。

$y = kx + b$ 过 $A(3,\,1)$ 和 $\left(\dfrac{5}{2},\,0\right)$：

$$\begin{cases} 3k + b = 1 \\ \dfrac{5}{2}k + b = 0 \end{cases}$$

两式相减：$\dfrac{1}{2}k = 1 \implies k = 2$，$b = 1 - 6 = -5$。

但这样 $y = 2x - 5$，与已知函数相同，矛盾。重新审题：题目要求两直线交于 $x$ 轴上一点且不重合。

重新检查：$y = kx + b$ 过 $A(3,\,1)$，且与 $y = 2x - 5$ 交于 $x$ 轴上，即交点纵坐标为 $0$。$y = 2x - 5 = 0$ 得 $x = \dfrac{5}{2}$。所以 $y = kx + b$ 过 $\left(\dfrac{5}{2},\, 0\right)$ 和 $(3,\,1)$。

$$k = \dfrac{1 - 0}{3 - \dfrac{5}{2}} = \dfrac{1}{\dfrac{1}{2}} = 2$$

$k = 2$ 时两线重合。因此需要重新理解题意：$y = kx + b$ 与 $y = 2x - 5$ 交于 $x$ 轴上**某点**。如果是交于 $y = kx + b$ 自身在 $x$ 轴上的截距点。

更合理的理解：$y = kx + b$ 过 $A(3,\,1)$ 且 $y = kx + b$ 与 $x$ 轴的交点也在 $y = 2x - 5$ 的图像上。$y = 2x - 5$ 过 $x$ 轴的点为 $\left(\dfrac{5}{2},\,0\right)$，所以 $y = kx + b$ 过 $(3,\,1)$ 和 $\left(\dfrac{5}{2},\,0\right)$，确实得 $k = 2$。

**修正题意**：设 $y = kx + b$ 的图像过 $A(-1,\,1)$，且与 $y = 2x - 5$ 的图像交于 $x$ 轴上一点。

$y = 2x - 5 = 0 \implies x = \dfrac{5}{2}$，交于 $\left(\dfrac{5}{2},\,0\right)$。

$$\begin{cases} -k + b = 1 \\ \dfrac{5}{2}k + b = 0 \end{cases}$$

相减：$\dfrac{7}{2}k = -1 \implies k = -\dfrac{2}{7}$，$b = 1 + k = 1 - \dfrac{2}{7} = \dfrac{5}{7}$。

$$\boxed{k = -\dfrac{2}{7},\quad b = \dfrac{5}{7}}$$

**(2)** 两直线交于 $\left(\dfrac{5}{2},\,0\right)$。$y_1 = -\dfrac{2}{7}x + \dfrac{5}{7}$ 的斜率为负，$y_2 = 2x - 5$ 的斜率为正。当 $x < \dfrac{5}{2}$ 时 $y_1 > y_2$；当 $x = \dfrac{5}{2}$ 时 $y_1 = y_2$。

$$kx + b \geq 2x - 5 \implies \boxed{x \leq \dfrac{5}{2}}$$

## 题 3

如图，在平面直角坐标系中，直线 $y = -\dfrac{1}{2}x + 3$ 与 $x$ 轴交于点 $A$，与 $y$ 轴交于点 $B$。点 $P(a,\,b)$ 是线段 $AB$ 上的一个动点（不含端点）。

(1) 写出 $a$ 的取值范围；

(2) 求 $a + 2b$ 的取值范围；

(3) 若 $2a - b > 0$，求 $a$ 的取值范围。

**答案：**

**(1)** $A(6,\,0)$，$B(0,\,3)$。$P$ 在线段 $AB$ 上（不含端点），$a$ 的范围：

$$\boxed{0 < a < 6}$$

**(2)** $P$ 在直线上，$b = -\dfrac{1}{2}a + 3$。

$$a + 2b = a + 2\!\left(-\dfrac{1}{2}a + 3\right) = a - a + 6 = 6$$

$$\boxed{a + 2b = 6}$$

**(3)** $2a - b > 0$，代入 $b = -\dfrac{1}{2}a + 3$：

$$2a - \left(-\dfrac{1}{2}a + 3\right) > 0 \implies 2a + \dfrac{1}{2}a - 3 > 0 \implies \dfrac{5}{2}a > 3 \implies a > \dfrac{6}{5}$$

结合 $0 < a < 6$：

$$\boxed{\dfrac{6}{5} < a < 6}$$

## 题 4

一次函数 $y = (2m-1)x + (m-5)$ 满足：$y$ 随 $x$ 的增大而减小，且图像不经过第二象限。求 $m$ 的取值范围。

**答案：**

$y$ 随 $x$ 增大而减小 $\implies$ 斜率 $2m - 1 < 0 \implies m < \dfrac{1}{2}$。

图像不经过第二象限，需要：

- 斜率 $< 0$（已满足）；
- $y$ 轴截距 $\leq 0$，即 $m - 5 \leq 0 \implies m \leq 5$（已被 $m < \dfrac{1}{2}$ 包含）。

但还需检查：不经过第二象限意味着当 $x < 0$ 时 $y \leq 0$。由于斜率 $< 0$，$x = 0$ 时 $y = m - 5$。

- 若 $m - 5 \leq 0$，即 $m \leq 5$：函数在 $x = 0$ 处 $y \leq 0$，斜率为负，$x < 0$ 时 $y > y(0) = m - 5$。这不能保证 $x < 0$ 时 $y \leq 0$。

重新分析：不经过第二象限（$x < 0, y > 0$ 的区域），等价于：

- 当 $x \leq 0$ 时 $y \leq 0$。
- $x = 0$ 时 $y = m - 5 \leq 0 \implies m \leq 5$。
- 由于 $k < 0$，$x < 0$ 时 $y > y(0) = m - 5$。所以需要 $m - 5 \leq 0$ 不够。

需要函数与 $x$ 轴的交点在 $x \leq 0$ 处（或 $y$ 轴截距 $\leq 0$）：

令 $y = 0$：$x = \dfrac{5 - m}{2m - 1}$。不经过第二象限要求直线与 $x$ 轴的交点 $x_0 \leq 0$ 且 $y$ 轴截距 $m - 5 \leq 0$。

由 $k = 2m - 1 < 0$，$b = m - 5$。直线在 $y$ 轴左侧递增（反向看），图像不经过第二象限需要：

$$m - 5 \leq 0 \quad \text{且} \quad x_0 = \dfrac{5-m}{2m-1} \leq 0$$

$m < \dfrac{1}{2}$ 时 $2m - 1 < 0$，$5 - m > 0$（因为 $m < \dfrac{1}{2}$），所以 $x_0 = \dfrac{5 - m}{2m - 1} < 0$。

因此 $x_0 < 0$，$b = m - 5 < 0$（因为 $m < \dfrac{1}{2} < 5$）。

斜率为负，$y$ 轴截距为负，$x$ 轴截距为负 —— 直线从第三象限进入第四象限，不经过第一、二象限。但这不对，因为 $k < 0$ 且 $b < 0$ 时，$x \to -\infty$ 时 $y \to +\infty$，所以会经过第二象限。

正确分析：$k < 0$，直线从左上到右下。$x$ 轴交点 $x_0 < 0$，$y$ 轴截距 $b < 0$。则 $x < x_0 < 0$ 时 $y > 0$，在第二象限。所以仍然经过第二象限。

不经过第二象限的条件：$x$ 轴交点 $x_0 \geq 0$（直线进入正 $y$ 的部分在 $x \geq 0$ 处）。

$$x_0 = \dfrac{5 - m}{2m - 1} \geq 0$$

$2m - 1 < 0$ 且 $5 - m > 0$，分子正、分母负 $\implies x_0 < 0$。

这说明 $k < 0$ 时 $x_0$ 始终 $< 0$，不可能不经过第二象限——除非 $b \geq 0$ 且 $k < 0$。

当 $b \geq 0$，$k < 0$ 时：$x_0 = -\dfrac{b}{k} \geq 0$。直线过第一、二（$b > 0$）、四象限。仍经过第二象限当 $b > 0$。

当 $b = 0$，$k < 0$ 时过原点，经过第二、四象限（$x < 0$ 时 $y > 0$）。仍经过第二象限。

所以 $k < 0$ 时一次函数一定经过第二象限。题目条件无解？

重新理解：题目说 **不经过第二象限** 可以理解为图像不经过第二象限的充要条件是 $k > 0$，$b \leq 0$。但题目又要求 $y$ 随 $x$ 增大而减小（$k < 0$），矛盾。

**修正题目**：一次函数 $y = (2m - 1)x + (m - 5)$ 满足：$y$ 随 $x$ 的增大而减小，且图像不经过第一象限。求 $m$ 的取值范围。

$k = 2m - 1 < 0 \implies m < \dfrac{1}{2}$。

不经过第一象限：$k < 0$ 且 $b \leq 0$ 且 $x$ 轴截距 $\leq 0$。

$b = m - 5 \leq 0 \implies m \leq 5$（已含在 $m < \dfrac{1}{2}$ 中）。

$x_0 = \dfrac{5-m}{2m-1} \leq 0$：$m < \dfrac{1}{2}$ 时分母 $< 0$，$5 - m > 0$（因为 $m < \dfrac{1}{2}$），$x_0 < 0$ 自动满足。

所以 $k < 0$，$b < 0$，$x_0 < 0$ 时直线经过第二、三、四象限，不经过第一象限。

$$\boxed{m < \dfrac{1}{2}}$$

## 题 5

已知一次函数 $y_1 = x + a$ 和 $y_2 = -2x + b$ 的图像交于点 $M(m,\,3)$，且不等式 $x + a \leq -2x + b$ 的解集为 $x \leq 1$。

(1) 求 $a$、$b$ 的值；

(2) 求两直线与 $y$ 轴围成的三角形面积。

**答案：**

**(1)** 交点横坐标 $m$。由图像知，$y_1 \leq y_2$ 的解集为 $x \leq m$，又已知为 $x \leq 1$，所以 $m = 1$。

交点 $M(1,\,3)$：

$$\begin{cases} 1 + a = 3 \\ -2 + b = 3 \end{cases} \implies \boxed{a = 2,\quad b = 5}$$

**(2)** $y_1 = x + 2$ 与 $y$ 轴交于 $(0,\,2)$；$y_2 = -2x + 5$ 与 $y$ 轴交于 $(0,\,5)$。

底 $= |5 - 2| = 3$（沿 $y$ 轴），高 $= |1 - 0| = 1$（交点到 $y$ 轴的水平距离）。

$$S = \dfrac{1}{2} \times 3 \times 1 = \dfrac{3}{2}$$

$$\boxed{S = \dfrac{3}{2}}$$

## 题 6

直线 $l_1\colon y = 2x + 6$ 与 $x$ 轴交于点 $A$，与 $y$ 轴交于点 $B$。直线 $l_2$ 经过点 $A$，且与 $l_1$、$y$ 轴围成的三角形面积为 $9$。

(1) 求直线 $l_2$ 的解析式；

(2) 设 $l_2\colon y = kx + n$，利用图像求不等式 $2x + 6 > kx + n$ 的解集。

**答案：**

**(1)** $l_1$ 与 $x$ 轴交点：$2x + 6 = 0 \implies x = -3$，$A(-3,\, 0)$。$B(0,\, 6)$。

$l_2$ 过 $A(-3,\, 0)$，设 $l_2\colon y = k(x + 3)$。$l_2$ 与 $y$ 轴交于 $C(0,\, 3k)$。

$l_1$、$l_2$、$y$ 轴围成三角形的顶点为 $B(0,6)$、$C(0,3k)$、和 $l_1$ 与 $l_2$ 的另一个交点。

$l_1$ 与 $l_2$ 在 $A(-3,0)$ 已经相交。三角形顶点为 $A(-3,\,0)$、$B(0,\,6)$、$C(0,\,3k)$。

底 $BC = |6 - 3k|$（在 $y$ 轴上），高为 $A$ 到 $y$ 轴距离 $= 3$。

$$S = \dfrac{1}{2} \times |6 - 3k| \times 3 = 9 \implies |6 - 3k| = 6$$

$6 - 3k = 6 \implies k = 0$（退化，舍去）或 $6 - 3k = -6 \implies k = 4$。

$$\boxed{l_2\colon y = 4x + 12}$$

**(2)** $l_1$ 与 $l_2$ 交于 $A(-3,\,0)$。$l_1$ 斜率为 $2$，$l_2$ 斜率为 $4$，$l_2$ 更陡。当 $x > -3$ 时 $l_2$ 在 $l_1$ 上方（$l_2 > l_1$），所以 $l_1 > l_2$ 在 $x < -3$ 时成立。

$$2x + 6 > 4x + 12 \implies \boxed{x < -3}$$

## 题 7

如图，直线 $y = -x + 4$ 与 $x$ 轴、$y$ 轴分别交于点 $A$、$B$。点 $C$ 在线段 $OA$ 上，且 $OC = 1$。过 $C$ 作 $CD \perp x$ 轴，交直线 $AB$ 于点 $D$。

(1) 求点 $D$ 的坐标；

(2) 在直线 $AB$ 上是否存在点 $P$，使得 $\triangle PCD$ 的面积为 $3$？若存在，求 $P$ 的坐标。

**答案：**

**(1)** $A(4,\,0)$，$O$ 为原点，$C$ 在 $OA$ 上且 $OC = 1$，所以 $C(1,\,0)$。

$CD \perp x$ 轴，即 $x = 1$ 与 $y = -x + 4$ 交于 $D$：

$$y = -1 + 4 = 3 \implies \boxed{D(1,\,3)}$$

**(2)** $CD$ 在 $x = 1$ 上，$CD = 3$。设 $P(p,\, -p + 4)$ 在直线 $AB$ 上。

$\triangle PCD$ 以 $CD$ 为底（长度 $3$），高为 $P$ 到直线 $x = 1$ 的距离 $= |p - 1|$。

$$S = \dfrac{1}{2} \times 3 \times |p - 1| = 3 \implies |p - 1| = 2$$

$p = 3$ 或 $p = -1$。

- $p = 3$：$P(3,\,1)$；
- $p = -1$：$P(-1,\,5)$。

$$\boxed{P(3,\,1) \text{ 或 } P(-1,\,5)}$$

## 题 8

甲、乙两人同时从 $A$ 地出发前往 $B$ 地（匀速），$A$、$B$ 两地相距 $30$ km。甲骑自行车，速度为 $15$ km/h；乙步行，速度为 $5$ km/h。设出发 $x$ 小时后，甲距 $A$ 地 $y_1$ km，乙距 $A$ 地 $y_2$ km。

(1) 分别写出 $y_1$、$y_2$ 关于 $x$ 的函数关系式及自变量取值范围；

(2) 利用不等式，求甲比乙至少多走 $10$ km 的时间范围。

**答案：**

**(1)**

$$y_1 = 15x \quad (0 \leq x \leq 2)$$
$$y_2 = 5x \quad (0 \leq x \leq 6)$$

**(2)** 甲比乙多走的路程 $= y_1 - y_2 = 15x - 5x = 10x$。但甲在 $x = 2$ h 时到达 $B$ 地后停下，之后距离不再增加。

当 $0 \leq x \leq 2$ 时：$y_1 - y_2 = 10x \geq 10 \implies x \geq 1$。

当 $x > 2$ 时：$y_1 = 30$（已到达），$y_1 - y_2 = 30 - 5x \geq 10 \implies x \leq 4$。

综合：

$$\boxed{1 \leq x \leq 4}$$

## 题 9

关于 $x$ 的不等式 $(a - 1)x > a - 1$ 的解集为 $x < 1$。

(2) 设一次函数 $y = (a-1)x + (2a-3)$，在 $a$ 的范围内，判断此函数图像是否经过第三象限。

**答案：**

**(1)** $(a - 1)x > a - 1$ 的解集为 $x < 1$，说明两边除以 $a - 1$ 时不等号改变方向，即 $a - 1 < 0$：

$$a < 1$$

**(2)** $a < 1$ 时斜率 $k = a - 1 < 0$，截距 $b = 2a - 3$。

- $a < 1 \implies 2a < 2 \implies 2a - 3 < -1 < 0$。

$k < 0$，$b < 0$：图像经过第二、三、四象限。

$$\boxed{\text{一定经过第三象限}}$$

## 题 10

已知一次函数 $y = ax + b$ 和 $y = cx + d$ 的图像如图所示（两直线交于第二象限一点）。

下列不等式：① $a > c$；② $b < d$；③ $ad > bc$；④ $a + c < 0$。其中正确的有哪些？

（图像信息：$l_1\colon y = ax + b$，斜率为正且较陡，$y$ 轴截距较小为正；$l_2\colon y = cx + d$，斜率为正且较平缓，$y$ 轴截距较大为正。两直线交于第二象限。）

**答案：**

由图像读取信息：
- 两直线斜率均为正：$a > 0$，$c > 0$。
- $l_1$ 比 $l_2$ 陡：$a > c > 0$。✅ ①正确。
- $l_1$ 的 $y$ 轴截距 $b$ 较小，$l_2$ 截距 $d$ 较大：$b < d$。✅ ②正确。
- ③ 判断 $ad$ 与 $bc$ 的大小：交点在第二象限，设交点横坐标 $x_0 < 0$。
  $ax_0 + b = cx_0 + d \implies (a-c)x_0 = d - b$。
  $a > c$ 且 $x_0 < 0$，所以 $d - b = (a - c)x_0 < 0$，即 $d < b$，与②矛盾。

重新分析图像：交于第二象限，$l_1$ 更陡但截距更小，从交点向右 $l_1$ 在上方。设交点 $x_0 < 0$：

$(a - c)x_0 = d - b$，$a > c$，$d > b$，所以 $x_0 = \dfrac{d - b}{a - c} > 0$，矛盾于交于第二象限。

重新设定图像：$l_1$ 斜率为正但较小（$l_1$ 较平缓），$l_2$ 斜率为正但较大（$l_2$ 较陡）。$l_1$ 截距大，$l_2$ 截距小。交于第二象限。

$a < c$，$b > d$。$x_0 = \dfrac{d - b}{a - c}$，$d - b < 0$，$a - c < 0$，$x_0 > 0$。仍然矛盾。

交于第二象限需 $x_0 < 0$：$x_0 = \dfrac{d - b}{a - c} < 0$。需 $d - b$ 与 $a - c$ 异号。

设 $a > c > 0$（$l_1$ 更陡），$d > b > 0$（$l_2$ 截距更大）。$a - c > 0$，$d - b > 0$，$x_0 > 0$。不满足。

设 $c > a > 0$（$l_2$ 更陡），$b > d > 0$（$l_1$ 截距更大）。$a - c < 0$，$d - b < 0$，$x_0 > 0$。不满足。

要交于第二象限：$a - c > 0$，$d - b < 0$（即 $b > d$），$x_0 = \dfrac{d-b}{a-c} < 0$。或 $a - c < 0$，$d - b > 0$，$x_0 < 0$。

**取后者**：$a < c$（$l_2$ 更陡），$d > b$（$l_2$ 截距更大？不，是 $l_1$ 截距更小）。不对，$b$ 是 $l_1$ 截距，$d$ 是 $l_2$ 截距，$d > b$。

重新确定图像：$l_1$ 斜率 $a > 0$ 较平缓，截距 $b$ 较小；$l_2$ 斜率 $c > 0$ 较陡，截距 $d$ 较大。$a < c$，$b < d$。$x_0 = \dfrac{d - b}{a - c} = \dfrac{(+)}{(-)} < 0$。✅

所以图像应为：$0 < a < c$，$0 < b < d$，交于第二象限。

① $a > c$：**错误**。$a < c$。
② $b < d$：**正确**。
③ $ad$ 与 $bc$：$\dfrac{a}{c} < 1$，$\dfrac{b}{d} < 1$，但不确定 $ad$ 与 $bc$ 的关系。交点纵坐标 $y_0 = ax_0 + b = a \cdot \dfrac{d-b}{a-c} + b = \dfrac{ad - ab + ab - bc}{a - c} = \dfrac{ad - bc}{a - c}$。交于第二象限 $y_0 > 0$，$a - c < 0$，所以 $ad - bc < 0$，即 $ad < bc$。③ **错误**。
④ 无法仅从图像确定 $a + c$ 的正负。$a > 0$，$c > 0$，$a + c > 0$。④ **错误**。

$$\boxed{\text{正确的是 ②}}$$

## 题 11

已知一次函数 $y = kx + b$ 满足 $kb > 0$ 且 $k + b < 0$。

(1) 判断该函数图像经过哪些象限；

(2) 写出不等式 $kx + b > 0$ 的解集。

**答案：**

**(1)** $kb > 0$：$k$、$b$ 同号。

**情况一**：$k > 0$，$b > 0$。此时 $k + b > 0$，与 $k + b < 0$ 矛盾。

**情况二**：$k < 0$，$b < 0$。$k + b < 0$ 自动满足。

所以 $k < 0$，$b < 0$。图像斜率为负，$y$ 轴截距为负。

$$\boxed{\text{经过第二、三、四象限}}$$

**(2)** $k < 0$，$kx + b > 0 \implies x < -\dfrac{b}{k}$。

$k + b < 0 \implies b < -k \implies -\dfrac{b}{k} < \dfrac{-(-k)}{k} = 1$。但这只给出上界。实际 $-\dfrac{b}{k} = -\dfrac{b}{k}$，因为 $k < 0$，$b < 0$，$-\dfrac{b}{k} = \dfrac{|b|}{|k|} > 0$。

$$\boxed{x < -\dfrac{b}{k},\quad \text{其中 } 0 < -\dfrac{b}{k} < 1}$$

## 题 24

一次函数 $y = kx + b$（$k \neq 0$）的图像过点 $(1,\, 2)$，且与两坐标轴围成的三角形面积为 $4$。

(1) 求所有满足条件的 $k$、$b$；

(2) 对于每组解，写出 $kx + b > 0$ 的解集。

**答案：**

**(1)** 过 $(1,\, 2)$：$k + b = 2$，$b = 2 - k$。

$x$ 轴截距：$x_0 = -\dfrac{b}{k} = -\dfrac{2-k}{k} = 1 - \dfrac{2}{k}$。

$y$ 轴截距：$b = 2 - k$。

三角形面积 $= \dfrac{1}{2}|x_0||b| = 4$，即 $|x_0||b| = 8$。

$$\left|1 - \dfrac{2}{k}\right| \cdot |2 - k| = 8$$

$$\left|\dfrac{k - 2}{k}\right| \cdot |2 - k| = 8 \implies \dfrac{(k-2)^2}{|k|} = 8$$

$(k-2)^2 = 8|k|$。

**若 $k > 0$**：$(k-2)^2 = 8k$，$k^2 - 4k + 4 = 8k$，$k^2 - 12k + 4 = 0$。

$$k = \dfrac{12 \pm \sqrt{144 - 16}}{2} = \dfrac{12 \pm 8\sqrt{2}}{2} = 6 \pm 4\sqrt{2}$$

$k_1 = 6 + 4\sqrt{2} \approx 11.66$，$b_1 = 2 - k_1 = -4 - 4\sqrt{2}$。
$k_2 = 6 - 4\sqrt{2} \approx 0.34$，$b_2 = 2 - k_2 = -4 + 4\sqrt{2}$。

**若 $k < 0$**：$(k-2)^2 = -8k$，$k^2 - 4k + 4 = -8k$，$k^2 + 4k + 4 = 0$，$(k+2)^2 = 0$，$k = -2$。

$k_3 = -2$，$b_3 = 4$。

$$\boxed{(k,b) = (6 + 4\sqrt{2},\, -4 - 4\sqrt{2}),\; (6 - 4\sqrt{2},\, -4 + 4\sqrt{2}),\; (-2,\, 4)}$$

**(2)** 对于 $k > 0$ 的两组：$kx + b > 0 \implies x > -\dfrac{b}{k}$。

- $k = 6 + 4\sqrt{2}$：$x > \dfrac{4 + 4\sqrt{2}}{6 + 4\sqrt{2}} = \dfrac{4(1+\sqrt{2})}{2(3+2\sqrt{2})} = \dfrac{2(1+\sqrt{2})}{(1+\sqrt{2})^2} = \dfrac{2}{1+\sqrt{2}} = 2(\sqrt{2}-1)$。

$$x > 2\sqrt{2} - 2$$

- $k = 6 - 4\sqrt{2}$：$x > \dfrac{4 - 4\sqrt{2}}{6 - 4\sqrt{2}} = \dfrac{4(1-\sqrt{2})}{2(3-2\sqrt{2})} = \dfrac{2(1-\sqrt{2})}{(\sqrt{2}-1)^2} = \dfrac{-2(\sqrt{2}-1)}{(\sqrt{2}-1)^2} = \dfrac{-2}{\sqrt{2}-1} = -2(\sqrt{2}+1)$。

$$x > -2\sqrt{2} - 2$$

对于 $k = -2$：$-2x + 4 > 0 \implies x < 2$。

$$\boxed{x > 2\sqrt{2} - 2;\quad x > -2\sqrt{2} - 2;\quad x < 2}$$

## 题 25

如图，在平面直角坐标系中，已知 $A(-6,\, 0)$，$B(0,\, 8)$。

(1) 求直线 $AB$ 的解析式；

(2) 点 $P$ 在线段 $AB$ 上，过 $P$ 作 $PE \perp x$ 轴于 $E$，作 $PF \perp y$ 轴于 $F$。设 $P(a,\, b)$（$a < 0$，$b > 0$），求矩形 $OEPF$ 面积的最大值；

(3) 在直线 $AB$ 上求一点 $Q$，使 $Q$ 到两坐标轴距离相等。

**答案：**

**(1)** 过 $A(-6,\, 0)$、$B(0,\, 8)$：斜率 $= \dfrac{8}{6} = \dfrac{4}{3}$。

$$\boxed{y = \dfrac{4}{3}x + 8}$$

**(2)** $P(a,\, b)$ 在直线上：$b = \dfrac{4}{3}a + 8$，$-6 < a < 0$，$0 < b < 8$。

矩形 $OEPF$：$E(a,\, 0)$，$F(0,\, b)$，$O$ 原点。面积 $= |a| \cdot b = (-a) \cdot b$（因为 $a < 0$）。

$$S = -a\!\left(\dfrac{4}{3}a + 8\right) = -\dfrac{4}{3}a^2 - 8a$$

令 $t = -a$（$0 < t < 6$）：$S = -\dfrac{4}{3}t^2 + 8t = -\dfrac{4}{3}\!\left(t^2 - 6t\right) = -\dfrac{4}{3}\!\left[(t - 3)^2 - 9\right] = -\dfrac{4}{3}(t-3)^2 + 12$。

$t = 3$ 时 $S$ 最大 $= 12$。此时 $a = -3$，$b = \dfrac{4}{3}(-3) + 8 = 4$。$P(-3,\, 4)$。

$$\boxed{S_{\max} = 12,\quad P(-3,\, 4)}$$

**(3)** $Q$ 到两坐标轴距离相等：$|x| = |y|$，即 $y = x$ 或 $y = -x$。

**与 $y = x$ 联立**：$x = \dfrac{4}{3}x + 8 \implies -\dfrac{1}{3}x = 8 \implies x = -24$，$y = -24$。$Q_1(-24,\, -24)$。

**与 $y = -x$ 联立**：$-x = \dfrac{4}{3}x + 8 \implies -\dfrac{7}{3}x = 8 \implies x = -\dfrac{24}{7}$，$y = \dfrac{24}{7}$。$Q_2\!\left(-\dfrac{24}{7},\, \dfrac{24}{7}\right)$。

$$\boxed{Q_1(-24,\, -24) \text{ 或 } Q_2\!\left(-\dfrac{24}{7},\, \dfrac{24}{7}\right)}$$

## 题 26

已知函数 $y_1 = ax + b$ 和 $y_2 = cx + d$，其中 $a$、$b$、$c$、$d$ 满足 $ac < 0$，$bd > 0$，$ad > 0$。

(1) 判断两直线斜率的正负关系；

(2) 判断两直线是否一定相交，若相交，判断交点在第几象限。

**答案：**

**(1)** 由 $ac < 0$：$a$、$c$ 异号，即两直线斜率一正一负。

$$\boxed{\text{斜率一正一负}}$$

**(2)** $a \neq c$（因为异号），两直线一定相交。

交点横坐标 $x_0 = \dfrac{d - b}{a - c}$，纵坐标 $y_0 = a \cdot \dfrac{d-b}{a-c} + b = \dfrac{ad - ab + ab - bc}{a - c} = \dfrac{ad - bc}{a - c}$。

分析 $x_0$ 和 $y_0$ 的符号：

由 $bd > 0$：$b$、$d$ 同号。由 $ad > 0$：$a$、$d$ 同号，所以 $a$、$b$、$d$ 同号。又 $ac < 0$：$c$ 与 $a$ 异号。

**情况一**：$a > 0$，$b > 0$，$d > 0$，$c < 0$。

$x_0 = \dfrac{d - b}{a - c}$，$a - c > 0$。$d - b$ 可正可负（不确定），所以 $x_0$ 可正可负。

$y_0 = \dfrac{ad - bc}{a - c}$，$ad > 0$，$bc < 0$（$b > 0$，$c < 0$），$ad - bc > 0$，$a - c > 0$，$y_0 > 0$。

**情况二**：$a < 0$，$b < 0$，$d < 0$，$c > 0$。

$a - c < 0$。$ad - bc$：$ad > 0$（$a < 0$，$d < 0$），$bc > 0$（$b < 0$，$c > 0$）。$ad - bc$ 不确定。

不对，$bc = (-)( +) < 0$，$ad = (-)(-) > 0$，$ad - bc > 0$，$a - c < 0$，$y_0 < 0$。

两种情况下 $y_0$ 的符号不同。但在两种情况下，$y_0 = \dfrac{ad - bc}{a - c}$，而 $ad > 0$，$bc < 0$（因为 $b$ 与 $c$ 异号：情况一 $b > 0, c < 0$；情况二 $b < 0, c > 0$）。所以 $ad - bc > 0$。

$a - c$：情况一 $> 0$，$y_0 > 0$；情况二 $< 0$，$y_0 < 0$。

所以交点不一定在同一象限。但 $x_0$ 的符号：$x_0 = \dfrac{d-b}{a-c}$，$d$ 与 $b$ 同号，$d - b$ 不确定。

$$\boxed{\text{两直线一定相交，交点一定在 } y \text{ 轴上方（第一或第二象限）或下方（第三或第四象限），但不能确定具体象限}}$$

更精确地：当 $a > 0$（情况一）时 $y_0 > 0$，交点在第一或第二象限；当 $a < 0$（情况二）时 $y_0 < 0$，交点在第三或第四象限。

$$\boxed{\text{一定相交；} a > 0 \text{ 时交于上半平面，} a < 0 \text{ 时交于下半平面}}$$

## 题 27

在平面直角坐标系中，直线 $y = -\dfrac{3}{4}x + 3$ 与 $x$ 轴、$y$ 轴分别交于 $A$、$B$。在第一象限内直线 $AB$ 上取一点 $P$，过 $P$ 向 $x$ 轴作垂线，垂足为 $H$。

(1) 设 $P(t,\, y_P)$，用 $t$ 表示 $\triangle OPH$ 的面积 $S$（$O$ 为原点）；

(2) 当 $\triangle OPH$ 的面积等于 $\triangle OAB$ 面积的 $\dfrac{1}{3}$ 时，求 $P$ 的坐标；

(3) 是否存在 $P$，使 $\triangle OPH$ 的面积为 $\triangle OAB$ 面积的 $\dfrac{1}{2}$？说明理由。

**答案：**

$A(4,\, 0)$，$B(0,\, 3)$。$\triangle OAB$ 面积 $= \dfrac{1}{2} \times 4 \times 3 = 6$。

**(1)** $P(t,\, y_P)$，$y_P = -\dfrac{3}{4}t + 3$。$P$ 在第一象限内直线上：$0 < t < 4$。

$H(t,\, 0)$，$PH = y_P = -\dfrac{3}{4}t + 3$，$OH = t$。

$$S = \dfrac{1}{2} \times t \times \left(-\dfrac{3}{4}t + 3\right) = \dfrac{1}{2}\left(-\dfrac{3}{4}t^2 + 3t\right) = -\dfrac{3}{8}t^2 + \dfrac{3}{2}t$$

$$\boxed{S = -\dfrac{3}{8}t^2 + \dfrac{3}{2}t \quad (0 < t < 4)}$$

**(2)** $S = \dfrac{1}{3} \times 6 = 2$：

$$-\dfrac{3}{8}t^2 + \dfrac{3}{2}t = 2 \implies 3t^2 - 12t + 16 = 0 \cdot (-8) \implies -3t^2 + 12t = 16 \implies 3t^2 - 12t + 16 = 0$$

$\Delta = 144 - 192 = -48 < 0$。无实数解。

重新计算：$-\dfrac{3}{8}t^2 + \dfrac{3}{2}t = 2$，两边乘 $-8$：$3t^2 - 12t = -16$，$3t^2 - 12t + 16 = 0$。$\Delta = 144 - 192 < 0$，无解。

那么取 $S = \dfrac{1}{3} \times 6 = 2$ 无解。我们来求 $S$ 的最大值：$S = -\dfrac{3}{8}(t^2 - 4t) = -\dfrac{3}{8}[(t-2)^2 - 4] = -\dfrac{3}{8}(t-2)^2 + \dfrac{3}{2}$。$S_{\max} = \dfrac{3}{2}$，在 $t = 2$ 时取到。

$\dfrac{3}{2} < 2$，所以 $\dfrac{1}{3}$ 面积确实无解。改为 $\dfrac{1}{4}$：$S = \dfrac{1}{4} \times 6 = \dfrac{3}{2} = S_{\max}$。

$$P(2,\, \dfrac{3}{2}) \text{ 时 } S = \dfrac{3}{2} = \dfrac{1}{4} \times 6。$$

**修正**：改为面积为 $1$：$-\dfrac{3}{8}t^2 + \dfrac{3}{2}t = 1$，$3t^2 - 12t + 8 = 0$。

$$t = \dfrac{12 \pm \sqrt{144 - 96}}{6} = \dfrac{12 \pm 4\sqrt{3}}{6} = 2 \pm \dfrac{2\sqrt{3}}{3}$$

两个值均在 $(0, 4)$ 内。

$$\boxed{P\!\left(2 + \dfrac{2\sqrt{3}}{3},\; \dfrac{3}{2} - \dfrac{\sqrt{3}}{2}\right) \text{ 或 } P\!\left(2 - \dfrac{2\sqrt{3}}{3},\; \dfrac{3}{2} + \dfrac{\sqrt{3}}{2}\right)}$$

**(3)** $\dfrac{1}{2} \times 6 = 3 > S_{\max} = \dfrac{3}{2}$。

$$\boxed{\text{不存在。} S \text{ 的最大值为 } \dfrac{3}{2},\text{ 小于 } 3}$$

## 题 28

设关于 $x$ 的一元一次不等式 $2(x - a) \leq 3(x - 1) + 1$ 的最大整数解为 $2$。

(1) 求 $a$ 的取值范围；

(2) 在此范围内取一个合适的 $a$，画出 $y = 2(x - a) - [3(x - 1) + 1]$ 的图像，用图像验证结论。

**答案：**

**(1)** 化简不等式：

$$2x - 2a \leq 3x - 3 + 1 \implies -2a \leq x - 2 \implies x \geq 2 - 2a$$

解集为 $x \geq 2 - 2a$。最大整数解为 $2$？

$x \geq 2 - 2a$ 无最大值（向右无穷），所以"最大整数解"不合理。

**修正不等式方向**：$2(x - a) \geq 3(x - 1) + 1$ 化简得 $x \leq 2 - 2a$。

最大整数解为 $2$：$2 \leq 2 - 2a < 3$。

$$2 \leq 2 - 2a \implies a \leq 0$$
$$2 - 2a < 3 \implies a > -\dfrac{1}{2}$$

$$\boxed{-\dfrac{1}{2} < a \leq 0}$$

**(2)** 取 $a = 0$：$y = 2x - [3(x-1)+1] = 2x - 3x + 3 - 1 = -x + 2$。

$y = -x + 2$：斜率 $-1$，过 $(0, 2)$ 和 $(2, 0)$。

不等式 $2(x - 0) \geq 3(x - 1) + 1$ 即 $y \geq 0$，从图像看 $-x + 2 \geq 0 \implies x \leq 2$。最大整数解为 $2$。✅

$$\boxed{\text{图像验证：直线 } y = -x + 2 \text{ 在 } x \leq 2 \text{ 时位于 } x \text{ 轴上方或上面，最大整数解为 } 2}$$

## 题 29

已知直线 $l\colon y = kx + b$ 经过 $A(4,\, 3)$、$B(-2,\, -6)$。

(1) 求 $k$、$b$；

(2) 若点 $C(a,\, 0)$ 在 $x$ 轴上，且 $\triangle ABC$ 的面积为 $15$，求 $a$；

(3) 设 $P(x,\, y)$ 在直线 $l$ 上运动，当 $-1 \leq y \leq 8$ 时，求 $3x - 2y + 1$ 的取值范围。

**答案：**

**(1)**

$$k = \dfrac{3 - (-6)}{4 - (-2)} = \dfrac{9}{6} = \dfrac{3}{2},\quad b = 3 - \dfrac{3}{2} \times 4 = 3 - 6 = -3$$

$$\boxed{k = \dfrac{3}{2},\quad b = -3}$$

**(2)** $AB$ 的长度：$\sqrt{(4+2)^2 + (3+6)^2} = \sqrt{36 + 81} = \sqrt{117} = 3\sqrt{13}$。

点 $C(a,\, 0)$ 到直线 $3x - 2y - 6 = 0$（即 $\dfrac{3}{2}x - y - 3 = 0$ 化为 $3x - 2y - 6 = 0$）的距离：

$$d = \dfrac{|3a - 0 - 6|}{\sqrt{9 + 4}} = \dfrac{|3a - 6|}{\sqrt{13}}$$

$$S = \dfrac{1}{2} \times 3\sqrt{13} \times \dfrac{|3a - 6|}{\sqrt{13}} = \dfrac{3|3a - 6|}{2} = 15$$

$$|3a - 6| = 10 \implies 3a - 6 = 10 \text{ 或 } 3a - 6 = -10$$

$$a = \dfrac{16}{3} \text{ 或 } a = -\dfrac{4}{3}$$

$$\boxed{a = \dfrac{16}{3} \text{ 或 } a = -\dfrac{4}{3}}$$

**(3)** $y = \dfrac{3}{2}x - 3$，$-1 \leq y \leq 8$。

$y = -1$：$x = \dfrac{2(-1+3)}{3} = \dfrac{4}{3}$。$y = 8$：$x = \dfrac{2(8+3)}{3} = \dfrac{22}{3}$。

所以 $\dfrac{4}{3} \leq x \leq \dfrac{22}{3}$。

$3x - 2y + 1 = 3x - 2\!\left(\dfrac{3}{2}x - 3\right) + 1 = 3x - 3x + 6 + 1 = 7$。

$$\boxed{3x - 2y + 1 = 7}$$

（这是一个常数！因为 $P$ 在直线 $y = \dfrac{3}{2}x - 3$ 上，$3x - 2y = 3x - 2 \cdot \dfrac{3}{2}x + 6 = 6$ 恒成立。）

## 题 30

已知在平面直角坐标系中，$A(-3,\, 0)$、$B(5,\, 0)$，直线 $l_1\colon y = x + 3$ 过 $A$，直线 $l_2\colon y = -x + 5$ 过 $B$，两直线交于点 $C$。

(1) 求 $C$ 的坐标及 $\triangle ABC$ 的面积；

(2) 在直线 $l_1$ 上取点 $D$，在直线 $l_2$ 上取点 $E$，使 $D$、$E$ 的横坐标相同且 $DE = 2$。求所有满足条件的 $D$、$E$ 坐标；

(3) 在 $x$ 轴上求一点 $M$，使 $MA + MC$ 最小，并求最小值。

**答案：**

**(1)** $x + 3 = -x + 5 \implies 2x = 2 \implies x = 1$，$y = 4$。$C(1,\, 4)$。

$AB = 5 - (-3) = 8$。$C$ 到 $x$ 轴距离 $= 4$。

$$S = \dfrac{1}{2} \times 8 \times 4 = 16$$

$$\boxed{C(1,\, 4),\quad S_{\triangle ABC} = 16}$$

**(2)** 设 $D$、$E$ 横坐标为 $t$。

$D$ 在 $l_1$ 上：$D(t,\, t+3)$。$E$ 在 $l_2$ 上：$E(t,\, -t+5)$。

$$DE = |(t+3) - (-t+5)| = |2t - 2| = 2$$

$$|2t - 2| = 2 \implies 2t - 2 = 2 \text{ 或 } 2t - 2 = -2$$

$t = 2$ 或 $t = 0$。

- $t = 2$：$D(2,\, 5)$，$E(2,\, 3)$。
- $t = 0$：$D(0,\, 3)$，$E(0,\, 5)$。

$$\boxed{D(2,5),\, E(2,3) \text{ 或 } D(0,3),\, E(0,5)}$$

**(3)** $A(-3,\, 0)$ 已在 $x$ 轴上，$C(1,\, 4)$ 在 $x$ 轴上方。$M$ 在 $x$ 轴上。

$MA + MC$ 最小：$A$ 在 $x$ 轴上，$MA = |x_M - (-3)| = |x_M + 3|$。

将 $C$ 关于 $x$ 轴作对称点 $C'(1,\, -4)$。$MC = MC'$，所以 $MA + MC = MA + MC' \geq AC'$。

$$AC' = \sqrt{(1+3)^2 + (-4)^2} = \sqrt{16 + 16} = 4\sqrt{2}$$

当 $M$ 在线段 $AC'$ 与 $x$ 轴的交点时取最小值。

$A(-3,\, 0)$，$C'(1,\, -4)$。直线 $AC'$：斜率 $= \dfrac{-4 - 0}{1 - (-3)} = -1$。$y = -(x+3) = -x - 3$。

与 $x$ 轴交点：$-x - 3 = 0 \implies x = -3$。即 $M = A$，但此时 $MA = 0$，$MC = AC = \sqrt{16+16} = 4\sqrt{2}$。

但这意味着 $A$、$M$、$C'$ 共线需要 $M$ 在线段 $AC'$ 上。由于 $A$ 在 $x$ 轴上，$C'$ 在 $x$ 轴下方，线段 $AC'$ 与 $x$ 轴的交点就是 $A$ 本身。

所以 $M$ 取 $A(-3,\, 0)$ 时 $MA + MC = 0 + \sqrt{16 + 16} = 4\sqrt{2}$。

验证：取 $M(1,\, 0)$：$MA = 4$，$MC = 4$，$MA + MC = 8 > 4\sqrt{2}$。✅

$$\boxed{M(-3,\, 0),\quad MA + MC \text{ 最小值为 } 4\sqrt{2}}$$

注：$M$ 与 $A$ 重合。若题目要求 $M \neq A$，则设 $M$ 在 $A$ 与 $B$ 之间（不含 $A$），利用对称点方法：$C'(1,\, -4)$，$A(-3, 0)$ 到 $C'(1, -4)$ 的线段只过 $x$ 轴于 $A$ 点，所以严格来说最小值 $4\sqrt{2}$ 只在 $M = A$ 时取到，不存在 $M \neq A$ 的更优解。

$$\boxed{(MA + MC)_{\min} = 4\sqrt{2}}$$
