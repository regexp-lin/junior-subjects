# 基本不等式 —— 公式精讲与提高训练

---

## 一、核心公式

### 公式 1：基本不等式（均值不等式）

$$a + b \geq 2\sqrt{ab} \quad (a > 0,\; b > 0)$$

等号成立条件：$a = b$。

**讲解：**
- 当 $a$、$b$ 均为正数时，它们的**算术平均值**不小于**几何平均值**。
- 等价变形：$\sqrt{ab} \leq \dfrac{a+b}{2}$，即几何平均 ≤ 算术平均。
- 证明：$a + b - 2\sqrt{ab} = (\sqrt{a} - \sqrt{b})^2 \geq 0$，当且仅当 $\sqrt{a} = \sqrt{b}$，即 $a = b$ 时取等。

### 公式 2：积的上界

$$ab \leq \left(\dfrac{a+b}{2}\right)^2 \quad (a > 0,\; b > 0)$$

等号成立条件：$a = b$。

**讲解：**
- 由基本不等式两边平方可得。当两个正数的和为定值 $S$ 时，它们的积 $ab$ 有最大值 $\dfrac{S^2}{4}$。
- 口诀：**和定积最大**。

### 公式 3：和的下界

$$a + b \geq 2\sqrt{ab} \quad (a > 0,\; b > 0)$$

**讲解：**
- 当两个正数的积为定值 $P$ 时，它们的和 $a + b$ 有最小值 $2\sqrt{P}$。
- 口诀：**积定和最小**。

### 公式 4：倒数和不等式

$$\dfrac{1}{a} + \dfrac{1}{b} \geq \dfrac{4}{a+b} \quad (a > 0,\; b > 0)$$

等号成立条件：$a = b$。

**讲解：**
- 证明：由基本不等式 $a + b \geq 2\sqrt{ab}$，取倒数得 $\dfrac{1}{\sqrt{ab}} \geq \dfrac{2}{a+b}$。
- 又 $\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{a+b}{ab} \geq \dfrac{2}{\sqrt{ab}} \geq \dfrac{4}{a+b}$。
- 中考中常与分式结合出题。

### 公式 5：平方和不等式

$$a^2 + b^2 \geq 2ab$$

等号成立条件：$a = b$（$a, b$ 为任意实数）。

**讲解：**
- $a^2 + b^2 - 2ab = (a - b)^2 \geq 0$。
- 不要求 $a, b > 0$，对一切实数成立。
- 推论：$a^2 + b^2 \geq \dfrac{(a+b)^2}{2}$。

### 公式 6："1" 的代换（对勾函数）

$$f(x) = x + \dfrac{k}{x} \quad (x > 0,\; k > 0)$$

$$f(x) \geq 2\sqrt{k}$$

等号成立条件：$x = \sqrt{k}$。

**讲解：**
- 将基本不等式应用于 $x$ 与 $\dfrac{k}{x}$。
- 中考常见题型：求 $x + \dfrac{1}{x}$ 的最小值（$x > 0$ 时最小值为 $2$）。
- 注意：若 $x < 0$，则 $x + \dfrac{k}{x} \leq -2\sqrt{k}$（取最大值）。

---

## 二、使用基本不等式求最值的三个条件

中考解题中，使用基本不等式必须同时满足 **"一正、二定、三相等"**：

| 条件 | 含义 |
|------|------|
| **一正** | 相关变量必须为正数 |
| **二定** | 和为定值或积为定值 |
| **三相等** | 等号必须能够取到（即存在 $a = b$ 的情况） |

三个条件缺一不可，否则不能直接用基本不等式求最值。

---

## 三、常用变形技巧

1. **凑积为定值**：已知 $a + b = S$（定值），求 $ab$ 的最大值 → $ab \leq \dfrac{S^2}{4}$。
2. **凑和为定值**：已知 $ab = P$（定值），求 $a + b$ 的最小值 → $a + b \geq 2\sqrt{P}$。
3. **拆项配凑**：把一个表达式拆成两项之和，使它们的积为常数。
4. **乘 "1"**：利用已知条件（如 $a + b = 1$）乘到待求表达式上，制造可用基本不等式的结构。
5. **换元法**：令 $t = a + b$ 或 $t = ab$ 化简后再用基本不等式。

## 四、中等难度题（10 道）

---

### 题 1

已知 $x > 0$，求 $x + \dfrac{4}{x}$ 的最小值。

**答案：**

由基本不等式：

$$x + \dfrac{4}{x} \geq 2\sqrt{x \cdot \dfrac{4}{x}} = 2\sqrt{4} = 4$$

当 $x = \dfrac{4}{x}$，即 $x = 2$ 时取等号。

$$\boxed{\text{最小值为 } 4}$$

---

### 题 2

已知 $a > 0$，$b > 0$，$a + b = 4$，求 $ab$ 的最大值。

**答案：**

由基本不等式：$a + b \geq 2\sqrt{ab}$，即 $4 \geq 2\sqrt{ab}$。

$$\sqrt{ab} \leq 2 \implies ab \leq 4$$

当 $a = b = 2$ 时取等号。

$$\boxed{ab \text{ 的最大值为 } 4}$$

---

### 题 3

已知 $x > 0$，求 $\dfrac{x}{x^2 + 9}$ 的最大值。

**答案：**

$$\dfrac{x}{x^2 + 9} = \dfrac{1}{x + \dfrac{9}{x}}$$

由基本不等式：$x + \dfrac{9}{x} \geq 2\sqrt{9} = 6$，当 $x = 3$ 时取等。

$$\dfrac{1}{x + \dfrac{9}{x}} \leq \dfrac{1}{6}$$

$$\boxed{\text{最大值为 } \dfrac{1}{6}}$$

---

### 题 4

已知 $a > 0$，$b > 0$，$ab = 9$，求 $a + b$ 的最小值。

**答案：**

由基本不等式：$a + b \geq 2\sqrt{ab} = 2\sqrt{9} = 6$。

当 $a = b = 3$ 时取等号。

$$\boxed{a + b \text{ 的最小值为 } 6}$$

---

### 题 5

已知 $a > 0$，$b > 0$，$a + 2b = 1$，求 $\dfrac{1}{a} + \dfrac{1}{b}$ 的最小值。

**答案：**

$$\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{1}{a} + \dfrac{1}{b} \cdot \dfrac{(a + 2b)}{1} = \dfrac{a + 2b}{a} + \dfrac{a + 2b}{b}$$

不，用乘"1"法更简洁：

$$\dfrac{1}{a} + \dfrac{1}{b} = \left(\dfrac{1}{a} + \dfrac{1}{b}\right)(a + 2b)$$

展开：$= 1 + \dfrac{2b}{a} + \dfrac{a}{b} + 2 = 3 + \dfrac{2b}{a} + \dfrac{a}{b}$

由基本不等式：$\dfrac{2b}{a} + \dfrac{a}{b} \geq 2\sqrt{\dfrac{2b}{a} \cdot \dfrac{a}{b}} = 2\sqrt{2}$

所以 $\dfrac{1}{a} + \dfrac{1}{b} \geq 3 + 2\sqrt{2}$

当 $\dfrac{2b}{a} = \dfrac{a}{b}$，即 $a = \sqrt{2}\,b$ 时取等。联立 $a + 2b = 1$ 得 $b = \dfrac{1}{2 + \sqrt{2}}$，$a = \dfrac{\sqrt{2}}{2 + \sqrt{2}}$。

$$\boxed{\text{最小值为 } 3 + 2\sqrt{2}}$$

---

### 题 6

已知 $x > 1$，求 $x + \dfrac{1}{x - 1}$ 的最小值。

**答案：**

令 $t = x - 1 > 0$，则 $x = t + 1$。

$$x + \dfrac{1}{x-1} = t + 1 + \dfrac{1}{t} \geq 2\sqrt{t \cdot \dfrac{1}{t}} + 1 = 2 + 1 = 3$$

当 $t = 1$，即 $x = 2$ 时取等号。

$$\boxed{\text{最小值为 } 3}$$

---

### 题 7

已知 $a > 0$，$b > 0$，$2a + b = 1$，求 $\dfrac{1}{a} + \dfrac{2}{b}$ 的最小值。

**答案：**

$$\dfrac{1}{a} + \dfrac{2}{b} = \left(\dfrac{1}{a} + \dfrac{2}{b}\right)(2a + b) = 2 + \dfrac{b}{a} + \dfrac{4a}{b} + 2 = 4 + \dfrac{b}{a} + \dfrac{4a}{b}$$

由基本不等式：$\dfrac{b}{a} + \dfrac{4a}{b} \geq 2\sqrt{4} = 4$

$$\dfrac{1}{a} + \dfrac{2}{b} \geq 8$$

当 $\dfrac{b}{a} = \dfrac{4a}{b}$，即 $b = 2a$ 时取等。联立 $2a + b = 1$ 得 $a = \dfrac{1}{4}$，$b = \dfrac{1}{2}$。

$$\boxed{\text{最小值为 } 8}$$

---

### 题 8

已知 $0 < x < 2$，求 $x(4 - 2x)$ 的最大值。

**答案：**

令 $y = x(4 - 2x) = 4x - 2x^2$。

用基本不等式：$x$ 和 $4 - 2x$ 均为正数（因为 $0 < x < 2$）。

为使两项之和为定值，注意 $2x + (4 - 2x) = 4$ 为定值。

$$x(4 - 2x) = \dfrac{1}{2} \cdot 2x \cdot (4 - 2x) \leq \dfrac{1}{2} \cdot \left(\dfrac{2x + 4 - 2x}{2}\right)^2 = \dfrac{1}{2} \cdot 4 = 2$$

当 $2x = 4 - 2x$，即 $x = 1$ 时取等号。

$$\boxed{\text{最大值为 } 2}$$

---

### 题 9

已知 $a > 0$，$b > 0$，$a + b = 1$，求 $\sqrt{a} + \sqrt{b}$ 的最大值。

**答案：**

设 $S = \sqrt{a} + \sqrt{b}$，则 $S^2 = a + b + 2\sqrt{ab} = 1 + 2\sqrt{ab}$。

由基本不等式：$ab \leq \left(\dfrac{a+b}{2}\right)^2 = \dfrac{1}{4}$，所以 $\sqrt{ab} \leq \dfrac{1}{2}$。

$$S^2 \leq 1 + 2 \cdot \dfrac{1}{2} = 2 \implies S \leq \sqrt{2}$$

当 $a = b = \dfrac{1}{2}$ 时取等号。

$$\boxed{\text{最大值为 } \sqrt{2}}$$

---

### 题 10

已知 $x > 0$，$y > 0$，$x + 2y = 2$，求 $xy$ 的最大值。

**答案：**

$x + 2y = 2$，由基本不等式：

$$2 = x + 2y \geq 2\sqrt{2xy}$$

$$1 \geq \sqrt{2xy} \implies 2xy \leq 1 \implies xy \leq \dfrac{1}{2}$$

当 $x = 2y$ 时取等，联立 $x + 2y = 2$ 得 $x = 1$，$y = \dfrac{1}{2}$。

$$\boxed{xy \text{ 的最大值为 } \dfrac{1}{2}}$$

### 题 11

已知 $a > 0$，$b > 0$，$\dfrac{1}{a} + \dfrac{4}{b} = 1$，求 $a + b$ 的最小值。

**答案：**

$$a + b = (a + b)\left(\dfrac{1}{a} + \dfrac{4}{b}\right) = 1 + \dfrac{4a}{b} + \dfrac{b}{a} + 4 = 5 + \dfrac{4a}{b} + \dfrac{b}{a}$$

由基本不等式：$\dfrac{4a}{b} + \dfrac{b}{a} \geq 2\sqrt{4} = 4$

$$a + b \geq 9$$

当 $\dfrac{4a}{b} = \dfrac{b}{a}$，即 $b = 2a$ 时取等。代入 $\dfrac{1}{a} + \dfrac{4}{2a} = 1$ 得 $\dfrac{3}{a} = 1$，$a = 3$，$b = 6$。

$$\boxed{a + b \text{ 的最小值为 } 9}$$

---

### 题 12

已知 $x > 0$，$y > 0$，$x + 3y = 5xy$，求 $3x + 4y$ 的最小值。

**答案：**

由 $x + 3y = 5xy$，两边同除以 $xy$：$\dfrac{1}{y} + \dfrac{3}{x} = 5$。

$$3x + 4y = \dfrac{(3x + 4y)\left(\dfrac{1}{y} + \dfrac{3}{x}\right)}{5} = \dfrac{3 \cdot \dfrac{x}{y} + \dfrac{9x}{x} + \dfrac{4y}{y} + \dfrac{12y}{x}}{5}$$

$$= \dfrac{\dfrac{3x}{y} + 9 + 4 + \dfrac{12y}{x}}{5} = \dfrac{13 + \dfrac{3x}{y} + \dfrac{12y}{x}}{5}$$

由基本不等式：$\dfrac{3x}{y} + \dfrac{12y}{x} \geq 2\sqrt{36} = 12$

$$3x + 4y \geq \dfrac{13 + 12}{5} = 5$$

当 $\dfrac{3x}{y} = \dfrac{12y}{x}$，即 $x = 2y$ 时取等。代入 $\dfrac{1}{y} + \dfrac{3}{2y} = 5$ 得 $\dfrac{5}{2y} = 5$，$y = \dfrac{1}{2}$，$x = 1$。

$$\boxed{3x + 4y \text{ 的最小值为 } 5}$$

### 题 13

已知 $a > 0$，$b > 0$，$a + b = 2$，求 $\dfrac{4}{a} + \dfrac{9}{b}$ 的最小值。

**答案：**

$$\dfrac{4}{a} + \dfrac{9}{b} = \left(\dfrac{4}{a} + \dfrac{9}{b}\right) \cdot \dfrac{a + b}{2} = \dfrac{1}{2}\left(4 + \dfrac{9a}{b} + \dfrac{4b}{a} + 9\right) = \dfrac{13}{2} + \dfrac{1}{2}\left(\dfrac{9a}{b} + \dfrac{4b}{a}\right)$$

由基本不等式：$\dfrac{9a}{b} + \dfrac{4b}{a} \geq 2\sqrt{36} = 12$

$$\dfrac{4}{a} + \dfrac{9}{b} \geq \dfrac{13}{2} + 6 = \dfrac{25}{2}$$

当 $\dfrac{9a}{b} = \dfrac{4b}{a}$，即 $3a = 2b$ 时取等。联立 $a + b = 2$ 得 $a = \dfrac{4}{5}$，$b = \dfrac{6}{5}$。

$$\boxed{\text{最小值为 } \dfrac{25}{2}}$$

---

### 题 14

已知 $x > 2$，求 $\dfrac{x^2 - 4x + 8}{x - 2}$ 的最小值。

**答案：**

$$\dfrac{x^2 - 4x + 8}{x - 2} = \dfrac{(x-2)^2 + 4}{x - 2} = (x - 2) + \dfrac{4}{x - 2}$$

令 $t = x - 2 > 0$：

$$t + \dfrac{4}{t} \geq 2\sqrt{4} = 4$$

当 $t = 2$，即 $x = 4$ 时取等号。

$$\boxed{\text{最小值为 } 4}$$

---

### 题 15

已知 $0 < x < 1$，求 $\dfrac{2}{x} + \dfrac{9}{1 - x}$ 的最小值。

**答案：**

$$\dfrac{2}{x} + \dfrac{9}{1-x} = \left(\dfrac{2}{x} + \dfrac{9}{1-x}\right)(x + 1 - x) = \dfrac{2}{x} \cdot x + \dfrac{2(1-x)}{x} + \dfrac{9x}{1-x} + \dfrac{9(1-x)}{1-x}$$

$$= 2 + \dfrac{2(1-x)}{x} + \dfrac{9x}{1-x} + 9 = 11 + \dfrac{2(1-x)}{x} + \dfrac{9x}{1-x}$$

由基本不等式：$\dfrac{2(1-x)}{x} + \dfrac{9x}{1-x} \geq 2\sqrt{18} = 6\sqrt{2}$

$$\dfrac{2}{x} + \dfrac{9}{1-x} \geq 11 + 6\sqrt{2}$$

当 $\dfrac{2(1-x)}{x} = \dfrac{9x}{1-x}$ 时取等，即 $2(1-x)^2 = 9x^2$，解得 $\sqrt{2}(1-x) = 3x$（取正），$x = \dfrac{\sqrt{2}}{3 + \sqrt{2}}$。

$$\boxed{\text{最小值为 } 11 + 6\sqrt{2}}$$

### 题 16

已知 $a > 0$，$b > 0$，$a + b = 1$，求 $(a + \dfrac{1}{a})(b + \dfrac{1}{b})$ 的最小值。

**答案：**

$(a + \dfrac{1}{a})(b + \dfrac{1}{b}) = ab + \dfrac{a}{b} + \dfrac{b}{a} + \dfrac{1}{ab}$

由 $a + b = 1$ 和基本不等式：$ab \leq \dfrac{1}{4}$，所以 $\dfrac{1}{ab} \geq 4$。

又 $\dfrac{a}{b} + \dfrac{b}{a} \geq 2$。

所以原式 $\geq ab + 2 + \dfrac{1}{ab}$。

设 $t = ab$，$0 < t \leq \dfrac{1}{4}$，$f(t) = t + \dfrac{1}{t} + 2$。

由于 $t + \dfrac{1}{t}$ 在 $(0, 1]$ 上递减，而 $0 < t \leq \dfrac{1}{4} < 1$，所以 $f(t)$ 在 $(0, \dfrac{1}{4}]$ 上递减，$f(t)$ 在 $t = \dfrac{1}{4}$ 处取最小值：

$$f\!\left(\dfrac{1}{4}\right) = \dfrac{1}{4} + 4 + 2 = \dfrac{25}{4}$$

当 $a = b = \dfrac{1}{2}$ 时取等号。

$$\boxed{\text{最小值为 } \dfrac{25}{4}}$$

### 题 17

已知 $x > 0$，$y > 0$，$2x + y = 2$，求 $\dfrac{1}{x} + \dfrac{4}{y}$ 的最小值。

**答案：**

$$\dfrac{1}{x} + \dfrac{4}{y} = \left(\dfrac{1}{x} + \dfrac{4}{y}\right) \cdot \dfrac{2x + y}{2} = \dfrac{1}{2}\left(2 + \dfrac{y}{x} + \dfrac{8x}{y} + 4\right) = 3 + \dfrac{1}{2}\left(\dfrac{y}{x} + \dfrac{8x}{y}\right)$$

由基本不等式：$\dfrac{y}{x} + \dfrac{8x}{y} \geq 2\sqrt{8} = 4\sqrt{2}$

$$\dfrac{1}{x} + \dfrac{4}{y} \geq 3 + 2\sqrt{2}$$

当 $\dfrac{y}{x} = \dfrac{8x}{y}$，即 $y^2 = 8x^2$，$y = 2\sqrt{2}\,x$ 时取等。代入 $2x + y = 2$ 得 $x = \dfrac{2}{2 + 2\sqrt{2}} = \dfrac{1}{1+\sqrt{2}}$。

$$\boxed{\text{最小值为 } 3 + 2\sqrt{2}}$$

### 题 18

已知 $a > 1$，求 $a + \dfrac{4}{a - 1}$ 的最小值。

**答案：**

$$a + \dfrac{4}{a - 1} = (a - 1) + \dfrac{4}{a - 1} + 1$$

令 $t = a - 1 > 0$：

$$t + \dfrac{4}{t} + 1 \geq 2\sqrt{4} + 1 = 5$$

当 $t = 2$，即 $a = 3$ 时取等号。

$$\boxed{\text{最小值为 } 5}$$

### 题 19

已知 $x > 0$，$y > 0$，$\dfrac{x}{3} + \dfrac{y}{4} = 1$，求 $xy$ 的最大值。

**答案：**

由基本不等式：

$$1 = \dfrac{x}{3} + \dfrac{y}{4} \geq 2\sqrt{\dfrac{xy}{12}}$$

$$\dfrac{1}{2} \geq \sqrt{\dfrac{xy}{12}} \implies \dfrac{xy}{12} \leq \dfrac{1}{4} \implies xy \leq 3$$

当 $\dfrac{x}{3} = \dfrac{y}{4}$ 时取等，即 $x = \dfrac{3}{2}$，$y = 2$。

$$\boxed{xy \text{ 的最大值为 } 3}$$

### 题 20

已知 $a > 0$，$b > 0$，$a + b = 4$，求 $\dfrac{1}{a+1} + \dfrac{4}{b+1}$ 的最小值。

**答案：**

$a + b = 4$ 意味着 $(a + 1) + (b + 1) = 6$。

令 $m = a + 1 > 1$，$n = b + 1 > 1$，$m + n = 6$。

$$\dfrac{1}{m} + \dfrac{4}{n} = \left(\dfrac{1}{m} + \dfrac{4}{n}\right) \cdot \dfrac{m + n}{6} = \dfrac{1}{6}\left(1 + \dfrac{4m}{n} + \dfrac{n}{m} + 4\right) = \dfrac{5}{6} + \dfrac{1}{6}\left(\dfrac{4m}{n} + \dfrac{n}{m}\right)$$

由基本不等式：$\dfrac{4m}{n} + \dfrac{n}{m} \geq 2\sqrt{4} = 4$

$$\dfrac{1}{m} + \dfrac{4}{n} \geq \dfrac{5}{6} + \dfrac{4}{6} = \dfrac{3}{2}$$

当 $\dfrac{4m}{n} = \dfrac{n}{m}$，即 $n = 2m$ 时取等。联立 $m + n = 6$ 得 $m = 2$，$n = 4$，即 $a = 1$，$b = 3$。

$$\boxed{\text{最小值为 } \dfrac{3}{2}}$$

### 题 21

已知 $x > 0$，求 $\dfrac{x^2 + 3}{x}$ 的最小值。

**答案：**

$$\dfrac{x^2 + 3}{x} = x + \dfrac{3}{x} \geq 2\sqrt{3}$$

当 $x = \sqrt{3}$ 时取等号。

$$\boxed{\text{最小值为 } 2\sqrt{3}}$$

### 题 22

已知 $a > b > 0$，求 $a + \dfrac{1}{b(a - b)}$ 的最小值。

**答案：**

由于 $a = b + (a - b)$，且 $b > 0$，$a - b > 0$。

由基本不等式：$a = b + (a - b) \geq 2\sqrt{b(a-b)}$，所以 $b(a - b) \leq \dfrac{a^2}{4}$。

但我们需要求最小值，用另一个方向：

$$a + \dfrac{1}{b(a-b)} = b + (a - b) + \dfrac{1}{b(a-b)}$$

令 $u = b > 0$，$v = a - b > 0$。

$$= u + v + \dfrac{1}{uv}$$

由三元均值不等式（AM-GM）：

$$u + v + \dfrac{1}{uv} \geq 3\sqrt[3]{u \cdot v \cdot \dfrac{1}{uv}} = 3\sqrt[3]{1} = 3$$

当 $u = v = \dfrac{1}{uv}$，即 $u = v$ 且 $u^2 \cdot u = 1$，$u^3 = 1$，$u = 1$ 时取等。

所以 $b = 1$，$a - b = 1$，$a = 2$。

$$\boxed{\text{最小值为 } 3}$$

### 题 23

已知 $a > 0$，$b > 0$，$c > 0$，$a + b + c = 1$，求 $\dfrac{1}{a} + \dfrac{4}{b} + \dfrac{9}{c}$ 的最小值。

**答案：**

由柯西不等式（或权方和不等式）：

$$\left(\dfrac{1}{a} + \dfrac{4}{b} + \dfrac{9}{c}\right)(a + b + c) \geq (1 + 2 + 3)^2 = 36$$

因此 $\dfrac{1}{a} + \dfrac{4}{b} + \dfrac{9}{c} \geq 36$。

等号成立条件：$\dfrac{1/a}{a} = \dfrac{4/b}{b} = \dfrac{9/c}{c}$，即 $\dfrac{1}{a^2} = \dfrac{4}{b^2} = \dfrac{9}{c^2}$，得 $a : b : c = 1 : 2 : 3$。

联立 $a + b + c = 1$ 得 $a = \dfrac{1}{6}$，$b = \dfrac{1}{3}$，$c = \dfrac{1}{2}$。

$$\boxed{\text{最小值为 } 36}$$

### 题 24

已知 $x > 0$，$y > 0$，$\dfrac{1}{x} + \dfrac{9}{y} = 2$，求 $x + y$ 的最小值。

**答案：**

$$x + y = \dfrac{(x + y)\left(\dfrac{1}{x} + \dfrac{9}{y}\right)}{2} = \dfrac{1}{2}\left(1 + \dfrac{9x}{y} + \dfrac{y}{x} + 9\right) = 5 + \dfrac{1}{2}\left(\dfrac{9x}{y} + \dfrac{y}{x}\right)$$

由基本不等式：$\dfrac{9x}{y} + \dfrac{y}{x} \geq 2\sqrt{9} = 6$

$$x + y \geq 5 + 3 = 8$$

当 $\dfrac{9x}{y} = \dfrac{y}{x}$，即 $y = 3x$ 时取等。代入 $\dfrac{1}{x} + \dfrac{9}{3x} = 2$ 得 $\dfrac{4}{x} = 2$，$x = 2$，$y = 6$。

$$\boxed{x + y \text{ 的最小值为 } 8}$$

### 题 25

已知 $x > 0$，$y > 0$，$x + y = 4$，求 $\dfrac{x^2}{x + 1} + \dfrac{y^2}{y + 1}$ 的最小值。

**答案：**

对每一项变形：$\dfrac{x^2}{x+1} = \dfrac{x^2 + x - x}{x+1} = x - \dfrac{x}{x+1} = x - 1 + \dfrac{1}{x+1}$

$$\dfrac{x^2}{x+1} + \dfrac{y^2}{y+1} = (x + y) - 2 + \dfrac{1}{x+1} + \dfrac{1}{y+1} = 2 + \dfrac{1}{x+1} + \dfrac{1}{y+1}$$

设 $m = x + 1 > 1$，$n = y + 1 > 1$，$m + n = 6$。

由调和 - 算术平均：$\dfrac{1}{m} + \dfrac{1}{n} \geq \dfrac{4}{m + n} = \dfrac{4}{6} = \dfrac{2}{3}$

$$\dfrac{x^2}{x+1} + \dfrac{y^2}{y+1} \geq 2 + \dfrac{2}{3} = \dfrac{8}{3}$$

当 $m = n = 3$，即 $x = y = 2$ 时取等号。

$$\boxed{\text{最小值为 } \dfrac{8}{3}}$$

### 题 26

已知 $x > 0$，$y > 0$，$2x + 3y = 12$，求 $\lg x + \lg y$ 的最大值。

**答案：**

$\lg x + \lg y = \lg(xy)$，因此需要求 $xy$ 的最大值。

$$12 = 2x + 3y \geq 2\sqrt{2x \cdot 3y} = 2\sqrt{6xy}$$

$$6 \geq \sqrt{6xy} \implies 36 \geq 6xy \implies xy \leq 6$$

当 $2x = 3y$ 时取等，即 $x = 3$，$y = 2$。

$$\lg x + \lg y = \lg 6$$

$$\boxed{\text{最大值为 } \lg 6}$$

### 题 27

已知 $a > 0$，$b > 0$，$a + 2b = 1$，求 $\sqrt{ab}$ 的最大值。

**答案：**

$$1 = a + 2b \geq 2\sqrt{2ab}$$

$$\sqrt{2ab} \leq \dfrac{1}{2} \implies 2ab \leq \dfrac{1}{4} \implies ab \leq \dfrac{1}{8}$$

$$\sqrt{ab} \leq \dfrac{1}{2\sqrt{2}} = \dfrac{\sqrt{2}}{4}$$

当 $a = 2b$ 时取等，联立 $a + 2b = 1$ 得 $4b = 1$，$b = \dfrac{1}{4}$，$a = \dfrac{1}{2}$。

$$\boxed{\sqrt{ab} \text{ 的最大值为 } \dfrac{\sqrt{2}}{4}}$$

### 题 28

已知 $x > 0$，$y > 0$，$x + y = 1$，求 $(1 + \dfrac{1}{x})(1 + \dfrac{1}{y})$ 的最小值。

**答案：**

$$(1 + \dfrac{1}{x})(1 + \dfrac{1}{y}) = \dfrac{(x+1)(y+1)}{xy} = \dfrac{xy + x + y + 1}{xy} = 1 + \dfrac{1}{y} + \dfrac{1}{x} + \dfrac{1}{xy}$$

$$= 1 + \dfrac{x + y}{xy} + \dfrac{1}{xy} = 1 + \dfrac{1}{xy} + \dfrac{1}{xy} = 1 + \dfrac{2}{xy}$$

等等，重新计算：$\dfrac{x + y}{xy} = \dfrac{1}{xy}$（因为 $x + y = 1$）。

$$(1 + \dfrac{1}{x})(1 + \dfrac{1}{y}) = 1 + \dfrac{1}{xy} + \dfrac{1}{xy} = 1 + \dfrac{2}{xy}$$

不对，展开重来：

$$\dfrac{(x+1)(y+1)}{xy} = \dfrac{xy + x + y + 1}{xy} = 1 + \dfrac{x}{xy} + \dfrac{y}{xy} + \dfrac{1}{xy} = 1 + \dfrac{1}{y} + \dfrac{1}{x} + \dfrac{1}{xy}$$

$$= 1 + \dfrac{x+y}{xy} + \dfrac{1}{xy} = 1 + \dfrac{1}{xy} + \dfrac{1}{xy} = 1 + \dfrac{2}{xy}$$

上面 $\dfrac{x+y}{xy} = \dfrac{1}{xy}$，这不对。$\dfrac{x+y}{xy} = \dfrac{1}{y} + \dfrac{1}{x}$。

直接算：$x + y = 1$，$xy \leq \dfrac{1}{4}$。

$$1 + \dfrac{1}{x} + \dfrac{1}{y} + \dfrac{1}{xy} = 1 + \dfrac{x+y}{xy} + \dfrac{1}{xy} = 1 + \dfrac{1+1}{xy} = 1 + \dfrac{2}{xy}$$

这次正确了：$\dfrac{x + y}{xy} = \dfrac{1}{xy}$，再加 $\dfrac{1}{xy}$ 就是 $\dfrac{2}{xy}$。

因为 $xy \leq \dfrac{1}{4}$，所以 $\dfrac{2}{xy} \geq 8$。

原式 $\geq 1 + 8 = 9$。

当 $x = y = \dfrac{1}{2}$ 时取等号。

$$\boxed{\text{最小值为 } 9}$$

### 题 29

已知 $a > 0$，$b > 0$，$a^2 + b^2 = 2$，求 $\dfrac{1}{a} + \dfrac{1}{b}$ 的最小值。

**答案：**

由 $a^2 + b^2 \geq \dfrac{(a+b)^2}{2}$，所以 $(a+b)^2 \leq 4$，$a + b \leq 2$。

$$\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{a + b}{ab}$$

由基本不等式：$ab \leq \dfrac{a^2 + b^2}{2} = 1$。

但我们需要下界。由柯西不等式：

$$\left(\dfrac{1}{a} + \dfrac{1}{b}\right)(a + b) \geq (1 + 1)^2 = 4$$

$$\dfrac{1}{a} + \dfrac{1}{b} \geq \dfrac{4}{a+b}$$

又 $a + b \leq 2$，所以 $\dfrac{4}{a + b} \geq 2$。

但要验证等号能否同时取到：柯西等号条件 $a = b$；$a + b = 2$ 在 $a^2 + b^2 = 2$ 下当 $a = b = 1$ 时成立。此时 $a^2 + b^2 = 2$ ✓，$a + b = 2$ ✓。

$$\dfrac{1}{a} + \dfrac{1}{b} = 1 + 1 = 2$$

$$\boxed{\text{最小值为 } 2}$$

### 题 30

已知 $a > 0$，$b > 0$，$c > 0$，$a + b + c = 6$，求 $\dfrac{9}{a} + \dfrac{1}{b} + \dfrac{25}{c}$ 的最小值。

**答案：**

由柯西不等式：

$$\left(\dfrac{9}{a} + \dfrac{1}{b} + \dfrac{25}{c}\right)(a + b + c) \geq \left(3 + 1 + 5\right)^2 = 81$$

$$\dfrac{9}{a} + \dfrac{1}{b} + \dfrac{25}{c} \geq \dfrac{81}{6} = \dfrac{27}{2}$$

等号成立条件：$\dfrac{9/a}{a} = \dfrac{1/b}{b} = \dfrac{25/c}{c}$，即 $\dfrac{3}{a} = \dfrac{1}{b} = \dfrac{5}{c}$。

设公共值为 $k$，则 $a = \dfrac{3}{k}$，$b = \dfrac{1}{k}$，$c = \dfrac{5}{k}$。

$a + b + c = \dfrac{9}{k} = 6$，所以 $k = \dfrac{3}{2}$。

$a = 2$，$b = \dfrac{2}{3}$，$c = \dfrac{10}{3}$。

$$\boxed{\text{最小值为 } \dfrac{27}{2}}$$
