# 初中数学《一元二次方程》教案（精简版）

## 一、总体设计

### 1. 适用对象

适用于九年级《一元二次方程》新授课，也可用于中考复习中“方程与应用”专题。学生学习前应会解一元一次方程，掌握整式乘法、乘法公式、因式分解、平方根和简单二次根式。

教学中要突出：方程的解是使等式成立的未知数的值；一元二次方程的特征是“一个未知数、整式方程、最高次数为 2”；各种解法的共同目标是把二次问题转化为一次问题或平方问题；实际问题中的代数根必须检验。

### 2. 教学目标

学生通过本专题学习，应能：

1. 判断一元二次方程，并化为一般形式

   $$ax^2+bx+c=0\quad(a\ne0)$$

2. 准确指出 $a,b,c$，特别注意符号。
3. 掌握直接开平方法、配方法、公式法、因式分解法。
4. 根据题目特征选择合适解法。
5. 用判别式 $\Delta=b^2-4ac$ 判断根的情况。
6. 初步应用根与系数关系：

   $$x_1+x_2=-\frac ba,\quad x_1x_2=\frac ca$$

7. 用一元二次方程解决面积、增长率、利润、几何图形等问题。

### 3. 课时安排

| 课时 | 主题 | 核心任务 |
|---|---|---|
| 第 1 课时 | 概念与直接开平方法 | 判断方程，解平方形式 |
| 第 2 课时 | 配方法 | 理解并使用“配成完全平方” |
| 第 3 课时 | 公式法与判别式 | 使用求根公式，判断根的情况 |
| 第 4 课时 | 因式分解法与解法选择 | 用零因式原理解方程 |
| 第 5 课时 | 判别式综合与含参数问题 | 把根的情况转化为参数条件 |
| 第 6 课时 | 根与系数关系 | 用根的和与积简化计算 |
| 第 7 课时 | 实际应用 | 建立方程模型并检验根 |
| 第 8 课时 | 单元复习 | 梳理方法，分层训练，纠错 |

### 4. 学情与对策

| 常见困难 | 教学对策 |
|---|---|
| 只看是否含 $x^2$，不先化简 | 坚持“先化简，再判断” |
| 化一般形式时右边不为 0 | 每题先写 $ax^2+bx+c=0$ |
| $a,b,c$ 漏符号 | 要求系数连同符号一起读 |
| 开平方漏负根 | 强调 $x^2=a$ 且 $a>0$ 时 $x=\pm\sqrt a$ |
| 公式法符号错误 | 每题先列 $a,b,c,\Delta$ |
| 因式分解后不令因式为 0 | 板书零因式原理 |
| 应用题不舍根 | 固定“五步法”：设、列、解、验、答 |

### 5. 核心知识框架

| 内容 | 要点 |
|---|---|
| 定义 | 一个未知数，整式方程，化简后最高次数为 2 |
| 一般形式 | $ax^2+bx+c=0\ (a\ne0)$ |
| 直接开平方法 | $x^2=a$，$(x+m)^2=n$ |
| 配方法 | $x^2+px+\left(\frac p2\right)^2=\left(x+\frac p2\right)^2$ |
| 公式法 | $x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$ |
| 判别式 | $\Delta>0$ 两个不等实根；$\Delta=0$ 两个相等实根；$\Delta<0$ 无实根 |
| 因式分解法 | $AB=0\Longleftrightarrow A=0$ 或 $B=0$ |
| 根与系数关系 | $x_1+x_2=-\dfrac ba$，$x_1x_2=\dfrac ca$ |
| 应用题 | 面积、增长率、利润、几何限制，必须检验根 |

## 第 1 课时：概念与直接开平方法

### 1. 课时目标

理解一元二次方程的定义；会化一般形式并指出 $a,b,c$；会解 $x^2=a$ 和 $(x+m)^2=n$；知道平方方程可能有两个解、一个解或没有实数解。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 导入 | 正方形面积 $36$，列 $x^2=36$ | 方程有 $x=\pm6$，实际边长只取 $6$ |
| 概念 | 比较 $x^2-3x+2=0$、$2x-5=0$、$x^2+\frac1x=3$、$(x+1)^2=x^2+4x$、$x(x+3)=40$ | 一个未知数、整式方程、化简后最高次数为 2 |
| 一般形式 | $(x-2)(x+5)=3$ | 化为 $x^2+3x-13=0$，$a=1,b=3,c=-13$ |
| 参数条件 | $(m-1)x^2+2x-5=0$ 是一元二次方程 | $m-1\ne0$，即 $m\ne1$ |
| 直接开方 | 解 $x^2=25$、$(x-3)^2=16$、$(2x-1)^2=5$ | 右边为正数时写 $\pm$ |

### 3. 例题板书

1. 解 $(x-3)^2=16$：

   $$x-3=\pm4,\quad x=7\text{ 或 }x=-1$$

2. 解 $(2x-1)^2=5$：

   $$2x-1=\pm\sqrt5,\quad x=\frac{1\pm\sqrt5}{2}$$

3. 若 $(k+2)x^2-3x+1=0$ 是一元二次方程，则

   $$k+2\ne0,\quad k\ne-2$$

### 4. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 判断 $3x^2-2x+1=0$、$x^2+2x=x^2-1$、$x+\frac2x=5$、$(x-1)(x+4)=0$ 是否为一元二次方程 |
| 当堂检测 | 化 $2x(x-3)=x+5$ 为一般形式：$2x^2-7x-5=0$ |
| 当堂检测 | 解 $(x+2)^2=25$，$3(x-1)^2=12$，$(x+4)^2=-1$ |
| 课后作业 | 判断并说明理由：$x^2-6x+8=0$、$(x+2)^2=x^2+1$、$2x^2+3=5x$、$x^2+y=1$ |
| 课后作业 | 解 $x^2=49$，$(x-5)^2=9$，$4(x+2)^2=28$ |

## 第 2 课时：配方法

### 1. 课时目标

理解配方法；会把 $x^2+px$ 配成完全平方；会用配方法解二次项系数为 1 的方程；会处理简单二次项系数不为 1 的方程。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 复习 | $x^2+6x+9=(x+3)^2$，$x^2-8x+16=(x-4)^2$ | 补的是一次项系数一半的平方 |
| 归纳 | $x^2+px+\left(\frac p2\right)^2=\left(x+\frac p2\right)^2$ | 说明“为什么加这个数” |
| 基本例题 | 解 $x^2+6x+5=0$ | 移项、两边同加、开方 |
| 变式例题 | 解 $2x^2+8x+3=0$ | 先让二次项系数化为 1 |
| 易错辨析 | 左边加数右边不加；开方漏 $\pm$ | 强调等式平衡 |

### 3. 例题板书

1. 解 $x^2+6x+5=0$：

   $$x^2+6x=-5$$

   $$x^2+6x+9=4$$

   $$(x+3)^2=4$$

   $$x=-1\text{ 或 }x=-5$$

2. 解 $x^2-4x-1=0$：

   $$x^2-4x=1,\quad (x-2)^2=5,\quad x=2\pm\sqrt5$$

3. 解 $2x^2+8x+3=0$：

   $$x^2+4x+\frac32=0$$

   $$(x+2)^2=\frac52$$

   $$x=-2\pm\frac{\sqrt{10}}2$$

### 4. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 用配方法解 $x^2+4x+1=0$，$x^2-8x+7=0$，$x^2+2x-3=0$，$2x^2-4x-1=0$ |
| 参考答案 | $x=-2\pm\sqrt3$；$x=1$ 或 $7$；$x=1$ 或 $-3$；$x=1\pm\frac{\sqrt6}{2}$ |
| 课后作业 | 解 $x^2+10x+9=0$，$x^2-6x+2=0$，$x^2+12x+20=0$，$3x^2+6x-2=0$ |
| 提高题 | 用配方法说明 $x^2-4x+7$ 的最小值；解 $x^2-2mx+m^2-9=0$ |

## 第 3 课时：公式法与判别式

### 1. 课时目标

知道求根公式由配方法推导；会用公式法解方程；会用判别式判断根的情况；能正确处理 $b$ 的符号和分母 $2a$。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 公式推导 | 从 $ax^2+bx+c=0$ 配方得到公式 | 强调 $a\ne0$ |
| 步骤规范 | 化一般形式、写 $a,b,c$、算 $\Delta$、代公式 | 避免直接套错 |
| 判别式 | $\Delta>0$、$\Delta=0$、$\Delta<0$ | 根号内决定根的情况 |
| 例题训练 | 解 $2x^2-5x+2=0$、$x^2+2x-6=0$、$4x^2-12x+9=0$ | 兼顾两个不等根、无理根、等根 |

### 3. 公式推导与板书

由

$$ax^2+bx+c=0\quad(a\ne0)$$

得

$$x^2+\frac bax=-\frac ca$$

两边同加 $\left(\frac b{2a}\right)^2$：

$$\left(x+\frac b{2a}\right)^2=\frac{b^2-4ac}{4a^2}$$

若 $\Delta=b^2-4ac\ge0$，则

$$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$$

判别式：

| $\Delta$ | 根的情况 |
|---|---|
| $\Delta>0$ | 两个不相等实数根 |
| $\Delta=0$ | 两个相等实数根 |
| $\Delta<0$ | 无实数根 |

### 4. 例题

1. 解 $2x^2-5x+2=0$：

   $$a=2,b=-5,c=2,\quad \Delta=9$$

   $$x=\frac{5\pm3}{4},\quad x=2\text{ 或 }\frac12$$

2. 解 $x^2+2x-6=0$：

   $$\Delta=28,\quad x=-1\pm\sqrt7$$

3. 解 $4x^2-12x+9=0$：

   $$\Delta=0,\quad x_1=x_2=\frac32$$

### 5. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 用公式法解 $x^2-3x-1=0$，$2x^2+4x-3=0$ |
| 当堂检测 | 判断 $x^2+6x+10=0$ 的根的情况；判断并求解 $9x^2-6x+1=0$ |
| 参考答案 | $\frac{3\pm\sqrt{13}}2$；$\frac{-2\pm\sqrt{10}}2$；无实数根；$x_1=x_2=\frac13$ |
| 课后作业 | 解 $x^2-5x+3=0$，$2x^2-3x-4=0$，$3x^2+6x+3=0$，$x^2+2x+5=0$ |
| 提高题 | $x^2-2x+k=0$ 有两个相等实数根，求 $k$ |

## 第 4 课时：因式分解法与解法选择

### 1. 课时目标

理解零因式原理；会用因式分解法解一元二次方程；知道右边必须先化为 0；能根据题目特征选择解法。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 导入 | $x^2-5x+6=0$ | 比公式法更快：分解为 $(x-2)(x-3)=0$ |
| 原理 | $AB=0\Longleftrightarrow A=0$ 或 $B=0$ | 分解后还要继续求一次方程 |
| 基本类型 | 平方差、十字相乘、提公因式 | 提公因式时不要漏根 |
| 右边非零 | $(x+1)(x-4)=2x+2$ | 先移项再分解 |
| 整体思想 | $(2x-1)^2=3(2x-1)$ | 把 $2x-1$ 看作整体 |

### 3. 例题板书

1. $x^2-9=0$：

   $$(x-3)(x+3)=0,\quad x=\pm3$$

2. $x^2-6x=0$：

   $$x(x-6)=0,\quad x=0\text{ 或 }6$$

3. $(x+1)(x-4)=2x+2$：

   $$(x+1)(x-4)-2(x+1)=0$$

   $$(x+1)(x-6)=0,\quad x=-1\text{ 或 }6$$

4. $(2x-1)^2=3(2x-1)$：

   $$(2x-1)(2x-4)=0,\quad x=\frac12\text{ 或 }2$$

### 4. 解法选择

| 方程特征 | 优先方法 |
|---|---|
| $(x-m)^2=n$ | 直接开平方法 |
| 左边容易分解且右边为 0 | 因式分解法 |
| 需要凑平方或推导公式 | 配方法 |
| 一般形式且分解困难 | 公式法 |
| 只问根的个数 | 判别式 |

### 5. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 解 $x^2-4x=0$，$x^2-16=0$，$x^2-3x-10=0$，$3x^2+2x-1=0$，$(x-2)^2=5(x-2)$ |
| 参考答案 | $0,4$；$\pm4$；$5,-2$；$\frac13,-1$；$2,7$ |
| 课后作业 | 解 $x^2+x=0$，$x^2-25=0$，$x^2-8x+15=0$，$2x^2+x-6=0$，$(x+3)^2=4(x+3)$ |
| 提高题 | 解 $(x-1)(x+2)=2(x+2)$，$(3x+1)^2=5(3x+1)$ |

## 第 5 课时：判别式综合与含参数问题

### 1. 课时目标

熟练用判别式判断根的情况；会把根的条件转化为参数条件；会处理简单已知根求参数问题；注意 $a\ne0$。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 复习 | 根的情况与 $\Delta$ 对应 | “有实数根”是 $\Delta\ge0$ |
| 参数范围 | $x^2+4x+m=0$ 有两个不等实根 | 转化为 $\Delta>0$ |
| 无实根 | $2x^2-3x+k=0$ 无实数根 | 转化为 $\Delta<0$ |
| 二次项含参数 | $(m-1)x^2+2x+1=0$ | 同时考虑 $m\ne1$ |
| 已知根 | $x=2$ 是 $x^2+mx-8=0$ 的根 | 代入求参数 |

### 3. 例题板书

1. $x^2-2x+k=0$ 有两个相等实数根：

   $$\Delta=4-4k=0,\quad k=1$$

2. $x^2+4x+m=0$ 有两个不相等实数根：

   $$16-4m>0,\quad m<4$$

3. $2x^2-3x+k=0$ 没有实数根：

   $$9-8k<0,\quad k>\frac98$$

4. $(m-1)x^2+2x+1=0$ 是一元二次方程且有实数根：

   $$m\ne1,\quad \Delta=4-4(m-1)\ge0$$

   $$m\le2\quad\text{且}\quad m\ne1$$

5. $x=2$ 是 $x^2+mx-8=0$ 的一个根：

   $$4+2m-8=0,\quad m=2$$

   方程为 $(x-2)(x+4)=0$，另一个根为 $-4$。

### 4. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | $x^2-6x+k=0$ 有两个相等实根，求 $k$ |
| 当堂检测 | $x^2+2x+m=0$ 无实根，求 $m$ |
| 当堂检测 | $2x^2+x+k=0$ 有实根，求 $k$ |
| 当堂检测 | $(m+2)x^2-4x+1=0$ 是一元二次方程且有两个不等实根，求 $m$ |
| 当堂检测 | $x=3$ 是 $x^2+px-12=0$ 的根，求 $p$ 和另一个根 |
| 参考答案 | $k=9$；$m>1$；$k\le\frac18$；$m<2$ 且 $m\ne-2$；$p=1$，另一个根 $-4$ |
| 课后作业 | 完成同类型参数题 5 道，要求每题写清 $a\ne0$ 与 $\Delta$ 条件 |

## 第 6 课时：根与系数关系

### 1. 课时目标

理解根与系数关系；会用根的和与积进行计算；会构造以给定两数为根的一元二次方程；会处理简单对称式。

### 2. 教学流程

| 环节 | 内容 | 关键点 |
|---|---|---|
| 观察 | $x^2-5x+6=0$ 的根为 $2,3$ | 和为 $5$，积为 $6$ |
| 推导 | $a(x-x_1)(x-x_2)$ 展开并比较系数 | 得出 $x_1+x_2=-\frac ba$，$x_1x_2=\frac ca$ |
| 基本应用 | 求两根和与积 | 注意符号 |
| 对称式 | $x_1^2+x_2^2$、$\frac1{x_1}+\frac1{x_2}$ | 转化为和与积 |
| 构造方程 | 已知两根 $x_1,x_2$ | $x^2-(x_1+x_2)x+x_1x_2=0$ |

### 3. 例题板书

1. $2x^2-7x+3=0$ 的两根为 $x_1,x_2$：

   $$x_1+x_2=\frac72,\quad x_1x_2=\frac32$$

2. $x_1,x_2$ 是 $x^2-3x-5=0$ 的两根，求 $x_1^2+x_2^2$：

   $$x_1+x_2=3,\quad x_1x_2=-5$$

   $$x_1^2+x_2^2=(x_1+x_2)^2-2x_1x_2=19$$

3. $x_1,x_2$ 是 $2x^2+3x-1=0$ 的两根，求 $\frac1{x_1}+\frac1{x_2}$：

   $$\frac1{x_1}+\frac1{x_2}=\frac{x_1+x_2}{x_1x_2}=\frac{-\frac32}{-\frac12}=3$$

4. 以 $2$ 和 $-5$ 为根，二次项系数为 1 的方程：

   $$x^2+3x-10=0$$

### 4. 检测与作业

| 类型 | 题目 |
|---|---|
| 当堂检测 | 求 $x^2-8x+12=0$ 两根的和与积 |
| 当堂检测 | 求 $3x^2+2x-5=0$ 两根的和与积 |
| 当堂检测 | $x_1,x_2$ 是 $x^2-4x-1=0$ 的两根，求 $x_1^2+x_2^2$ |
| 当堂检测 | $x_1,x_2$ 是 $2x^2-5x+1=0$ 的两根，求 $\frac1{x_1}+\frac1{x_2}$ |
| 当堂检测 | 写出以 $3$ 和 $-2$ 为根，二次项系数为 1 的方程 |
| 参考答案 | $8,12$；$-\frac23,-\frac53$；$18$；$5$；$x^2-x-6=0$ |
| 课后作业 | 完成和积、对称式、构造方程各 2 题 |

## 第 7 课时：一元二次方程的实际应用

### 1. 课时目标

会找等量关系；会设未知数并列方程；会根据实际意义检验和舍根；掌握面积、增长率、利润和几何模型。

### 2. 建模方法

应用题五步法：

$$\text{设}\rightarrow\text{列}\rightarrow\text{解}\rightarrow\text{验}\rightarrow\text{答}$$

常见模型：

| 类型 | 模型 |
|---|---|
| 面积 | 长 $\times$ 宽 = 面积 |
| 增长率 | 原量 $\times(1+x)^2=$ 后来量 |
| 下降率 | 原量 $\times(1-x)^2=$ 后来量 |
| 利润 | 单件利润 $\times$ 销售量 = 总利润 |
| 几何限制 | 长度为正，宽度不超过图形限制 |

### 3. 例题板书

1. 长方形长比宽多 $3\text{ m}$，面积 $40\text{ m}^2$。设宽为 $x$：

   $$x(x+3)=40,\quad x^2+3x-40=0$$

   $$(x+8)(x-5)=0$$

   舍去 $x=-8$，宽 $5\text{ m}$，长 $8\text{ m}$。

2. 藏书量两年从 $10000$ 册增至 $14400$ 册。设年增长率为 $x$：

   $$10000(1+x)^2=14400$$

   $$(1+x)^2=1.44$$

   $$x=0.2\text{ 或 }-2.2$$

   舍去 $-2.2$，年增长率为 $20\%$。

3. 商品进价 $30$ 元，售价 $50$ 元时每天售 $100$ 件；每降价 $1$ 元多售 $5$ 件；目标利润 $2400$ 元。设降价 $x$ 元：

   $$(20-x)(100+5x)=2400$$

   $$x^2-20x+80=0,\quad x=10\pm2\sqrt5$$

   售价为 $40\mp2\sqrt5$，约 $44.47$ 元或 $35.53$ 元。

4. 长 $20\text{ m}$、宽 $12\text{ m}$ 的矩形四周修等宽小路，中间绿地 $128\text{ m}^2$。设路宽 $x$：

   $$(20-2x)(12-2x)=128$$

   $$x^2-16x+28=0,\quad x=2\text{ 或 }14$$

   因 $x<6$，路宽为 $2\text{ m}$。

| 类型 | 题目 |

## 第 8 课时：单元复习与分层训练

### 1. 课时目标

系统梳理知识结构；快速选择解法；准确使用判别式和根与系数关系；识别常见错误；完成分层训练。

### 2. 复习提纲

| 模块 | 复习问题 |
|---|---|
| 概念 | 是否只有一个未知数？是否整式？化简后最高次数是否为 2？ |
| 一般形式 | 是否写成 $ax^2+bx+c=0$？$a\ne0$ 吗？ |
| 解法 | 平方形式、可分解形式、一般形式分别用什么方法？ |
| 判别式 | $\Delta$ 的符号与根的情况如何对应？ |
| 根与系数 | 和、积、对称式如何转化？ |
| 应用题 | 有没有检验根的实际意义？ |

### 3. 典型易错题

1. 判断 $(x+1)^2=x^2+3$：

   $$x^2+2x+1=x^2+3\Rightarrow 2x-2=0$$

   化简后是一次方程，不是一元二次方程。

2. 解 $(x-1)^2=16$：

   $$x-1=\pm4,\quad x=5\text{ 或 }-3$$

   错误点：只写 $x=5$。

3. 解 $x(x-3)=10$：

   $$x^2-3x-10=0$$

   $$(x-5)(x+2)=0$$

   $$x=5\text{ 或 }-2$$

   错误点：右边不是 0 就直接令因式等于 10。

4. 应用题中若解得长度 $x=4$ 或 $x=-7$，要舍去负数根。

### 4. 分层训练

| 层次 | 题目 | 参考答案 |
|---|---|---|
| A | 判断 $x^2+3x=2$ 并化一般形式 | 是，$x^2+3x-2=0$ |
| A | 解 $x^2-36=0$ | $x=\pm6$ |
| A | 解 $(x+5)^2=12$ | $x=-5\pm2\sqrt3$ |
| A | 解 $x^2-7x+10=0$ | $x=2$ 或 $5$ |
| A | 判断 $x^2+4x+5=0$ 的根 | $\Delta=-4<0$，无实数根 |
| B | $x^2-2x+k=0$ 有两个不等实根，求 $k$ | $k<1$ |
| B | $x_1,x_2$ 是 $x^2-5x+1=0$ 的两根，求 $x_1^2+x_2^2$ | $23$ |
| B | $x=2$ 是 $x^2+mx-6=0$ 的根，求 $m$ 和另一个根 | $m=1$，另根 $-3$ |
| B | 解 $(2x-1)^2=4(2x-1)$ | $x=\frac12$ 或 $\frac52$ |
| B | $(m-2)x^2+4x+1=0$ 是一元二次方程且有实根，求 $m$ | $m\le6$ 且 $m\ne2$ |
| C | 长方形周长 $34$，面积 $60$，求长宽 | $12$ 和 $5$ |
| C | 原价 $100$ 元，连续两次降价后 $81$ 元，求降价率 | $10\%$ |
| C | 果园长 $30$、宽 $20$，长宽同增后面积 $936$，求增加长度 | $6\text{ m}$ |

### 5. 单元小结

本章的主线是“转化”：直接开平方法把方程转化为平方根问题；因式分解法把二次方程转化为两个一次方程；配方法把一般方程转化为平方形式；公式法是配方法的一般化。应用题则要把实际数量关系转化为方程，并把代数根再放回实际情境中检验。

## 附：教学建议

1. 基础薄弱学生重点抓三件事：化一般形式、公式法稳定求根、应用题检验根。
2. 中等学生重点训练解法选择：平方形式开方，可分解先分解，一般式用公式，根的个数看判别式。
3. 学有余力学生可补充含参数分类讨论、根与系数综合题、与二次函数交点问题的联系。
4. 第 1、2 课时放慢，重在概念和配方理解；第 3、4 课时重规范和方法选择；第 5、6 课时可分层；第 7 课时要求完整写“设、列、解、验、答”；第 8 课时以错题纠偏和综合训练为主。
