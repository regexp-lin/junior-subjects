# 深圳中考道德与法治考点大全（开卷速查版）

> 更新：2026-10-30。适用对象：准备深圳中考道德与法治的初中生。**这是一份依据国家课程标准整理的复习索引，不是深圳市教育局发布的逐条考试大纲，也不表示各点必考或出现频率。**具体考试要求以当年深圳市教育局和市招考办通知为准。

## 一、先认清考试边界

- **2026 年起**，深圳中考道德与法治单独进行**开卷笔试**，满分 **50 分**、时长 **50 分钟**；与历史分场考试。考试依据《义务教育课程方案和课程标准（2022 年版）》的初中学段要求命题，强调在真实情境中分析和解决问题，减少单纯记忆和机械训练题。[深圳市 2024 年中考改革实施意见](https://www.sz.gov.cn/zfgb/2024/gb1327/content/post_11235007.html)、[2026 年招生考试通知](https://szeb.sz.gov.cn/szzkw/zcwj/content/post_12687204.html)。
- 开卷允许携带**教科书等纸质材料**；不得携带手机等通讯工具或电子存储、记忆、录放设备。“只准带课本，不准带其他纸质资料”的网传说法已由教育局澄清。实际入场仍应遵守当年考点的考务要求。[深圳市教育局关于材料携带的说明](https://szeb.sz.gov.cn/szzkw/qt/tzgg/content/post_12470658.html)。
- 2025 年及以前的历史与道法合卷、道法闭卷结构，不应直接套到 2026 年以后。新旧统编教材也在分年级过渡；查页码时以**自己实际使用的教材版本**为准。[教育部关于新修订教材使用安排的说明](https://www.moe.gov.cn/jyb_xwfb/s5147/202408/t20240828_1147579.html)。

## 二、用什么框架找考点

国家 2022 年版道法课程标准将 7—9 年级内容组织为**生命安全与健康教育、法治教育、中华优秀传统文化教育、革命传统教育、国情教育**五个主题；对应培养**政治认同、道德修养、法治观念、健全人格、责任意识**五项核心素养。[教育部《义务教育道德与法治课程标准（2022 年版）》](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582343475848.pdf)。下列“考点”是将课标要求转写成便于开卷检索的知识与应用清单，不等同于官方逐题范围。

**每一项都要会三个动作：**说清概念或道理；指出材料中哪一句或哪种行为体现它；针对设问作出判断、解释或可执行建议。只找到书上的句子，尚未完成材料题。

## 三、五大主题考点清单

### A. 生命安全与健康教育：认识自己、珍爱生命、学会相处

| 编号 | 需要掌握和会用的内容 | 常见材料信号 |
|---|---|---|
| A01 | 青春期身心变化：悦纳变化，尊重差异，正确处理青春期烦恼和两性交往，识别性骚扰、性侵害并寻求保护。 | 容貌焦虑、身体变化、边界被侵犯 |
| A02 | 认识自己：自我评价与他人评价相结合，看到优点和不足；接纳自己、发展潜能，不把一次评价当成全部。 | 老师评语、同伴评价、兴趣选择 |
| A03 | 情绪与心理调适：识别情绪，合理表达和调节，遇到持续困扰主动求助；尊重他人情绪。 | 考前焦虑、争吵、网络情绪宣泄 |
| A04 | 学习与成长：认识学习的意义，掌握适合自己的学习方法，正确面对压力、竞争、失败与挫折，培养自强品质。 | 成绩波动、升学压力、职业理想 |
| A05 | 敬畏生命：生命独特而宝贵，既珍爱自己的生命也尊重他人生命；自救互救应以科学、安全为前提。 | 救援、意外、校园欺凌、冒险行为 |
| A06 | 健康生活与安全：合理作息、体育锻炼、拒绝毒品和不良诱惑，增强防溺水、防火、防诈骗、防侵害意识。 | 禁毒、陌生链接、危险活动 |
| A07 | 家庭与师长：理解亲子差异、孝亲敬长、平等沟通；正确对待教师的表扬和批评，依法维护自身正当权益。 | 家长代做决定、亲子争执、师生误解 |
| A08 | 友谊与集体：真诚友善、尊重与边界、正确处理竞争和冲突；在集体中承担责任、合作共进。 | 朋友圈、班级分工、同伴压力 |
| A09 | 社会交往：诚实守信、尊重他人、文明有礼、关爱弱势群体；在公共生活中守规则、维护秩序。 | 志愿服务、公共场所失序、失信 |
| A10 | 网络生活：辨别信息真伪，保护个人隐私，抵制网络暴力和沉迷，合理利用互联网参与学习和公共生活。 | AI 内容、谣言、个人信息泄露 |

**常见设问：**“如何评价某人的行为？”先判断行为及其影响，再用生命观、人格成长、交往道德或规则意识解释，最后给出具体做法。不要把材料未交代的成绩、动机和违法事实写成既成事实。

| B15 | 规则与自由：自由受法律和规则约束；正确使用网络表达权，保护隐私和个人信息，拒绝造谣传谣。 | 社交平台发言、拍摄传播他人信息 |
| B16 | 公平正义与司法：理解公平正义的价值，用法治方式维护；不把舆论判断等同于法院裁判。 | 同案同判、程序公正、社会救助 |
| B17 | 生态与国家安全法治：依法保护环境，理解总体国家安全观；识别危害国家安全行为并通过合法渠道报告。 | 污染治理、军事设施拍摄、数据安全 |

**易错分辨：**“政府征求意见”不能自动写成“人大立法”；“基层立法联系点”不等同于“基层群众自治组织”；“守法公民”不代表可以自行执法；“有损失”不自动构成犯罪。材料题要先辨认主体、权力或权利、行为与法律后果。

## 四、容易混淆的概念速查

| 概念组 | 作答时要分清 |
|---|---|
| 党的初心使命 / 根本宗旨 | 初心使命是为中国人民谋幸福、为中华民族谋复兴；根本宗旨是全心全意为人民服务。 |
| 人民 / 公民 | 人民是国家权力的主人；公民是具有中国国籍的人。宪法规定“国家一切权力属于人民”，公民依法享有权利并履行义务。 |
| 根本政治制度 / 基本政治制度 | 人民代表大会制度是**根本政治制度**；多党合作和政治协商、民族区域自治、基层群众自治属于**基本政治制度**。 |
| 人大 / 政府 / 法院 / 检察院 / 监察委员会 | 人大是国家权力机关；政府是行政机关；法院是审判机关；检察院是法律监督机关；监察委员会是监察机关。按材料中的**主体和行为**选用。 |
| 权利 / 权力 | 公民依法享有权利；国家机关依法行使公权力。不能把公民参加民主协商写成“行使立法权”。 |
| 违法 / 犯罪 | 违法行为不一定构成犯罪；犯罪是严重违法行为，应受刑罚处罚。是否构成犯罪不能仅凭“影响不好”判断。 |
| 宪法 / 普通法律 | 宪法是国家根本法，具有最高法律效力；普通法律依据宪法制定，不能与宪法相抵触。 |
| 民族区域自治 / “一国两制” | 前者是我国基本政治制度，联系民族自治地方；后者联系港澳和国家统一，不能互相替代。 |
| 新发展理念 / 基本经济制度 | 创新、协调、绿色、开放、共享是发展理念；所有制、分配制度、社会主义市场经济体制是基本经济制度的三个方面。 |
| 高质量发展 / 经济高速增长 | 高质量发展强调质量、效益、结构、创新与可持续，不能只用增长速度判断。 |
| 第一个百年目标 / 第二个百年目标 | 全面建成小康社会已经实现；到 2035 年基本实现社会主义现代化，到本世纪中叶建成社会主义现代化强国，是后续战略安排。 |
| “我国已取得成就” / “未来发展目标” | 分析材料时看清文件发布时间和动词。“提出要建设”是目标，不能写成“已经建成”。 |
| 文化传承 / 文化创新 | 传承重在保存、理解、弘扬有价值的文化内涵；创新重在结合时代条件更新内容或表达形式，两者可以共同出现。 |
| 民族精神 / 时代精神 | 爱国主义是民族精神的核心；改革创新是时代精神的核心。人物事迹中可同时体现多种精神，不必机械二选一。 |

这些是**快速辨错提示**。涉及精确法律概念或教材专有表述时，仍应回到所用教材和题干核对。

## 六、开卷资料怎么整理

1. **用自己的教材作主索引。**给每册书建立“主题—关键词—页码”三列表。页码必须来自自己使用的版本，不能照抄其他学校或其他版次的目录。
2. **把相似概念放在同一页。**例如“人民/公民”“权利/义务”“人大/政府”“民族区域自治/一国两制”“新发展理念/基本经济制度”，减少翻找和误用。
3. **为每个大主题留一张材料题定位表。**只写关键词、核心观点和教材页码，不堆整段答案。练习时先独立审题，再翻书核对。
4. **定期用真题或适应性题检索。**若 30 秒内找不到相关页，就补上同义词或交叉索引；若找到知识却不会结合材料，则要练“材料事实＋知识解释＋题目结论”。

本仓库已有一份[九上教材开卷知识点总索引](../../九上教材/章节拆分/开卷考试知识点总索引.md)，可作知识整理样例；其中课次和页码只对应它所依据的那一本扫描教材，**不能直接认定为本届深圳中考统一教材页码或官方考点频率**。
