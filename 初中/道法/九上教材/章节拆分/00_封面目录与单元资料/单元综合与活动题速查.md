## 第一单元：坚持党的全面领导

原文：[第一单元导语与单元思考与行动](第一单元_坚持党的全面领导_导语与单元思考与行动.pdf)。

### 单元主线（教材第1页）

党的领导是历史和人民的选择 → 党领导人民奋斗取得伟大成就、形成精神谱系 → 党始终坚持人民至上、全心全意为人民服务 → 坚持和加强党的全面领导关系党和国家前途命运。

**导语对青少年的要求：**了解党领导人民团结奋斗的历史及伟大成绩，明确党的领导合乎时代潮流、顺应人民意愿；坚决拥护党的领导，坚持走中国特色社会主义道路，积极弘扬伟大建党精神，为实现中华民族伟大复兴而奋斗。

- 回答“成就怎样取得”：查第1课的奋斗历程、第3课的领导核心。
- 回答“党为什么得到人民拥护”：查第2课的初心使命、人民立场。
- 回答“精神怎样传承”：查第1课伟大建党精神、精神谱系，结合具体事迹。

### 延安时期的探索（教材第27页）

教材材料的三个层次：

**材料背景：**1935—1948年，党中央和毛泽东等老一辈革命家在延安生活、战斗了13年，领导中国革命事业从低潮走向高潮、实现历史性转折。2022年10月，习近平带领中共中央政治局常委瞻仰延安革命纪念地，强调弘扬伟大建党精神、延安精神，坚定历史自信、增强历史主动、发扬斗争精神，为实现党的二十大提出的目标任务团结奋斗。

1. 在土地革命战争最后时期，开始确立毛泽东同志在中央和全党的领导，这是党在这一时期的最大成就，是中国人民获得解放的最大保证。
2. 1945年党的七大第一次把毛泽东思想写进党章，在全党确立毛泽东思想的指导地位，极大加速了中国革命胜利的进程。
3. 在延安时期形成和发扬光荣传统、优良作风，培育形成延安精神。

**延安精神的主要内容**：坚定正确的政治方向；解放思想、实事求是的思想路线；全心全意为人民服务的根本宗旨；自力更生、艰苦奋斗的创业精神。

**问“在坚持和加强党的领导方面进行了哪些探索”时的组织方式**：分别从领导核心、思想指导、精神和作风三个方面提炼，不能只写“坚持党的领导”一句话。

**问“这些探索有什么作用”时的组织方式**：联系各项探索说明有利于维护党的团结统一、形成坚强领导力量；以科学理论指导革命实践；坚定理想信念、坚持人民立场、凝聚奋斗力量，从而推动革命事业发展。每一点都要落回材料中对应的探索。

### 参观或主题小论文（教材第28页）

- 参观前：明确“弘扬延安精神，坚持党的领导”的主题，列任务单，确定要了解的人物、事件、精神内涵和史料来源。
- 参观中：遵守规则，做好笔记，记录展品名称、事件背景和能说明的道理。
- 参观后：整理史料，把事实与第1—3课知识对应；交流收获，提出具体行动。
- 小论文结构示例：提出观点“坚持党的领导、传承优良作风” → 用延安时期具体史实论证 → 联系新时代和青少年实际，写学习党史、服务他人、艰苦奋斗等行动。

## 第二单元：进入新时代

原文：[第二单元导语与单元思考与行动](第二单元_进入新时代_导语与单元思考与行动.pdf)。

### 单元主线（教材第29页）

党的十八大以来进入新时代 → 习近平新时代中国特色社会主义思想在新时代实践中创立并不断发展 → 在这一思想指引下取得辉煌成就。

**导语对青少年的要求：**坚持不懈用习近平新时代中国特色社会主义思想武装头脑，感受其强大真理力量和实践伟力，了解新时代伟大成就，自觉做这一思想的**坚定信仰者、积极传播者、忠实实践者**。

复习对应：第4课解释新的历史方位；第5课解释思想旗帜；第6课展示经济、民主政治、文化、民生、生态文明建设成就。

### “感悟新时代，解码新成就”展览（教材第65页）

| 教材镜头 | 可以说明什么 | 首查课次 |
|---|---|---|
| 空间站长期有人驻留，远程医疗、智慧物流，“无人工厂”、工业互联网 | 科技创新、新产业新业态、制造业发展、经济实力提升 | 第6课；进一步联系第8课创新发展 |
| 高铁网、高速公路网、世界级港口群，航空航海通达全球 | 基础设施建设成就，经济发展和人民生活条件改善 | 第6课 |
| 平安中国建设，居家安心、出行放心、生活舒心 | 民生福祉、安全感提升；如材料涉及法治建设，再联系民主政治相关内容 | 第6课 |
| 自行补充的家乡变化 | 先说清具体变化，再判断属于经济、政治、文化、社会、生态哪一方面 | 第6课相应框题 |

**图表原文中的比较性结论：**镜头二强调我国已建成全球最大的高速铁路网、高速公路网、世界级港口群；镜头三强调我国成为世界上最有安全感的国家之一。答题保留“最……之一”等限定词，不把材料中的具体比较范围任意扩大。

**问“新时代取得成就的原因”**：结合材料选用坚持党的全面领导、科学思想指导、坚持以人民为中心、人民团结奋斗等要点，分别回查第3、5、2、10课；材料明确呈现改革开放或新发展理念时，再联系第1、8课。不要把“成就表现”原样写成“原因”。

### 家乡变化研学、调研报告（教材第66页）

教材要求：搜集资料 → 分组制订方案，明确目的、对象、内容、方式、分工 → 走访调研 → 记录、整理、留存资料 → 讨论交流，完成报告。调研中既关注成绩，也梳理存在的问题并思考建议。

**可直接使用的报告骨架（应用整理）**：

1. 标题：关于家乡某方面变化的调研报告。
2. 调研目的与对象：明确研究的是交通、医疗、文化服务、环境等具体问题，说明访问了哪些人或单位。
3. 调研方法：实地观察、访谈、问卷、查阅政府公开资料等，依题目条件选择。
4. 主要发现：按“具体事实或数据—所反映的变化—对应教材知识”组织。
5. 存在问题及建议：问题与建议一一对应，写明实施主体和措施。
6. 收获与行动：表达真实收获和自己能落实的行动。

只提供调查计划时使用“拟调查”；没有实际开展的活动，不写成已经得到的数据或结论。

## 第三单元：奋进新征程

原文：[第三单元导语与单元思考与行动](第三单元_奋进新征程_导语与单元思考与行动.pdf)。

### 单元主线（教材第67页）

全面建成小康社会、实现第一个百年奋斗目标 → 迈上全面建设社会主义现代化国家新征程 → 按“两步走”战略安排推进中国式现代化 → 贯彻新发展理念、构建新发展格局，推动高质量发展。

**导语规范表述：**高质量发展关系全局，要推动经济实现**质的有效提升和量的合理增长**。青少年要以“咬定青山不放松”的韧劲，与新时代同向同行、共同前进。

青年角度：我们处在学习和成长的黄金时期，到本世纪中叶将在各行各业担当重任，要把成长与国家发展相联系。

### 各领域强国目标怎样与总目标相联系（教材第83—84页）

教材指出：教育强国、科技强国、人才强国、数字中国等，既是社会主义现代化强国的组成部分，也是现代化强国在各领域的体现。

| 教材列举的文件 | 文件当时提出的目标 | 查阅时的用途 |
|---|---|---|
| 2016年《国家创新驱动发展战略纲要》 | 到2030年跻身创新型国家前列，发展驱动力实现根本转换，经济社会发展水平和国际竞争力大幅提升，为建成经济强国和共同富裕社会奠定坚实基础；到2050年建成世界科技创新强国，成为世界主要科学中心和创新高地 | 说明创新对经济发展和国际竞争力的作用 |
| 2019年《中国教育现代化2035》 | 到2035年总体实现教育现代化，迈入教育强国行列，推动我国成为学习大国、人力资源强国和人才强国，为到本世纪中叶建成富强民主文明和谐美丽的社会主义现代化强国奠定坚实基础 | 说明教育、科技、人才与现代化建设的联系 |
| 2023年《数字中国建设整体布局规划》 | 到2035年数字化发展水平进入世界前列，数字中国建设取得重大成就；体系化布局更加科学完备，经济、政治、文化、社会、生态文明建设各领域数字化发展更加协调充分，有力支撑全面建设社会主义现代化国家 | 说明数字技术赋能各领域发展、支撑现代化建设 |

以上是**教材引用文件中的目标**，不是对这些目标已经实现的判断。题目提供更新材料时，应看清材料中的文件名称和时间。

**第84页自主查阅领域清单：**文化强国、航天强国、农业强国、体育强国、健康中国、制造强国、交通强国、网络强国。教材要求选择一个感兴趣的领域，了解其发展目标和战略安排。

**问“各领域发展有什么意义”**：先指明该领域解决的实际问题，再联系创新能力、发展质量、人民生活、综合国力、现代化目标等适用角度。例：数字化改造生产线 → 提高生产效率和创新能力 → 推动高质量发展 → 为中国式现代化提供支撑。

### “我看到的高质量发展”调查（教材第84页）

- 在当地政府网站查找相关工作和成果，记录标题、发布时间、数据口径、涉及主体。
- 选择一个可观察主题，如科技创新、区域协调、绿色转型、开放合作、公共服务。
- 用第8课“五大发展理念”解释措施，用第7课现代化目标说明方向。
- 建议采用“措施—对应理念—产生的变化—可改进之处”的表达。
- 题目让选一个领域时，围绕该领域写深入，不必把所有“强国”名称罗列一遍。

## 第四单元：共圆中国梦

原文：[第四单元导语与单元思考与行动](第四单元_共圆中国梦_导语与单元思考与行动.pdf)。

### 单元主线（教材第85页）

铸牢中华民族共同体意识 → 维护民族团结、促进共同发展；实现祖国完全统一 → 凝聚全体中华儿女力量；共同指向实现中华民族伟大复兴的中国梦。

**导语的完整关系：**铸牢中华民族共同体意识，是维护各民族根本利益、实现中华民族伟大复兴、巩固和发展**平等团结互助和谐**社会主义民族关系的必然要求。实现祖国完全统一是全体中华儿女的共同愿望，是民族复兴的题中之义。

中国梦是国家的梦、民族的梦，也是每个中国人的梦；实现中国梦是中华民族团结奋斗的最大公约数。第9课着重回答“凝聚谁、怎样团结”；第10课着重回答“共同追求什么、怎样奋斗”。

**导语对青少年的要求：**实现中国梦需要广泛汇聚团结奋斗的正能量，需要全体中华儿女共同奋斗；我们要共担民族复兴大任，让青春在实现中国梦的历史进程中绽放异彩。

### 两项青年工程为什么重要（教材第106页）

教材以2017年党中央、国务院印发的《中长期青年发展规划（2016—2025年）》中的两项工程为材料。这是我国第一个中长期青年发展规划：

| 工程 | 材料中的主要做法 | 可用知识与意义 |
|---|---|---|
| 青年民族团结进步促进工程 | 实施青年民族团结交流万人计划，每年组织边疆民族地区与内地各族青年互访、联谊，鼓励不同民族青年结对子、互帮互助 | 增进了解、信任和感情；促进交往交流交融；铸牢中华民族共同体意识；维护民族团结 |
| 港澳台青少年交流工程 | 扩大内地与港澳青少年之间的交流规模、提升质量；举办海峡青年论坛、两岸青年社团负责人圆桌会议、两岸青年联欢节等 | 增进对祖国和中华文化的认同；密切同胞感情；凝聚维护国家统一、实现民族复兴的力量 |

**问“为什么把它们列为重点项目”**：国家角度联系民族团结、国家统一、民族复兴；青年角度联系树立正确民族观和国家观、了解国情、增强责任、共同成长。按材料对象分别说明，避免把民族地区交流与港澳台交流混写成同一种制度安排。

### 交流活动策划（教材第107页）

教材给出的基本栏目：**活动主题、参加人员、活动内容**。

**示例（应用整理）**：

- 活动主题：同心同行，共绘青春梦想。
- 参加人员：本校学生代表、来访港澳台青少年、指导教师。
- 活动内容：结对交流与校园参观；共同了解当地历史文化；合作开展一项科技或志愿服务活动；分享家乡发展与个人理想；制作交流成果展。
- 组织补充：明确时间地点、分工和联络方式；尊重彼此生活习惯，保障活动有序开展。
- 效果表达：增进了解与友谊，增强文化认同和国家认同，形成共同奋斗的责任意识。

如果题目是“向不同民族朋友介绍自己和家乡”，可从个人兴趣、家乡历史文化、发展变化、特色生活等方面介绍；使用平等、尊重的表达，不能用刻板印象代替了解。

## 综合题使用提醒

1. 先看设问：说明、原因、意义、措施、评析、活动设计分别要求不同内容。
2. 再圈材料：主体是谁，做了什么，解决什么问题，带来什么变化。
3. 用本册总索引找到章节，再用该章的材料提示选要点。
4. 一点一层：“材料事实＋教材道理＋本题结论”；做法题写“主体＋具体行动＋目的”。
5. 没有对应材料的知识不强行加入；题目要求“运用本单元知识”时，不越过范围堆砌其他课内容。
