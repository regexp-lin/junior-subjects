## K01　这一思想怎样创立？回答了哪些时代课题？（第38—39页）

**教材提炼**

1. 一个民族要走在时代前列，就一刻不能没有理论思维，一刻不能没有正确思想指引。习近平新时代中国特色社会主义思想是**新时代实践的结晶，是新时代的思想旗帜**。
2. **时代是思想之母，实践是理论之源。**新时代以来，面对国内外形势新变化和实践新要求，以习近平同志为主要代表的中国共产党人，坚持把**马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合**，创立了习近平新时代中国特色社会主义思想。
3. 这一思想科学回答了以下重大时代课题：
   - 新时代**坚持和发展什么样的中国特色社会主义、怎样坚持和发展中国特色社会主义**；
   - **建设什么样的社会主义现代化强国、怎样建设社会主义现代化强国**；
   - **建设什么样的长期执政的马克思主义政党、怎样建设长期执政的马克思主义政党**等。

**答题应用：**问“形成原因、创立背景”，按“形势与实践新要求 → 坚持两个结合 → 回答重大时代课题”展开。问“古典名句与新思想的联系”，重点联系同中华优秀传统文化相结合，不把引用古语理解为照搬古代制度，也不能把理论形成说成脱离实践的主观想象。

## K02　为什么说这是系统科学的理论体系？（第39、42页）

**教材提炼：**习近平新时代中国特色社会主义思想是一个**系统科学的理论体系**。

| 组成内容 | 教材确定的作用 |
|---|---|
| “十个明确”“十四个坚持”“十三个方面成就” | 概括了这一思想的**主要内容** |
| “六个必须坚持” | 是这一思想的**世界观、方法论和贯穿其中的立场观点方法的重要体现** |

**四者的关系：**“十个明确”“十四个坚持”“十三个方面成就”“六个必须坚持”**内在贯通、有机统一**；凝结着我们党认识世界、改造世界的宝贵经验和重大成果；体现了**理论与实际相结合、认识论和方法论相统一**的鲜明特色；共同构成了习近平新时代中国特色社会主义思想的科学体系。

**答题应用：**题目只问“主要内容”，先写前三项；问“科学体系怎样构成”，应写四项及其关系；问“世界观和方法论”，优先查K06。不能把四套内容看成彼此割裂的口号。

## K03　“十个明确”是什么？（第40页）

> 下列按原书编号整理，保留用于开卷定位的完整实质要点。问具体领域时，在相应条目中取用，不必机械列出十项。

| 序号、定位词 | 教材内容提炼 |
|---|---|
| 1　党的领导 | 明确中国特色社会主义**最本质的特征**是中国共产党领导，中国特色社会主义制度的**最大优势**是中国共产党领导，中国共产党是**最高政治领导力量**，全党必须增强“四个意识”、坚定“四个自信”、做到“两个维护”。 |
| 2　总任务、现代化 | 明确坚持和发展中国特色社会主义，总任务是实现**社会主义现代化和中华民族伟大复兴**；在全面建成小康社会的基础上，**分两步走在本世纪中叶**建成富强民主文明和谐美丽的社会主义现代化强国，以**中国式现代化**推进中华民族伟大复兴。 |
| 3　主要矛盾、人民中心 | 明确新时代我国社会主要矛盾是人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾；必须坚持**以人民为中心的发展思想**，发展**全过程人民民主**，推动人的全面发展、全体人民共同富裕取得更为明显的**实质性进展**。 |
| 4　总体布局、战略布局 | 明确中国特色社会主义事业总体布局是**经济建设、政治建设、文化建设、社会建设、生态文明建设“五位一体”**；战略布局是**全面建设社会主义现代化国家、全面深化改革、全面依法治国、全面从严治党“四个全面”**。 |
| 5　全面深化改革总目标 | 明确全面深化改革总目标是**完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化**。 |
| 6　全面推进依法治国总目标 | 明确全面推进依法治国总目标是**建设中国特色社会主义法治体系、建设社会主义法治国家**。 |
| 7　经济发展 | 明确必须坚持和完善**社会主义基本经济制度**，使市场在资源配置中起**决定性作用**，**更好发挥政府作用**；把握新发展阶段，贯彻**创新、协调、绿色、开放、共享**的新发展理念，加快构建**以国内大循环为主体、国内国际双循环相互促进**的新发展格局，推动高质量发展，统筹发展和安全。 |
| 8　强军目标 | 明确党在新时代的强军目标是建设一支**听党指挥、能打胜仗、作风优良**的人民军队，把人民军队建设成为**世界一流军队**。 |
| 9　中国特色大国外交 | 明确中国特色大国外交要**服务民族复兴、促进人类进步**，推动建设新型国际关系，推动构建**人类命运共同体**。 |
| 10　全面从严治党 | 明确**全面从严治党的战略方针**，提出新时代党的建设总要求，全面推进党的**政治建设、思想建设、组织建设、作风建设、纪律建设**，把**制度建设贯穿其中**，深入推进反腐败斗争，落实管党治党政治责任，以伟大**自我革命**引领伟大**社会革命**。 |

**易混提示：**改革总目标与依法治国总目标不能互换；“五位一体”是总体布局，“四个全面”是战略布局；经济发展的市场作用与政府作用须同时把握。题目问总任务，不能只答经济增长。

## K06　“六个必须坚持”是什么？怎样用于分析材料？（第39、42页）

**教材提炼：**必须坚持**人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下**。这六项是这一思想的世界观、方法论和贯穿其中的立场观点方法的重要体现。

| 教材关键词 | 材料识别和答题应用举例（以下是应用概括） |
|---|---|
| 人民至上 | 政策回应民生诉求、维护人民利益 → 说明坚持人民立场、把人民放在重要位置 |
| 自信自立 | 立足本国实际、坚持自主探索、自立自强 → 说明坚定自信、独立自主解决发展问题 |
| 守正创新 | 坚持正确方向，同时适应新情况探索新办法 → 说明继承与创新相结合，不能把创新理解为否定一切 |
| 问题导向 | 针对短板、堵点、急难愁盼提出办法 → 先指出问题，再写解决问题的措施和效果 |
| 系统观念 | 统筹各领域、全局和局部、当前和长远 → 说明综合施策、相互协调，不能只见局部 |
| 胸怀天下 | 中国发展与世界共同发展、人类命运共同体 → 说明为人类进步贡献智慧与力量 |

**使用边界：**上表右栏是帮助识别材料的解释，不替代左栏教材名称；材料只突出一两项时，要说明事实与观点的对应关系，不必强行凑齐六项。

## K07　为什么这一思想具有强大实践力量？成就最根本原因是什么？（第43页）

**教材提炼**

1. **实践是理论的基础，科学理论对实践又具有巨大指导作用。**
2. 新时代党和国家事业之所以取得历史性成就、发生历史性变革，**最根本的原因**在于：
   - 有**习近平同志作为党中央的核心、全党的核心掌舵领航**；
   - 有**习近平新时代中国特色社会主义思想科学指引**。
3. 这一思想**植根于新时代坚持和发展中国特色社会主义的伟大实践**，坚持理论指导和实践探索相统一，在指导实践、推动实践中展现出强大真理力量和独特思想魅力，是**经过实践检验又指导实践发展的强大思想武器**。

**怎样回答“社会各界为什么认真学习这一思想”？（答题应用）**

先从科学理论对实践的指导作用说明学习必要性，再结合新时代成就说明其经实践检验、能够指导实践发展，最后落到它是行动指南、应以之武装头脑和指导行动。若问成就“最根本原因”，上面两项都要写，不漏掉任何一项。

## K08　这一思想的地位是什么？为什么必须长期坚持并不断发展？（第44页）

**教材提炼：理论地位。**习近平新时代中国特色社会主义思想，是**当代中国马克思主义、二十一世纪马克思主义**，是**中华文化和中国精神的时代精华**，实现了**马克思主义中国化时代化新的飞跃**。

**坚持与发展的要求：**

- 在新时代新征程中，这一思想必将随着**强国建设、民族复兴伟业的全面拓展**而持续发展、不断丰富、更加完善。
- 在当代中国，**坚持和发展习近平新时代中国特色社会主义思想，就是真正坚持和发展马克思主义**。
- 必须高举马克思主义、中国特色社会主义旗帜不动摇，必须坚持习近平新时代中国特色社会主义思想**指导地位不动摇**。

## K09　作为中学生，怎样学习和践行？（第45页）

**教材提炼：**党和国家的希望寄托在青年身上。我们要**坚持不懈用习近平新时代中国特色社会主义思想武装头脑**，**积极投身新时代中国特色社会主义伟大事业**，在实现民族复兴的赛道上奋勇争先，在为人民利益的不懈奋斗中书写人生华章。

教材活动提出做**有理想、敢担当、能吃苦、肯奋斗**的新时代好青年。

**可操作做法（答题应用）：**

1. **认真学：**结合道德与法治课程、权威读物和“学习强国”等平台，理解基本观点；带着问题阅读，做好学习笔记，交流学习体会。
2. **联系实际学：**把理论与家乡发展、公共服务、生态治理、身边变化联系起来，通过观察和调查理解其指导作用。
3. **落实到行动：**坚定理想信念，勤奋学习，增强本领；积极参加力所能及的社会实践和志愿服务，关心人民利益，勇于担当、吃苦奋斗。
4. **学思用贯通：**用所学分析问题、指导实际行动，避免只抄写概念、只喊口号。举具体行动时，写清自己能做什么、怎样做。

**学习笔记示例结构：**“选学主题与出处 → 主要观点 → 联系的一件现实事例 → 自己的理解 → 一项可实践的行动”。这是记录方法，不能把未实际开展的活动写成亲身经历。

### 易混易错与跨课提示

- **“六个必须坚持”不能写成“六个方面成就”。**前三套概括主要内容，六项体现世界观、方法论和立场观点方法。
- **“十四个坚持”第7项是“社会主义核心价值体系”。**第六课具体谈“社会主义核心价值观”，题目要求列原项时不要替换。
- **“十个明确”不是只有党的领导或经济建设。**还涉及总任务、主要矛盾、改革法治、强军外交、党的建设等，按设问完整选点。
- **“最根本原因”要完整写出两方面。**不能仅用“大家努力”替代教材的核心表述。
- **创立思想、党的十九大正式提出、随后丰富发展**是不同层次的表述，应按题目时间和问法区分。

**跨课查找：**第三课查党的全面领导；第四课查新时代社会主要矛盾、历史方位和意义；第六课查科学理论指导下“五位一体”成就；第七、八课查现代化、高质量发展；第十课查中国梦与奋斗责任。跨课引用仍应围绕本题，不以目录堆砌替代材料分析。
