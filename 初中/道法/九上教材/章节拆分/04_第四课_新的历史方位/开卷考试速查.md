## K01　新时代社会主要矛盾是什么？准确把握它有什么意义？（第30—32页）

**教材提炼**

1. 我国社会主要矛盾已经转化为**人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾**，这是我国进入新时代的**基本依据**。
2. 我国社会主要矛盾发生深刻变化，反映了我国发展的**阶段性要求**，体现了党和国家事业发展**战略重点的变化**。
3. 社会主要矛盾的变化是**关系全局的历史性变化**，对党和国家工作提出了许多新要求。
4. 党和人民事业能不能沿着正确方向前进，取决于能否准确认识和把握社会主要矛盾、确定中心任务。判断准确，事业就顺利发展；判断失误，事业就会遭受挫折。
5. 发展是动态的，不平衡不充分是永远存在的。当发展到一定阶段，不平衡不充分成为**突出问题**时，就必须下功夫认识它、解决它，否则会制约发展全局。

**答题应用：怎样根据这一矛盾分析发展任务？**

先写人民需要发生的新变化，再指出材料中的发展短板，最后提出有针对性的解决措施。例如“群众期待更好的医疗服务”对应人民美好生活需要；“城乡医疗资源配置差异”对应发展不平衡；“优质服务供给不足”对应发展不充分。由此提出补短板、改善服务、促进协调发展等措施。具体措施应与材料相扣，不把所有发展问题都笼统归为同一种表现。

## K02　我国社会主要矛盾为什么发生变化？（第31—32页）

**教材提炼：从发展水平、需要变化、发展问题三方面作答。**

| 分析方面 | 完整要点 | 材料识别提示（答题应用） |
|---|---|---|
| 发展水平提高 | 随着改革开放深入推进和中国特色社会主义不断发展，我国长期所处的短缺经济和供给不足状况已经发生**根本性转变**，社会生产力水平**总体上显著提高**，人民生活全方位改善 | 从“有没有”逐步转向“好不好”、物资更丰富、生活改善 |
| 人民需要升级 | 进入新时代，人民对美好生活的向往更加强烈、需要日益广泛；不仅对物质文化生活提出更高要求，而且在**民主、法治、公平、正义、安全、环境**等方面的要求日益增长 | 优质教育、公平机会、清洁环境、社会安全、参与公共事务 |
| 发展仍有短板 | 我国各区域各领域各方面还存在发展不平衡问题，制约整体发展水平提升；我国全面实现社会主义现代化还有很长的路要走，发展的任务仍然很重 | 地区、城乡、领域差距，公共服务供给不足、关键领域短板 |
| 主要制约因素 | **发展不平衡不充分**已经成为满足人民日益增长的美好生活需要的主要制约因素 | 有成就与有差距可以同时成立 |

### 社会主要矛盾表述的历史变化（教材“相关链接”，第31页）

| 时间、会议 | 教材表述 |
|---|---|
| 1956年，党的八大 | 人民对于建立先进的工业国的要求同落后的农业国的现实之间的矛盾；人民对于经济文化迅速发展的需要同当前经济文化不能满足人民需要的状况之间的矛盾 |
| 1981年，党的十一届六中全会 | 在社会主义改造基本完成以后，我国所要解决的主要矛盾，是**人民日益增长的物质文化需要同落后的社会生产之间的矛盾** |
| 2017年，党的十九大 | 中国特色社会主义进入新时代，我国社会主要矛盾已经转化为**人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾** |

**查找提醒：**题目问“新时代的社会主要矛盾”，使用2017年的完整表述；历史材料要结合当时阶段判断，不能把三个时期的关键词拼接。

## K03　进入新时代，哪些变了、哪些没有变？（第33页）

**教材提炼**

- **变化：**我国社会主要矛盾发生变化，中国特色社会主义进入新时代，这是我国发展新的历史方位。
- **没有改变的判断：**我国社会主要矛盾的变化，没有改变我们对我国社会主义所处历史阶段的判断。
- **基本国情没有变：**我国仍处于并将长期处于**社会主义初级阶段**。
- **国际地位没有变：**我国是**世界最大发展中国家**。
- **实践要求：**牢牢把握社会主义初级阶段这个基本国情，牢牢立足社会主义初级阶段这个**最大实际**，不动摇贯彻党在社会主义初级阶段的基本路线。

### 如何辨析“经济总量世界第二，所以我国已经是发达国家”？

**答题应用：**这一结论不成立。应先肯定我国经济实力提升和发展成就，再指出判断发展水平不能只看经济总量，还要看人均水平和发展的协调、充分程度。教材活动提示：我国人均国内生产总值与发达国家还有较大差距，科技发展还面临“卡脖子”问题。最后回到“两个没有变”，说明必须立足初级阶段实际继续发展。

**辨析骨架：**“成就值得肯定”＋“总量不能替代人均、局部不能替代整体”＋“初级阶段与发展中国家地位未变”＋“继续贯彻基本路线”。不要因存在短板而否定全部成就，也不要因成就突出而拔高发展阶段。

## K04　党在社会主义初级阶段的基本路线是什么？（第33页）

**教材完整表述：**领导和团结全国各族人民，以经济建设为中心，坚持四项基本原则，坚持改革开放，自力更生，艰苦创业，为把我国建设成为**富强民主文明和谐美丽的社会主义现代化强国**而奋斗。

**快速拆分查词：**

| 题目问什么 | 对应表述 |
|---|---|
| 领导和团结谁 | 全国各族人民 |
| 以什么为中心 | 经济建设 |
| 坚持什么 | 四项基本原则、改革开放 |
| 依靠怎样的奋斗 | 自力更生，艰苦创业 |
| 为何奋斗 | 建设富强民主文明和谐美丽的社会主义现代化强国 |

**答题应用：**社会主要矛盾变化要求回应新需要、解决新问题，但不能据此说“不再以经济建设为中心”。“新的历史方位”与“继续贯彻初级阶段基本路线”相互联系，并不矛盾。

## K05　中国特色社会主义何时进入新时代？有什么意义？（第34—36页）

**教材提炼：时间与背景。**改革开放之初，我们党发出走自己的路、建设中国特色社会主义的伟大号召；此后党团结带领全国各族人民不懈奋斗，推动中国特色社会主义取得举世瞩目的伟大成就。**党的十八大以来，中国特色社会主义进入新时代**，这是对党和国家事业具有重大现实意义和深远历史意义的大事。

**意义总括：**在**中华人民共和国发展史、中华民族发展史**上具有重大意义，在**世界社会主义发展史、人类社会发展史**上也具有重大意义。

**三个“意味着”（教材“相关链接”，第35—36页）：**

1. **中华民族发展：**意味着近代以来久经磨难的中华民族迎来了从**站起来、富起来到强起来**的伟大飞跃，迎来了实现中华民族伟大复兴的光明前景。
2. **世界社会主义发展：**意味着科学社会主义在二十一世纪的中国焕发出强大生机活力，在世界上高高举起了中国特色社会主义伟大旗帜。
3. **发展道路与人类贡献：**意味着中国特色社会主义**道路、理论、制度、文化**不断发展，拓展了发展中国家走向现代化的途径，给世界上那些**既希望加快发展又希望保持自身独立性**的国家和民族提供了全新选择，为解决人类问题贡献了**中国智慧和中国方案**。

**答题应用：**只问对中华民族的意义，可集中第1点；问对世界或人类的意义，选第2、3点；问总体意义，则先总括再分层展开。不能把“提供全新选择”写成“各国都必须照搬中国道路”。

<a id="k06"></a>
## K06　中国特色社会主义新时代是一个什么样的时代？（第36页）

**教材提炼：五个方面一并查阅。**

1. **事业接续：**承前启后、继往开来，在新的历史条件下继续夺取中国特色社会主义伟大胜利的时代。
2. **建设进程：**决胜全面建成小康社会、进而全面建设社会主义现代化强国的时代。
3. **人民生活：**全国各族人民团结奋斗、不断创造美好生活、**逐步实现全体人民共同富裕**的时代。
4. **民族复兴：**全体中华儿女勠力同心、奋力实现中华民族伟大复兴中国梦的时代。
5. **世界贡献：**我国不断为人类作出更大贡献的时代。

**易错限定：**“逐步实现”不能删成“已经实现”；“全体人民共同富裕”不能改为“少数人富裕”或“同时、同等富裕”。第2点是对新时代历史进程的整体概括，并不是说今天还没有完成全面建成小康社会任务；完成该任务的成就可查第六课第58页。

## K08　材料题组织、易混易错与跨课提示

### 材料关键词 → 考点 → 答题组织

| 材料关键词 | 优先考点 | 推荐组织方式（答题应用） |
|---|---|---|
| “群众盼好学校、好医疗、好环境” | K01、K02 | 美好生活需要升级 → 发展不平衡不充分的具体表现 → 解决短板、增进福祉 |
| “某地发展快，某地公共服务薄弱” | K02 | 指出不平衡 → 说明其制约满足需要 → 提出协调、补短板措施 |
| “GDP世界第二，所以已是发达国家” | K03 | 肯定成就 → 指出判断片面 → 写两个没有变 → 立足实际继续奋斗 |
| “党的十八大以来、进入新时代” | K05、K06 | 时间与历史方位 → 按提问选民族、社会主义、人类意义或五方面内涵 |
| “为其他发展中国家提供借鉴” | K05 | 中国道路等不断发展 → 拓展现代化途径 → 独立自主的全新选择 → 中国智慧和方案 |

### 易混易错

- **新时代 ≠ 社会主义初级阶段已经结束。**“历史方位”发生变化与“历史阶段”判断未变同时成立。
- **美好生活需要 ≠ 只有物质文化需要。**还包括民主、法治、公平、正义、安全、环境等方面。
- **不平衡不充分 ≠ 落后的社会生产。**后者属于1981年表述，不能替换现阶段主要矛盾中的关键词。
- **进入新时代的时间 ≠ 党的十九大召开时才开始。**教材明确写党的十八大以来进入新时代；党的十九大提出相应重大判断。
- **迎来伟大复兴光明前景 ≠ 已经实现伟大复兴。**成就与未来任务必须区分。

**跨课查找：**党的领导与根本政治保证，查第三课；新时代科学理论的形成、指导地位，查第五课；经济、民主、文化、民生、生态成就，查第六课；发展目标与现代化进程，查第七课；高质量发展和解决发展问题，查第八课；实现中国梦与青少年责任，查第十课。作答时按题目所问选择相关知识，避免把整课内容全部堆上去。
