## 三、材料题详细答案

### M01 深圳发展背后的历史逻辑

**考点：K01—K04；第一课2—6页。**

**第1问（2分）**

共同主题是**实现中华民族伟大复兴**。四个时期的具体任务不同，但共同服务于这一主题。

建议给分：主题准确2分。“建设深圳”只是地方任务，不能替代百年主题。

**第2问（4分）**

| 历史时期 | 为民族复兴作出的贡献 |
|---|---|
| 新民主主义革命时期 | 创造了**根本社会条件**。 |
| 社会主义革命和建设时期 | 奠定了**根本政治前提和制度基础**。 |
| 改革开放和社会主义现代化建设新时期 | 提供了**充满新的活力的体制保证和快速发展的物质条件**。 |
| 中国特色社会主义新时代 | 提供了**更为完善的制度保证、更为坚实的物质基础、更为主动的精神力量**。 |

建议给分：每行完整对应1分。注意政治前提、体制保证和新时代三方面保证不能串位。

**第3问（6分）**

1. 深圳作为经济体制改革的试验田、对外开放的窗口，通过改革探索和扩大开放激发活力，其城市变化展示改革开放的磅礴伟力。（2分）
2. 改革开放为民族复兴提供充满新活力的体制保证和快速发展的物质条件，是决定当代中国前途命运的关键一招。今天的交往与服务能力有长期改革发展的基础，不能只归因于一次会议。（2分）
3. 不能据此断言“民族复兴已经实现”或“我国已经成为发达国家”“所有发展短板已经消失”。承认成就不等于拔高发展阶段。（任举一项并解释，2分）

**易错：**只写“深圳高楼多、交通好”是列事实，缺少改革开放作用的概括。

### M02 现代城市还需要精神力量吗

**考点：K05—K08；第一课7—12页。**

**第1问（4分）**

伟大建党精神：**坚持真理、坚守理想，践行初心、担当使命，不怕牺牲、英勇斗争，对党忠诚、不负人民**。

建议给分：每组1分；不要用“爱国、友善”等一般品质替换四组完整内涵。

**第2问（4分）**

该观点片面。先进设备有助于改善城市服务，但不能取代人的理想信念、责任担当和奋斗意志。

1. 伟大建党精神是中国共产党的**精神之源**；改革开放精神、特区精神等属于以其为源头的中国共产党人精神谱系。（2分）
2. 精神谱系跨越时空、历久弥新，能够提供攻坚克难、奋勇前行的强大精神动力。材料中敢于探索、不推诿困难、牵挂群众等精神，能推动建设者用好设备、履行责任，不能因技术进步就取消精神传承。（2分）

**第3问（2分）**

- 开展“改革开放足迹与人物故事”分享：查阅教材和可靠史料，介绍一项深圳探索，说明其精神价值。
- 参与适龄社区服务，认真完成分工，遇到困难主动沟通改进，将担当精神落到日常。

建议给分：每项具体可行1分。参观、阅读、讲述等合理替代也可。

**易错：**精神是“精神动力”，不是直接替代资金设施的“物质基础”；本教材列出特区精神名称，不要求凭空补写整套外部定义。

### M03 从服务中认识中国共产党

**考点：K09—K12；第二课13—16页。**

**第1问（4分）**

- 初心使命：**为中国人民谋幸福、为中华民族谋复兴**。（2分）
- 根本宗旨：**全心全意为人民服务**。（1分）
- 最高理想和最终目标：**实现共产主义**。（1分）

**第2问（5分）**

党的性质：中国共产党是**中国工人阶级的先锋队，同时是中国人民和中华民族的先锋队**。（2分）

材料的三类服务可分别作如下联系：

1. 支持科技企业获得公共服务、改善发展条件，有助于生产力发展，对应代表中国先进生产力的发展要求。（1分）
2. 支持文化工作者开展公益展示，有助于文化建设，对应代表中国先进文化的前进方向。（1分）
3. 走访困难家庭、解决生活难题，对应代表中国最广大人民的根本利益。（1分）

这三类材料用于理解代表性，不能由一个项目就证明某地全部事业已经充分发展。

**第3问（3分）**

1. 初心使命集中体现党的性质宗旨、理想信念、奋斗目标，是激励一代代共产党人前赴后继、英勇奋斗的根本动力。（1分）
2. 只有坚守初心，才能在困难挑战中发展壮大；忘记初心会改变性质颜色、失去人民和未来。（1分）
3. 始终牢记初心，办活动时真正解决群众问题，才能持续得到人民拥护支持、走在时代前列，推进民族复兴。（1分）

**易错：**根本宗旨、最高理想、初心使命有联系但不是同一概念，写对词却贴错标签仍不准确。

### M04 为了人民、依靠人民、接受人民评价

**考点：K13—K17；第二课17—19页。**

**第1问（4分）**

1. 人民立场是党的根本立场，党应把人民利益放在第一位。走访老人、上班族和商户，能了解真实需要，目的在于为人民创造更美好生活。（2分）
2. 人民是历史的创造者，是决定党和国家前途命运的根本力量。居民熟悉社区实际，参与讨论和实施能汇集智慧、形成力量，所以不仅要“为人民”，还要“依靠人民”。（2分）

**第2问（4分）**

1. 先走访、听取不同群体意见，是从群众中来，让方案建立在真实需要之上。（1分）
2. 居民共同讨论、修订方案，体现充分相信群众，发挥群众积极性主动性。（1分）
3. 组织群众共同参与实施，是到群众中去，依靠群众推动落实。（1分）
4. 公开改进情况并回访，使方案体现群众意愿，又在实践中接受检验、继续完善。（1分）

**第3问（4分）**

根本标准是人民**拥护不拥护、赞成不赞成、高兴不高兴、答应不答应**。（2分）

材料没有只追求好看或宣传数量，而是针对接驳、环境、信息服务等实际问题改进，并关注居民是否真正方便、满意，把人民利益落实到具体安排中。（2分）

**易错：**“有群众参与”不意味着所有要求都可绕开法律和客观条件直接照办；应通过合法合理程序回应诉求。

### M05 统一领导是否等于包办一切

**考点：K18—K22；第三课21—24页。**

**第1问（4分）**

1. 中国共产党是中国特色社会主义事业的坚强领导核心。
2. 中国共产党领导是中国特色社会主义最本质的特征。
3. 党的领导是中国特色社会主义制度的最大优势。
4. 党的领导是实现社会主义现代化和民族复兴的最根本保证。

建议给分：每项1分，准确保留判断对象。

**第2问（4分）**

1. 党具有广泛坚实的群众基础，能够集中力量、凝聚共同意志，让部门、企业、社区等围绕共同任务行动。（2分）
2. 党发挥总揽全局、协调各方作用，把方向、谋大局、定政策、促改革；通过统筹分工和相互配合，将组织优势转化为接驳、医疗、便民等服务成效。（2分）

**第3问（4分）**

小明承认党的领导是对的，但把全面领导解释为包办具体事务是错误的。（1分）

党的领导是全面、系统、整体的，体现在各领域、各方面、各环节，不等于取消职责分工。（1分）

在集中统一领导下，各主体仍应各司其职、各负其责、相互配合。交通、医疗、企业、社区依法依职责开展工作，恰恰是落实党的领导，而非削弱党的领导。（2分）

**易错：**党组织、政府部门、医疗机构和居民不是同一个履职主体，不能全部写成“党直接办理”。

### M06 从政治要求到青年行动

**考点：K23—K25；第三课25—26页。**

**第1问（3分）**

最重要的是**坚决维护党中央权威和集中统一领导**。（1分）

我们党是大党，我国是大国，需要坚强的领导核心和党中央权威；只有维护党中央权威，才能统一思想、统一意志、步调一致向前进。（2分）

**第2问（4分）**

“两个确立”：

- 确立习近平同志党中央的核心、全党的核心地位。（1分）
- 确立习近平新时代中国特色社会主义思想的指导地位。（1分）

“两个维护”：

- 坚决维护习近平同志党中央的核心、全党的核心地位。（1分）
- 坚决维护党中央权威和集中统一领导。（1分）

**第3问（3分）**

最关键的是**坚决维护习近平同志党中央的核心、全党的核心地位**。（1分）

中学生行动示例：认真学习党史与课程知识，增强认识、坚定不移听党话跟党走；努力学习、参加体育与劳动实践，在适龄社区服务中承担责任，促进德智体美劳全面发展。（两项具体行动，各1分）

**易错：**“两个确立”第二项是思想指导地位，不是“维护党中央权威”；确立与维护不能仅因词相近就互换。

### M07 从“有没有”到“好不好”

**考点：K17、K26—K27；第四课30—32页。**

**第1问（2分）**

反映**人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾**。需要升级与服务短板是矛盾两方面，不能只写其中一半。

**第2问（4分）**

学生观点片面。

1. 随改革开放和中国特色社会主义发展，社会生产力总体显著提高、生活改善，群众已有基本出行条件反映发展成就。（1分）
2. 人民需要更加广泛，不仅要“有”，还希望公平、安全、环境、服务质量更好。无障碍换乘、透明反馈等要求有其合理性。（1分）
3. 不同社区服务不均衡体现发展不平衡；便民设施不足体现相关供给不充分，不平衡不充分制约需要的满足。（1分）
4. 应在肯定成就的同时回应合理新需求，而不能把基本条件改善当作停止进步的理由。（1分）

**第3问（4分）**

准确认识和把握主要矛盾，有助于确定中心任务和工作重点，使党和人民事业沿正确方向前进；主要矛盾变化关系全局，对工作提出新要求。（2分）

### M21 绿色不是一时的装点

### M24 综合训练：办好城市的长期答卷

**考点：跨课综合；只用第一至第六课。以下按25分给出训练参考。**

**第1问（9分）**

任选三个领域，每个领域“领域判断1分＋材料对应及作用分析2分”，最多9分。以下五个方向供选择，**不要求全部写**。

| 领域 | 可采用的答案 |
|---|---|
| 经济建设 | 技术攻关、产业协作体现创新驱动和科技自立自强，能提高创新能力，推动产业升级、提升发展质量，为城市服务和居民生活提供更坚实物质基础。 |
| 政治建设 | 依法征询意见、公开采纳和实施情况，为群众表达、参与、监督提供渠道，有助于汇集民意、改进方案，体现全过程人民民主的制度程序和参与实践。 |
| 文化建设 | 保护有价值历史建筑、以新形式展示优秀文化，有助于延续文脉、探索创造性转化、增强文化影响力和文化自信；不能只凭形式新就断言全部文化内涵已创新。 |
| 社会建设 | 兼顾通勤、就医、养老，使设施长期便民，体现以人民为中心，回应急难愁盼、补齐服务短板，增进民生福祉。 |
| 生态文明建设 | 绿色出行、资源节约与河流系统治理，有助于减少污染浪费、改善人居环境，把保护与发展结合，支持长期可持续发展。 |

**第2问（12分）**

对甲：

1. 改善城市服务、展示城市形象有积极意义，但甲把形象与民生、文化、环境对立，主张都可忽略，结论错误。（1分）
2. 人民立场是党的根本立场，应把人民利益放在第一位。通勤就医等不能因短期展示被无条件牺牲。（1分）
3. 文化自信是深厚力量，历史资源有传承价值；城市国际化不能以抹去文脉为代价。（1分）
4. 经济与生态保护辩证统一，破坏环境会损害长期发展和群众福祉，不能为短期效果忽视环境。（1分）

对乙：

5. 注意到民生短板有必要，但由不足否定全部发展成就，是片面判断。（1分）
6. 改革开放和新时代建设已取得伟大成就，为城市交往和公共服务提供基础，应实事求是肯定。（1分）
7. 主要矛盾仍是美好生活需要与不平衡不充分发展之间的矛盾；基本国情未变，说明要继续发展、补短板，不说明过去成就无效。（1分）
8. 开放合作与立足自身实际、提升自主能力可以相统一，不能把存在短板当作停止合作的理由。（1分）

合理主张：

9. 坚持党的领导，统筹各主体各司其职、协调配合。（1分）
10. 以科学理论为指引，坚持人民至上、问题导向、系统观念，处理当前长远和局部整体关系。（1分）
11. 统筹经济、政治、文化、社会、生态文明建设，让创新、文化保护、绿色发展与便民服务相互促进。（1分）
12. 立足初级阶段实际，继续改革开放、依靠人民、补齐短板，以群众实际受益和可持续效果评价工作。（1分）

以上是四层任务的给分示例；其他有教材依据、能回应双方及合理主张的独立观点也可。不是要求逐字凑满12句。

**第3问（4分）**

选择问题：“居民意见怎样真正进入长期便民方案？”

1. **社区与相关部门**通过线上线下渠道收集老人、通勤者等意见，分类研究、公开回应，提高方案对不同群体需要的适配程度。（主体与措施1分，作用1分）
2. **负责实施的部门和服务单位**定期公开进度、接受居民监督，对已发现的不便及时整改，使意见征集转化为长期可检验的惠民成效。（主体与措施1分，作用1分）

也可针对技术、文化、生态、医疗等选题，要求两条建议各有动作和作用，不是把同一句“加强重视”换主体重复。

**易错：**“意义重大、促进发展、共同努力”没有具体机制；只批评甲、不分析乙，或只抄“五位一体”名词，均未完成题目任务。

## 四、六类保障与作用，避免混写

| 回答对象 | 宜用表述 | 材料里应有什么证据 |
|---|---|---|
| 党的领导 | 领导核心、根本政治保证、总揽全局协调各方 | 统一部署、组织统筹、各主体分工合作 |
| 科学理论 | 科学指引、行动指南、强大思想武器 | 理论指导实践、用立场观点方法分析问题 |
| 基本经济制度 | 制度基础、调动积极性、形成发展合力 | 不同所有制主体、市场与政府作用等 |
| 民主政治制度 | 人民当家作主的制度保障 | 依法表达协商监督、意见进入决策治理 |
| 精神与文化 | 精神动力、价值引领、文化力量 | 担当奋斗、文化传承、价值践行 |
| 法治与生态制度 | 法治保障、制度约束 | 规则程序、依法履职、监管追责、污染治理 |

“技术支持、人才支撑、物质基础”也须分别对应研发、人才和经济设施证据，不能互相替换。

## 五、自评清单

核对六件事：完成全部任务；概念与限定准确；有材料与解释；不把模拟或目标当成事实；不以局部代替全国；建议具体、适合身份且不超出第一至第六课。

**本资料的核心：用准确知识解释具体事实，而不是见到APEC就抄一整套开放、创新、文化、绿色的固定答案。**
